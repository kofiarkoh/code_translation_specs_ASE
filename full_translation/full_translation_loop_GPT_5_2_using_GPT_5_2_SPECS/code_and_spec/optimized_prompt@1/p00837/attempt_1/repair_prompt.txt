1. Functional Description  
Processes multiple test cases describing students’ ordered book requests and a set of desks with limited capacity. For each requested book in the global chronological order (by request position within a student, then by student index), it simulates retrieving that book from its current desk, optionally performing a desk-to-desk replacement when the primary desk is full, and finally placing the requested book onto the primary desk. It outputs the total accumulated cost of all desk interactions performed during this simulation.

2. Inputs  
For each test case, reads from standard input:  
- An integer count of auxiliary desks.  
- An integer capacity per desk.  
- An integer number of students.  
- For each student: an integer count of requested books, followed by that many book identifiers in the student’s request order.  
Test cases repeat until a non-positive auxiliary-desk count is encountered.

3. Outputs  
For each test case, writes to standard output:  
- A single integer: the total accumulated cost for the simulated sequence of book retrievals and placements.

4. Preconditions  
- The number of auxiliary desks is positive for a test case to be processed.  
- Desk capacity is non-negative.  
- The number of students is non-negative.  
- Total number of individual requests across all students does not exceed 5002.  
- Book identifiers are within a fixed small positive range supported by the program (not inferable precisely beyond being bounded).  
- The number of desks implied by the input fits within the program’s fixed limits (not inferable precisely beyond being bounded).  
- Input is well-formed and provides all required integers.

5. Postconditions  
For each processed test case:  
- Exactly one total-cost value is produced.  
- After processing all requests, every requested book’s final location is the primary desk.  
- The reported total cost equals the sum, over all processed requests, of:  
  - The index of the desk from which the requested book was removed at the time of the request, plus  
  - The index of the primary desk for placing the requested book, plus  
  - If the primary desk was at capacity immediately before placing the requested book, additional costs corresponding to:  
    - Temporarily placing the requested book onto the first available non-full auxiliary desk,  
    - Removing one book from the primary desk,  
    - Placing that removed book onto the first available non-full auxiliary desk (with a specific adjustment if it is the same auxiliary desk used for the temporary placement), and  
    - Removing the temporarily placed requested book from that auxiliary desk,  
    with each such action contributing the index of the desk involved.

6. Invariants  
- Each book that has appeared in any request is considered to exist at exactly one desk at any time during processing.  
- Each desk’s occupancy never exceeds the configured capacity.  
- The primary desk is treated as desk index 1; auxiliary desks are indexed consecutively above it.  
- Within any desk, the relative order of remaining books is preserved when a book is removed (i.e., removal compacts the desk without reordering the survivors).  
- Requests are processed in a deterministic global order: increasing request position within a student, breaking ties by increasing student index.

// AOJ 1258: Book Replacement

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct { int stu, seq, id; } T;
T req[5002]; int len;
int desk[12][5001]; int hi[12];
int book[101][2];

int cmp(T *a, T *b)
{
	if (a->seq - b->seq) return (a->seq - b->seq);
	return a->stu - b->stu;
}

int main()
{
	int m, c, n, i, j, id, ans;
	int from, pos, tmp, id2, t;

	while (scanf("%d%d%d", &m, &c, &n) && m > 0) {
		memset(hi, 0, sizeof(hi)), memset(book, 0, sizeof(book));
		tmp = m + 1;
		for (len = i = 0; i < n; i++) {
			scanf("%d", &t); 
			for (j = 0; j < t; j++) {
				scanf("%d", &id);
				req[len].stu = i, req[len].seq = j, req[len++].id = id;
				if (book[id][0] == 0) {
					book[id][0] = tmp, book[id][1] = hi[tmp], desk[tmp][hi[tmp]++] = id;
				}
			}
		}
		qsort(req, len, sizeof(T), cmp);

		for (ans = 0, i = 0; i < len; i++) {
			id = req[i].id;
			from = book[id][0], pos = book[id][1];

			for (j = pos+1; j < hi[from]; j++) {
				t = desk[from][j], book[t][1]--;
				desk[from][j-1] = desk[from][j];
			}
			hi[from]--, ans += from;

			if (hi[1] == c) {
				for (tmp = 2; tmp <= m && hi[tmp] == c; tmp++);
				desk[tmp][hi[tmp]++] = id, ans += tmp;

				id2 = desk[1][0];
				for (j = 1; j < hi[1]; j++) {
					t = desk[1][j], book[t][1]--;
					desk[1][j-1] = desk[1][j];
				}
				hi[1]--, ans++;

				for (j = 2; j <= m && hi[j] == c; j++);
				pos = hi[j]; if (j == tmp) pos--;
				desk[j][pos] = id2; hi[j]++;
				book[id2][0] = j, book[id2][1] = pos;
				ans += j + tmp; hi[tmp]--;
			}
			
			book[id][0] = 1, book[id][1] = hi[1];
			desk[1][hi[1]++] = id, ans++;
		}
		printf("%d\n", ans);
	}
	return 0;
}
