1. Functional Description
Processes one or more datasets describing an undirected relationship graph over a fixed set of entities, where each entity provides two associated integer attributes. For each connected component of the graph, it determines the maximum attribute value appearing among all attributes in that component and counts how many times that maximum occurs. It then computes, for each component, half of that count (integer division by 2), multiplies these values across all components, and reports the product modulo 10007.

2. Inputs
- Repeated datasets read from standard input.
- Each dataset begins with an integer specifying the number of entities.
- For each entity, four integers are provided:
  - Two referenced entity indices (each intended to be within the dataset’s entity range).

3. Outputs
- For each dataset, writes a single integer line to standard output: the computed product modulo 10007.

- The dataset size is non-negative and does not exceed 100002.

#define MAX 100002

/* UNION-FIND library */
int id[MAX], size[MAX];
void init(int n) { int i; for (i = 0; i < n; i++) id[i] = i, size[i] = 1; }
int root(int i) { while (i != id[i]) id[i] = id[id[i]], i = id[i]; return i; }
int connected(int p, int q) { return root(p) == root(q); }
void unite(int p, int q)
{
    int i = root(p), j = root(q); if (i == j) return;
    if (size[i] < size[j]) id[i] = j, size[j] += size[i]; else id[j] = i, size[i] += size[j];
}

void check(int k, int f)
{
	if (!cnt[k] || f > max[k]) {
		cnt[k] = 1;
		max[k] = f;
