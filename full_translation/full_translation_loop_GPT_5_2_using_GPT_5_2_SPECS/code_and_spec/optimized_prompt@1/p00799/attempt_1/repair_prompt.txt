1. Functional Description  
Simulates, over a fixed number of discrete time units, a set of independent devices that alternate between an “active” phase and a “charging” phase with device-specific durations. At each time unit, it accounts for how many charging devices are not being serviced by a single shared charging resource, and outputs the total count of such unserviced charging-device time units over the simulation horizon.

- Repeated test cases read from standard input.  
- For each test case:

3. Outputs  
- For each test case, writes a single integer to standard output: the total number of time units during the simulation in which a device is in charging state but is not the one currently being serviced by the shared charging resource.

4. Preconditions  
- The device count is positive to start a test case; input terminates when a non-positive device count is encountered.

- The number of active/charging pairs per device does not exceed the internal maximum supported by the program.

For each processed test case:  
- The printed value equals the sum, over all simulated time units, of the number of devices that are in charging state at that time unit excluding (at most) one device that is considered to be receiving charging service for that time unit (if any charging service is in progress).  
- Device phase progression follows the provided per-device cyclic sequence of active duration then charging duration, repeating from the beginning after the last pair.

- When a device completes an active phase, it immediately enters charging state and becomes eligible for the shared charging resource.  
- When a device completes a charging phase, it immediately enters active state and advances to the next active/charging duration pair in its cycle (wrapping to the first pair after the last).

// AOJ 1219: Pump up Batteries

#include <stdio.h>
#include <string.h>

#define QMAX 102
int que[104], top, end;

typedef struct { char use; int t, r, i, n, u[51], c[51]; } T; // r:remain time
T tbl[102], *tp, *tend;

int main() 
{
	int n, lim, i, u, c, t, ans;

	while (scanf("%d%d", &n, &lim) && n > 0) {
		for (tp = tbl, tend = tp + n; tp < tend; tp++) {
			tp->use = 1, tp->i = 0;
			for (i = 0; scanf("%d", &u) && u > 0; i++)
				scanf("%d", &c), tp->u[i] = u, tp->c[i] = c;
			tp->n = i, tp->r = tp->u[0];
		}

		ans = 0, top = end = 0;
		for (t = 1; t <= lim; t++) {
			for (tp = tbl, i = 0; i < n; i++, tp++) {
				if (tp->use) {
					tp->t = t;
					if (--tp->r == 0) {
						tp->use = 0, tp->r = tp->c[tp->i];
						que[end] = i; if (++end == QMAX) end = 0;
					}
				}
			}
			if (end == top) continue;
			for (tp = tbl, i = 0; i < n; i++, tp++) {
				if (tp->t != t && tp->use == 0) {
					if (i == que[top]) tp->r--;
					else ans++;
				}
			}
			if (top != end) {
				tp = tbl + que[top];
				if (tp->r == 0) {
					tp->use = 1;
					if (++tp->i == tp->n) tp->i = 0;
					tp->r = tp->u[tp->i];
					if (++top == QMAX) top = 0;
				}
			}
		}
		printf("%d\n", ans);
	}
	return 0; 
}
