```rust
use std::collections::HashSet;
use std::io::{self, BufRead};

fn main() {
    let stdin = io::stdin();
    let handle = stdin.lock();
    let mut lines = handle.lines();

    // Read the first line which indicates the number of subsequent integers
    let n: usize = lines.next().unwrap().unwrap().trim().parse().expect("Invalid input");

    // Precondition: n must be non-negative
    if n == 0 {
        println!("0");
        return;
    }

    let mut numbers = Vec::with_capacity(n);

    // Read the subsequent integers
    for _ in 0..n {
        let number: i32 = lines.next().unwrap().unwrap().trim().parse().expect("Invalid input");
        numbers.push(number);
    }

    // Use a HashSet to collect distinct integers
    let distinct_numbers: HashSet<_> = numbers.into_iter().collect();

    // Output the count of distinct integers
    println!("{}", distinct_numbers.len());
}
```

### Explanation of Translation Choices:
1. **Input Handling**: The Rust code uses `std::io` for reading input, which is idiomatic and handles input efficiently.
2. **Distinct Count**: A `HashSet` is used to store distinct integers, which simplifies the logic and ensures uniqueness without needing to sort the array explicitly.
3. **Error Handling**: The code checks for valid input parsing and handles the case where `n` is zero by directly printing `0`.
4. **Performance**: The use of `HashSet` provides average O(1) time complexity for insertions, and the overall complexity remains O(n) for collecting distinct integers, which is efficient and meets the specification's requirements.
5. **Output**: The output format is preserved exactly as specified, ensuring that the result is printed on a new line.
