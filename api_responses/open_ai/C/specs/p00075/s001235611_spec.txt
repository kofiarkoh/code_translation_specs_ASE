1. Functional Description  
The program calculates the Body Mass Index (BMI) for a series of individuals based on their weight and height, and outputs the identifiers of those individuals whose BMI is classified as overweight or obese.

2. Inputs  
The program reads a sequence of values consisting of an integer identifier, a weight in kilograms, and a height in meters, formatted as "integer,double,double".

3. Outputs  
The program outputs the integer identifiers of individuals whose BMI is greater than or equal to 25, each followed by a newline.

4. Preconditions  
The input must consist of valid data in the specified format. The weight must be a positive real number, and the height must be a positive real number.

5. Postconditions  
For each valid input, if the calculated BMI is greater than or equal to 25, the corresponding identifier is output. If no identifiers meet the criteria, no output is produced.

6. Invariants  
The program maintains that the BMI is calculated as the weight divided by the square of the height, and that the output only includes identifiers for individuals with a BMI of 25 or higher.

7. Error Handling / Exceptional Behavior  
If the input format is incorrect or if the values are not valid (e.g., negative weight or height), the program does not produce output for those entries. The program continues processing until the end of input.

8. State Transitions (if applicable)  
The program transitions from reading input to calculating BMI and then to outputting identifiers based on the BMI classification.

9. Non-functional Constraints (if inferable)  
The program processes input until the end of input is reached, and it outputs results in a timely manner, adhering to standard output conventions.
