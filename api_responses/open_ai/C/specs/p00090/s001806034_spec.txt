The program calculates the maximum number of overlapping circles based on their coordinates. It determines how many circles overlap with each other and outputs the maximum overlap count for each set of circles provided.

The program reads multiple sets of circle data, where each set begins with an integer indicating the number of circles, followed by pairs of floating-point numbers representing the coordinates of the circle centers. The input terminates when a zero is read.

3. **Outputs**  
The program outputs the maximum number of overlapping circles for each set of input circles, incremented by one.

4. **Preconditions**  
- The input must consist of valid integers and floating-point numbers.
- The number of circles must be a non-negative integer.
- The maximum number of circles in a single set does not exceed a defined limit.

5. **Postconditions**  
- The output reflects the maximum overlap of circles for each set of input data.
- The program terminates gracefully upon receiving a zero as input.

6. **Invariants**
