1. Functional Description
   - High-level description:
     The program processes multiple test cases of 2D points (centers of equal-radius circular seals). For each test case it computes and prints a single integer value derived from pairwise adjacency (centers within distance 2) and triangle (3-clique) relationships among points.
   - What problem it solves:
     For each set of input points, it builds an undirected adjacency relation based on center-to-center distance ≤ 2. It then performs iterative pruning of low-degree vertices, counts triangle-based co-occurrence metrics for remaining vertices, derives a scalar "max_overlap" measure from those metrics, and prints max_overlap + 1.
   - Core behavior:
     - Read repeated test cases until an integer n = 0 is encountered.
     - For each test case with n > 0:
       1. Read n 2D points (double precision).
       2. Build an adjacency matrix where two distinct points are adjacent iff squared Euclidean distance ≤ 4 (and every node is adjacent to itself).
       3. Repeatedly remove (delete from the adjacency relation) any vertex whose current degree is 1 or 2; if any vertex removed had degree exactly 2 during pruning, record that fact by setting an internal threshold to 2 (initially 1).
       4. For the remaining adjacency relation, for every ordered triple (i, j, k) where i is adjacent to both j and k and j is adjacent to k (i.e., triangle), increment a counter overlap[i][j] and overlap[i][k]. This yields per-pair triangle counts relative to each anchor vertex i.
       5. For each vertex i, compute the maximum and minimum positive overlap counts across partners j.
       6. Using those overlap counts and per-vertex min/max, update a global max_overlap according to the program's comparison rule.
       7. Output max_overlap + 1 (one integer per test case, followed by newline).

     - Pruning state transitions:
