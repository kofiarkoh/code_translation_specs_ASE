The program reads multiple grids of size n x n, where n is a positive integer. The input terminates when a zero is read.

3. **Outputs**  
The program outputs the maximum length of consecutive '1's for each grid, printed as an integer.

The input must consist of valid integers followed by corresponding grid data. Each grid must be square (n x n) and contain only '0's and '1's.

After processing each grid, the program guarantees that the maximum length of consecutive '1's is calculated and printed.

The program maintains that the maximum length of consecutive '1's is updated correctly throughout the processing of the grid.
