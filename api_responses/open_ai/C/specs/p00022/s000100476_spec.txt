3. **Outputs**  
   The program outputs the maximum sum for each sequence of integers, one result per line.

   After processing each sequence, the program guarantees that the output is the maximum sum of the specified contiguous subarray for that sequence.

   The values in the left and right arrays represent the maximum sums of contiguous subarrays to the left and right of each element, respectively, at all times during the computation.

   The program does not handle invalid input formats or values outside the specified range. It assumes that the input adheres to the defined structure.
