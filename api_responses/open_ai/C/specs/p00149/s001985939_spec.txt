1. **Functional Description**  
The program categorizes pairs of floating-point values into predefined ranges and counts the occurrences of each category for both the right and left values. It outputs the counts for each category after processing all input pairs.

2. **Inputs**  
The program reads pairs of floating-point values from standard input until the end of input is reached.

3. **Outputs**  
The program outputs four counts for the right values and four counts for the left values, each count representing the number of occurrences in specific ranges.

4. **Preconditions**  
The input must consist of valid floating-point numbers. The program assumes that input will be provided in pairs.

5. **Postconditions**  
After processing the input, the program guarantees that the counts for each category of right and left values are correctly computed and displayed.

6. **Invariants**  
The counts for each category are non-negative integers and are updated only based on the input values processed.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or types. It terminates gracefully upon reaching the end of input.

8. **State Transitions (if applicable)**  
The state transitions occur as the program reads input pairs, updating the counts based on the values encountered.
