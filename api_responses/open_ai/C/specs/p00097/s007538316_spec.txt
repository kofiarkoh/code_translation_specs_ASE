1. **Functional Description**  
The program calculates the number of ways to sum integers to a specified total using a defined number of summands, constrained by specific limits.

2. **Inputs**  
The program reads two integers:  
- A positive integer representing the number of summands.  
- A non-negative integer representing the target sum.

3. **Outputs**  
The program outputs the number of distinct combinations of integers that sum to the target value, or zero if the target exceeds a predefined limit.

4. **Preconditions**  
- The number of summands must be a positive integer.  
- The target sum must be a non-negative integer.

5. **Postconditions**  
- If the target sum is less than or equal to 864, the output is the count of combinations that sum to the target using the specified number of summands.  
- If the target sum exceeds 864, the output is zero.

6. **Invariants**  
- The program maintains a data structure that accurately reflects the number of ways to achieve various sums with a given number of summands throughout its execution.

7. **Error Handling / Exceptional Behavior**  
- If the input for the number of summands is zero or negative, the program terminates without producing output.  
- If the target sum exceeds 864, the program outputs zero.

Not applicable.

9. **Non-functional Constraints (if inferable)**
