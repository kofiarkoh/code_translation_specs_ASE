1. Functional Description  
Calculates the average of a specified number of integer inputs.

2. Inputs  
Reads an integer indicating the number of subsequent integer values to be processed.

3. Outputs  
Returns the average of the input integers as an integer value, followed by a newline.

4. Preconditions  
The first input must be a positive integer. The subsequent inputs must be integers.

5. Postconditions  
The output is the integer result of the sum of the input integers divided by the number of inputs.

6. Invariants  
The sum of the input integers is maintained throughout the processing of inputs.

7. Error Handling / Exceptional Behavior  
If the first input is zero or negative, the behavior is not defined. If no integers are provided after the first input, the behavior is not defined.

8. State Transitions (if applicable)  
Not applicable.

9. Non-functional Constraints (if inferable)  
Not inferable from code.
