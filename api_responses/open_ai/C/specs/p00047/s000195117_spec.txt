1. **Functional Description**  
The program simulates a ball-switching game where three positions (A, B, C) can hold a ball. It processes a series of commands to swap the positions of the balls and determines the final position of a specific ball.

2. **Inputs**  
The program reads pairs of characters from standard input, where each character represents a position (A, B, or C) to be swapped. Input continues until the end of the file is reached.

3. **Outputs**  
The program outputs a single character (A, B, or C) indicating the final position of the ball that starts in position A.

4. **Preconditions**  
The input must consist of valid character pairs (A, B, or C) separated by a comma. The input must be terminated by an end-of-file signal.

5. **Postconditions**  
After processing all input, the program guarantees that the output reflects the final position of the ball that started in position A.

6. **Invariants**  
Throughout the execution, the program maintains the integrity of the ball positions, ensuring that only valid swaps occur based on the input commands.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input characters or malformed input. It assumes that input will be correctly formatted as specified.

8. **State Transitions (if applicable)**  
The state transitions occur with each valid input pair, where the positions of the balls are updated based on the specified swaps.
