1. **Functional Description**  
The program processes a sequence of integer inputs, storing non-zero values and outputting the most recently stored values in reverse order upon encountering a zero.

2. **Inputs**  
The program reads a sequence of integers from standard input until the end of input is reached. The integers can be positive, negative, or zero.

3. **Outputs**  
The program outputs a sequence of integers to standard output, which are the values stored prior to each zero encountered in the input, in reverse order of their storage.

4. **Preconditions**  
The input must be a sequence of integers, and the program assumes that the input will terminate with an end-of-file signal.

5. **Postconditions**  
The output will consist of integers corresponding to the values stored before each zero in the input, printed in the order they were stored, but in reverse.

6. **Invariants**  
At any point during execution, the stored values are maintained in a collection, and the count of stored values is accurately tracked.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input types (non-integer values) and will terminate unexpectedly if such input is encountered.

8. **State Transitions (if applicable)**  
The state transitions occur when a non-zero integer is read (storing the value) or when a zero is read (outputting the last stored value).

9. **Non-functional Constraints (if inferable)**  
The program is limited to handling a maximum of 100 integers for both input storage and output. The performance is dependent on the number of inputs processed, with a linear relationship to the number of integers read.
