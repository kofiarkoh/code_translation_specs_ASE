1. **Functional Description**  
The program determines whether a point lies within or on the boundary of a triangle defined by three vertices in a two-dimensional space.

2. **Inputs**  
The program reads a series of sets of eight floating-point values representing the coordinates of three triangle vertices and a point.

3. **Outputs**  
For each set of inputs, the program outputs "YES" if the point lies within or on the boundary of the triangle, and "NO" otherwise.

4. **Preconditions**  
The input values must be valid floating-point numbers. The triangle must be defined by non-collinear points.

5. **Postconditions**  
The output will reflect the relationship of the point to the triangle for each set of inputs processed.

6. **Invariants**  
The triangle's vertices remain fixed for each evaluation, and the calculations for distances and areas are consistent throughout the execution.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or values that could lead to undefined behavior, such as collinear points.

8. **State Transitions (if applicable)**  
The program transitions from reading input to processing the geometric calculations and finally to producing output for each set of inputs until the end of input is reached.
