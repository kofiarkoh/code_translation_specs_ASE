1. Functional Description  
The program calculates the difference between the maximum and minimum values from a sequence of floating-point numbers provided as input.

2. Inputs  
The program reads a sequence of floating-point numbers until the end of input is reached.

3. Outputs  
The program outputs a single floating-point number representing the difference between the maximum and minimum values, formatted to one decimal place.

4. Preconditions  
At least one floating-point number must be provided as input; otherwise, the behavior is not defined.

5. Postconditions  
The output value is the difference between the maximum and minimum values of the input numbers.

6. Invariants  
Throughout the execution, the maximum and minimum values are maintained accurately based on the input received.

7. Error Handling / Exceptional Behavior  
If no input is provided, the program does not produce a valid output. The behavior in this case is not defined.

8. State Transitions (if applicable)  
The program transitions from an initial state (no values processed) to a final state (maximum and minimum values determined) upon processing the input.

9. Non-functional Constraints (if inferable)  
The output is guaranteed to be formatted to one decimal place. The program operates in a single-threaded manner and processes input sequentially.
