1. **Functional Description**  
The code implements Prim's algorithm to compute the minimum spanning tree (MST) of a weighted undirected graph. It reads the number of vertices and edges, constructs a cost matrix representing the graph, and returns the total weight of the MST.

2. **Inputs**  
- A positive integer representing the number of vertices in the graph.  
- A positive integer representing the number of edges.  
- A series of triplets, each consisting of two integers (representing vertices) and a third integer (representing the edge weight).

3. **Outputs**  
- An integer representing the total weight of the minimum spanning tree.  
- The output is printed to standard output.

4. **Preconditions**  
- The number of vertices must be a positive integer.  
- The number of edges must be a positive integer.  
- Each edge must connect valid vertex indices within the range of the number of vertices.

5. **Postconditions**  
- The total weight of the minimum spanning tree is returned if the graph is connected.  
- If the graph is not connected, the behavior is undefined, and the output may not represent a valid MST.

6. **Invariants**  
- The cost matrix is initialized such that all edge weights are set to a predefined infinite value, except for the edges defined by the input.  
- The minimum cost to reach each vertex is updated iteratively based on the edges included in the MST.

7. **Error Handling / Exceptional Behavior**  
- If the number of vertices is zero, the program terminates without further processing.  
- If invalid input is provided (e.g., non-integer values), the behavior is undefined.

8. **State Transitions (if applicable)**  
- The state transitions occur as vertices are added to the MST, updating the minimum costs and marking vertices as used until all reachable vertices are included or no more vertices can be added.

9. **Non-functional Constraints (if inferable)**  
- The algorithm operates with a time complexity of O(V^2), where V is the number of vertices, due to the nested loops iterating over the vertices.  
- The space complexity is O(V^2) due to the cost matrix used to store edge weights.
