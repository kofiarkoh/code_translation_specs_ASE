1. Functional Description
   - High-level description:
     - The program reads a sequence of comma-separated pairs of floating-point numbers (mov, dir) from standard input and produces two integers on standard output representing the final accumulated X and Y coordinates.
   - What problem it solves:
     - Interprets a stream of movement commands composed of a forward distance (mov) and a rotation (dir, degrees) and reports the final integer coordinates after applying all commands up to a terminating pair.
   - Core behavior:
     - For each input pair (mov, dir), while the pair is not exactly (0, 0), update an internal direction value by adding dir, and update an internal 2D position by moving mov units in the current direction. After processing all pairs up to (0,0), print the integer-cast X and Y coordinates, each followed by a newline.

2. Inputs
   - Parameters:
     - The program reads from standard input a sequence of values matching the pattern: <double>,<double> repeated zero or more times.
   - Data types:
     - Each value is parsed as a C double (floating-point).
     - The first value of each pair is interpreted as "mov" (distance), the second as "dir" (angle increment in degrees).
   - Valid ranges or constraints:
     - mov: any finite double (positive, zero, or negative is accepted by parsing). mov = 0 is used as part of termination condition.
     - dir: any finite double (degrees). dir = 0 is used as part of termination condition.
     - The input sequence must contain a terminating pair where both mov and dir are exactly 0.0 to stop normal processing.
     - Pairs must be formatted with a literal comma between the two numbers (e.g., "12.5,90").
   - Assumptions about inputs:
     - Assumes scanf successfully parses two doubles per pair in the expected format. If parsing fails or EOF occurs prematurely, behavior is not checked by the program (see Error Handling).
     - Angle values are in degrees.

3. Outputs

     - Casting to int uses the C-language truncation semantics (fractional portion discarded toward zero).
   - Output format/schema:
     - Two ASCII integer lines:
       - Line 1: integer representation of final X coordinate
       - Line 2: integer representation of final Y coordinate
