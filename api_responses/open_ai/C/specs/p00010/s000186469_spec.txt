1. **Functional Description**  
   The program calculates the circumcenter and radius of a circle that passes through three given points in a 2D space. It processes multiple sets of points as specified by the user.

2. **Inputs**  
   - An integer indicating the number of sets of points to process.  
   - For each set, six floating-point numbers representing the coordinates of three points in 2D space.

3. **Outputs**  
   - For each set of points, three floating-point numbers representing the x-coordinate, y-coordinate of the circumcenter, and the radius of the circle, formatted to three decimal places.

4. **Preconditions**  
   - The input integer must be non-negative.  
   - Each set of coordinates must consist of three distinct points that do not all lie on a straight line.

5. **Postconditions**  
   - The program outputs the circumcenter coordinates and radius for each set of points, ensuring that the circle passes through the specified points.

6. **Invariants**  
   - The circumcenter and radius are consistently calculated based on the geometric properties of the input points throughout the execution of the program.

7. **Error Handling / Exceptional Behavior**  
   - If the input points are collinear, the behavior is not defined, and the output may not represent a valid circle.  
   - The program does not handle invalid input formats or types.

8. **State Transitions (if applicable)**  
   - The program transitions from reading input to processing each set of points, and finally to outputting the results for each set.

9. **Non-functional Constraints (if inferable)**  
   - The output precision is constrained to three decimal places.  
   - The program must complete execution in a reasonable time frame for a typical number of input sets.
