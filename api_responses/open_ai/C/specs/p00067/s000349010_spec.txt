1. **Functional Description**  
The program processes a grid representation of land and water, identifying and counting distinct islands formed by adjacent land cells. An island is defined as a contiguous group of land cells, represented by the value '1'. The program outputs the total number of islands detected in the grid.

2. **Inputs**  
The program reads multiple grids from standard input until the end of input is reached. Each grid consists of 12 rows, with each row containing 12 characters representing either land ('1') or water ('0').

3. **Outputs**  
The program outputs the count of distinct islands for each grid processed, with each count printed on a new line.

4. **Preconditions**  
The input must consist of valid grids with exactly 12 rows and 12 columns, where each cell contains either '0' or '1'. The program assumes that the input is well-formed and adheres to these constraints.

5. **Postconditions**  
After processing each grid, the program guarantees that the output reflects the correct number of distinct islands identified in the grid.

6. **Invariants**  
Throughout the execution, the grid remains a 12x12 structure, and the values in the grid are either '0' or '1', where '1' indicates land and '0' indicates water. The count of islands is incremented only when a new island is detected.

7. **Error Handling / Exceptional Behavior**  
The program does not explicitly handle malformed input or unexpected values. If the input does not conform to the expected format, behavior is not defined.

8. **State Transitions (if applicable)**  
The program transitions between states based on the detection of islands. Each time an island is detected, the state changes to reflect the incremented island count, and the corresponding land cells are marked as water to prevent recounting.

9. **Non-functional Constraints (if inferable)**  
The program operates within a fixed memory constraint due to the static allocation of the grid. Performance is expected to be linear with respect to the number of cells processed in each grid.
