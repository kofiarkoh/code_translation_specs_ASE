1. **Functional Description**  
The program computes the shortest path between pairs of nodes in a weighted undirected graph and evaluates a specific cost based on the computed paths.

2. **Inputs**  
- Two integers representing the number of nodes and the number of edges in the graph.  
- A series of edges defined by four integers for each edge, representing two nodes and their respective weights.  
- A final set of four integers representing two nodes and a cost.

3. **Outputs**  
- A single integer representing the adjusted cost based on the shortest path between the specified nodes.

4. **Preconditions**  
- The number of nodes is a positive integer.  
- The number of edges is a non-negative integer.  
- The edges provided must reference valid node indices within the range of the number of nodes.

5. **Postconditions**  
- The output integer is computed as the difference between a specified cost and the sum of the shortest path weights between two nodes.

6. **Invariants**  
- The weight matrix is initialized such that the diagonal elements are zero and non-diagonal elements are set to a large value, representing infinity.  
- After processing the edges, the weight matrix reflects the shortest paths between all pairs of nodes.

7. **Error Handling / Exceptional Behavior**  
- If the input for the number of nodes or edges is invalid (e.g., negative values), the behavior is not defined.  
- If the edges reference invalid node indices, the behavior is not defined.

8. **State Transitions (if applicable)**  
- The state transitions occur as the weight matrix is updated based on the input edges and subsequently modified through the Floyd-Warshall algorithm to compute shortest paths.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a fixed size of 20 nodes, limiting scalability.  
- The time complexity is influenced by the number of nodes and edges, specifically O(n^3) due to the shortest path computation.
