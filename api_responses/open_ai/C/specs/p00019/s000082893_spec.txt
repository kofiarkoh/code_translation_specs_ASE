1. Functional Description  
Calculates the factorial of a non-negative integer input and outputs the result.

2. Inputs  
Reads a single non-negative integer value from standard input.

3. Outputs  
Returns the factorial of the input integer as an integer value, printed to standard output.

4. Preconditions  
The input must be a non-negative integer.

5. Postconditions  
If the input is a non-negative integer \( n \), the output will be \( n! \) (n factorial). If the input is 0, the output will be 1.

6. Invariants  
The output value is always a non-negative integer, representing the factorial of the input.

7. Error Handling / Exceptional Behavior  
If the input is not a valid non-negative integer, the behavior is undefined. No specific error messages or handling mechanisms are implemented.

8. State Transitions (if applicable)  
Not applicable.

9. Non-functional Constraints (if inferable)  
The program operates within the limits of integer representation for factorial values, which may lead to overflow for larger inputs.
