1. **Functional Description**  
The program calculates the number of unique combinations of `n` distinct integers from the range 0 to 9 that sum to a specified value `s`. It continuously accepts input until a termination condition is met.

2. **Inputs**  
- Two integers, `n` and `s`, where `n` represents the number of distinct integers to select, and `s` represents the target sum.

3. **Outputs**  
- An integer representing the count of unique combinations of `n` integers that sum to `s`. This value is printed to standard output.

4. **Preconditions**  
- The input integers `n` and `s` must be non-negative.  
- The maximum value for `n` is constrained to 10, as it cannot exceed the number of available distinct integers (0 to 9).

5. **Postconditions**  
- The output is the total number of combinations of `n` distinct integers from the range 0 to 9 that sum to `s`.  
- The program terminates when both `n` and `s` are zero.

6. **Invariants**  
- The array used to track selected integers remains within the bounds of 0 to 9.  
- The sum of selected integers does not exceed `s` during the computation.

- If `s` is less than 0, the behavior is not defined.
