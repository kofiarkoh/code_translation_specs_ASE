1. **Functional Description**  
The program counts the number of combinations of four digits (from 0 to 9) that sum to a given integer input. It processes multiple inputs until the end of input is reached.

2. **Inputs**  
The program reads a sequence of integers from standard input, where each integer represents a target sum.

3. **Outputs**  
The program outputs the count of digit combinations for each input integer, with each count printed on a new line.

4. **Preconditions**  
The input integers must be non-negative and within a reasonable range to ensure meaningful output. The program assumes valid integer input is provided.

5. **Postconditions**  
For each input integer, the output is the total number of unique combinations of four digits (0-9) that sum to the input integer.

6. **Invariants**  
The count of combinations is non-negative and is reset to zero for each new input integer. The program maintains the integrity of the digit range (0-9) throughout the counting process.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or non-integer values. It terminates gracefully upon reaching the end of input.

8. **State Transitions (if applicable)**  
The program transitions from reading input to counting combinations and then to outputting results for each input until the end of input is reached.

9. **Non-functional Constraints (if inferable)**  
The program operates within a time complexity that is polynomial with respect to the number of digits being processed, specifically O(1) for each input due to fixed digit limits. Memory usage is minimal and constant, as it does not store input values beyond the current integer being processed.
