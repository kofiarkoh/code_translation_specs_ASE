1. **Functional Description**  
The program determines whether two line segments, defined by four points in a two-dimensional space, are parallel. It processes multiple sets of input until the end of input is reached.

2. **Inputs**  
The program reads a sequence of eight double-precision floating-point numbers representing the coordinates of four points in a two-dimensional space.

3. **Outputs**  
For each set of input coordinates, the program outputs "YES" if the line segments formed by the first two points and the last two points are parallel; otherwise, it outputs "NO". Each output is followed by a newline.

The input must consist of valid double-precision floating-point numbers. The program expects at least one complete set of eight numbers before reaching the end of input.

5. **Postconditions**  
The program will have produced a series of outputs corresponding to each set of input coordinates, indicating whether the line segments are parallel.

6. **Invariants**  
The program maintains the invariant that it only processes complete sets of eight input values at a time. The output is guaranteed to be consistent with the parallelism check of the line segments defined by the input points.
