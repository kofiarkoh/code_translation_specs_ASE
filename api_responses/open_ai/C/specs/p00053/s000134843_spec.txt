1. **Functional Description**  
   The program computes the sum of the first `d` prime numbers for multiple input values of `d`, terminating when a zero is input.

2. **Inputs**  
   The program reads integer values from standard input, where each value represents the number of prime numbers to sum. The input sequence ends when a zero is encountered.

3. **Outputs**  
   The program outputs the sum of the first `d` prime numbers for each valid input `d` on a new line.

4. **Preconditions**  
   The input must be a non-negative integer. The program expects at least one valid input before a terminating zero.

5. **Postconditions**  
   For each valid input `d`, the output is the sum of the first `d` prime numbers. If `d` is zero, the program terminates without output.

6. **Invariants**  
   The list of prime numbers is maintained in a sequence, and the sum is updated correctly as new primes are identified.

7. **Error Handling / Exceptional Behavior**  
   The program does not handle invalid inputs (e.g., non-integer values). It assumes all inputs are valid integers.

8. **State Transitions (if applicable)**  
   The program transitions between states based on the input value: it continues to read and compute sums for positive integers and transitions to termination upon reading zero.

9. **Non-functional Constraints (if inferable)**  
   The program is expected to handle inputs efficiently up to a reasonable limit of `d`, constrained by the maximum size of the prime storage array. Performance may degrade with larger values of `d` due to the prime generation algorithm.
