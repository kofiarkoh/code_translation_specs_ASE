1. **Functional Description**  
The program computes the reflection point of a given point across a line defined by two points in a 2D space. It processes multiple sets of input until the end of input is reached.

2. **Inputs**  
The program reads multiple sets of six double values representing the coordinates of two points that define a line and a point to be reflected.

3. **Outputs**  
The program outputs the coordinates of the reflection point for each set of inputs, formatted as two double values.

4. **Preconditions**  
The input must consist of six double values for each set, formatted as specified, and must be provided until the end of input.

5. **Postconditions**  
For each valid input set, the program guarantees that the output will be the coordinates of the reflection point across the line defined by the first two points.

6. **Invariants**  
The program maintains the integrity of the input data throughout processing, ensuring that the calculations for the reflection point are based on the provided coordinates.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or values. If the input does not conform to the expected format, the behavior is undefined. The program terminates gracefully upon reaching the end of input.

8. **State Transitions (if applicable)**  
The program transitions from reading input to computing the reflection point and then to outputting the result for each set of inputs until the end of input is reached.

9. **Non-functional Constraints (if inferable)**  
The program operates in a continuous loop until the end of input, and the output is generated in real-time for each set of inputs without delay. Performance is not explicitly constrained but is dependent on the efficiency of input reading and output writing.
