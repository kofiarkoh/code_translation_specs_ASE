1. **Functional Description**  
The program reads pairs of integers from standard input, counts the occurrences of each unique integer, and outputs each unique integer along with its count, sorted in ascending order.

2. **Inputs**  
The program reads an unspecified number of pairs of integers from standard input until EOF is reached. Each pair is expected to be formatted as two integers separated by a comma.

3. **Outputs**  
The program outputs each unique integer followed by its count, formatted as "integer count", for each integer that appears more than once in the input. The output is sorted in ascending order based on the integers.

4. **Preconditions**  
The input must consist of valid integer pairs formatted correctly. The total number of pairs must not exceed the predefined limit of 10,000.

5. **Postconditions**  
The output will contain only unique integers that have a count greater than one, each followed by its respective count. The integers in the output will be sorted in ascending order.

6. **Invariants**  
The program maintains a collection of integers and their counts throughout its execution, ensuring that duplicates are identified and counted correctly.

7. **Error Handling / Exceptional Behavior**  
The program does not handle malformed input or non-integer values. If the input exceeds the predefined limit, the behavior is not defined. The program does not provide feedback for invalid input formats.

8. **State Transitions (if applicable)**  
The program transitions from an input state, where it collects integer pairs, to a processing state, where it counts occurrences, and finally to an output state, where it displays the results.

9. **Non-functional Constraints (if inferable)**  
The program is limited to processing a maximum of 10,000 integer pairs and assumes that the input can be processed within reasonable time constraints for this volume. The output is generated in a single pass after processing the input.
