1. Functional Description  
Calculates the number of 5-meter intervals a falling object covers based on its initial velocity until the end of input.

2. Inputs  
Reads a series of floating-point values representing initial velocities from standard input.

3. Outputs  
Prints the number of 5-meter intervals covered by the object for each input velocity, each on a new line.

4. Preconditions  
Input values must be valid floating-point numbers representing initial velocities. The input stream must be open and accessible.

5. Postconditions  
For each input velocity, the output is a positive integer representing the number of 5-meter intervals covered by the object.

6. Invariants  
The output is always greater than or equal to 1 for any positive input velocity. The calculations are based on the physics of free fall under gravity.

7. Error Handling / Exceptional Behavior  
If the input is not a valid floating-point number, the program may exhibit undefined behavior. The program does not handle EOF or input errors gracefully beyond terminating input processing.

8. State Transitions (if applicable)  
The program transitions from reading input to calculating and printing output for each valid input until EOF is reached.

9. Non-functional Constraints (if inferable)  
The program operates in a continuous loop until EOF, and the output is generated in real-time as inputs are processed. Performance is dependent on the number of inputs provided.
