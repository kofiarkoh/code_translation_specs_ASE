1. **Functional Description**  
The program computes the greatest common divisor (GCD) of two integers and returns both the GCD and the product of the two integers divided by the GCD.

2. **Inputs**  
The program reads pairs of integers from standard input until the end of input is reached.

3. **Outputs**  
For each pair of integers, the program outputs two values: the GCD of the integers and the product of the integers divided by the GCD.

4. **Preconditions**  
The input integers must be non-negative.

5. **Postconditions**  
The output values are guaranteed to be non-negative integers, where the first value is the GCD and the second value is the product of the two integers divided by the GCD.

6. **Invariants**  
Throughout the execution, the GCD remains a divisor of both input integers, and the product of the two integers divided by the GCD is always equal to the product of the two integers.

7. **Error Handling / Exceptional Behavior**  
If the input is not in the expected format or if non-integer values are provided, the behavior is not defined. The program does not handle such errors explicitly.

8. **State Transitions (if applicable)**  
The program transitions between states based on the input pairs read, processing each pair independently until the end of input is reached.
