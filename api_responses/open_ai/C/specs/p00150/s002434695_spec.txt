1. **Functional Description**  
The code identifies and outputs pairs of prime numbers that differ by two, known as twin primes, for given input values. It processes multiple input values until a termination condition is met.

2. **Inputs**  
The program reads a series of integer values from standard input, where each value represents an upper limit for searching twin primes. The input terminates when a zero is encountered.

3. **Outputs**  
The program outputs pairs of twin prime numbers, formatted as two integers on a single line, for each input value. If no twin primes are found for a given input, no output is generated for that input.

4. **Preconditions**  
The input values must be non-negative integers. The maximum input value must not exceed 10,000.

5. **Postconditions**  
For each input value greater than or equal to 7, the program guarantees that if twin primes exist within the specified range, the first found pair will be output. If no twin primes exist, no output will be produced.

6. **Invariants**  
The array used to track prime numbers remains consistent throughout the execution, ensuring that all identified primes are accurately marked. The twin prime search is conducted only within the bounds of the input value.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or negative integers. It assumes that input will be valid as per the preconditions. If the input is zero, the program terminates without further action.

8. **State Transitions (if applicable)**  
The program transitions from an initial state of waiting for input to a processing state upon receiving a valid integer. It may transition to an output state when twin primes are found, or return to the input state for subsequent values.

9. **Non-functional Constraints (if inferable)**  
The program operates within a time complexity that is efficient for the range of inputs specified, ensuring timely responses for valid input values. Memory usage is constrained to the fixed size of the prime tracking array.
