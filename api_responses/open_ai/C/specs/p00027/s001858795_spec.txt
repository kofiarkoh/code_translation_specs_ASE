1. **Functional Description**  
The code determines the day of the week for given dates in a specific year and outputs the corresponding day name.

2. **Inputs**  
The program reads two integer values representing the month and day of a date. Input continues until a zero is entered for either the month or the day.

3. **Outputs**  
The program outputs the name of the day of the week corresponding to the provided date. This output occurs for each valid input until termination conditions are met.

4. **Preconditions**  
The month input must be an integer between 1 and 12, and the day input must be a valid day for the specified month. The year is fixed at 2004.

5. **Postconditions**  
For each valid input, the program outputs the correct day of the week. The program terminates when a zero is entered for either input.

6. **Invariants**  
The program maintains that the year is always 2004 during execution. The day of the week calculation is based on the Gregorian calendar.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid month or day inputs explicitly. It assumes that the user will provide valid inputs within the specified range. If a zero is entered, the program terminates gracefully.

8. **State Transitions (if applicable)**  
The program transitions from a reading state to an output state upon receiving valid inputs. It returns to the reading state after outputting the day of the week until termination conditions are met.

9. **Non-functional Constraints (if inferable)**  
The program operates in a continuous loop until termination conditions are met, and it outputs results immediately after processing each input. Performance is not explicitly constrained but is expected to be efficient for typical input sizes.
