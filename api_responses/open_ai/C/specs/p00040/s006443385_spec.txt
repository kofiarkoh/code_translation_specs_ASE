1. **Functional Description**  
The program processes multiple lines of input, searching for specific patterns encoded using an affine transformation. If a pattern is found, it outputs the transformed line based on the parameters of the affine transformation.

2. **Inputs**  
- An integer indicating the number of lines to process.  
- Multiple lines of text, each containing up to 512 characters.  
- Two integer parameters for the affine transformation, ranging from 0 to 99.

3. **Outputs**  
- Transformed lines of text based on the affine transformation if a specific pattern is detected.  
- No output if no patterns are found after processing all lines.

4. **Preconditions**  
- The first input must be a valid integer greater than or equal to zero.  
- Each subsequent line must be a valid string of characters, with a maximum length of 512.

5. **Postconditions**  
- If a pattern is found, the corresponding transformed line is printed.  
- If no patterns are found after processing all lines, no output is generated.

6. **Invariants**  
- The affine transformation is consistently applied to each character in the input lines.  
- The search for patterns is conducted for all combinations of the affine parameters within the specified range.

7. **Error Handling / Exceptional Behavior**  
- If the input does not conform to the expected format (e.g., non-integer for the number of lines), behavior is not defined.  
- If the input line exceeds the maximum length, behavior is not defined.

8. **State Transitions (if applicable)**  
- The program transitions from reading input to processing each line, then to searching for patterns, and finally to outputting results or terminating without output.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a time complexity that allows for exhaustive searching of affine parameters within the specified range.  
- Memory usage is constrained by the maximum line length and the number of lines processed.
