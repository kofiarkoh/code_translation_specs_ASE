1. **Functional Description**  
   The program computes and outputs the frequency of distinct differences between pairs of squared integers modulo a given integer, for multiple input values until a terminating condition is met.

2. **Inputs**  
   The program reads a series of positive integers from standard input, terminating when a zero is encountered.

3. **Outputs**  
   For each input integer \( n \), the program outputs the frequency of distinct differences for values from 1 to \( (n-1)/2 \), each on a new line.

4. **Preconditions**  
   The input must consist of positive integers, with at least one integer provided before the terminating zero.

5. **Postconditions**  
   The output will consist of \( (n-1)/2 \) lines of integers, each representing the count of distinct differences for the corresponding input integer \( n \).

6. **Invariants**  
   The program maintains a count of distinct squared values modulo \( n \) and their corresponding differences throughout its execution.

7. **Error Handling / Exceptional Behavior**  
   The program does not handle invalid input formats or negative integers; it assumes all inputs are valid as per the preconditions.

8. **State Transitions (if applicable)**  
   The program transitions between states based on the input values read, processing each integer until a zero is encountered, at which point it terminates.

9. **Non-functional Constraints (if inferable)**  
   The program operates within a fixed memory limit for arrays and has a time complexity that is dependent on the input size, specifically \( O(n^2) \) for each input \( n \).
