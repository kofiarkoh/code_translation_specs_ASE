1. **Functional Description**  
The program identifies and outputs all leap years within a specified inclusive range of two integers. It continues to process multiple ranges until a termination condition is met.

2. **Inputs**  
The program reads pairs of integers from standard input, representing the start and end of a range.

3. **Outputs**  
The program outputs each leap year found within the specified range, one per line. If no leap years are found, it outputs "NA". After processing each range, it outputs a newline.

4. **Preconditions**  
The input must consist of pairs of integers. The first integer must be less than or equal to the second integer for valid range processing.

5. **Postconditions**  
For each valid range, the program guarantees that all leap years within that range are outputted. If no leap years exist in the range, "NA" is outputted.

6. **Invariants**  
The program maintains that it will only output leap years or "NA" for each range processed. The termination condition is that both input integers are zero.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or non-integer values. It assumes valid integer input as per the preconditions.

8. **State Transitions (if applicable)**  
The program transitions between states of reading input, processing ranges, and outputting results. It enters a termination state when both input integers are zero.

9. **Non-functional Constraints (if inferable)**  
The program operates in a continuous loop until the termination condition is met, and it outputs results immediately after processing each range. Performance is not explicitly constrained but is dependent on the range size.
