1. Functional Description
   - High-level description:
     - A command-line program that reads pairs of integers (year ranges) from standard input and, for each pair, lists all years in the inclusive range that are leap years according to the Gregorian leap-year rule.
   - Problem it solves:
     - Given many year-range queries, report leap years within each range or indicate when none exist.
   - Core behavior:
     - Repeatedly read two integers a and b. For each pair (a, b) unless both are zero, print every year y with a <= y <= b that is a leap year. If no leap years are found in the range, print "NA". After processing each pair (except the terminating 0 0 pair) print a blank (empty) line. Terminate when the pair (0, 0) is read.

2. Inputs
   - Parameters:
     - No function parameters; reads from standard input (stdin).
     - Each iteration reads two whitespace-separated integers: a and b.
   - Data types:
     - a and b are standard C ints (signed 32-bit on many platforms, but not specified).
   - Valid ranges or constraints:
     - Values must be representable in the platform's int type.
     - To avoid undefined behavior, ranges should be such that incrementing a up to b does not cause signed integer overflow.
   - Assumptions about inputs:
     - Input consists of well-formed integers separated by whitespace.
     - A terminating pair of exactly two zeros (0 0) is provided to stop the program.
     - Behavior on malformed input or premature EOF is not handled by the program (see Error Handling).

3. Outputs
   - Return values:
     - Program exits with status code 0 on normal termination.
   - Side effects:
     - Writes to standard output (stdout).
   - Output format/schema:
     - For each input pair (a, b) except the terminating (0, 0):
       - Each leap year in the inclusive range [a, b] is printed on its own line as a decimal integer (in ascending order).
       - If no leap years are found in the range, a single line containing exactly: NA
       - After the leap-year lines or the "NA" line, an additional blank line (a single newline) is printed.
     - For the terminating pair (0, 0), nothing is printed and the program terminates.

4. Preconditions
   - The program expects two integers per query on stdin.
   - There exists at least one pair of integers (a, b) equal to (0, 0) eventually to terminate normally.
   - The integer range from a to b must be such that iterating (a++ until a > b) does not cause signed integer overflow.

5. Postconditions
   - For each processed input pair (a, b) with a and b as read:
     - If any years y in [a, b] satisfy the leap-year predicate (see guarantees), those years have been printed, one per line, in non-decreasing order.
     - If none satisfy the predicate, a single line "NA" has been printed for that pair.
     - A blank line has been printed after each pair's output block.
   - On reading the pair (0, 0), program execution ends and returns 0.

   - Leap-year predicate guaranteed:
     - A year y is considered a leap year iff:
       - y is divisible by 400, or
       - y is divisible by 4 and not divisible by 100.
     - (Divisibility is determined by integer remainder equal to zero.)

6. Invariants
   - Per-query invariant:
     - While processing a single (a, b) pair, any printed year y satisfies a <= y <= b and the leap-year predicate.
   - Program-level invariant:
     - The program continues reading pairs and producing outputs until it reads the terminating pair (0, 0) (unless invalid input/EOF occurs).

7. Error Handling / Exceptional Behavior
   - Invalid or non-integer input:
     - Not handled; behavior is unspecified/undefined (the code does not check scanf return values).
   - Premature EOF:
     - Not handled explicitly; behavior is unspecified/undefined.
   - If a > b:
     - The program treats the range as empty and will print "NA" followed by a blank line for that pair.
   - Integer overflow:
     - If iterating from a up to b requires incrementing beyond the representable range of int (signed overflow), behavior is undefined.
   - No exceptions are thrown (C program); error conditions do not generate structured error reports.

8. State Transitions (if applicable)
   - Valid runtime states:
     - Waiting for input (reading a, b).
     - Processing current pair (printing leap years or "NA" and a blank line).
     - Terminated (after reading (0, 0)).
   - State changes caused by execution:
     - On reading a non-(0,0) pair: transition from waiting to processing and back to waiting.
     - On reading (0, 0): transition to terminated and program exit.

9. Non-functional Constraints (if inferable)
   - Time complexity:
     - For a single pair (a, b), time is O(max(0, b - a + 1)) — linear in the size of the inclusive range.
   - Space complexity:
     - O(1) additional space (constant memory).
   - Performance assumptions:
     - Performance is directly proportional to the length of the ranges processed; large ranges may take correspondingly long time.
