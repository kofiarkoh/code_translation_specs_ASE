1. Functional Description
   - High-level description of the purpose
     - Reads a sequence of integer test cases and, for each integer n, produces an n-by-n character grid where a single continuous clockwise spiral made of '#' characters is drawn on a background of spaces.
   - What problem it solves
     - Generates a printable spiral pattern of '#' characters of specified size for each input n.
   - Core behavior
     - For each test case with parameter n, generate an n×n matrix of characters such that '#' characters form a single connected clockwise spiral path that starts from a position near the lower-left of the printed area and winds inward until it can no longer advance. Print the matrix as n text lines (each line containing exactly n characters, consisting of '#' and space), and separate consecutive test case outputs by exactly one blank line.

2. Inputs
   - Parameters
     - First input value: integer T (number of test cases).
     - Then T lines follow, each containing one integer n.
   - Data types
     - Inputs are parsed as ASCII textual integers (via atoi).
   - Valid ranges or constraints
     - The code contains no explicit runtime validation of T or n. However, to avoid out-of-bounds memory access in the internal fixed-size grid, n must be small enough such that the program’s internal buffer (105×105) is not exceeded. From the code’s indexing, safe operation requires:
       - n is a non-negative integer with n + 3 <= 104 (i.e., n <= 101).
     - T should be non-negative and reasonably small to fit within program memory/time; no explicit upper bound enforced.
   - Assumptions about inputs
     - Each test case line contains an integer parseable by atoi. Non-numeric or empty lines are treated as zero by atoi.
     - The input contains at least T additional lines after the T value.

3. Outputs
   - Return values
     - Program returns 0 on normal termination.
   - Side effects
     - Writes textual output to standard output:
       - For each test case, prints exactly n lines; each line is exactly n characters long (may include trailing spaces) followed by a newline.
       - Prints a single blank line between consecutive test cases (no leading blank line before the first test case).
   - Output format/schema (if applicable)
     - Each line contains only the characters '#' and space ' '.
     - The printed n×n block represents the interior portion of the generated grid, with '#' marking the spiral and spaces elsewhere.

4. Preconditions
   - Conditions that must hold before execution
     - Input must conform to the expected format: first line an integer T, followed by at least T lines each containing an integer n.
     - Each n should satisfy the safe-bound condition (n + 3 <= 104) to avoid buffer overflows.
   - Explicit logical constraints
     - T >= 0.
     - n >= 0 (negative values are interpreted as zero by the parser).

5. Postconditions
   - Conditions guaranteed after execution
     - For each processed test case, an n×n textual representation of a clockwise spiral is printed to standard output, separated by blank lines between test cases.
     - The program terminates and returns 0 unless runtime undefined behavior occurs due to invalid inputs violating preconditions.
   - State changes
     - No persistent external state is modified beyond the program’s standard output.

6. Invariants
   - Conditions that must always remain true
     - The output for a single test case is exactly n lines of length n each.
     - The spiral formed by '#' is a single connected path (no multiple disjoint '#' regions) and follows clockwise progression from its start until it can no longer extend.
   - Class-level invariants
     - Not applicable (program is procedural).

7. Error Handling / Exceptional Behavior
   - What happens on invalid input?
     - If input lines are missing, malformed, or do not contain parsable integers, atoi returns 0 and the program will attempt to process those values as 0 (which results in no printed lines for that test case).
     - If n exceeds the safe buffer bounds (see Inputs), the program may write out of bounds and exhibit undefined behavior (possible crashes or corrupted output). The code does not validate or guard against this.
   - Exceptions thrown?
     - The C program does not throw exceptions; errors manifest as undefined behavior or incorrect output in case of invalid inputs.
   - Edge-case behavior
     - n = 0: produces no output lines for that test case (only the inter-test blank-line logic may still apply).
     - Very small n (e.g., n = 1 or 2): the spiral degenerates appropriately within the n×n output; behavior follows the same rules but result may be a single '#' or other small configurations consistent with the spiral termination rule.
     - Non-numeric lines: treated as zero by atoi.

8. State Transitions (if applicable)
   - Valid object states
     - Not object-oriented; internal representation is a fixed-size 2D character buffer that temporarily holds the backing grid.
   - State changes caused by execution
     - The internal buffer is populated with spaces and '#' to form the spiral, then a sub-rectangle of that buffer is serialized to standard output. No state persists after program termination.

9. Non-functional Constraints (if inferable)
   - Time complexity
     - O(n^2) per test case in the worst case (the algorithm marks at most O(n^2) grid cells and each step does constant-time checks).
   - Space complexity
     - Uses a fixed-size buffer of 105×105 characters (O(1) with respect to n within the compiled limits). Logical working space required is proportional to the fixed buffer; when considering n only, conceptual space used is O(n^2) for the n×n output region.
   - Performance assumptions
     - Reasonable performance for n within the safe bounds (n <= ~101). For very large T or invalid large n, behavior and performance are undefined due to potential memory corruption.

Notes on ambiguity / limits of inference
   - The exact starting coordinates of the spiral inside the internal buffer are an implementation detail; the observable guarantee is the produced n×n printed block contains a clockwise spiral of '#' characters. 
   - Exact behavior for n values that violate the internal buffer bounds is undefined and cannot be precisely specified from the code.
