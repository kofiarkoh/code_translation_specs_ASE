1. **Functional Description**  
The program determines the number of distinct pairs of prime numbers that sum up to a given integer. It outputs the count of such pairs for each input integer until a zero is encountered.

2. **Inputs**  
The program reads a series of integers from standard input, terminating when a zero is input.

3. **Outputs**  
For each input integer greater than zero, the program outputs a single integer representing the count of distinct pairs of prime numbers that sum to the input integer.

4. **Preconditions**  
The input integers must be non-negative. The program assumes that the input integers are within the range of 0 to 5000.

5. **Postconditions**  
The output for each input integer is guaranteed to be a non-negative integer representing the count of distinct prime pairs that sum to the input integer.

6. **Invariants**  
The array used to track prime numbers is maintained such that all indices corresponding to prime numbers are marked appropriately before processing input integers.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input (e.g., non-integer values). It assumes all inputs are valid integers. If an input integer is less than zero, the program does not produce output and terminates.

8. **State Transitions (if applicable)**  
The program transitions from an initial state of no input to a state where it processes each input integer, updating the count of prime pairs for each valid input until a zero is encountered.

9. **Non-functional Constraints (if inferable)**  
The program operates within a time complexity that is efficient for the range of inputs specified, ensuring that it can handle multiple inputs in a reasonable time frame. The space complexity is constrained by the fixed size of the prime number array.
