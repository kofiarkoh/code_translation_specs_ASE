1. Functional Description

   - Core behavior: For each input n ≠ 0, examine prime values ≤ n, count ordered prime-pairs (p,q) with p+q == n, and convert that ordered-count to an unordered count (pairs (p,q) and (q,p) are considered the same; a self-pair p=p is counted once). Output one integer (the count) per input line.
