1. **Functional Description**  
The program reads time values in hours, minutes, and seconds, computes two derived time values based on a fixed reference, and outputs these values in a formatted manner until a termination condition is met.

The program reads three integer values representing time in the format of total seconds, hours, and seconds.

3. **Outputs**  
The program outputs two formatted time strings for each set of input values, representing the remaining time until a reference point and a third of that remaining time.

The input values must be integers. The program continues to read input until the termination condition of all values being -1 is met.

5. **Postconditions**  
For each valid input set, the program outputs two formatted time strings. The first string represents the time remaining until a reference point, and the second string represents one-third of that remaining time.

6. **Invariants**  
The program maintains that the computed time values are always non-negative and that the output format remains consistent throughout the execution.

The program does not handle invalid input formats or values outside the expected range. It assumes that input will be provided correctly until the termination condition is met.

The program transitions between states based on the input values read. It continues processing until the termination condition is encountered.
