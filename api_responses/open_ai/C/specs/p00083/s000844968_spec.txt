1. **Functional Description**  
The program reads a series of date inputs and converts them from the Western calendar to the Japanese era system, outputting the corresponding era name and adjusted date values.

2. **Inputs**  
The program reads multiple sets of three integer values representing a year, month, and day until the end of input is reached.

3. **Outputs**  
The program outputs the Japanese era name followed by the adjusted year, month, and day values. If the input date falls within a recognized era, it prints the era name; otherwise, it prints the adjusted date values.

4. **Preconditions**  
The input must consist of valid integers representing a year, month, and day. The program assumes that the input is formatted correctly and that the month is within the range of 1 to 12 and the day is within the valid range for the given month.

5. **Postconditions**  
For each valid input date, the program guarantees that it will output either the corresponding Japanese era name or the adjusted date values. The output will reflect the correct era based on the input date.

6. **Invariants**  
The program maintains that the input date is processed in chronological order, and the output will always correspond to the input date's era classification.

7. **Error Handling / Exceptional Behavior**  
The program does not explicitly handle invalid input formats or out-of-range values. If the input is invalid, the behavior is not defined.

8. **State Transitions (if applicable)**  
The program transitions between states based on the input date's year, month, and day, determining the appropriate Japanese era and adjusting the date accordingly.

9. **Non-functional Constraints (if inferable)**  
The program operates in a continuous loop until the end of input, processing each date in constant time relative to the number of inputs. The output is generated immediately after processing each input set.
