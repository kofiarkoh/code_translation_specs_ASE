1. **Functional Description**  
The program reads strings from standard input, extracts all numeric values from those strings, sums them, and outputs the total sum.

2. **Inputs**  
The program reads multiple strings from standard input until the end of input is reached. Each string may contain alphanumeric characters.

3. **Outputs**  
The program outputs a single integer value representing the sum of all numeric values extracted from the input strings.

4. **Preconditions**  
The input must be provided in a format that allows for reading strings until the end of input. Each string can contain a mix of characters, including digits.

5. **Postconditions**  
The output will be the total sum of all numeric values found in the input strings. If no numeric values are found, the output will be zero.

6. **Invariants**  
The sum of numeric values is maintained throughout the execution of the program, ensuring that it reflects the cumulative total of all extracted numbers at the time of output.

7. **Error Handling / Exceptional Behavior**  
The program does not handle errors related to input reading or invalid data formats explicitly. It assumes that input will be provided correctly and will terminate normally upon reaching the end of input.

8. **State Transitions (if applicable)**  
The program transitions from an initial state of zero sum to a final state where the sum reflects the total of all numeric values found in the input.

9. **Non-functional Constraints (if inferable)**  
The program is limited to processing strings of up to 80 characters in length and can handle multiple strings until the end of input. The output is produced in a single operation after all input has been processed.
