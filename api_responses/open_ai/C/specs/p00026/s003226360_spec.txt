1. **Functional Description**  
The program processes a series of input coordinates, modifies a 10x10 grid based on these coordinates, and computes two metrics: the number of untainted cells and the maximum taint level in the grid.

2. **Inputs**  
The program reads a sequence of three integers from standard input, formatted as "x,y,z", until the end of input is reached. Each integer represents a coordinate and a taint level.

3. **Outputs**  
The program outputs two integers to standard output: the first integer is the count of untainted cells in the grid, and the second integer is the maximum taint level found in any cell of the grid.

4. **Preconditions**  
The input integers must be within the range of 0 to 9 for the first two integers (representing grid coordinates). The third integer must be a positive integer indicating the taint level (1, 2, or 3).

5. **Postconditions**  
After processing all inputs, the grid will reflect the taint levels based on the input coordinates. The first output will be the count of cells in the grid that remain untainted (i.e., have a value of 0). The second output will be the highest value present in the grid, representing the maximum taint level.

6. **Invariants**  
The grid remains a 10x10 structure throughout the execution. The values in the grid are non-negative integers, representing the taint levels, which can only increase based on the input coordinates.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or out-of-range values explicitly. If the input does not conform to the expected format or range, behavior is not defined.

8. **State Transitions (if applicable)**  
The state of the grid transitions with each valid input read, where the taint levels of specific cells are incremented based on the input coordinates and the specified taint level.

9. **Non-functional Constraints (if inferable)**  
The program operates within a fixed memory footprint due to the static size of the grid. Performance is linear with respect to the number of inputs processed, as each input results in a constant-time update to the grid and a subsequent linear scan for output calculations.
