1. **Functional Description**  
The program reads strings representing Roman numerals from standard input and computes their integer values, outputting the results to standard output.

2. **Inputs**  
The program accepts multiple strings of Roman numeral characters until the end of input is reached.

3. **Outputs**  
The program outputs the integer value corresponding to each Roman numeral string, each followed by a newline.

4. **Preconditions**  
Each input string must consist solely of valid Roman numeral characters (I, V, X, L, C, D, M) and must not exceed 100 characters in length.

5. **Postconditions**  
For each valid input string, the program outputs the correct integer value of the Roman numeral representation.

6. **Invariants**  
The program maintains an array that maps each Roman numeral character to its corresponding integer value throughout the execution.

7. **Error Handling / Exceptional Behavior**  
If an input string contains characters outside the valid Roman numeral set, those characters are treated as representing the value 1000. The program does not handle malformed input or provide error messages.

8. **State Transitions (if applicable)**  
The program transitions from reading input to processing each string and then to outputting the computed integer value for each string until the end of input is reached.

9. **Non-functional Constraints (if inferable)**  
The program processes each input string in a linear fashion, with time complexity proportional to the length of the string. The maximum length of input strings is constrained to 100 characters.
