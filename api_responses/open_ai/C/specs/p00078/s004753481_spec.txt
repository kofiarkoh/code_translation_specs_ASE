1. **Functional Description**  
   The program generates and prints a magic square of size \( n \times n \) for any positive integer \( n \) provided as input. A magic square is a grid where the sum of the numbers in each row, column, and both main diagonals are the same.

2. **Inputs**  
   The program reads positive integers from standard input until a zero is encountered. Each positive integer represents the size of the magic square to be generated.

3. **Outputs**  
   The program outputs the generated magic square to standard output, formatted as a grid of integers, with each integer right-aligned within a width of four characters.

4. **Preconditions**  
   The input must consist of positive integers followed by a zero. The program assumes that the input is well-formed and does not handle non-integer or negative values.

5. **Postconditions**  
   For each positive integer \( n \) read, a corresponding \( n \times n \) magic square is printed. The numbers in the square range from 1 to \( n^2 \) and are arranged such that the sums of each row, column, and both diagonals are equal.

6. **Invariants**  
   At any point during the generation of the magic square, the numbers placed in the grid are unique and range from 1 to \( n^2 \). The grid remains within the bounds of \( n \times n \).

7. **Error Handling / Exceptional Behavior**  
   The program does not handle errors related to invalid input formats or negative integers. It terminates gracefully upon encountering a zero.

8. **State Transitions (if applicable)**  
   The program transitions between states of reading input, generating a magic square, and printing the output. Each valid input leads to the generation of a new magic square.

9. **Non-functional Constraints (if inferable)**  
   The program operates within a fixed memory allocation for the magic square, specifically a \( 16 \times 16 \) grid, limiting the maximum size of \( n \) to 16. The output formatting ensures consistent alignment of numbers.
