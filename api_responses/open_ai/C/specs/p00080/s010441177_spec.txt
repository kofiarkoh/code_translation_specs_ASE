1. Functional Description  
The program computes the cube root of a given integer input, continuously processing inputs until a termination signal is received.

2. Inputs  
The program reads integer values from standard input, where each value represents a number for which the cube root is to be calculated. The input terminates when the value -1 is provided.

3. Outputs  
The program outputs the computed cube root of each input integer to standard output, formatted as a floating-point number.

4. Preconditions  
The program assumes that the input values are valid integers. The input must include at least one integer before the termination signal.

5. Postconditions  
For each integer input (except -1), the program guarantees that the output is the cube root of the input value, accurate to within a specified tolerance.

6. Invariants  
The program maintains that the computed cube root remains within a defined precision relative to the input value throughout the calculation process.

7. Error Handling / Exceptional Behavior  
The program does not handle invalid input types or out-of-range values explicitly. It will continue to prompt for input until the termination signal is received.

8. State Transitions (if applicable)  
The program transitions from an input state to an output state upon receiving a valid integer input, and it returns to the input state after outputting the result. The program transitions to a termination state upon receiving the input -1.

9. Non-functional Constraints (if inferable)  
The program operates with a precision requirement for the cube root calculation, ensuring results are accurate to within a specified tolerance of the input value. Performance is not explicitly constrained but is dependent on the convergence of the cube root calculation.
