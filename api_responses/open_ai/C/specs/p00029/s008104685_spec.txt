1. **Functional Description**  
The program reads a line of text, splits it into words, and identifies the most frequently occurring word along with the longest word in the input. It outputs these two words.

2. **Inputs**  
The program reads a sequence of characters from standard input until a newline character is encountered.

3. **Outputs**  
The program outputs two words: the most frequently occurring word and the longest word, separated by a space.

4. **Preconditions**  
The input must consist of printable characters and may include spaces. The input line must not exceed 1000 characters.

5. **Postconditions**  
The output will always include the most frequently occurring word and the longest word from the input. If there are ties in frequency or length, the first encountered word will be selected.

6. **Invariants**  
The program maintains a collection of words extracted from the input, ensuring that each word is stored correctly and that the counts of occurrences are accurately tracked.

7. **Error Handling / Exceptional Behavior**  
If the input exceeds the maximum allowed length, the behavior is not defined. The program does not handle invalid characters or empty input gracefully.

8. **State Transitions (if applicable)**  
The program transitions from reading input to processing the words and finally to outputting the results, with distinct states for each phase.

9. **Non-functional Constraints (if inferable)**  
The program operates within a time complexity that is dependent on the number of words and their lengths, with a maximum limit on the number of words processed. Memory usage is constrained by the fixed size of the word storage array.
