The program determines whether a point lies within or on the boundary of a triangle defined by three vertices in a two-dimensional space.

The program reads a series of eight floating-point values representing the coordinates of three triangle vertices and one point.

3. **Outputs**  
The program outputs "YES" if the point lies within or on the boundary of the triangle; otherwise, it outputs "NO". This output occurs for each set of inputs until the end of input is reached.

The input must consist of valid floating-point numbers formatted as specified, and there must be at least one complete set of eight values for processing.

For each complete set of inputs, the program guarantees that it will output either "YES" or "NO" based on the positional relationship of the point to the triangle.

The program maintains the invariant that the triangle is defined by the first three points, and the fourth point is evaluated against this triangle for each input set.
