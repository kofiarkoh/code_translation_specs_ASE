1. **Functional Description**  
The program processes a line of text input, extracting and printing words that have a length between 3 and 6 characters, separated by spaces.

2. **Inputs**  
The program reads a single line of text from standard input, which may contain words separated by spaces, commas, or periods.

3. **Outputs**  
The program outputs a single line of text to standard output, consisting of the extracted words that meet the length criteria, separated by spaces. It also outputs a newline character at the end.

4. **Preconditions**  
The input line must not exceed 1024 characters in length. The input may contain any combination of letters, digits, spaces, commas, and periods.

5. **Postconditions**  
The output will contain only those words from the input that have a length between 3 and 6 characters, formatted as a single line with words separated by spaces.

6. **Invariants**  
The program maintains that only words of valid length (3 to 6 characters) are included in the output. The output will not contain leading or trailing spaces.

7. **Error Handling / Exceptional Behavior**  
If the input line is empty or contains no valid words, the output will be a blank line followed by a newline character. The program does not handle input errors explicitly.

8. **State Transitions (if applicable)**  
Not applicable.

9. **Non-functional Constraints (if inferable)**  
The program operates within a time complexity that is linear with respect to the length of the input line. The output is guaranteed to be formatted correctly with respect to spacing and line termination.
