1. **Functional Description**  
The program compares two sets of four integers and counts the number of exact matches (hits) and the number of matches in different positions (blows) for each pair of sets provided.

2. **Inputs**  
The program reads two sets of four integers from standard input. This process continues until the end of input is reached.

3. **Outputs**  
The program outputs the counts of hits and blows for each pair of sets, formatted as two integers separated by a space, followed by a newline.

4. **Preconditions**  
Each set of integers must consist of exactly four integers. The input must be provided in pairs until the end of input.

5. **Postconditions**  
For each pair of sets read, the program guarantees that the output will reflect the correct counts of hits and blows based on the comparison of the two sets.

6. **Invariants**  
The counts of hits and blows are non-negative integers. The program maintains the integrity of the input data by processing only complete sets of four integers.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or values. It assumes that the input will always be valid as per the preconditions.

8. **State Transitions (if applicable)**  
The program transitions from reading input to processing the counts of hits and blows, and then to outputting the results for each pair of sets until the end of input is reached.

9. **Non-functional Constraints (if inferable)**  
The program operates in a continuous loop until the end of input, and the time complexity is proportional to the number of input pairs processed, with a constant factor due to the fixed size of the sets.
