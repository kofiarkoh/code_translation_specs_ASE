1. **Functional Description**  
The program computes the least common multiple (LCM) of the counts of cycles for three given integers under specified modular bases. It repeatedly reads input values until all are zero, calculates the cycle counts for each integer, and outputs the LCM of these counts.

2. **Inputs**  
The program reads six integer values from standard input, representing three pairs of integers and their respective modular bases.

3. **Outputs**  
The program outputs the LCM of the cycle counts for the three pairs of integers, one result per line, until the input values are all zero.

4. **Preconditions**  
The input integers must be valid 64-bit signed integers. The program assumes that at least one of the input integers is non-zero to initiate processing.

5. **Postconditions**  
For each set of non-zero inputs, the program guarantees that the output is the LCM of the cycle counts derived from the input integers and their modular bases.

6. **Invariants**  
The cycle count for each integer is always a positive integer, as it counts the number of iterations until the integer returns to 1 under modular arithmetic.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or out-of-range values explicitly. It terminates gracefully when all input values are zero.

8. **State Transitions (if applicable)**  
The program transitions from reading input to processing the input values and then to outputting results. It continues this cycle until the termination condition (all inputs are zero) is met.

9. **Non-functional Constraints (if inferable)**  
The program operates in a continuous loop until termination, and the output is produced in a sequential manner corresponding to the input processing. Performance is dependent on the number of iterations required to compute the cycle counts.
