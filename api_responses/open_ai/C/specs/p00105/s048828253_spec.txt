1. **Functional Description**  
The program reads pairs of words and associated integers from input, processes them to remove duplicates, sorts the words, and organizes the integers associated with each unique word. It then outputs each unique word followed by its associated integers.

2. **Inputs**  
The program reads a sequence of word-integer pairs until the end of input is reached. Each word is a string, and each integer is a non-negative integer.

3. **Outputs**  
The program outputs each unique word followed by its associated integers, each on a new line. If a word has no associated integers, it is followed by a newline.

4. **Preconditions**  
The input must consist of valid word-integer pairs. Each word must not exceed 255 characters, and the number of pairs must not exceed the defined limits of the program.

5. **Postconditions**  
The output contains each unique word from the input, sorted in lexicographical order, followed by the integers associated with that word. Each word and its integers are printed on separate lines.

6. **Invariants**  
Throughout the execution, the list of words remains sorted, and duplicates are marked and excluded from the final output. The integrity of the associated integers is maintained relative to their corresponding words.

7. **Error Handling / Exceptional Behavior**  
The program does not handle malformed input or errors during reading. If the input is not as expected, behavior is undefined. The program assumes that input will be correctly formatted.

8. **State Transitions (if applicable)**  
The program transitions through states of reading input, processing data (sorting and deduplication), and finally outputting results. Each state is dependent on the successful completion of the previous state.

9. **Non-functional Constraints (if inferable)**  
The program is expected to operate within the constraints of memory usage defined by the fixed-size arrays. Performance may degrade with a large number of input pairs due to the sorting and deduplication processes.
