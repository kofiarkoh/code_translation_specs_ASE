1. **Functional Description**  
The program evaluates multiple sequences of ten integers to determine if each sequence contains at most two distinct values. It outputs "YES" if the condition is met and "NO" otherwise.

2. **Inputs**  
The program reads an integer indicating the number of sequences, followed by ten integers for each sequence.

3. **Outputs**  
The program outputs "YES" or "NO" for each sequence based on the evaluation of distinct values.

4. **Preconditions**  
The input must consist of a positive integer followed by sequences of ten integers. The total number of integers read must match the specified number of sequences multiplied by ten.

5. **Postconditions**  
For each sequence, the program guarantees that it will output either "YES" or "NO" based on the distinct value condition.

6. **Invariants**  
Throughout the evaluation of each sequence, the program maintains the count of distinct values encountered.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or out-of-bounds values. It assumes all inputs are valid as per the specified format.

8. **State Transitions (if applicable)**  
The program transitions between states based on the evaluation of each sequence, moving from reading input to evaluating distinct values, and finally to outputting results.

9. **Non-functional Constraints (if inferable)**  
The program operates within a fixed memory limit due to the static array size and processes each sequence in linear time relative to the number of integers in the sequence.
