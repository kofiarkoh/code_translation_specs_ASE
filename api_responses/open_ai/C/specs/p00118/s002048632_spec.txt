1. **Functional Description**  
The program processes a grid representing a farm, where each cell contains a character. It identifies and counts distinct contiguous regions of the same character, marking them in the grid. The program continues to process multiple grids until a termination condition is met.

2. **Inputs**  
The program reads multiple pairs of integers representing the height and width of the grid, followed by the grid itself, which consists of characters. The input terminates when both height and width are zero.

3. **Outputs**  
The program outputs the count of distinct contiguous regions of the same character for each grid processed.

4. **Preconditions**  
The input grid dimensions must be positive integers, and the grid must be filled with valid characters. The maximum dimensions of the grid are constrained by a predefined constant.

5. **Postconditions**  
After processing each grid, the program guarantees that the output reflects the total number of distinct contiguous regions of the same character, with the grid modified to mark processed regions.

6. **Invariants**  
Throughout the execution, the grid remains within the defined dimensions, and the count of regions accurately reflects the number of distinct contiguous areas identified up to that point.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or out-of-bounds errors explicitly. It assumes that the input will always conform to the expected structure.

8. **State Transitions (if applicable)**  
The program transitions between states based on the input of grid dimensions and the subsequent processing of the grid, moving from an unprocessed state to a processed state for each contiguous region identified.

9. **Non-functional Constraints (if inferable)**  
The program operates within a fixed memory limit defined by the maximum grid size and is expected to run in a reasonable time frame for typical input sizes. Performance may degrade with larger grids due to the nature of the region counting algorithm.
