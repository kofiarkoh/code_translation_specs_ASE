1. **Functional Description**  
The code identifies all prime numbers up to a specified maximum value and counts the number of prime numbers less than or equal to a given input value.

2. **Inputs**  
The program reads integer values from standard input until the end of input is reached.

3. **Outputs**  
The program outputs the count of prime numbers less than or equal to each input value, one count per line.

4. **Preconditions**  
The input values must be non-negative integers. The maximum input value must not exceed the defined limit.

5. **Postconditions**  
For each input value, the output will accurately reflect the number of prime numbers that are less than or equal to that value.

6. **Invariants**  
The array used to store prime number indicators remains consistent throughout the execution, ensuring that once a number is marked as non-prime, it remains so.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input or errors related to input reading. It assumes that all inputs are valid integers.

8. **State Transitions (if applicable)**  
The state transitions occur when the program processes each input value, updating the count of primes based on the precomputed prime indicators.

9. **Non-functional Constraints (if inferable)**  
The program operates within a fixed memory limit defined by the maximum size for prime number storage. Performance is influenced by the efficiency of the prime number generation algorithm.
