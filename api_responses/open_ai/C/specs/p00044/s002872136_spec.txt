1. **Functional Description**  
The program identifies and outputs the nearest prime numbers surrounding a given input value. It generates a list of prime numbers up to a specified limit and responds to multiple input queries by providing the closest primes.

2. **Inputs**  
The program reads integer values from standard input until the end of input is reached.

3. **Outputs**  
For each input value, the program outputs two integers: the largest prime number less than or equal to the input and the smallest prime number greater than the input.

4. **Preconditions**  
The input values must be non-negative integers. The program assumes that the input values are within the range of generated prime numbers.

5. **Postconditions**  
For each input value, the output consists of two prime numbers that satisfy the conditions of being the nearest primes surrounding the input.

6. **Invariants**  
The list of prime numbers is maintained in a sorted order, and the program guarantees that the primes are correctly identified and stored up to the specified limit.

7. **Error Handling / Exceptional Behavior**  
If the input is not an integer or if the end of input is reached unexpectedly, the program will terminate without producing output for that input. The program does not handle negative inputs or inputs exceeding the range of generated primes.

8. **State Transitions (if applicable)**  
The program transitions between states of reading input, processing the input to find surrounding primes, and outputting the results. Each input read triggers a search in the list of primes.

9. **Non-functional Constraints (if inferable)**  
The program is designed to handle multiple input queries efficiently, with a focus on performance in prime number generation and retrieval. The maximum number of primes generated is capped at a predefined limit.
