1. **Functional Description**  
The program processes pairs of integers representing edges in a graph and determines if the graph can be classified as having an Eulerian path or circuit based on the degree of its vertices.

2. **Inputs**  
The program reads pairs of integers from standard input until it encounters the end of input or a pair of zeros. Each pair represents a directed edge from the first integer to the second.

3. **Outputs**  
The program outputs "OK" if the graph has either an Eulerian circuit or an Eulerian path, and "NG" otherwise. This output occurs after processing each set of edges.

4. **Preconditions**  
The input must consist of pairs of integers, where each integer is in the range of 1 to 100, and the input terminates with a pair of zeros or end of input.

5. **Postconditions**  
After processing the input, the program guarantees that it will output either "OK" or "NG" based on the degree of the vertices in the graph.

6. **Invariants**  
Throughout the execution, the degree of each vertex is maintained in an array, where an uninitialized vertex has a degree of -1. The program ensures that the degree of each vertex is updated correctly with each input pair.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or values outside the specified range. It assumes that input will be correctly formatted as pairs of integers.

8. **State Transitions (if applicable)**  
The program transitions between states based on the input pairs read. Each valid pair updates the state of the graph's vertex degrees, and the program can transition to outputting results based on the final state of the graph.

9. **Non-functional Constraints (if inferable)**  
The program operates within a fixed memory constraint for the graph representation, limited to 101 vertices. Performance is not explicitly constrained but is dependent on the number of input pairs processed.
