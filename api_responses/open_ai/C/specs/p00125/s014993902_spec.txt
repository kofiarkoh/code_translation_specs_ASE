1. **Functional Description**  
The program calculates the number of days between two specified dates and outputs the result. It continues to process pairs of dates until a termination condition is met.

2. **Inputs**  
The program reads pairs of dates consisting of two years, two months, and two days from standard input. Each date is provided in the format: year1, month1, day1, year2, month2, day2.

3. **Outputs**  
The program outputs the number of days between the two dates as an integer value to standard output. Each result is printed on a new line.

4. **Preconditions**  
The input dates must be valid calendar dates. The program assumes that the input will be provided in the correct format and that the values for months and days are within valid ranges for the specified years.

5. **Postconditions**  
The program guarantees that for each valid pair of dates provided, the output will be the integer number of days between the two dates. If the termination condition is met, the program will cease further processing.

6. **Invariants**  
The program maintains that the input values for year, month, and day must be non-negative integers, and the months must be in the range of 1 to 12. The program will not process dates if any of the input values are -1.

7. **Error Handling / Exceptional Behavior**  
If any of the input values for the dates are -1, the program will terminate without processing further input. The program does not handle invalid date formats or out-of-range values explicitly; such cases may lead to undefined behavior.

8. **State Transitions (if applicable)**  
The program transitions between states of reading input, processing date calculations, and outputting results. It remains in a loop until the termination condition is met.

9. **Non-functional Constraints (if inferable)**  
The program is expected to operate in a continuous loop until termination, with each calculation performed in constant time relative to the input size. The output is expected to be produced promptly after each input pair is processed.
