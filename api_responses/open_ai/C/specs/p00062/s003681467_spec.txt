1. **Functional Description**  
The program processes a sequence of numeric strings, each containing up to 10 digits. For each string, it computes a single-digit result based on a specific reduction algorithm and outputs the results sequentially.

2. **Inputs**  
The program reads multiple strings of digits from standard input until the end of input is reached. Each string can contain up to 10 characters, representing digits.

3. **Outputs**  
The program outputs a sequence of integers, each representing the computed result for the corresponding input string. Each result is printed on a new line.

4. **Preconditions**  
Each input string must consist solely of numeric characters ('0' to '9') and must not exceed 10 characters in length. The input ends when an end-of-file condition is encountered.

5. **Postconditions**  
For each valid input string, the program guarantees that an integer result is produced and printed. The result is derived from the input string through a reduction process that combines adjacent digits.

6. **Invariants**  
The program maintains that the output for each input string is a single-digit integer derived from the reduction of the input string. The sequence of outputs corresponds directly to the sequence of inputs.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or characters. If an invalid input is encountered, the behavior is undefined. The program terminates gracefully upon reaching the end of input.

8. **State Transitions (if applicable)**  
The program transitions from reading input to processing each string and finally to outputting results. The state changes occur upon reading a new string, completing the reduction process, and printing the result.

9. **Non-functional Constraints (if inferable)**  
The program is designed to handle up to 10,000 input strings efficiently, with each string processed in a fixed number of operations based on its length. The output is generated in a sequential manner, ensuring that results are printed in the order of input.
