1. **Functional Description**  
   The program reads multiple sets of data, each consisting of a name and three integer values. It calculates a weighted score based on the integer values, sorts the data by this score in descending order, and outputs the sorted names along with their corresponding scores.

2. **Inputs**  
   - An integer `n` indicating the number of data entries to process.
   - For each entry, a string (name) and three integers.

3. **Outputs**  
   - For each set of data, the program outputs the names and their corresponding scores in descending order, separated by commas. Each set of output is separated by a newline.

4. **Preconditions**  
   - The input integer `n` must be non-negative.
   - Each name must not exceed a specified length.
   - The three integers must be valid integers.

5. **Postconditions**  
   - The output consists of sorted names and scores for each set of data, formatted correctly.
   - The program terminates after processing all input sets.

6. **Invariants**  
   - The scores are consistently calculated using the specified weights for the three integer values.
   - The sorting mechanism maintains the integrity of the name-score pairs throughout the sorting process.

7. **Error Handling / Exceptional Behavior**  
   - If the input for `n` is zero, the program terminates without processing any data.
   - If invalid input is provided (e.g., non-integer values for the integers), behavior is not defined.

8. **State Transitions (if applicable)**  
   - The program transitions between states based on the input value of `n`, processing data sets until `n` is zero.

9. **Non-functional Constraints (if inferable)**  
   - The program must handle a maximum of 20 names and their associated data in a single execution.  
   - The sorting operation must complete in a reasonable time for the maximum input size.
