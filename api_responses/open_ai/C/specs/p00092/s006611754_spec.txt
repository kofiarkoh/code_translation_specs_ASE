1. **Functional Description**  
The program processes a grid representation of a map to determine the maximum length of consecutive non-obstacle cells in any column, returning this maximum length for each input map until a termination condition is met.

2. **Inputs**  
The program reads multiple maps from standard input, where each map consists of a size followed by a grid of characters representing obstacles and free cells. The size is a positive integer, and the grid contains characters, with '*' representing obstacles and other characters representing free cells.

3. **Outputs**  
The program outputs the maximum length of consecutive non-obstacle cells for each map, printed as an integer on a new line. The output terminates when a map size of zero is encountered.

4. **Preconditions**  
- The input must start with a positive integer representing the size of the map.
- The subsequent lines must contain valid characters for the grid, matching the specified size.

5. **Postconditions**  
- For each valid map input, the program outputs a single integer representing the maximum length of consecutive non-obstacle cells in any column.
- The program terminates gracefully upon receiving a map size of zero.

6. **Invariants**  
- The grid representation is maintained throughout the processing of each map.
- The maximum length of consecutive non-obstacle cells is updated correctly based on the processed data.

7. **Error Handling / Exceptional Behavior**  
- If the input size is zero, the program exits without processing further input.
- The program does not handle malformed input or unexpected characters in the grid.

8. **State Transitions (if applicable)**  
- The program transitions from reading input to processing the map and then to outputting results, repeating this cycle until a termination condition is met.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a fixed memory limit for the grid size, specifically accommodating maps of size up to 1000x1000.  
- The performance is influenced by the size of the input map, with a complexity that involves iterating through the grid and performing binary search operations.
