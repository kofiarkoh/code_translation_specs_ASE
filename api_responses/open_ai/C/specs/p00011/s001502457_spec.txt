1. **Functional Description**  
The program initializes a list of integers from 1 to a specified width, then performs a series of swaps between specified pairs of elements in that list, and finally outputs the modified list.

2. **Inputs**  
- An integer representing the width of the list.  
- An integer representing the number of swap operations.  
- A series of pairs of integers indicating the indices of the elements to be swapped.

3. **Outputs**  
- A list of integers, each printed on a new line, representing the final state of the list after all specified swaps.

4. **Preconditions**  
- The width must be a positive integer.  
- The number of swap operations must be a non-negative integer.  
- Each index specified for swapping must be within the range of the list (1 to width).

5. **Postconditions**  
- The output list reflects the initial sequence of integers from 1 to width, modified by the specified swaps.

6. **Invariants**  
- The list always contains integers from 1 to width, though their order may change due to swaps.  
- The indices used for swaps are valid and within the defined range.

7. **Error Handling / Exceptional Behavior**  
- If the input for width or number of swaps is invalid (e.g., negative), the behavior is not defined.  
- If any swap indices are out of bounds, the behavior is not defined.

8. **State Transitions (if applicable)**  
- The initial state is a list of integers from 1 to width.  
- Each swap operation modifies the state of the list by exchanging the values at the specified indices.  
- The final state is the modified list after all swaps have been applied.

9. **Non-functional Constraints (if inferable)**  
- The program assumes that the input is provided in a valid format and within reasonable limits for processing.  
- The output is generated sequentially, with each integer printed on a new line.
