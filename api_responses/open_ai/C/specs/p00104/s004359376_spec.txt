1. **Functional Description**  
The program processes a grid of tiles, where each tile can represent a direction or a special character. It navigates through the grid based on the tile values, updating a data structure to track visits and printing coordinates of specific tiles.

2. **Inputs**  
- Two integers representing the height and width of the grid.  
- A grid of characters representing tile types, read from standard input.

3. **Outputs**  
- Prints the coordinates of tiles that are marked with a dot.  
- Prints "LOOP" if a tile is revisited during navigation.

4. **Preconditions**  
- The height and width of the grid must be positive integers.  
- The grid must be initialized with valid tile characters.

5. **Postconditions**  
- The program terminates after processing the grid, having printed coordinates or "LOOP" as applicable.  
- The data structure tracking visits is updated according to the navigation rules.

6. **Invariants**  
- The data structure maintains a count of visits for each tile.  
- The navigation only occurs within the bounds of the grid.

7. **Error Handling / Exceptional Behavior**  
- If the height and width are both zero, the program terminates without further processing.  
- No explicit error handling for invalid tile characters or out-of-bounds navigation is defined.

8. **State Transitions (if applicable)**  
- The state transitions occur as the program navigates through the grid based on tile values, updating the position and the visit count accordingly.

9. **Non-functional Constraints (if inferable)**  
- The program assumes that the grid size does not exceed predefined limits.  
- Performance is not explicitly constrained but may be affected by the grid size and complexity of tile navigation.
