1. **Functional Description**  
The program categorizes a given weight into predefined weight classes and outputs the corresponding class name.

2. **Inputs**  
The program reads a sequence of double-precision floating-point values representing weights from standard input until the end of input is reached.

3. **Outputs**  
The program outputs the name of the weight class corresponding to each input weight, followed by a newline character.

4. **Preconditions**  
The input must consist of valid double-precision floating-point values. The program assumes that the input will terminate with an end-of-file signal.

5. **Postconditions**  
For each input weight, the program guarantees that a corresponding weight class name is outputted. The output is consistent with the defined weight ranges.

6. **Invariants**  
The weight class names are consistently mapped to their respective weight ranges throughout the execution of the program.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or non-numeric values. If such values are encountered, the behavior is not defined.

8. **State Transitions (if applicable)**  
The program transitions from reading input to outputting a weight class for each valid weight read until the end of input is reached.

9. **Non-functional Constraints (if inferable)**  
The program operates in a continuous loop until the end of input, and each output operation is performed immediately after reading a valid input weight.
