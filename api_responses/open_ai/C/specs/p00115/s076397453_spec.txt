1. Functional Description
   - High-level description:
     - Reads five 3D points (each with x,y,z coordinates) from standard input, solves a linear system to determine intersection parameters, and prints either "HIT" or "MISS" (followed by newline) to standard output.
   - What problem it solves:
     - Determines whether the parametric line from point "me" toward point "enemy" intersects the triangle defined by points p1, p2, p3 under specific numeric tolerance rules.
   - Core behavior:
     - Constructs the linear system that expresses the equality me + x*(enemy - me) = p1 + y*(p2 - p1) + z*(p3 - p1).
     - Solves the 3x3 linear system for unknowns x, y, z using Gaussian elimination with partial pivoting.
     - Applies numeric tolerance checks (EPS = 1e-7) and bounds on x, y, z to decide which of two literal strings to print:
       - Print "HIT\n" when the linear system is singular (no unique solution), or when x < EPS, or x > 1.0 + EPS, or y < -EPS, or z < -EPS, or y+z > 1.0 + EPS.
       - Otherwise print "MISS\n".
     - Exit with process return code 0.

2. Inputs
   - Parameters:
     - No function parameters (program uses stdin).
     - Expects 5 points in this order: me, enemy, p1, p2, p3.
     - Each point is represented by three whitespace-separated double-precision floating-point numbers (x y z).
   - Data types:
     - All coordinates are double (IEEE-754 double assumed).
   - Valid ranges or constraints:
     - Numeric ranges: not explicitly constrained in code (must fit in double).
     - For meaningful geometric interpretation, the vectors (enemy-me), (p2-p1), (p3-p1) should not make the coefficient matrix singular; if they do, program treats it as the singular case (see Outputs / Error Handling).
   - Assumptions about inputs:
     - Exactly 15 double values are provided and parseable by scanf (the code does not check return value of scanf).
     - Points are provided in the specified order and coordinate system.

3. Outputs
   - Return values:
     - Process exit code: 0 (the program always returns 0 on normal completion).
   - Side effects:
     - A single line is written to stdout: either "HIT" or "MISS" followed by a newline.
   - Output decision schema:
     - Let EPS = 1e-7.
     - Solve for x, y, z in me + x*(enemy-me) = p1 + y*(p2-p1) + z*(p3-p1).
     - If the linear system is singular (no unique solution) OR any of these conditions hold:
       - x < EPS
       - x > 1.0 + EPS
       - y < -EPS
       - z < -EPS
       - y + z > 1.0 + EPS
       then output "HIT".
     - Otherwise output "MISS".
