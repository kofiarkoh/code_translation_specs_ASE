1. **Functional Description**  
The program determines whether a specified range of x-coordinates overlaps with a specified range of y-coordinates based on input values. It outputs a confirmation of overlap for each set of inputs.

2. **Inputs**  
The program reads multiple sets of eight double-precision floating-point numbers representing four pairs of coordinates (x[0], y[0], x[1], y[1], x[2], y[2], x[3], y[3]).

3. **Outputs**  
For each set of inputs, the program outputs either "YES" or "NO" to indicate whether there is an overlap between the specified ranges.

4. **Preconditions**  
The input must consist of valid double-precision floating-point numbers. The program continues to read inputs until the end of the input stream is reached.

5. **Postconditions**  
After processing the input, the program guarantees that it will output "YES" if there is an overlap between the specified ranges, and "NO" otherwise.

The program maintains the integrity of the input data throughout its execution, ensuring that all comparisons are made with the most recent set of coordinates read.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or types. It assumes that the input will always be valid double-precision numbers until the end of the input stream.

The program transitions between states based on the reading of input values and the evaluation of conditions for overlap, producing outputs accordingly.
