1. **Functional Description**  
The code computes the minimum cost to achieve specific values based on predefined combinations of quantities and costs, storing these costs in a lookup table for efficient retrieval.

2. **Inputs**  
The program reads integer values from standard input, representing target values for which the minimum cost is to be determined.

3. **Outputs**  
The program outputs the minimum cost associated with each input value, or zero if the value is not achievable, to standard output.

4. **Preconditions**  
The input values must be non-negative integers. The program expects input values to be in multiples of 100.

5. **Postconditions**  
For each input value, the program guarantees that the output reflects the minimum cost to achieve that value, or zero if it is not possible to achieve the value.

6. **Invariants**  
The lookup table maintains the minimum cost for each achievable value up to 50, ensuring that no value is stored with a cost greater than necessary.

If the input is zero, the program terminates gracefully. Invalid inputs (e.g., negative values) are not explicitly handled and may lead to undefined behavior.

The state transitions occur as the program processes each input value, updating the lookup table based on the combinations calculated during the execution of the combination function.
