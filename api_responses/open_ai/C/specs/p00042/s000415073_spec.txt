1. **Functional Description**  
The program computes the maximum value of coins that can be carried given a weight limit and a set of coins with associated weights. It processes multiple test cases until a termination condition is met.

2. **Inputs**  
- A series of test cases, each consisting of:
  - An integer representing the weight limit (W).
  - An integer representing the number of coin types (N).
  - For each coin type, a pair of integers representing the coin value and its weight.

3. **Outputs**  
- For each test case, the program outputs:
  - The case number.
  - The maximum value of coins that can be carried.
  - The total weight of the coins that yield this maximum value.

4. **Preconditions**  
- The weight limit (W) and the number of coin types (N) must be non-negative integers.
- The input for coin values and weights must be valid integers.

5. **Postconditions**  
- The program guarantees that the maximum value of coins and the corresponding weight are correctly calculated and displayed for each test case.

6. **Invariants**  
- The dynamic programming table maintains valid states throughout the computation, ensuring that each entry reflects the maximum coin value achievable for a given weight.

7. **Error Handling / Exceptional Behavior**  
- The program terminates gracefully when a weight limit of zero is encountered, indicating no further test cases will be processed.

8. **State Transitions (if applicable)**  
- The program transitions between states based on the input of weight limits and coin types, updating the dynamic programming table accordingly for each test case.

9. **Non-functional Constraints (if inferable)**  
- The program is expected to handle multiple test cases efficiently, with performance constraints implied by the size of the dynamic programming table and the number of iterations based on the input values.
