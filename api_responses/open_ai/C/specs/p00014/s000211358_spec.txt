1. Functional Description  
Calculates and outputs the weighted sum of squares of multiples of a given integer within a specified range.

2. Inputs  
Reads integer values from standard input until the end of input is reached.

3. Outputs  
Returns the computed weighted sum of squares for each input integer, printed to standard output.

4. Preconditions  
The input must consist of valid integer values. Each integer must be positive and within a reasonable range to avoid overflow.

5. Postconditions  
For each input integer, the output is the product of the integer and the sum of the squares of its multiples within the range from the integer to 600.

6. Invariants  
The computed sum is always non-negative as it is derived from the squares of integers multiplied by a positive integer.

7. Error Handling / Exceptional Behavior  
If the input is not a valid integer, the behavior is not defined. The program continues to read until EOF, ignoring invalid inputs.

8. State Transitions (if applicable)  
The program transitions from reading input to computing the sum and then to outputting the result for each valid input until EOF is reached.

9. Non-functional Constraints (if inferable)  
The program must handle multiple inputs efficiently and produce outputs in a timely manner, with a focus on maintaining accuracy in calculations.
