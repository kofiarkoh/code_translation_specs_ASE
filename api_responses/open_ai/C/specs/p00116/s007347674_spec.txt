1. **Functional Description**  
The program computes the maximum area of a rectangle composed entirely of '.' characters in a grid defined by height and width, where each cell can either be '.' or another character.

2. **Inputs**  
The program reads multiple pairs of integers representing the height and width of the grid, followed by the grid itself, which consists of characters.

3. **Outputs**  
The program outputs the maximum area of rectangles formed by '.' characters for each grid input.

4. **Preconditions**  
The input must consist of valid integers for height and width, followed by a grid of characters of the specified dimensions. The grid must contain at least one character.

5. **Postconditions**  
The output is a non-negative integer representing the maximum area of rectangles formed by '.' characters for each grid input.

6. **Invariants**  
Throughout the execution, the program maintains the integrity of the grid dimensions and the character data, ensuring that calculations for the maximum area are based on valid grid entries.

7. **Error Handling / Exceptional Behavior**  
If the input does not conform to the expected format (e.g., invalid integers or insufficient characters), the program's behavior is not defined. It assumes well-formed input.

8. **State Transitions (if applicable)**  
The program transitions between states based on the input of new grid dimensions and the subsequent processing of the grid data, culminating in the output of the maximum area.

9. **Non-functional Constraints (if inferable)**  
The program is expected to handle grids of size up to 700x700 efficiently, with performance dependent on the dimensions of the input grid.
