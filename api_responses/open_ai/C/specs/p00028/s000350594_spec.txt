1. **Functional Description**  
The program reads a sequence of integers from standard input, counts the occurrences of each integer within a specified range, identifies the maximum integer that has the highest frequency, and outputs all integers that share this maximum frequency.

2. **Inputs**  
The program reads a sequence of integers, where each integer is expected to be in the range from 1 to 100. Input terminates when the end-of-file (EOF) is reached.

3. **Outputs**  
The program outputs all integers that have the highest frequency of occurrence, each on a new line. The output is produced only if there are integers present in the input.

4. **Preconditions**  
The input must consist of integers within the range of 1 to 100. The program assumes that at least one valid integer is provided before EOF.

5. **Postconditions**  
The program guarantees that if valid integers are provided, it will output all integers that have the highest frequency. If no valid integers are provided, no output will occur.

6. **Invariants**  
Throughout execution, the count of each integer from 1 to 100 is maintained accurately in a dedicated array. The maximum frequency and corresponding integer(s) are updated correctly based on the input received.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input (e.g., integers outside the range of 1 to 100 or non-integer values). It will not produce output if no valid integers are read.

8. **State Transitions (if applicable)**  
The program transitions from an initial state of zero counts for all integers to a final state where the counts are updated based on the input, and the maximum frequency integers are identified and output.

9. **Non-functional Constraints (if inferable)**  
The program operates within a fixed memory constraint for counting occurrences, limited to 101 integer slots. Performance is dependent on the number of integers read, with a linear relationship to the input size.
