3. **Outputs**  
The program outputs six lines, each starting with a label followed by a number of asterisks corresponding to the count of heights in each defined range.

The program guarantees that the output will reflect the counts of heights in the specified ranges, with each range represented by a line of asterisks.

The total count of heights processed will equal the integer input value. The counts for each range will be non-negative integers.
