1. **Functional Description**  
The program reads a series of integers from standard input, converts each integer from decimal to octal representation, applies specific transformations to the octal digits, and outputs the modified octal representation until a sentinel value is encountered.

2. **Inputs**  
The program accepts a sequence of integers from standard input, terminating when a zero is entered.

3. **Outputs**  
The program outputs the transformed octal representation of each input integer, printed line by line.

4. **Preconditions**  
The input integers must be non-negative. The program expects at least one integer input before the sentinel value.

5. **Postconditions**  
For each input integer (except the sentinel), the output is the octal representation with the following transformations applied:  
- If any octal digit is greater than 3, it is incremented by 1.  
- If any octal digit is greater than 5 after the first transformation, it is incremented by 1 again.  
The output is printed in reverse order of the octal digits.

6. **Invariants**  
The program maintains an array of octal digits that is initialized to zero and is populated with the octal representation of the input integer. The array is guaranteed to have a terminating zero after the last valid octal digit.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input types or negative integers. It assumes all inputs are valid integers. If a non-integer is entered, behavior is not defined.

8. **State Transitions (if applicable)**  
The program transitions between states based on input:  
- From waiting for input to processing input upon receiving a non-zero integer.  
- From processing input to outputting results after transforming the octal representation.  
- From outputting results back to waiting for input upon encountering the sentinel value.

9. **Non-functional Constraints (if inferable)**  
The program operates within a fixed memory limit for storing octal digits, specifically an array of size 200. The output is generated in a sequential manner, with each result printed immediately after processing an input integer.
