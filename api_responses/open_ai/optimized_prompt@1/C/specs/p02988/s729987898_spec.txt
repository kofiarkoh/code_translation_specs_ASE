1. **Functional Description**  
   The program counts the number of times a sequence of three consecutive integers in an input list is either strictly increasing or strictly decreasing.

2. **Inputs**  
   The program reads an integer representing the number of subsequent integers, followed by that many integers.

3. **Outputs**  
   The program outputs a single integer representing the count of strictly increasing or strictly decreasing sequences of three consecutive integers.

4. **Preconditions**  
   The input integer must be greater than or equal to 3 to form at least one sequence of three integers.

5. **Postconditions**  
   The output integer reflects the total count of valid sequences found in the input list.

6. **Invariants**  
   The count of sequences is non-negative and is incremented only when a valid sequence is identified.

7. **Error Handling / Exceptional Behavior**  
   If the input integer is less than 3, the program does not perform any counting and outputs zero.

8. **State Transitions (if applicable)**  
   The program transitions from an initial state of zero sequences counted to a final state reflecting the total count after processing the input.

9. **Non-functional Constraints (if inferable)**  
   The program operates within a fixed memory limit for storing input integers, specifically accommodating up to 1000 integers.
