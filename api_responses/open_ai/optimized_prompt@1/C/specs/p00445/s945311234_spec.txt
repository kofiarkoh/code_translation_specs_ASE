1. **Functional Description**  
The program counts occurrences of the substrings "JOI" and "IOI" within input strings and outputs these counts.

2. **Inputs**  
The program reads multiple strings from standard input until the end of input is reached.

3. **Outputs**  
For each input string, the program outputs two integers: the count of occurrences of "JOI" and the count of occurrences of "IOI", each on a new line.

4. **Preconditions**  
The input strings must be composed of characters that can be processed by the program and must not exceed a length of 10,000 characters.

5. **Postconditions**  
After processing each input string, the program guarantees that the counts of "JOI" and "IOI" are accurately computed and printed.

6. **Invariants**  
The counts of "JOI" and "IOI" are non-negative integers throughout the execution of the program.

7. **Error Handling / Exceptional Behavior**  
The program does not handle malformed input or errors in reading input; it assumes valid input until EOF.

8. **State Transitions (if applicable)**  
The program transitions from reading input to counting occurrences and then to outputting results for each string until EOF is reached.

9. **Non-functional Constraints (if inferable)**  
The program operates within a time complexity that is linear with respect to the length of the input strings, and it uses a fixed amount of memory for the input buffer.
