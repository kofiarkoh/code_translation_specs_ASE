1. **Functional Description**  
The code generates a table of prime numbers up to a specified maximum and counts the number of distinct pairs of prime numbers that sum to a given input value.

2. **Inputs**  
The program reads integer values from standard input until a zero is encountered. Each integer represents a target sum for which pairs of prime numbers are to be counted.

3. **Outputs**  
The program outputs the count of distinct pairs of prime numbers that sum to each input value, one count per line.

4. **Preconditions**  
The input values must be non-negative integers. The maximum input value must not exceed the defined limit.

5. **Postconditions**  
For each input value, the output will reflect the number of distinct pairs of prime numbers that sum to that value, or no output if the input is zero.

6. **Invariants**  
The prime table remains consistent throughout the execution, accurately reflecting the primality of numbers up to the maximum limit.

7. **Error Handling / Exceptional Behavior**  
If the input is not a valid integer, the program will not produce output for that input. The program terminates gracefully upon receiving a zero.

8. **State Transitions (if applicable)**  
The state transitions occur when reading input values and updating the count of prime pairs based on the current input.

9. **Non-functional Constraints (if inferable)**  
The program operates within a fixed memory limit defined by the maximum size of the prime table. Performance is constrained by the efficiency of the prime generation and counting algorithm.
