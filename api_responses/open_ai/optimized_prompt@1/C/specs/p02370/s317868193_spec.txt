1. **Functional Description**  
The code implements a topological sorting algorithm for a directed graph, ensuring that for every directed edge from vertex A to vertex B, vertex A appears before vertex B in the output.

2. **Inputs**  
The program reads two integers representing the number of vertices and edges in the graph, followed by pairs of integers representing directed edges between vertices.

3. **Outputs**  
The program outputs the vertices of the graph in a topologically sorted order, each on a new line.

4. **Preconditions**  
The input must consist of valid integers for the number of vertices and edges, followed by valid pairs of integers representing directed edges. The graph must not contain cycles.

5. **Postconditions**  
The output will list all vertices in a valid topological order if the graph is acyclic. If the graph contains cycles, the behavior is undefined.

6. **Invariants**  
Throughout the execution, the count of incoming edges for each vertex is maintained accurately, ensuring that vertices are only processed when all their dependencies have been resolved.

7. **Error Handling / Exceptional Behavior**  
If the input does not conform to the expected format or if the graph contains cycles, the program may produce incorrect output or behave unexpectedly. No explicit error handling is implemented.

8. **State Transitions (if applicable)**  
The state transitions occur as vertices are processed and removed from the queue, updating the counts of incoming edges for adjacent vertices and adding them to the queue when their dependencies are resolved.

The program is constrained by memory usage due to the allocation of arrays based on the number of vertices and edges, and it operates within a time complexity that is linear with respect to the number of vertices and edges.
