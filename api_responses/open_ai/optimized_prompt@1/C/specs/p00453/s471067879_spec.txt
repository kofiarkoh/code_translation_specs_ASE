1. **Functional Description**  
The program computes the minimum cost to traverse a series of points defined by their coordinates and associated weights, based on user-defined input. It processes multiple datasets until a termination condition is met.

2. **Inputs**  
The program reads multiple datasets, each consisting of:  
- Two integers, `n` and `m`, where `n` is the number of point sets and `m` is the maximum number of transitions allowed.  
- For each point set, an integer indicating the number of points followed by pairs of integers representing the coordinates and weights of each point.

3. **Outputs**  
The program outputs the minimum traversal cost for each dataset, printed as a single integer.

4. **Preconditions**  
- The input must contain valid integers for `n` and `m`, where `n` and `m` are non-negative.  
- Each point set must have a valid number of points, and each point must have valid coordinate and weight values.

5. **Postconditions**  
- The output is the minimum cost calculated based on the provided points and their weights for each dataset.  
- The program terminates when a dataset with `n` and `m` both equal to zero is encountered.

6. **Invariants**  
- The cost array is initialized to a high value, ensuring that any valid cost computed will be lower.  
- The minimum cost is updated only if a lower cost is found during the traversal calculations.

7. **Error Handling / Exceptional Behavior**  
- The program does not explicitly handle invalid input formats or values. It assumes that the input adheres to the expected structure and constraints.  
- If the input is malformed or out of expected bounds, behavior is not defined.

8. **State Transitions (if applicable)**  
- The program transitions between states based on the input datasets, recalculating costs and updating the cost array for each dataset until termination conditions are met.
