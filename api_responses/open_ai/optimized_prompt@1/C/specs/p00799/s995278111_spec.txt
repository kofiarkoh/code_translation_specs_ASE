1. **Functional Description**  
The program simulates a battery management system that tracks the usage and recharge cycles of multiple batteries over a specified time limit. It calculates and outputs the total number of times batteries are used without being recharged within the given time frame.

2. **Inputs**  
- A series of test cases, each consisting of:
  - An integer representing the number of batteries.
  - An integer representing the time limit.
  - For each battery, a sequence of positive integers representing usage times followed by corresponding recharge times.

3. **Outputs**  
- For each test case, an integer representing the total number of battery usages that occurred without a corresponding recharge within the specified time limit.

4. **Preconditions**  
- The number of batteries must be a positive integer.
- The time limit must be a positive integer.
- Each battery must have at least one usage and recharge time specified.

5. **Postconditions**  
- The output integer reflects the total count of battery usages without recharge for each test case processed.

6. **Invariants**  
- The state of each battery (active or inactive) is maintained throughout the simulation.
- The queue structure used for managing battery recharges remains consistent and correctly reflects the order of battery usage.

7. **Error Handling / Exceptional Behavior**  
- If the input does not conform to the expected format (e.g., non-integer values), the program may exhibit undefined behavior. 
- The program terminates gracefully when a non-positive integer is encountered for the number of batteries.

8. **State Transitions (if applicable)**  
- Each battery transitions between active and inactive states based on its remaining usage time.
- The queue transitions as batteries are recharged and become available for use again.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a fixed memory limit defined by the maximum queue size.
- The execution time is dependent on the number of batteries and the time limit, with performance implications for larger inputs.
