1. **Functional Description**  
The program counts the number of unique combinations of three distinct integers from the range 1 to n that sum to a specified value x. It continues to process input until a termination condition is met.

2. **Inputs**  
The program reads pairs of integers, n and x, from standard input. The first integer, n, defines the range of integers (1 to n), and the second integer, x, is the target sum.

3. **Outputs**  
The program outputs the count of unique combinations of three distinct integers that sum to x, divided by 6, to standard output. Each result is printed on a new line.

4. **Preconditions**  
The input values for n and x must be integers. The program assumes that n is a non-negative integer.

5. **Postconditions**  
For each valid input pair (n, x), the program outputs a non-negative integer representing the number of unique combinations of three distinct integers that sum to x, or zero if no such combinations exist.

6. **Invariants**  
During execution, the program maintains that the integers considered for combinations are always distinct and within the range from 1 to n.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or values outside the expected range. If n and x are both zero, the program terminates without further processing.

8. **State Transitions (if applicable)**  
The program transitions between states based on the input pairs read. It processes each pair until the termination condition (n = 0 and x = 0) is met.

9. **Non-functional Constraints (if inferable)**  
The program operates in a loop until termination, and the time complexity is dependent on the cubic relationship with n, as it evaluates combinations of three integers. The output is produced in a sequential manner, one result per input pair.
