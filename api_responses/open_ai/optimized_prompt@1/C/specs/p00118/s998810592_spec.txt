1. **Functional Description**  
The program identifies and counts distinct connected areas in a grid of characters, where connectivity is defined by adjacent cells containing the same character.

2. **Inputs**  
The program reads multiple pairs of integers representing the height and width of the grid, followed by the grid itself, which consists of characters.

3. **Outputs**  
The program outputs the count of distinct connected areas for each grid input.

4. **Preconditions**  
The height and width of the grid must be non-negative integers. The grid must not exceed the dimensions of 128x128.

5. **Postconditions**  
The output will reflect the total number of distinct connected areas in the grid, where each area is defined by contiguous cells containing the same character.

6. **Invariants**  
The `area_id` array maintains a mapping of each cell to its corresponding area identifier throughout the execution. The `area_num` array tracks which area identifiers have been encountered.

7. **Error Handling / Exceptional Behavior**  
If the input height and width are both zero, the program terminates gracefully without further processing. No other error handling is specified for invalid inputs.

8. **State Transitions (if applicable)**  
The program transitions between states based on the input of grid dimensions and the subsequent reading of grid data, followed by the computation of connected areas.

9. **Non-functional Constraints (if inferable)**  
The program operates within a fixed memory limit defined by the maximum grid size of 128x128, ensuring efficient use of resources for the specified input size.
