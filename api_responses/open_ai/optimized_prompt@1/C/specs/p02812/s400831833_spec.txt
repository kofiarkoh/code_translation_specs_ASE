1. Functional Description  
Counts the number of non-overlapping occurrences of the substring "ABC" in a given string of characters.

2. Inputs  
- An integer representing the length of the string (n).  
- A string of characters with a maximum length of 50.

3. Outputs  
- An integer representing the count of non-overlapping occurrences of the substring "ABC".

4. Preconditions  
- The integer input must be greater than or equal to 3.  
- The string input must be null-terminated and contain at least n characters.

5. Postconditions  
- The output integer is non-negative and reflects the number of non-overlapping occurrences of "ABC" in the input string.

6. Invariants  
- The count of occurrences is incremented only when the substring "ABC" is found.  
- The loop iterates through the string without exceeding its bounds.

7. Error Handling / Exceptional Behavior  
- If the integer input is less than 3, the output will be 0, as no occurrences of "ABC" can exist.  
- If the string input is shorter than the specified length, behavior is not defined.

8. State Transitions (if applicable)  
- The state transitions occur as the count of occurrences is updated based on the detection of the substring "ABC".

9. Non-functional Constraints (if inferable)  
- The execution time is linear with respect to the length of the string.  
- Memory usage is constrained to the size of the input string and a fixed number of integer variables.
