1. **Functional Description**  
The program computes the minimum number of transitions required to move from a starting point marked by a specific character to the edges of a grid, where each transition is counted based on the character type encountered.

2. **Inputs**  
The program reads multiple grids defined by their width and height, followed by the grid contents, until a grid with both dimensions equal to zero is encountered.

3. **Outputs**  
The program outputs the minimum number of transitions required to reach any edge of the grid from the starting point for each grid input.

4. **Preconditions**  
- The width and height of the grid must be non-negative integers.
- The grid must contain at least one starting point marked by a specific character.

5. **Postconditions**  
- The output is a non-negative integer representing the minimum number of transitions for each grid processed.

6. **Invariants**  
- The grid remains unchanged throughout the execution.
- The transition count for each cell is updated based on the character type and the number of transitions from adjacent cells.

7. **Error Handling / Exceptional Behavior**  
- If the grid dimensions are zero, the program terminates without processing further input.
- If the grid does not contain the starting character, the behavior is not defined.

8. **State Transitions (if applicable)**  
- The state transitions occur as the program processes each cell in the grid, updating the transition counts based on adjacent cells and character comparisons.

9. **Non-functional Constraints (if inferable)**  
- The program operates within the constraints of a maximum grid size of 101x101.  
- The performance is influenced by the grid size, with a complexity that scales with the number of cells processed.
