1. **Functional Description**  
The program computes a numerical value based on the input parameters, which represent digits and their respective positions. It handles specific cases for zero digits and validates the consistency of input data.

2. **Inputs**  
- Two integers, N and M, where N represents the number of digits and M represents the number of specified digit-position pairs.  
- M pairs of integers, each consisting of a position and a corresponding digit value.

3. **Outputs**  
- Returns a computed integer value based on the input conditions.  
- If certain conditions are met, outputs "-1" as a string.

4. **Preconditions**  
- N must be a positive integer.  
- M must be a non-negative integer.  
- The positions specified in the M pairs must be valid indices within the range of 1 to N.

5. **Postconditions**  
- If M is zero, the output is determined solely by the value of N.  
- If M is greater than zero, the output is the sum of the computed digit values, or -1 if inconsistencies are detected in the input data.

6. **Invariants**  
- The digit array is initialized to -1 for all indices.  
- Each position can only be assigned a digit value once, and any attempt to assign a different value to the same position results in an inconsistency.

7. **Error Handling / Exceptional Behavior**  
- If M is zero and N is greater than 3, no output is generated for that case.  
- If the first position is specified as 1 with a digit value of 0, the output is "-1".

8. **State Transitions (if applicable)**  
- Transition from an initial state (uninitialized) to a state where digit values are assigned based on input pairs.  
- Transition to a final state where the output is determined based on the computed value or error conditions.

9. **Non-functional Constraints (if inferable)**  
- The program must handle input and output efficiently, ensuring that the output is produced in a timely manner based on the input size.  
- The program assumes valid input formats as per the specified constraints.
