1. **Functional Description**  
The program identifies pairs of prime numbers that satisfy specific multiplicative constraints based on user-provided input values.

2. **Inputs**  
The program reads three integer values: `m`, `a`, and `b`. Input continues until a termination condition is met, specifically when all three values are zero.

3. **Outputs**  
The program outputs pairs of integers representing prime numbers `p` and `q` that meet the specified conditions. If no valid pairs are found, the output will be `0 0`.

4. **Preconditions**  
The input values must be integers. The program assumes that the input will be provided in a valid format and that the values are within a reasonable range for processing.

5. **Postconditions**  
For each set of inputs, the program guarantees that the output consists of two integers `p` and `q` such that:
- `p` and `q` are prime numbers.
- The product `p * q` is less than or equal to `m`.
- The product `a * q` is less than or equal to `p * b`.
If no such pair exists, the output will be `0 0`.

6. **Invariants**  
Throughout the execution, the following invariants hold:
- The array of prime numbers is correctly populated and sorted.
- The values of `p` and `q` are updated only when a valid pair is found that maximizes the product `p * q`.

7. **Error Handling / Exceptional Behavior**  
The program does not explicitly handle erroneous input formats or out-of-range values. It assumes valid input is provided. If invalid input is encountered, behavior is not defined.

8. **State Transitions (if applicable)**  
The program transitions between states based on input reading and processing:
- Initial state: No primes identified.
- After processing input: State reflects the last valid pair of primes found or indicates no valid pairs.

9. **Non-functional Constraints (if inferable)**  
The program is expected to operate efficiently within the constraints of the input size, specifically handling up to 100,000 primes. Performance may degrade with larger values of `m`, `a`, and `b` due to the nested search for valid pairs.
