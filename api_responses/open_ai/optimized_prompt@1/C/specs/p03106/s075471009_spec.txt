1. **Functional Description**  
The program calculates the greatest common divisor (GCD) of two integers and counts how many common divisors exist up to that GCD. It returns the GCD if the count of common divisors matches a specified value.

2. **Inputs**  
Three integers are read: two integers for which the GCD is to be calculated, and a third integer that specifies the desired count of common divisors.

3. **Outputs**  
The program outputs the GCD of the two integers if the count of common divisors equals the specified value; otherwise, it does not output a valid GCD.

4. **Preconditions**  
The input integers must be non-negative. The third integer must be a non-negative integer representing the expected count of common divisors.

5. **Postconditions**  
If the count of common divisors equals the specified value, the output is the GCD of the two integers. If the count does not match, the output is undefined.

6. **Invariants**  
The program maintains that the GCD is always a divisor of both input integers. The count of common divisors is non-negative and cannot exceed the smaller of the two input integers.

7. **Error Handling / Exceptional Behavior**  
If the input values do not meet the preconditions (e.g., negative integers), the behavior is not defined. The program does not handle invalid input gracefully.

8. **State Transitions (if applicable)**  
The program transitions from an input state to an output state based on the evaluation of the common divisors and their count.

9. **Non-functional Constraints (if inferable)**  
The program operates in linear time relative to the smaller of the two input integers, as it iterates through potential divisors. The output is produced in a single operation after processing the inputs.
