1. **Functional Description**  
The program processes a grid defined by width and height, marking certain cells based on specific movement rules, and counts the number of cells that are adjacent to marked cells.

2. **Inputs**  
- Two integers representing the width and height of the grid.  
- A grid of integers with dimensions (height + 2) x (width * 2 + 4), where each cell is filled with integer values.

3. **Outputs**  
- An integer representing the count of specific cells adjacent to marked cells, printed to standard output.

4. **Preconditions**  
- The width and height inputs must be positive integers.  
- The grid must be filled with valid integer values as specified by the input format.

5. **Postconditions**  
- The output integer reflects the count of unmarked cells that are adjacent to marked cells in the grid.

6. **Invariants**  
- The grid remains within the defined boundaries throughout processing.  
- Marked cells are consistently updated based on the defined movement rules.

7. **Error Handling / Exceptional Behavior**  
- If the input dimensions exceed the allocated grid size, behavior is undefined.  
- If the input values are not integers, the program may not behave as expected.

8. **State Transitions (if applicable)**  
- The state transitions occur as cells are marked based on movement from previously marked cells, updating the grid state iteratively.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a time complexity that is dependent on the grid size and the number of movements processed.  
- Memory usage is constrained by the fixed size of the grid and auxiliary arrays.
