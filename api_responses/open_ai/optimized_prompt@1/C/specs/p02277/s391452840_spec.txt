1. **Functional Description**  
The program reads a list of cards, each characterized by a character and an integer value, sorts them based on their integer values, and checks the stability of the sorting algorithm used. It outputs whether the sorting is stable and prints the sorted list of cards.

2. **Inputs**  
- An integer representing the number of cards.  
- A sequence of pairs consisting of a character and an integer value for each card.

3. **Outputs**  
- A message indicating whether the sorting is "Stable" or "Not stable".  
- A list of sorted cards, each represented by its character and integer value.

4. **Preconditions**  
- The input must contain a valid integer followed by the corresponding number of character-integer pairs.  
- The integer must be non-negative.

5. **Postconditions**  
- The output list of cards is sorted in non-decreasing order based on the integer values.  
- The stability of the sorting algorithm is determined and reported.

6. **Invariants**  
- The original order of cards with equal integer values is preserved if the sorting algorithm is stable.  
- The number of cards processed matches the input count.

7. **Error Handling / Exceptional Behavior**  
- If the input does not conform to the expected format, behavior is not defined.  
- No explicit error handling is implemented for invalid inputs.

8. **State Transitions (if applicable)**  
- The initial state contains an unsorted list of cards.  
- The final state contains a sorted list of cards and a stability status.

9. **Non-functional Constraints (if inferable)**  
- The sorting operation is expected to be efficient, with a time complexity typical of quicksort.  
- The program assumes sufficient memory is available to store the input list of cards.
