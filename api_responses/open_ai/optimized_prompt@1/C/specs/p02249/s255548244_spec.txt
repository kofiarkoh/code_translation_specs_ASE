1. **Functional Description**  
The program performs a pattern search within a given text grid, identifying all starting positions where a specified pattern grid matches the text.

2. **Inputs**  
- A grid of characters representing the text, defined by dimensions H (height) and W (width).  
- A grid of characters representing the pattern, defined by dimensions R (height) and C (width).

3. **Outputs**  
- A list of coordinates (row, column) indicating the top-left positions in the text grid where the pattern grid matches.

4. **Preconditions**  
- The dimensions H, W, R, and C must be non-negative integers.  
- The text grid must have dimensions H x W, and the pattern grid must have dimensions R x C.

5. **Postconditions**  
- The output coordinates are valid indices within the text grid, ensuring that the pattern fits entirely within the text at those positions.

6. **Invariants**  
- The hash values for the text and pattern grids are consistently computed based on their respective character contents and dimensions.  
- The program maintains the integrity of the input grids throughout the execution.

7. **Error Handling / Exceptional Behavior**

- If the input grids contain characters outside the expected range, the behavior is not defined.

8. **State Transitions (if applicable)**  
- The program transitions from reading input to processing the text and pattern grids, followed by generating hash values, and finally to outputting matching coordinates.
