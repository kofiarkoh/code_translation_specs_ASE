1. **Functional Description**  
The program processes a series of non-negative integers and weights to determine the minimum absolute difference between the integers and a set of computed values derived from the weights. It outputs the minimum difference or -1 if no valid difference is found.

2. **Inputs**  
- A sequence of non-negative integers representing weights and values.
- The first integer indicates the number of subsequent integers.
- The second integer indicates the number of weights to be processed.

3. **Outputs**  
- A single integer representing the minimum absolute difference between the input integers and the computed values, or -1 if no valid difference exists.

4. **Preconditions**  
- The input integers must be non-negative.
- The number of integers and weights must be positive.

5. **Postconditions**  
- The output is either the minimum absolute difference or -1, based on the processing of the input integers and weights.

6. **Invariants**  
- The computed values derived from the weights are maintained in a set throughout the execution.
- The integrity of the input integers is preserved during processing.

7. **Error Handling / Exceptional Behavior**  
- If no valid absolute difference is found during processing, the output will be -1.
- The program does not handle invalid input formats or negative integers.

8. **State Transitions (if applicable)**  
- The state transitions occur as the program processes each weight, updating the set of computed values and checking against the input integers.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a time complexity that is dependent on the number of weights and integers, with a focus on efficiency in searching and inserting values.
