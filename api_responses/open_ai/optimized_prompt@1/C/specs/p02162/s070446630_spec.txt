1. **Functional Description**  
The program determines and outputs the winner of a game based on two sets of scores. It compares two time values and two result values to decide the outcome, which can be either "Alice", "Bob", or "Draw".

2. **Inputs**  
The program reads four integer values representing two time values and two result values.

3. **Outputs**  
The program outputs a string indicating the winner or if the game is a draw.

4. **Preconditions**  
The program requires exactly four integer values to be provided as input. The result values must be non-negative integers for the second comparison.

5. **Postconditions**  
The program guarantees that one of the three strings ("Alice", "Bob", or "Draw") is output based on the comparisons of the input values.

6. **Invariants**  
The output will always be one of the three predefined strings, and the program will not produce any output if the input does not meet the preconditions.

7. **Error Handling / Exceptional Behavior**  
If fewer than four integer values are provided, the program terminates without outputting a result. If the result values are negative, the program will still output a result based on the time values.

8. **State Transitions (if applicable)**  
Not applicable.

9. **Non-functional Constraints (if inferable)**  
The program must complete execution in a timely manner, and the output must be correctly formatted as a single line string.
