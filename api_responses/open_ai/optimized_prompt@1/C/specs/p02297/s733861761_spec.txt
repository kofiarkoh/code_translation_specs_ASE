1. **Functional Description**  
Calculates the area of a polygon defined by a set of vertices provided as input.

2. **Inputs**  
Reads an integer representing the number of vertices, followed by pairs of integers representing the coordinates of each vertex.

3. **Outputs**  
Returns the area of the polygon as a floating-point number, formatted to one decimal place.

4. **Preconditions**  
The number of vertices must be a positive integer. Each vertex coordinate must be an integer.

5. **Postconditions**  
The output area is a non-negative floating-point number representing the calculated area of the polygon.

6. **Invariants**  
The input coordinates must consistently define a closed polygon, and the area calculation is based on the vertices in the order they are provided.

7. **Error Handling / Exceptional Behavior**  
Not inferable from code.

8. **State Transitions (if applicable)**  
Not applicable.

9. **Non-functional Constraints (if inferable)**  
The area calculation is performed in linear time relative to the number of vertices. The output is formatted to one decimal place.
