1. Functional Description  
The program checks if the second input string is a substring of a concatenated version of the first input string with itself.

2. Inputs  
Two strings, the first with a maximum length of 100 characters and the second with a maximum length of 100 characters.

3. Outputs  
A string indicating either "Yes" if the second input string is found within the concatenated first input string, or "No" if it is not.

4. Preconditions  
The first input string must not exceed 100 characters, and the second input string must not exceed 100 characters. Both strings must be non-empty.

5. Postconditions  
The output will be "Yes" if the second string is a substring of the first string concatenated with itself; otherwise, it will be "No".

6. Invariants  
The first string is always concatenated with itself before checking for the presence of the second string.

7. Error Handling / Exceptional Behavior  
If the input strings exceed their specified maximum lengths, behavior is not defined. No explicit error handling is implemented for invalid inputs.

8. State Transitions (if applicable)  
The program transitions from an input state to an output state based on the substring check.

9. Non-functional Constraints (if inferable)  
The program operates within a time complexity that is linear with respect to the length of the input strings for the substring search. Memory usage is constrained by the fixed size of the character arrays.
