1. **Functional Description**  
The program computes the minimum cost to traverse a series of nodes in a graph, considering both direct and indirect paths, based on user-defined edges and a sequence of nodes to visit.

2. **Inputs**  
- A series of test cases, each consisting of:
  - Two integers representing the number of nodes and edges.
  - A list of edges, each defined by two nodes, a cost, and a type (direct or indirect).
  - An integer representing the number of nodes to visit, followed by the specific nodes in order.

3. **Outputs**  
- For each test case, the program outputs the minimum traversal cost to visit the specified nodes in the given order.

4. **Preconditions**  
- The number of nodes and edges must be non-negative integers.
- The edges must connect valid node indices within the range of the total number of nodes.
- The sequence of nodes to visit must contain valid node indices.

5. **Postconditions**  
- The output is a non-negative integer representing the minimum cost of traversal for each test case.
- If no valid path exists, the output will reflect the maximum possible cost defined in the program.

6. **Invariants**  
- The distance matrices for direct and indirect paths are consistently updated to reflect the shortest paths between all pairs of nodes throughout the execution.
- The dynamic programming table maintains the minimum costs to reach each node in the sequence of visits.

7. **Error Handling / Exceptional Behavior**  
- If the input does not conform to the expected format or contains invalid values, the behavior is not defined.
- The program assumes valid input as per the specified constraints; otherwise, it may produce incorrect results or undefined behavior.

8. **State Transitions (if applicable)**  
- The state transitions occur as the program processes each test case, updating the distance matrices and the dynamic programming table based on the edges and the sequence of nodes to visit.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a time complexity that is polynomial with respect to the number of nodes and edges, specifically O(N^3) for the shortest path calculations and O(R * N^2) for the dynamic programming solution, where R is the number of nodes to visit.
