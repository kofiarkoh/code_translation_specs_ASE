1. Functional Description  
The program reads five integer values and determines the first value among them that is zero. It outputs a corresponding integer indicating the position of that zero value.

2. Inputs  
Five integer values are read from standard input.

3. Outputs  
The program outputs a single integer:  
- "1" if the first input is zero,  
- "2" if the second input is zero,  
- "3" if the third input is zero,  
- "4" if the fourth input is zero,  
- "5" if the fifth input is zero.  
If none of the inputs are zero, no output is produced.

4. Preconditions  
The program assumes that exactly five integer values are provided as input.

5. Postconditions  
If at least one of the input values is zero, the program guarantees that an integer corresponding to the position of the first zero value is output. If no input values are zero, there is no output.

6. Invariants  
The program maintains that it will only output an integer if at least one of the input values is zero.

7. Error Handling / Exceptional Behavior  
The program does not handle cases where the input is not as expected (e.g., non-integer values or fewer/more than five integers). In such cases, behavior is undefined.

Not applicable.

Not inferable from code.
