1. **Functional Description**  
The program processes a series of input strings representing paths through a predefined mapping of cities. It determines if the final city reached after following the path is a specific target city.

2. **Inputs**  
The program reads multiple strings from standard input, each representing a sequence of digits. Input terminates when a string starting with the character '#' is encountered.

3. **Outputs**  
For each input string (excluding the terminating string), the program outputs either "Yes" or "No" based on whether the final city reached is the target city.

4. **Preconditions**  
Each input string must consist solely of digits representing valid transitions, and the input must not exceed a length of 109 characters.

5. **Postconditions**  
The program guarantees that for each valid input string, it will output "Yes" if the final city reached is the target city; otherwise, it will output "No".

6. **Invariants**  
The mapping of cities remains constant throughout the execution of the program. The program maintains a valid state of the current city based on the transitions defined in the mapping.

7. **Error Handling / Exceptional Behavior**  
If an input string contains a character that does not correspond to a valid transition, the program will terminate processing that string and output "No". The program does not handle malformed input or unexpected characters beyond the defined digits.

8. **State Transitions (if applicable)**  
The state transitions occur based on the input digits, where each digit corresponds to a potential transition from the current city to a new city as defined in the mapping. The state is updated until an invalid transition is encountered or the end of the string is reached.

9. **Non-functional Constraints (if inferable)**  
The program operates in a loop until a termination condition is met, and it processes each input string in a sequential manner. The maximum length of input strings is constrained to 109 characters, ensuring efficient memory usage.
