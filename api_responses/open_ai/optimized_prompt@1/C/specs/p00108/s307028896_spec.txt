1. **Functional Description**  
The program processes a series of integer sequences, transforming each sequence until it reaches a stable state where the transformation no longer changes the sequence. It counts the number of transformations required to reach this stable state and outputs the final transformed sequence.

2. **Inputs**  
The program reads multiple sequences of integers from standard input. Each sequence begins with an integer indicating the number of subsequent integers in that sequence. The input terminates when a zero is read.

3. **Outputs**  
The program outputs the number of transformations performed to reach stability, followed by the final transformed sequence of integers.

4. **Preconditions**  
The input must consist of valid integers, with the first integer of each sequence being greater than zero. The integers in the sequences must be within the range of 0 to 100.

5. **Postconditions**  
The output will include the number of transformations performed (one less than the final count) and the final transformed sequence, which is stable and does not change with further transformations.

6. **Invariants**  
During the transformation process, the sequence remains non-empty and consists of integers within the specified range. The transformation continues until the sequence stabilizes.

7. **Error Handling / Exceptional Behavior**  
If the input is invalid (e.g., non-integer values), the program's behavior is not defined. The program does not handle negative integers or integers greater than 100.

8. **State Transitions (if applicable)**  
The program transitions between states based on the transformation of the integer sequence. Each state represents a different configuration of the sequence until it stabilizes.

9. **Non-functional Constraints (if inferable)**  
The program operates within a fixed memory limit for storing sequences and transformations, constrained by the defined maximum sizes. The performance is dependent on the number of transformations and the size of the input sequences.
