1. **Functional Description**  
The code implements Dijkstra's algorithm to compute the shortest path costs from a source node to all other nodes in a directed graph represented by a set of nodes, each with associated edges and costs.

- A non-negative integer representing the number of nodes in the graph.  
- For each node, a non-negative integer representing the node index, followed by a non-negative integer indicating the number of edges from that node.  
- For each edge, a non-negative integer representing the destination node index and a non-negative integer representing the cost of the edge.

3. **Outputs**  
- For each node, the index of the node followed by the computed shortest path cost from the source node to that node. The output is printed in a specific format.

4. **Preconditions**  
- The input must consist of valid non-negative integers.  
- The number of nodes must be greater than zero.  
- The node indices and edge destination indices must be within the range defined by the number of nodes.

5. **Postconditions**  
- Each node's cost is updated to reflect the shortest path cost from the source node.  
- If a node is unreachable from the source, its cost remains as initialized (indicating no path exists).

6. **Invariants**  
- The cost of the source node is always zero after initialization.  
- A node's visited status is updated only once, ensuring it is processed only when its shortest path cost is finalized.

- If an input value is out of the expected range (e.g., negative values or indices exceeding the number of nodes), the behavior is not defined.  
- The program does not handle memory allocation errors or invalid graph structures explicitly.

8. **State Transitions (if applicable)**  
- The state transitions occur as nodes are marked as visited and their costs are updated based on the edges processed. The algorithm iteratively selects the next node with the smallest cost until all reachable nodes are processed.
