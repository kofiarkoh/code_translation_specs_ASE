1. **Functional Description**  
The program computes the shortest time required to navigate from a starting position to a target position on a grid, considering obstacles and varying movement costs based on the presence of bombs.

2. **Inputs**  
- Two integers representing the height and width of the grid.  
- Two integers representing the movement costs associated with traversing normal and bomb-affected cells.  
- A grid of characters representing the map, where specific characters denote the starting position, target position, bombs, and obstacles.

3. **Outputs**  
- A long integer representing the minimum time to reach the target position from the starting position, or a string indicating that the target is unreachable.

4. **Preconditions**  
- The grid dimensions are positive integers.  
- The grid contains valid characters as specified (e.g., start, goal, bomb, obstacle).  
- The starting and target positions are distinct and within the grid boundaries.

5. **Postconditions**  
- If a path exists, the output is the minimum time required to reach the target position.  
- If no path exists, the output indicates that the target is unreachable.

6. **Invariants**  
- The grid remains unchanged throughout the execution.  
- The movement costs are consistently applied based on the type of cell being traversed.

7. **Error Handling / Exceptional Behavior**  
- If the input grid is malformed or does not contain the required start and goal positions, the behavior is not defined.  
- If the starting position is surrounded by bombs, the program will return that the target is unreachable.

8. **State Transitions (if applicable)**  
- The state transitions occur as the program explores the grid, updating the visited status of cells and the priority queue based on the current position and accumulated time.

9. **Non-functional Constraints (if inferable)**  
- The program is expected to operate efficiently within the constraints of the grid size, with a maximum of 1,000,000 cells.  
- The time complexity is influenced by the number of cells and the efficiency of the priority queue operations.
