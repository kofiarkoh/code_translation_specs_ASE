1. **Functional Description**  
The code implements a pathfinding algorithm using Dijkstra's method to find the shortest path in a grid-like structure defined by coordinates. It processes input to construct a graph of nodes and edges, representing connections between points, and returns the minimum distance from a starting point to a goal point.

2. **Inputs**  
- Three integers representing the dimensions of the grid and the number of connections.
- A series of coordinate pairs that define the connections between points in the grid.

3. **Outputs**  
- A single long long integer representing the shortest distance from the starting point to the goal point. If no path exists, it returns -1.

4. **Preconditions**  
- The input must consist of valid integers for grid dimensions and connections.
- The coordinates must be within the defined grid dimensions.

5. **Postconditions**  
- The output will be the minimum distance from the starting point to the goal point if a path exists; otherwise, it will be -1.

6. **Invariants**  
- The graph structure remains consistent throughout the execution, with nodes and edges correctly representing the connections as defined by the input.
- The priority queue used for Dijkstra's algorithm maintains the properties of a min-heap.

7. **Error Handling / Exceptional Behavior**  
- If the input is malformed or out of bounds, the behavior is not defined. The program assumes valid input as per the preconditions.
- If the starting or goal point is not defined in the input, the program will handle it by treating them as non-existent nodes.

8. **State Transitions (if applicable)**  
- The state transitions occur as nodes are processed in the priority queue, updating the distances to neighboring nodes and marking nodes as visited.

9. **Non-functional Constraints (if inferable)**  
- The algorithm operates within a time complexity of O((V + E) log V), where V is the number of vertices and E is the number of edges, due to the use of a priority queue for Dijkstra's algorithm. The maximum number of nodes is constrained by the input size.
