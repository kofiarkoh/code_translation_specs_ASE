1. **Functional Description**  
The program calculates the maximum number of overlapping time intervals based on user-provided departure and arrival times, expressed in hours, minutes, and seconds.

2. **Inputs**  
- A series of integers representing the number of time intervals, followed by pairs of time intervals (departure and arrival times) in the format of hours, minutes, and seconds. The input terminates when the number of intervals is zero.

3. **Outputs**  
- For each set of time intervals, the program outputs a single integer representing the maximum number of overlapping intervals at any point in time.

4. **Preconditions**  
- The input must consist of valid integers and time values formatted correctly as hours, minutes, and seconds. The number of intervals must be non-negative.

5. **Postconditions**  
- The output will reflect the maximum overlap of time intervals based on the provided input. The program will terminate gracefully upon receiving a zero for the number of intervals.

6. **Invariants**  
- The time array maintains a count of overlapping intervals for each second of the day (totaling 86,400 seconds). The maximum overlap is updated only when new intervals are processed.

7. **Error Handling / Exceptional Behavior**  
- The program does not handle invalid input formats or out-of-range time values. It assumes all input is valid as per the specified format.

8. **State Transitions (if applicable)**  
- The program transitions from reading input to processing time intervals, then to calculating the maximum overlap, and finally to outputting the result. It resets the state for each new set of intervals.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a time complexity that is linear with respect to the number of intervals, and it uses a fixed amount of memory for the time array, independent of the number of intervals.
