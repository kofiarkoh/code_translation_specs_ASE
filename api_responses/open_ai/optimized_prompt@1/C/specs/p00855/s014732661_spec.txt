1. Functional Description  
The program calculates the count of prime numbers within a specified range defined by two integer inputs, adjusting the range based on the primality of the boundary values.

2. Inputs  
The program reads a series of integer values from standard input, where each value represents the upper boundary of a range. The lower boundary is derived from the upper boundary by decrementing until a prime number is found.

3. Outputs  
The program outputs the count of prime numbers between the adjusted lower and upper boundaries for each input value, printing each count on a new line.

4. Preconditions  
The input values must be integers. The program assumes that at least one integer will be provided as input.

5. Postconditions  
For each input integer, the program guarantees that the output is the count of prime numbers between the largest prime less than or equal to the input integer and the smallest prime greater than or equal to the input integer.

6. Invariants  
The program maintains that the values used to determine primality are always non-negative integers. The count of primes is always a non-negative integer.

7. Error Handling / Exceptional Behavior  
The program does not explicitly handle invalid input (e.g., non-integer values). If invalid input is encountered, behavior is not defined.

8. State Transitions (if applicable)  
The program transitions between states based on the input values read and the corresponding adjustments made to the lower and upper boundaries as it searches for prime numbers.

9. Non-functional Constraints (if inferable)  
The program's performance may be affected by the efficiency of the primality testing, which is dependent on the size of the input values. The output is generated in a sequential manner, corresponding to the order of input values.
