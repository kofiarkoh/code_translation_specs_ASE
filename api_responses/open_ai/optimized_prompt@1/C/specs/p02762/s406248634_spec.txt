- Pairs of integers for queries, indicating which elements to check for connectivity.

3. **Outputs**  
- A sequence of integers representing the sizes of each set after processing all operations, adjusted for the number of removals.

5. **Postconditions**  
- Each output integer corresponds to the size of the set containing the respective element, reduced by the number of removals associated with that element.
