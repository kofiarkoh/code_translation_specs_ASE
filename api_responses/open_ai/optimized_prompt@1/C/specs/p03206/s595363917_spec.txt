1. Functional Description  
The program reads an integer input and outputs a specific string based on the value of the input, corresponding to the days leading up to Christmas.

2. Inputs  
An integer value representing a day in December.

3. Outputs  
A string indicating the specific day related to Christmas, or no output if the input does not match any specified values.

4. Preconditions  
The input must be an integer.

5. Postconditions  
If the input is 25, the output is "Christmas".  
If the input is 24, the output is "Christmas Eve".  
If the input is 23, the output is "Christmas Eve Eve".  
If the input is 22, the output is "Christmas Eve Eve Eve".  
If the input is any other integer, there is no output.

6. Invariants  
The program guarantees that only one of the specified strings is output for valid inputs, or no output for invalid inputs.

7. Error Handling / Exceptional Behavior  
The program does not handle non-integer inputs or out-of-range values explicitly; behavior is not defined for such cases.

8. State Transitions (if applicable)  
Not applicable.

9. Non-functional Constraints (if inferable)  
The program completes execution in constant time regardless of input value.
