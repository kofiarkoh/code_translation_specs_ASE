1. **Functional Description**  
The program processes a string of characters and computes a series of cumulative values based on specific character occurrences ('D', 'M', 'C') for multiple queries, each defined by a specified length.

2. **Inputs**  
- An integer representing the length of the string.  
- A string of characters consisting of 'D', 'M', and 'C'.  
- An integer representing the number of queries.  
- An array of integers, each specifying a length for the corresponding query.

3. **Outputs**  
- For each query, the program outputs a long integer representing the computed cumulative value based on the occurrences of 'D', 'M', and 'C' within the specified substring length.

4. **Preconditions**  
- The length of the string must be a positive integer.  
- The string must contain only the characters 'D', 'M', and 'C'.  
- The number of queries must be a positive integer.  
- Each query length must be a positive integer and less than or equal to the length of the string.

5. **Postconditions**  
- The program outputs a long integer for each query, representing the cumulative value based on the specified substring length.

6. **Invariants**  
- The cumulative value is consistently updated based on the occurrences of 'D', 'M', and 'C' as the program processes the string for each query.  
- The counts of 'D' and 'M' are maintained accurately throughout the sliding window of the substring.

7. **Error Handling / Exceptional Behavior**  
- If the input does not meet the preconditions (e.g., invalid characters, negative lengths), the behavior is not defined.  
- The program does not handle input errors or invalid data gracefully.

8. **State Transitions (if applicable)**  
- The program transitions through states based on the current index of the string being processed and the current query being evaluated, updating counts and cumulative values accordingly.

9. **Non-functional Constraints (if inferable)**  
- The program is expected to operate within time constraints suitable for processing strings of significant length and multiple queries efficiently.  
- Memory usage is constrained by the size of the input string and the number of queries.
