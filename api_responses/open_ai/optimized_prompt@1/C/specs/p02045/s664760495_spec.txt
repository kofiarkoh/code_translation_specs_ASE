1. **Functional Description**  
The program calculates a total cost based on the movement between a series of points, considering boundary constraints and potential adjustments to the cost based on specific conditions.

2. **Inputs**  
- A positive integer \( N \) representing the number of points.  
- Four integers \( A, B, C, D \) defining boundary limits.  
- \( N + 1 \) pairs of integers representing coordinates \( (X[i], Y[i]) \) for \( i \) from 0 to \( N \).

3. **Outputs**  
- A single integer representing the total calculated cost, printed to standard output.

4. **Preconditions**  
- The input for \( N \) must be a positive integer.  
- The input for \( A, B, C, D \) must consist of exactly four integers.  
- The input for coordinates must consist of \( N + 1 \) pairs of integers.

5. **Postconditions**  
- The output integer reflects the minimum cost of movement between the specified points, considering boundary constraints.

6. **Invariants**  
- The values of \( A, B, C, D \) remain constant throughout the execution of the program after being read.  
- The coordinates \( X[i] \) and \( Y[i] \) are valid integers as per the input constraints.

7. **Error Handling / Exceptional Behavior**  
- The program terminates with a return value of 1 if the input for \( A, B, C, D \) is not exactly four integers.  
- The program terminates with a return value of 1 if any coordinate input does not consist of exactly two integers.

8. **State Transitions (if applicable)**  
- The program transitions from reading input to processing the coordinates and calculating costs, ultimately leading to the output of the total cost.

9. **Non-functional Constraints (if inferable)**  
- The program assumes that the input size does not exceed the defined limits (e.g., \( N \leq 127 \)).  
- The program operates within the constraints of standard input and output handling.
