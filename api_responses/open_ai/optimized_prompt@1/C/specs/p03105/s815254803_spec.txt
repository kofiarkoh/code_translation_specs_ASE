1. Functional Description  
The program reads three integer values and computes the integer division of the first two values. It then compares this result with the third value and outputs the smaller of the two.

2. Inputs  
Three integer values are read from standard input.

3. Outputs  
The program outputs a single integer value, which is either the result of the integer division of the first two values or the third value, depending on their comparison.

4. Preconditions  
The first input value must be a non-zero integer to avoid division by zero. The second and third input values can be any integer.

5. Postconditions  
The output is guaranteed to be the smaller of the integer division result of the first two values and the third value.

6. Invariants  
The output will always be an integer. The program will not produce any output if the first input value is zero.

7. Error Handling / Exceptional Behavior  
If the first input value is zero, the program will not perform the division and will not produce an output.

Not applicable.
