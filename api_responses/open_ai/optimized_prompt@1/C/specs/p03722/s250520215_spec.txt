1. **Functional Description**  
   The program computes the minimum cost to reach a specified node in a directed graph with weighted edges, detecting negative cycles that may affect the result.

2. **Inputs**  
   - Two integers representing the number of nodes and the number of edges in the graph.
   - A series of triplets representing directed edges, where each triplet consists of two integers (source node, destination node) and an integer (cost of the edge).

3. **Outputs**  
   - The minimum cost to reach the specified node from the starting node, or "inf" if a negative cycle affects the path to the specified node.

4. **Preconditions**  
   - The number of nodes and edges must be non-negative integers.
   - The edges must be valid, meaning the source and destination nodes are within the range of defined nodes.

5. **Postconditions**  
   - If a valid path exists from the starting node to the specified node, the output is the minimum cost as a negative value.
   - If a negative cycle is detected that affects the path to the specified node, the output is "inf".

6. **Invariants**  
   - The minimum cost to reach any node is always less than or equal to the previously computed costs.
   - The algorithm maintains a valid state of minimum costs throughout its execution.

7. **Error Handling / Exceptional Behavior**  
   - If the input format is incorrect or if the number of edges exceeds the defined limit, behavior is not specified.
   - The program does not handle cases where the number of nodes is zero or negative.

8. **State Transitions (if applicable)**  
   - The state transitions occur as the minimum costs are updated based on the edges processed, reflecting the current minimum cost to reach each node.

9. **Non-functional Constraints (if inferable)**  
   - The algorithm operates within a time complexity that is polynomial in relation to the number of nodes and edges, specifically O(N * M) for the main processing loop.
