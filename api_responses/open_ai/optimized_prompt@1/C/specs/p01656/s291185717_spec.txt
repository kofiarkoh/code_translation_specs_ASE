1. Functional Description  
The program reads a set of names associated with years and determines the most recent name that corresponds to a year less than or equal to a specified threshold.

2. Inputs  
- Two integers: N (the number of names) and Q (the year threshold).  
- N pairs of inputs, each consisting of an integer (year) and a string (name).

3. Outputs  
- A single string representing the most recent name associated with a year less than or equal to Q. If no such name exists, the output will be the first name in the list.

4. Preconditions  
- N must be a non-negative integer.  
- Q must be a non-negative integer.  
- The number of names provided must not exceed the predefined limit.

5. Postconditions  
- The output string is guaranteed to be one of the names provided, based on the specified year condition.

6. Invariants  
- The program maintains a record of names and their associated years throughout its execution.  
- At any point, the selected name is either the first name or the most recent name that meets the year condition.

7. Error Handling / Exceptional Behavior  
- If N is zero, the program will output the first name by default.  
- If no names meet the year condition, the output will still be the first name.

8. State Transitions (if applicable)  
- The state transitions occur as the program processes each name and year pair, updating the selected name based on the year condition.

9. Non-functional Constraints (if inferable)  
- The program operates within a fixed memory limit for names and years.  
- The execution time is linear with respect to the number of names provided.
