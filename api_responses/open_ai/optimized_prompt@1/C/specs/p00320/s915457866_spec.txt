1. **Functional Description**  
The program determines if there exists a configuration of a set of hardware components that can be arranged such that specific connection lengths are equal. It evaluates all permutations of the components and their orientations to find a valid configuration.

2. **Inputs**  
The program reads six pairs of integers representing the dimensions (height/width) of six hardware components from standard input.

3. **Outputs**  
The program outputs "yes" if a valid configuration is found; otherwise, it outputs "no". 

4. **Preconditions**  
The input must consist of exactly six pairs of integers. Each integer must be non-negative.

5. **Postconditions**  
If a valid configuration exists, "yes" is printed; if not, "no" is printed. The program terminates after producing one of these outputs.

6. **Invariants**  
Throughout the execution, the program maintains the integrity of the input data, ensuring that the dimensions of the hardware components are not altered.

7. **Error Handling / Exceptional Behavior**  
If the input does not consist of exactly six pairs of integers, the program terminates with a return value indicating an error. 

8. **State Transitions (if applicable)**  
The program transitions through multiple states as it generates permutations of the hardware components and evaluates each configuration against the connection criteria.

9. **Non-functional Constraints (if inferable)**  
The program must efficiently handle the evaluation of all permutations of the hardware components, which may lead to significant computational overhead as the number of components increases.
