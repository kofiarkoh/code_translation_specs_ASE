1. Functional Description  
The program simulates a railroad car management system, allowing cars to enter and exit a storage area. It maintains a record of the cars currently in the storage and outputs the identifier of a car when it exits.

2. Inputs  
The program reads integer values from standard input until the end of input is reached. The integers represent railroad car identifiers, with a value of zero indicating a car exiting the storage.

3. Outputs  
The program outputs the identifier of a car that exits the storage area, each on a new line.

4. Preconditions  
The program assumes that the input consists of valid integers, including zero for exit commands. The maximum number of cars that can be stored is limited to ten.

5. Postconditions  
After processing the input, the program guarantees that the identifiers of cars that have exited the storage are printed in the order they exited.

6. Invariants  
The program maintains an internal state where the number of cars in the storage does not exceed ten. The identifiers of the cars in the storage are stored in the order they were added.

7. Error Handling / Exceptional Behavior  
The program does not handle invalid input or overflow conditions explicitly. If more than ten cars are attempted to be added, the behavior is not defined.

8. State Transitions (if applicable)  
- On receiving a non-zero integer, a car is added to the storage, increasing the count of stored cars.  
- On receiving a zero, a car is removed from the storage, decreasing the count of stored cars, provided there is at least one car in storage.

9. Non-functional Constraints (if inferable)  
The program operates under the constraint of a maximum storage capacity of ten cars and processes input in a sequential manner. The output is generated immediately upon a car exiting.
