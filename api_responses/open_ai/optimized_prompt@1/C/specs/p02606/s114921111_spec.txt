1. Functional Description  
Calculates the count of integers divisible by a specified divisor within a given inclusive range.

2. Inputs  
Three integers representing the lower bound, upper bound, and the divisor.

3. Outputs  
An integer representing the count of integers within the specified range that are divisible by the divisor, followed by a newline.

4. Preconditions  
The lower bound must be less than or equal to the upper bound. The divisor must be a positive integer.

5. Postconditions  
The output integer is non-negative and represents the total number of integers in the range that are divisible by the divisor.

6. Invariants  
The count of divisible integers remains consistent with the mathematical definition of divisibility throughout the execution.

7. Error Handling / Exceptional Behavior  
If the divisor is zero, the behavior is undefined. No explicit error handling is implemented for invalid inputs.

8. State Transitions (if applicable)  
Not applicable.

9. Non-functional Constraints (if inferable)  
The output is produced in constant time relative to the size of the input values.
