1. **Functional Description**  
The program computes the longest path in a railway network defined by connections between stations, returning the length of the path and the sequence of stations involved.

2. **Inputs**  
The program reads multiple sets of data, each consisting of:  
- Two integers representing the number of stations and the number of connections.  
- For each connection, three integers representing two stations and the distance between them.

3. **Outputs**  
The program outputs:  
- An integer representing the length of the longest path found.  
- A sequence of integers representing the stations in the longest path.

4. **Preconditions**  
- The number of stations and connections must be positive integers.  
- Each connection must involve valid station identifiers within the range of the total number of stations.

5. **Postconditions**  
- The output length is the maximum distance of any valid path found in the railway network.  
- The output sequence of stations corresponds to the stations traversed in the longest path.

6. **Invariants**  
- The connections between stations are undirected and can be traversed in both directions.  
- Each connection can only be used once in a single path computation.

7. **Error Handling / Exceptional Behavior**  
- If the input for the number of stations is zero, the program terminates without processing further input.  
- Invalid connections (e.g., connections between non-existent stations) are ignored.

8. **State Transitions (if applicable)**  
- The program transitions between states of reading input, processing connections, and outputting results based on the completion of each input set.

9. **Non-functional Constraints (if inferable)**  
- The program must efficiently handle multiple sets of input data and compute results within a reasonable time frame, given the constraints of the number of stations and connections.
