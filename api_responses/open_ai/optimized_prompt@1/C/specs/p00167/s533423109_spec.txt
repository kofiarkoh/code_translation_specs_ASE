The program reads a series of integer arrays, sorts each array in ascending order using a specific sorting algorithm, and counts the number of swaps made during the sorting process. It outputs the swap count for each array until a termination condition is met.

2. **Inputs**  
The program reads multiple integer values from standard input. The first integer indicates the number of subsequent integers in the array. The input terminates when a zero is read as the first integer.

3. **Outputs**  
The program outputs the total number of swaps made during the sorting of each array, with each count printed on a new line.

4. **Preconditions**  
The input must consist of valid integers. The first integer must be non-negative and less than or equal to 100, representing the number of integers in the array.

5. **Postconditions**  
For each valid input array, the program guarantees that the output will reflect the total number of swaps made to sort the array in ascending order.

6. **Invariants**  
The array is maintained in a state where all elements are integers, and the sorting process ensures that after completion, the array is sorted in non-decreasing order.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or non-integer values. If the input does not conform to the expected format, behavior is not defined.

8. **State Transitions (if applicable)**  
The program transitions between states based on the input read: it initializes an array, processes the sorting and counting of swaps, and outputs the result before resetting for the next input.

The program operates within a time complexity that is dependent on the number of elements being sorted, specifically O(n^2) due to the sorting algorithm used. The maximum size of the input array is constrained to 100 integers.
