1. Functional Description  
The program calculates the average of two integers if their sum is even; otherwise, it indicates that the operation is impossible.

2. Inputs  
The program reads two long integers from standard input.

3. Outputs  
The program outputs either the average of the two integers or a message indicating that the operation is impossible.

4. Preconditions  
The inputs must be valid long integers.

5. Postconditions  
If the sum of the two integers is even, the output is the average of the two integers. If the sum is odd, the output is a message indicating that the operation is impossible.

6. Invariants  
The sum of the two integers is either even or odd throughout the execution of the program.

7. Error Handling / Exceptional Behavior  
If the inputs are not valid long integers, the behavior is not defined. The program does not handle input errors explicitly.

8. State Transitions (if applicable)  
The program transitions from an input state to either an output state of the average or an output state of "IMPOSSIBLE" based on the parity of the sum.
