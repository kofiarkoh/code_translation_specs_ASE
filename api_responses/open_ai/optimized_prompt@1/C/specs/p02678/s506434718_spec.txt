1. **Functional Description**  
The program constructs an undirected graph based on user-provided edges and performs a breadth-first search (BFS) starting from a specified node. It determines the parent node for each reachable node in the graph and outputs the results.

2. **Inputs**  
- Two integers representing the number of nodes (N) and the number of edges (M).  
- M pairs of integers representing the edges between nodes.

3. **Outputs**  
- A string "Yes" indicating successful execution.  
- For each node from 2 to N, the program outputs the parent node in the BFS tree.

4. **Preconditions**  
- N is a positive integer representing the number of nodes.  
- M is a non-negative integer representing the number of edges.  
- Each edge connects two valid nodes within the range [1, N].

5. **Postconditions**  
- The program outputs "Yes" if the BFS completes successfully.  
- Each node from 2 to N has a corresponding parent node output, which is the node from which it was first reached during the BFS.

6. **Invariants**  
- The distance array is initialized to -1 for all nodes, indicating they are unvisited before the BFS starts.  
- The graph structure maintains the undirected nature of edges, ensuring that each edge is represented in both directions.

7. **Error Handling / Exceptional Behavior**  
- If the input does not conform to the expected format or contains invalid values, the behavior is not defined.  
- Memory allocation failures during edge creation may lead to undefined behavior.

8. **State Transitions (if applicable)**  
- The state transitions occur as nodes are visited during the BFS, updating the distance array and queue accordingly.

9. **Non-functional Constraints (if inferable)**  
- The program operates within the constraints of memory allocation for graph representation and BFS traversal, limited by the maximum number of nodes and edges.  
- Performance is expected to be linear with respect to the number of nodes and edges, given the BFS nature of the algorithm.
