1. **Functional Description**  
The program reads a target integer and a string of characters, then computes the maximum sum of integer values derived from substrings of the input string, constrained by the target. It identifies the specific combination of characters that yields this maximum sum and outputs the result.

2. **Inputs**  
- A target integer.  
- A string of characters, with a maximum length of 10.

3. **Outputs**  
- If no valid combinations are found, outputs "error".  
- If multiple valid combinations yield the same maximum sum, outputs "rejected".  
- If exactly one valid combination is found, outputs the maximum sum followed by the characters that form this combination.

4. **Preconditions**  
- The target integer must be a positive value.  
- The input string must be non-empty and contain at most 10 characters.

5. **Postconditions**  
- The output will reflect either an error, rejection, or the maximum sum and corresponding character combination based on the input constraints.

6. **Invariants**  
- The sum of the integer values derived from the substrings will always be non-negative.  
- The length of the input string will remain constant throughout the execution.

7. **Error Handling / Exceptional Behavior**  
- If the input string is empty or the target is zero, the program will output "error".  
- If multiple combinations yield the same maximum sum, the program will output "rejected".

8. **State Transitions (if applicable)**  
- The program transitions between states based on the evaluation of combinations of characters and their corresponding sums, ultimately leading to one of the defined output states.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a time complexity that is exponential relative to the length of the input string due to the evaluation of all possible combinations.  
- The program is limited to processing strings of a maximum length of 10 characters.
