1. **Functional Description**  
The program facilitates the analysis of ski resort courses based on user-defined dimensions and course data. It reads the dimensions of the course, collects course data, and computes a specific pattern based on the input, ultimately outputting a computed sum.

2. **Inputs**  
- Two integers representing the dimensions of the course (X and Y).
- A matrix of integers of size X by Y, representing course data.

3. **Outputs**  
- An integer value representing the computed sum based on the analyzed course data, printed to standard output.

4. **Preconditions**  
- The input for dimensions (X and Y) must be non-negative integers.
- The course data must be provided in a format that allows for parsing into integers.

5. **Postconditions**  
- The program terminates when the dimensions X and Y are both zero.
- The output is the computed sum based on the analysis of the course data.

6. **Invariants**  
- The dimensions X and Y remain consistent throughout the execution of the program after being read.
- The course data is stored in a matrix format and is accessible for analysis.

7. **Error Handling / Exceptional Behavior**  
- If the input for dimensions is invalid (e.g., non-integer values), behavior is not defined.
- If the course data does not match the specified dimensions, behavior is not defined.

8. **State Transitions (if applicable)**  
- The program transitions from reading dimensions to reading course data, followed by analyzing the data and producing output. The state resets upon receiving dimensions of zero.

9. **Non-functional Constraints (if inferable)**  
- The program assumes that input will be provided in a timely manner and that the input size will not exceed memory limits. Performance is not explicitly guaranteed for large inputs.
