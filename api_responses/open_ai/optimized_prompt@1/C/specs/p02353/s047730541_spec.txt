1. **Functional Description**  
The code implements a segment tree to manage and query a range of integer values. It supports two primary operations: updating a range of values and retrieving the sum of values within a specified range.

2. **Inputs**  
- Two integers representing the number of elements and the number of queries.
- For each query, an integer indicating the type of operation (update or get sum) followed by two integers representing the start and end of the range. If the operation is an update, an additional integer specifying the value to update is provided.

3. **Outputs**  
- For each sum query, the code outputs the computed sum of the specified range to standard output.

4. **Preconditions**  
- The number of elements must be greater than zero.
- The number of queries must be non-negative.
- Range values provided in queries must be within the bounds of the initialized segment tree.

5. **Postconditions**  
- After processing all queries, the segment tree reflects all updates made during the execution.
- The output contains the sums for all sum queries in the order they were requested.

6. **Invariants**  
- The segment tree maintains the correct sum of values for each segment, reflecting any updates made to the ranges.
- The lazy propagation mechanism ensures that updates are efficiently applied without immediate recalculation of all affected segments.

7. **Error Handling / Exceptional Behavior**  
- The code does not explicitly handle invalid input or out-of-bounds range queries. Behavior is undefined for such cases.

8. **State Transitions (if applicable)**  
- The state transitions occur during the update and sum operations, where the segment tree's internal state changes based on the updates applied and the sums calculated.

9. **Non-functional Constraints (if inferable)**  
- The implementation is designed to handle a maximum of 100,000 queries and supports a segment tree size of up to 131,072 elements, ensuring efficient performance within these limits.
