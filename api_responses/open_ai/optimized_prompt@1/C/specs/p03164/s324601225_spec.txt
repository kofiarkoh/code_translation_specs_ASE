1. **Functional Description**  
The program computes the maximum value of items that can be carried without exceeding a specified weight limit, based on given item weights and values.

2. **Inputs**  
The program reads two integers representing the number of items and the maximum weight capacity. It then reads pairs of integers for each item, representing the weight and value of the item.

3. **Outputs**  
The program outputs the maximum value that can be achieved without exceeding the weight limit. If no valid configuration exists, it outputs an error message.

4. **Preconditions**  
- The input must consist of valid integers.
- The number of items must be non-negative.
- The maximum weight capacity must be non-negative.

5. **Postconditions**  
- If a valid configuration exists, the output is the maximum value that can be achieved within the weight limit.
- If no valid configuration exists, the output is an error message.

6. **Invariants**  
- The array used to track the minimum weights for each possible value remains consistent throughout the execution, ensuring that it only contains valid weight configurations.

7. **Error Handling / Exceptional Behavior**  
- The program terminates with a return code if the input format is incorrect or if the number of items or weight capacity is invalid.
- An error message is printed if no valid configuration can be achieved.

8. **State Transitions (if applicable)**  
- The state transitions occur as the program processes each item, updating the weight configurations based on the current item’s weight and value.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a fixed memory limit defined by the constant for the maximum weight.
