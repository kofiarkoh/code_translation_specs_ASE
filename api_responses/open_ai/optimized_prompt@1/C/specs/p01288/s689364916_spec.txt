1. **Functional Description**  
The program processes a series of queries on a set of elements, maintaining a mapping and a count of modifications. It computes a cumulative result based on the queries, which is then output.

2. **Inputs**  
- A positive integer representing the number of elements, N.  
- A positive integer representing the number of queries, Q.  
- A sequence of N integers that establish a mapping for the elements.  
- A sequence of Q queries, each consisting of a character indicating the type of operation and an integer value.

3. **Outputs**  
- A single long integer representing the cumulative result after processing all queries.

4. **Preconditions**  
- N and Q must be positive integers.  
- The sequence of N integers must be valid indices within the range of 1 to N.  
- The queries must be well-formed, with valid characters and integer values.

5. **Postconditions**  
- The output is the sum of specific elements determined by the queries, reflecting the modifications made during the query processing.

6. **Invariants**  
- The mapping array maintains valid indices throughout the execution.  
- The modification counts are non-negative integers.

7. **Error Handling / Exceptional Behavior**  
- If invalid input is encountered (e.g., out-of-bounds indices), behavior is not defined.  
- The program does not handle malformed queries or unexpected input formats.

8. **State Transitions (if applicable)**  
- The state transitions occur with each query processed, updating the modification counts and the cumulative result accordingly.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a time complexity that is linear with respect to the number of queries and elements, assuming valid input.  
- Memory usage is constrained by the size of the input parameters, specifically O(N + Q).
