1. Functional Description  
The program reads a string of three characters, counts the occurrences of the character 'o', and computes a value based on this count, which is then output.

2. Inputs  
The program reads a string consisting of exactly three characters.

3. Outputs  
The program returns an integer value calculated as 700 plus 100 times the count of 'o' characters in the input string.

4. Preconditions  
The input string must consist of exactly three characters.

5. Postconditions  
The output value is guaranteed to be an integer in the range of 700 to 1000, inclusive.

6. Invariants  
The count of 'o' characters is always a non-negative integer and does not exceed 3.

7. Error Handling / Exceptional Behavior  
If the input does not consist of exactly three characters, the behavior of the program is undefined.

Not applicable.
