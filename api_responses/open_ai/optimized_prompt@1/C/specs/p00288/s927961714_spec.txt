1. **Functional Description**  
The code implements a solution to a minimum cost flow problem in a flow network, allowing for the calculation of the minimum cost to transport a specified flow from a source to a sink through a series of edges with associated capacities and costs.

2. **Inputs**  
- The number of nodes (N) and edges (M) in the flow network.
- The coordinates of N source nodes.
- The coordinates, capacities, and fixed costs of M sink nodes.

3. **Outputs**  
- Returns the minimum cost to achieve the specified flow from the source to the sink. If the flow cannot be achieved, it returns -1.

4. **Preconditions**  
- The input values for N, M, and the coordinates must be valid integers.
- The capacities and costs associated with the edges must be non-negative.

5. **Postconditions**  
- The output is the minimum cost calculated based on the provided inputs, or -1 if the flow cannot be achieved.

6. **Invariants**  
- The flow network maintains valid capacities throughout the execution, ensuring that no edge capacity becomes negative.
- The potential values for nodes are updated consistently to reflect the current state of the flow network.

7. **Error Handling / Exceptional Behavior**  
- If the flow cannot be achieved (i.e., there is no valid path from source to sink), the function returns -1.
- The program does not handle invalid input formats or types explicitly; behavior is undefined for such cases.

8. **State Transitions (if applicable)**  
- The state of the flow network transitions as edges are added and capacities are updated during the execution of the minimum cost flow algorithm.

9. **Non-functional Constraints (if inferable)**  
- The algorithm is expected to operate efficiently within the constraints of the problem, handling up to a maximum of 110 nodes and edges. Performance may vary based on the input size and structure.
