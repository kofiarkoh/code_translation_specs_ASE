1. Functional Description  
The program reads pairs of integer values and computes the difference between each pair, outputting the result for each computation.

2. Inputs  
The program reads a total of 14 integer values from standard input, organized as 7 pairs of integers.

3. Outputs  
The program outputs 7 integer values, each representing the difference between the two integers from each pair, printed on separate lines.

4. Preconditions  
The input must consist of exactly 14 integers provided in pairs. Each integer must be within the range of representable integers.

5. Postconditions  
The output will consist of 7 lines, each containing the result of subtracting the second integer of each pair from the first integer.

6. Invariants  
The program maintains that for each pair of integers read, the output will always be the result of the subtraction of the second integer from the first.

7. Error Handling / Exceptional Behavior  
The program does not handle input errors or invalid data types. If the input does not conform to the expected format, behavior is undefined.

8. State Transitions (if applicable)  
Not applicable.

9. Non-functional Constraints (if inferable)  
The program processes input and produces output in a linear fashion, with a fixed number of iterations and outputs. Performance is constant with respect to the number of pairs processed.
