1. Functional Description  
Calculates the sum of the input values, each decremented by one, and returns the result.

2. Inputs  
Reads an integer value representing the number of subsequent integers, followed by that many integer values.

3. Outputs  
Returns a single integer value representing the total sum of the input integers, each reduced by one.

4. Preconditions  
The first input must be a positive integer indicating the number of subsequent integers. Each subsequent integer must be within a valid range for integer representation.

5. Postconditions  
The output value is the sum of all input integers, each decreased by one.

6. Invariants  
The sum is always non-negative if the input integers are all greater than or equal to one.

If the first input is non-positive or if any subsequent input is invalid (e.g., non-integer), behavior is not defined.
