1. **Functional Description**  
   The program calculates the maximum value obtainable from a fractional knapsack problem given a set of items with specific weights and values, allowing for the inclusion of fractional parts of items.

2. **Inputs**  
   - An integer representing the number of items.  
   - A double representing the total weight capacity of the knapsack.  
   - For each item, an integer representing the weight and an integer representing the value.

3. **Outputs**  
   - A double representing the maximum value that can be obtained, printed to standard output.

4. **Preconditions**  
   - The number of items is a non-negative integer.  
   - The total weight capacity is a non-negative double.  
   - Each item's weight and value are integers, where weight can be negative, and value can be zero or negative.

5. **Postconditions**  
   - The output value is the maximum obtainable value based on the provided weights and values, adhering to the knapsack's weight capacity.

6. **Invariants**  
   - The total weight of selected items does not exceed the knapsack's weight capacity.  
   - The program maintains a list of items with positive value-to-weight ratios for consideration.

7. **Error Handling / Exceptional Behavior**  
   - Items with non-positive values and non-negative weights are ignored.  
   - If all items are ignored, the output will be zero.

8. **State Transitions (if applicable)**  
   - The state transitions involve updating the total weight capacity and the accumulated value as items are selected or partially selected.

9. **Non-functional Constraints (if inferable)**  
   - The program operates within a time complexity that allows sorting of items based on their value-to-weight ratio, which is efficient for a reasonable number of items.  
   - The output precision is maintained to a specific threshold, ensuring numerical stability in the result.
