1. **Functional Description**  
The program determines the stability of a structure represented in a grid format, where each cell can either be occupied or empty. It processes the grid to identify connected components and evaluates their stability based on specific geometric criteria.

2. **Inputs**  
- A series of grid dimensions (width and height) followed by the grid itself, where each cell is either occupied (represented by a character) or empty (represented by a dot). The input continues until a width of zero is encountered.

3. **Outputs**  
- For each grid processed, the program outputs either "STABLE" or "UNSTABLE" based on the stability evaluation of the structure.

4. **Preconditions**  
- The input must consist of valid integers for width and height, followed by a grid of characters with dimensions matching the specified width and height. The width must be greater than zero for processing to occur.

5. **Postconditions**  
- The program guarantees that it will output a stability status ("STABLE" or "UNSTABLE") for each valid grid input before terminating.

6. **Invariants**  
- The grid remains unchanged throughout the execution of the program. The relationships between occupied cells are maintained correctly during processing.

7. **Error Handling / Exceptional Behavior**  
- If the input dimensions are invalid (e.g., negative or non-integer values), the program does not process further and will not produce output for that case. The program assumes well-formed input as per the specified format.

8. **State Transitions (if applicable)**  
- The program transitions through states based on the processing of each cell in the grid, updating the internal structures that track connected components and their properties. The final state determines the output.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a fixed memory limit defined by the maximum grid size and the number of components, ensuring efficient use of resources. The execution time is expected to be linear relative to the number of cells in the grid.
