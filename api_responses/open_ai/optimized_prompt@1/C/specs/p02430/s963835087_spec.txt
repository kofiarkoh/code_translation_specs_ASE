1. **Functional Description**  
The program generates and outputs all combinations of indices from a set of size `n`, where exactly `k` indices are selected. Each combination is represented as a binary pattern.

2. **Inputs**  
The program reads two integers from standard input: `n` (the size of the set) and `k` (the number of indices to select).

3. **Outputs**  
The program outputs each valid combination of indices in the format "pattern: index1 index2 ...", where "pattern" is the binary representation of the selection and "index1, index2, ..." are the selected indices. Each combination is printed on a new line.

4. **Preconditions**  
- The input values for `n` and `k` must be non-negative integers.
- The value of `k` must not exceed `n`.

5. **Postconditions**  
- The output will contain all combinations of indices from 0 to `n-1` where exactly `k` indices are selected.
- If no valid combinations exist (e.g., when `k` is greater than `n`), no output will be produced.

6. **Invariants**  
- The program maintains that for each generated pattern, the number of selected indices (as determined by the binary representation) is exactly `k`.

7. **Error Handling / Exceptional Behavior**  
- If input reading fails, the program will return an error code. 
- If the input values are invalid (e.g., `k > n`), the program will not produce any output.

8. **State Transitions (if applicable)**  
Not applicable.

9. **Non-functional Constraints (if inferable)**  
- The program is limited by the maximum size of the input buffer, which may restrict the maximum value of `n` that can be processed effectively.
