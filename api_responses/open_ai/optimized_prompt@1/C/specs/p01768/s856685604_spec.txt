1. **Functional Description**  
The program initializes a graph structure representing ingredients and their associated costs, builds connections between them, and computes the minimum cost of each ingredient based on its connections. It returns the total minimum cost across all ingredients.

2. **Inputs**  
- An integer representing the number of ingredients.  
- A list of ingredient names (up to 10 characters each) and their associated costs.  
- An integer representing the number of connections between ingredients.  
- Pairs of ingredient names representing connections.

3. **Outputs**  
- An integer representing the total minimum cost of all ingredients.

4. **Preconditions**  
- The number of ingredients is a positive integer.  
- Each ingredient name is unique and does not exceed 10 characters.  
- The cost associated with each ingredient is a non-negative integer.  
- The number of connections is a non-negative integer.

5. **Postconditions**  
- The program computes and outputs the total minimum cost based on the connections established between ingredients.

6. **Invariants**  
- The graph structure remains consistent throughout the execution, with each ingredient correctly linked to its connections.  
- The minimum cost for each ingredient is updated correctly based on its connections.

7. **Error Handling / Exceptional Behavior**  
- If an ingredient name is not found during connection establishment, the program does not create a connection for that ingredient.  
- Memory allocation failures during initialization or connection addition are not explicitly handled.

8. **State Transitions (if applicable)**  
- The state transitions occur during the initialization of the graph, the addition of connections, and the computation of minimum costs for each ingredient.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a fixed maximum size for ingredients and connections (5000).  
- Memory usage may increase with the number of connections due to dynamic allocation.  
- The performance is influenced by the number of ingredients and connections, particularly during the depth-first search for minimum costs.
