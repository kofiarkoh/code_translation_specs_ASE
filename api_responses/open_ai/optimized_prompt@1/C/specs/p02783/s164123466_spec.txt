1. Functional Description  
Calculates the ceiling of the division of two integers.

2. Inputs  
Two integers provided via standard input.

3. Outputs  
An integer representing the ceiling of the division of the first integer by the second, printed to standard output.

4. Preconditions  
The second integer must not be zero.

5. Postconditions  
The output integer is greater than or equal to the result of the division of the first integer by the second.

6. Invariants  
The output integer is always a non-negative integer if the first integer is non-negative.

7. Error Handling / Exceptional Behavior  
If the second integer is zero, the behavior is undefined.

8. State Transitions (if applicable)  
Not applicable.

9. Non-functional Constraints (if inferable)  
Not inferable from code.
