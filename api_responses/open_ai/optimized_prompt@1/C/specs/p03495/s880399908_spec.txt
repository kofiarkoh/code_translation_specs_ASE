1. **Functional Description**  
The program reads a sequence of integers, counts the occurrences of each integer, sorts these counts, and computes the sum of the counts of the first \( N - K \) unique integers.

2. **Inputs**  
- Two integers \( N \) and \( K \) representing the number of integers to read and a threshold for unique counts, respectively.  
- An array of \( N \) integers.

3. **Outputs**  
- A single long long integer representing the sum of the counts of the first \( N - K \) unique integers.

4. **Preconditions**  
- \( N \) is a positive integer.  
- \( K \) is a non-negative integer such that \( K \leq N \).  
- The integers read are within a valid range that can be indexed by the counting array.

5. **Postconditions**  
- The output is the sum of the counts of the first \( N - K \) unique integers, or zero if there are fewer than \( N - K \) unique integers.

6. **Invariants**  
- The counting array accurately reflects the number of occurrences of each integer in the input array.  
- The counts in the counting array are sorted in non-decreasing order before the sum is computed.

7. **Error Handling / Exceptional Behavior**  
- If the input integers exceed the bounds of the counting array, behavior is not defined.  
- Memory allocation failures for the counting array may lead to undefined behavior.

8. **State Transitions (if applicable)**  
- The state transitions from reading input values to populating the counting array, then to sorting the counts, and finally to computing the sum of the specified counts.

9. **Non-functional Constraints (if inferable)**  
- The time complexity is influenced by the sorting operation, which is \( O(N \log N) \).  
- The space complexity is \( O(N) \) due to the counting array.
