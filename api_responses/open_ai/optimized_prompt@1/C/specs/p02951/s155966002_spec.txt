1. Functional Description  
The program reads three integer values, modifies one of them based on the others, and outputs the final value of the modified integer.

2. Inputs  
Three integers are read from standard input.

3. Outputs  
One integer is printed to standard output, representing the final value of the modified integer.

4. Preconditions  
The input integers must be valid integers. The third integer must be non-negative.

5. Postconditions  
The output integer is the result of subtracting the first integer from the second integer, with the result decremented by the minimum of the result and the third integer.

6. Invariants  
The first integer is always reduced by the value of the second integer before any further operations. The third integer is decremented until it reaches zero or the first integer becomes non-positive.

7. Error Handling / Exceptional Behavior  
If the input values are not valid integers, the behavior is undefined. If the third integer is negative, the behavior is also undefined.

8. State Transitions (if applicable)  
The state transitions involve reading input values, modifying the first integer, and decrementing the third integer based on the modified value.
