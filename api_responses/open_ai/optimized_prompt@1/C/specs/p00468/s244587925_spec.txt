1. **Functional Description**  
The program processes multiple datasets to determine the number of students connected to a specific student through direct or indirect relationships. It reads pairs of relationships and counts how many students are reachable from a designated starting student.

2. **Inputs**  
The program reads multiple datasets consisting of:  
- Two integers, `n` (number of students) and `m` (number of relationships).  
- `m` pairs of integers representing relationships between students.

3. **Outputs**  
The program outputs the count of students that are reachable from the designated starting student for each dataset, printed as an integer.

4. **Preconditions**  
- The input values for `n` and `m` must be non-negative integers.  
- The maximum value for `n` and `m` is 500.  
- The pairs of integers representing relationships must be within the range of valid student indices (1 to `n`).

5. **Postconditions**  
- For each dataset, the output is the count of students that can be reached from the starting student, excluding the starting student itself.

6. **Invariants**  
- The relationship matrix is initialized to zero for all students at the beginning of each dataset processing.  
- The list tracking reachable students is reset for each dataset.

7. **Error Handling / Exceptional Behavior**  
- The program terminates gracefully when both `n` and `m` are zero, indicating no further datasets to process.  
- No specific error handling for invalid input values is implemented; behavior is undefined for inputs outside specified constraints.

8. **State Transitions (if applicable)**  
- The program transitions between states based on the input datasets, resetting internal structures for each new dataset and accumulating counts of reachable students.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a time complexity that is manageable for the maximum constraints, ensuring efficient processing of relationships.  
- Memory usage is constrained by the fixed-size arrays, which are limited to 501x501 for the relationship matrix and 501 for the list.
