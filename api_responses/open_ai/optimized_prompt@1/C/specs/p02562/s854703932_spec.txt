1. **Functional Description**  
   The program computes the maximum flow in a flow network with associated costs, using a successive shortest path algorithm. It constructs a bipartite graph from input data, calculates the maximum flow, and outputs the flow configuration.

2. **Inputs**  
   - An integer representing the number of nodes in one partition of the bipartite graph.
   - An integer representing the capacity of the flow from the source to the sink.
   - A matrix of costs associated with edges between nodes in the two partitions.

3. **Outputs**  
   - A long integer representing the maximum flow value.
   - A visual representation of the flow configuration in the bipartite graph, indicating which edges are used in the flow.

4. **Preconditions**  
   - The number of nodes and the capacity must be positive integers.
   - The cost matrix must be properly formatted and correspond to the dimensions defined by the number of nodes.

5. **Postconditions**  
   - The output maximum flow value is non-negative and represents the optimal flow configuration.
   - The flow configuration output accurately reflects the edges utilized in achieving the maximum flow.

6. **Invariants**  
   - The flow values for each edge do not exceed their respective capacities.
   - The total flow into any node equals the total flow out, except for the source and sink nodes.

7. **Error Handling / Exceptional Behavior**  
   - If the maximum flow cannot be computed (e.g., due to negative cycles), the program returns a sentinel value indicating failure.
   - Memory allocation failures during execution result in undefined behavior.

8. **State Transitions (if applicable)**  
   - The state transitions occur as edges are added to the flow network, and flow values are updated based on the results of the successive shortest path calculations.

9. **Non-functional Constraints (if inferable)**  
   - The algorithm operates within polynomial time complexity relative to the number of nodes and edges in the graph.
   - Memory usage is proportional to the number of nodes and edges, with additional overhead for temporary data structures.
