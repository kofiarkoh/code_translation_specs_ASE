1. Functional Description  
The code transforms an input string by modifying each character based on its ASCII value. Uppercase letters are shifted backward by three positions, while all other characters are shifted forward by twenty-three positions.

2. Inputs  
The program reads a single string from standard input, which may consist of any characters.

3. Outputs  
The program outputs a modified string to standard output, reflecting the transformations applied to the input string.

4. Preconditions  
The input string must be null-terminated and can have a maximum length of 999 characters (excluding the null terminator).

5. Postconditions  
The output string is guaranteed to be a valid null-terminated string, with each character transformed according to the specified rules.

6. Invariants  
The length of the output string will not exceed the length of the input string. The output will always be null-terminated.

7. Error Handling / Exceptional Behavior  
If the input exceeds the maximum length, behavior is not defined. The program does not handle input errors or invalid characters explicitly.

8. State Transitions (if applicable)  
Not applicable.

9. Non-functional Constraints (if inferable)  
The program operates in linear time relative to the length of the input string.
