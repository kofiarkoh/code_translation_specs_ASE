1. Functional Description  
Computes and outputs an integer with exactly `N` decimal digits that satisfies `M` digit-position constraints of the form “the digit at position `s` equals `c`”. If no such `N`-digit integer exists, outputs `-1`. If `M` is zero, outputs the smallest `N`-digit integer (with the special case that for `N = 1` it outputs `0`).

2. Inputs  
- An integer `N`: the required number of digits.  
- An integer `M`: the number of constraints.  
- `M` pairs `(s, c)` where:  
  - `s` is a 1-based digit position within the `N`-digit number (from most significant to least significant).  
  - `c` is the required digit value at that position.

3. Outputs  
- A single integer:  
  - An `N`-digit nonnegative integer satisfying all constraints, if one is constructed by the program’s rules; or  
  - `-1` if the constraints are detected as inconsistent or if the most significant digit is constrained to `0` when `N > 1`.

4. Preconditions  
- `N` is intended to be in the range 1 to 3 (the program’s place-value handling is only defined for up to 3 digits).  
- Each constraint position `s` is intended to be within `1..N`.  
- Each constraint digit `c` is intended to be within `0..9`.  
(If these are violated, behavior is not reliably defined by the code.)

5. Postconditions  
- If `M = 0` and `N ∈ {1,2,3}`, the output is:  
  - `0` when `N = 1`,  
  - `10` when `N = 2`,  
  - `100` when `N = 3`.  
- If `M > 0` and the program does not output `-1`, the output is an integer with exactly `N` digits that matches every provided constraint that is not contradicted by another constraint. Unconstrained digits are chosen to make the number as small as possible under the program’s rules, including ensuring a nonzero most significant digit when `N > 1`.

6. Invariants  
- For any digit position that appears in multiple constraints, all specified digit values for that position must agree; otherwise the result is considered impossible.  
- When a valid result is produced for `N > 1`, the most significant digit is nonzero.

7. Error Handling / Exceptional Behavior  
- Outputs `-1` if it detects contradictory constraints for the same position.  
- Outputs `-1` if (and only if) the first provided constraint explicitly sets the most significant digit to `0` while `N > 1`, regardless of other constraints.  
- If `N` is outside 1..3, or if any constraint uses an out-of-range position or digit, the program’s behavior is not well-defined by the code.

8. State Transitions (if applicable)  
- No persistent state; a single computation from input to output.

9. Non-functional Constraints (if inferable)  
- Time and memory usage are linear in `M` and `N` (with `N` effectively bounded to at most 3 under intended use).
