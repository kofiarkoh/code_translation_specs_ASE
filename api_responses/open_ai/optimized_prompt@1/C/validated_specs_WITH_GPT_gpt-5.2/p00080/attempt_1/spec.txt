1. Functional Description  
Computes and outputs an approximation of the real cube root of each provided integer value, processing values sequentially until a designated termination value or end of input is reached.

2. Inputs  
- A sequence of integer values read from standard input.  
- A special sentinel integer value indicating termination.

3. Outputs  
- For each processed input integer (excluding the sentinel), one line to standard output containing a decimal approximation of its real cube root, rounded to a fixed number of digits after the decimal point.

4. Preconditions  
- Each non-terminating input integer is assumed to be strictly positive.  
- Input is assumed to be well-formed as a sequence of integers.

5. Postconditions  
For each processed input integer \( q \) (with \( q > 0 \)):  
- Exactly one output line is produced.  
- The printed value \( r \) satisfies the relative cube error criterion:  
  \[
  |r^3 - q| < \varepsilon \cdot q
  \]
  where \( \varepsilon = 10^{-5} \).  
- The output value is an approximation of the real cube root of \( q \).

6. Invariants  
- Each output line corresponds to exactly one input integer processed (excluding the sentinel).  
- Processing continues input-by-input until termination conditions are met.

7. Error Handling / Exceptional Behavior  
- No explicit error reporting is performed.  
- If a non-positive integer is provided (including zero), the behavior is not guaranteed by this specification (the computation may fail to terminate or may produce invalid numeric results).  
- If malformed input occurs, behavior is unspecified beyond potentially terminating input processing.

8. State Transitions (if applicable)  
- Initial state: ready to read the next integer.  
- For each read integer:  
  - If it is the sentinel value, transition to terminated state.  
  - Otherwise, transition to “compute cube root approximation,” then to “emit result,” then back to ready-to-read.  
- End-of-input transitions directly to terminated state.

9. Non-functional Constraints (if inferable)  
- Uses a fixed absolute/relative tolerance parameter \( \varepsilon = 10^{-5} \) to determine when the approximation is sufficiently accurate.  
- Output precision is fixed to a constant number of digits after the decimal point.
