Given an undirected tree on \(n\) labeled vertices, the program computes, for every vertex \(v\), a value determined by the sizes of the connected components that would remain if \(v\) were removed. \[
n!\;\cdot\;\prod_{i=1}^{k}\frac{1}{s_i! \cdot s_i}
\;\equiv\;
\frac{n!}{\left(\prod_i s_i!\right)\left(\prod_i s_i\right)}
\pmod P.
\]
Equivalently, since \(\prod_i (s_i!\,s_i)=\prod_i \bigl(s_i\cdot s_i!\bigr)=\prod_i \bigl((s_i+0)\cdot s_i!\bigr)\), the result is a component-size–based expression that includes both factorial terms and an additional multiplicative factor of the component sizes themselves.

2. Inputs  
- An integer \(n\), the number of vertices.  
- \(n-1\) undirected edges, each given as a pair of vertex indices.

3. Outputs  
- Exactly \(n\) lines are printed.  
- Line \(v\) (for vertex indices in increasing order) contains one integer in \([0, P-1]\) equal to:
  \[
  \frac{n!}{\left(\prod_{C \in \text{components}(V\setminus\{v\})} |C|!\right)\left(\prod_{C \in \text{components}(V\setminus\{v\})} |C|\right)}
  \bmod P,
  \]
  where the products range over the connected components of the graph obtained by removing \(v\).

- The input graph is a tree: it has exactly \(n\) vertices, exactly \(n-1\) edges, is connected, and has no cycles.
