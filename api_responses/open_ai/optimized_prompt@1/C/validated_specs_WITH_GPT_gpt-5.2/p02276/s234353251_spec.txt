1. Functional Description  
Reads a sequence of integers, performs a single partitioning step around the last element of the sequence (the pivot), rearranging the sequence in-place so that all values less than or equal to the pivot appear before it and all values greater than the pivot appear after it, then outputs the rearranged sequence while marking the pivot’s final position.

2. Inputs  
- An integer `n`: the number of elements.  
- A sequence of `n` integers.

3. Outputs  
- A single line containing the `n` integers after partitioning, separated by single spaces.  
- Exactly one element (the pivot in its final position) is printed with surrounding brackets to indicate its final index after partitioning.

4. Preconditions  
- `n` is within the supported storage capacity: `1 <= n <= 1,000,000`.  
- Exactly `n` integers are provided after `n`.  
- Input values fit within the range of the program’s integer type.  

5. Postconditions  
Let `pivot` be the original last input element. Let `k` be the pivot’s final 1-based position after partitioning. After execution:  
- The output sequence is a permutation of the input sequence.  
- The element at position `k` equals `pivot`.  
- For all positions `i` with `1 <= i < k`, the value at position `i` is `<= pivot`.  
- For all positions `i` with `k < i <= n`, the value at position `i` is `> pivot`.  
- The output marks exactly position `k` with brackets.

6. Invariants  
- The multiset of stored elements is preserved (only reordering occurs).  
- The pivot value remains present exactly once and ends at the marked position.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If input is missing, malformed, or `n` is outside the supported range, behavior is undefined (may produce incorrect output or access invalid memory).

8. State Transitions (if applicable)  
- Transitions from an initial state with an uninitialized sequence to a state where the sequence is populated from input.  
- Transitions to a partitioned state where the sequence satisfies the partition property around the pivot and the pivot index is determined.  
- Final transition to an output-completed state after printing the partitioned sequence.

9. Non-functional Constraints (if inferable)  
- Operates in-place using a fixed global storage capacity for up to 1,000,000 integers.  
- Performs a single linear-time partitioning pass over the `n` elements (time proportional to `n`).
