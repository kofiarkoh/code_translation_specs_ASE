#include <stdio.h>
#include <string.h>

typedef struct {
	char name[30];
	int score;
} TEAM;
	
	
int main(void)
{
	int n, i, j, f = 0;
	int win, lose, draw;
	TEAM team[10], temp;
	

	while (1){
		scanf("%d", &n);
		
		if (n == 0){
			break;
		}
		
		for (i = 0; i < n; i++){
			scanf("%s %d %d %d", team[i].name, &win, &lose, &draw);
			team[i].score = win * 3 + draw;
		}
		
		for (i = 0; i < n; i++){
			for (j = n - 1; j > i; j--){
				if (team[j].score > team[j-1].score){
					strcpy(temp.name, team[j-1].name);
					temp.score = team[j-1].score;
					
					strcpy(team[j-1].name, team[j].name);
					team[j-1].score = team[j].score;
					
					strcpy(team[j].name, temp.name);
					team[j].score = temp.score;
				}
			}
		}
		if (f == 1){
			puts("");
		}
		for (i = 0; i < n; i++){
			printf("%s,%d\n", team[i].name, team[i].score);	
			f = 1;
		}
	}
	
	return (0);
}

1. Functional Description  
Reads one or more datasets describing teams and their match results, computes a points total for each team, orders teams by descending points, and outputs each team with its computed points. Processing ends when a dataset size of zero is provided.

3. Outputs

6. Invariants  
- Across all datasets, the program does not retain or combine team data between datasets; each dataset is processed independently except for the insertion of a blank line between dataset outputs.

8. State Transitions (if applicable)

9. Non-functional Constraints (if inferable)

- Time and memory usage are bounded by small fixed limits due to the fixed maximum dataset size.

C. What general behavior should be clarified in the specification  
Clarify the exact line format for each team in the output, including the required punctuation between fields (i.e., whether the name and score are separated by a comma vs. whitespace) and that no extra text is included. This is a general formatting contract, not an edge case.

D. Why this clarification is supported by the source program  
The source uses `printf("%s,%d\n", team[i].name, team[i].score);`, which unambiguously requires a comma between the team name and the score on every output line. The blank line behavior between datasets already matches the spec and the source; the only observed divergence is the per-line delimiter, which the source hard-codes.
