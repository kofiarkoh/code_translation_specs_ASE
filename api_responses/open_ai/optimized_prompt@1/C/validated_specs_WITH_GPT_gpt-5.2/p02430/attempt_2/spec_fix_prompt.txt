1. Functional Description  
Generates and outputs all bitmask values representable with `n` bits that contain exactly `k` set bits. For each such bitmask, outputs the bitmask value followed by the list of zero-based bit positions that are set in that bitmask.

2. Inputs  
- Two integers read from standard input:

  - `k`: the required number of set bits in each generated bitmask.

3. Outputs  
- To standard output, zero or more lines. Each line corresponds to one bitmask with exactly `k` set bits and contains:  
  - The integer value of the bitmask, and  
  - The ordered list (ascending) of indices in `[0, n-1]` whose bits are set in that bitmask.

4. Preconditions  
- Input provides two integers.  
- `n` is assumed to be non-negative.

5. Postconditions  
- For every integer bitmask `p` in the range `[0, 2^n - 1]` that has exactly `k` set bits, exactly one output line is produced describing `p` and its set bit positions.

- Each produced line lists only indices `i` such that `0 <= i < n`.  
- Within a line, listed indices are strictly increasing.  
- For each produced line, the number of listed indices equals `k`.  
- Across all produced lines, each qualifying bitmask in `[0, 2^n - 1]` appears exactly once.

7. Error Handling / Exceptional Behavior  
- There is no explicit error reporting.  
- If input cannot be read or parsed as two integers, the values used for `n` and/or `k` are unspecified, and resulting output is unspecified.
