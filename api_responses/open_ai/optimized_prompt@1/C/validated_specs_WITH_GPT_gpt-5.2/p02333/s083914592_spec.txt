1. Functional Description  
Computes, under a fixed prime modulus, the value of the alternating binomial sum  
\[
\sum_{i=0}^{m} (-1)^{m-i}\binom{m}{i} \, i^{n}
\]
and outputs the result reduced to the canonical non-negative residue modulo that modulus.

2. Inputs  
- Two integers:  
  - \(n\): exponent parameter.  
  - \(m\): binomial-sum upper index.

3. Outputs  
- One integer: the computed sum modulo the fixed modulus, in the range \([0, \text{modulus}-1]\).

4. Preconditions  
- \(0 \le m \le 2000\) (required for internal precomputation bounds).  
- \(n \ge 0\) (required for exponentiation semantics used by the computation).  
- The modulus is prime and greater than the precomputation range (implied by correctness of modular inverses used).  
- Input is well-formed and provides exactly two integers.

5. Postconditions  
- The output equals the canonical residue modulo the modulus of  
  \[
  \sum_{i=0}^{m} (-1)^{m-i}\binom{m}{i} \, i^{n}.
  \]
- The printed value is within \([0, \text{modulus}-1]\).

6. Invariants  
- All intermediate arithmetic is interpreted modulo the fixed modulus.  
- Binomial coefficients used in the sum correspond to \(\binom{m}{i}\) for \(i \in [0,m]\), and are treated as zero outside valid ranges (though the summation only uses valid indices).

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If preconditions are violated (e.g., \(m>2000\), negative \(n\), malformed input), behavior is unspecified and may produce incorrect results.

8. State Transitions (if applicable)  
- Initializes internal precomputed tables for factorials and inverse factorials up to 2000 under the modulus.  
- No persistent state is maintained beyond program termination.

9. Non-functional Constraints (if inferable)  
- Time complexity is \(O(m \log n + m)\) for the main computation after precomputation, with precomputation bounded by a constant limit (2000).  
- Memory usage is \(O(2000)\) for precomputed tables.
