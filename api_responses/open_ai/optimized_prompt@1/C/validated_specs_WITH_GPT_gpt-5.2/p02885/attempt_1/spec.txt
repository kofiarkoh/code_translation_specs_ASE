1. Functional Description  
Reads two integers and outputs a single integer equal to the positive part of the expression (first integer minus twice the second integer). If the expression is not positive, outputs zero.

2. Inputs  
- Two signed integers provided via standard input.

3. Outputs  
- One signed integer written to standard output:
  - `max(first_input − 2 × second_input, 0)`

4. Preconditions  
- Standard input provides two integers in a readable form.
- The computation `first_input − 2 × second_input` is representable within the integer range of the execution environment (to avoid overflow/underflow).

5. Postconditions  
- Exactly one integer value is produced on standard output, equal to `max(first_input − 2 × second_input, 0)`.

6. Invariants  
- The output value is always greater than or equal to zero.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed for missing/invalid input.
- If input cannot be read as two integers, the resulting output is unspecified.
- If arithmetic overflow/underflow occurs during evaluation, behavior is undefined.

8. State Transitions (if applicable)  
- None beyond consuming two input values and producing one output value.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and uses constant memory.
