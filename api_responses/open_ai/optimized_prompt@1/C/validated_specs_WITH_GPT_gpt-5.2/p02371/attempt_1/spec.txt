1. Functional Description  
Computes and outputs the maximum total edge weight along any simple path between two vertices in a connected, undirected, weighted tree (i.e., the tree’s weighted diameter length).

2. Inputs  
- An integer specifying the number of vertices.  
- A sequence of exactly one fewer undirected edges than the number of vertices.  
- Each edge is given by two vertex indices and an integer edge weight.

3. Outputs  
- A single integer: the maximum possible sum of edge weights along any simple path in the given tree.

4. Preconditions  
- The number of vertices is positive and does not exceed the implementation’s fixed capacity.  
- Exactly (number of vertices − 1) edges are provided.  
- Vertex indices in edges refer to valid vertices.  
- The input graph is a tree: connected and acyclic.  
- The weighted diameter length fits within the range of the integer type used for accumulation.

5. Postconditions  
- The printed value equals the maximum, over all pairs of vertices, of the sum of edge weights along the unique simple path connecting the pair.

6. Invariants  
- During each traversal used to compute the result, each vertex is visited at most once.  
- For any visited vertex during a traversal, its stored distance equals the sum of edge weights along the unique path from the traversal’s start vertex to that vertex (under the tree precondition).

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If preconditions are violated (e.g., not a tree, out-of-range indices, excessive size, or arithmetic overflow), behavior is unspecified and the output is not guaranteed to be meaningful.

8. State Transitions (if applicable)  
- The program has no externally visible persistent state.  
- Internal working state is initialized for the computation, used for two traversals to determine the diameter length, and then discarded upon termination.

9. Non-functional Constraints (if inferable)  
- Operates within fixed, statically allocated memory bounds; inputs exceeding those bounds are unsupported.  
- Intended to run in time proportional to the number of vertices and edges for valid tree inputs.
