1. Functional Description  
Computes and outputs the number of ordered triples of integers \((a,b,c)\) such that \(1 \le a,b,c \le N\) and \((a+b+c)\) is divisible by \(K\).

2. Inputs  
- Two signed integers \(N\) and \(K\) read from standard input.

3. Outputs  
- A single signed integer written to standard output: the count of ordered triples \((a,b,c)\) in \([1,N]^3\) whose sum is divisible by \(K\).

4. Preconditions  
- \(K \ne 0\).  
- \(N \ge 0\).  
- The computed result fits within the signed 64-bit integer range (to avoid arithmetic overflow).  
- Input is present and parseable as two signed integers.

5. Postconditions  
- If \(K\) is odd, the output equals \(\left\lfloor \frac{N}{K} \right\rfloor^3\).  
- If \(K\) is even, the output equals \(\left\lfloor \frac{N}{K} \right\rfloor^3 + \left\lfloor \frac{N + K/2}{K} \right\rfloor^3\).  
- The output equals the number of ordered triples \((a,b,c)\) with \(1 \le a,b,c \le N\) satisfying \((a+b+c) \bmod K = 0\).

6. Invariants  
- The produced count is non-negative.  
- The produced count does not exceed \(N^3\).

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If input is missing/invalid, or if \(K=0\), or if intermediate/final arithmetic overflows the signed 64-bit range, behavior is undefined with respect to this specification.

8. State Transitions (if applicable)  
- None; the program is a single-shot computation with no persistent state.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory relative to \(N\) and \(K\).
