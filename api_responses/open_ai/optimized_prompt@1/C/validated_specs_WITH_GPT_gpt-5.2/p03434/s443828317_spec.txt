1. Functional Description  
The program reads an integer count and a sequence of that many integer values, sorts the values in nondecreasing order, then forms two sums by traversing the sorted sequence from largest to smallest and alternately adding the current value to the first sum, then the next value to the second sum, repeating until all values are assigned. It outputs the difference (first sum minus second sum) followed by a newline.

2. Inputs  
- One decimal integer `N` read using C `scanf` with the `%d` conversion (stored in an `int`).  
- Then `N` decimal integers read using C `scanf` with the `%lld` conversion (each stored in a `long long`).

3. Outputs  
- One decimal integer printed using C `printf` with the `%lld` conversion, representing the computed difference `SumA - SumB`, followed by `\n`.

4. Preconditions / Assumptions  
- `N` is nonnegative.  
- Exactly `N` values are present in the input in a form acceptable to `scanf` with the specified conversions; otherwise behavior is undefined.  
- The program uses a variable-length array `long long a[N]`; therefore `N` must be such that allocating this array on the stack is valid in the target environment.  
- All input values must be strictly less than `1,000,000,000,000,000,000` (1e18). This is required because the sorting routine uses that constant as a sentinel during merging; values greater than or equal to it can break correct ordering and thus the final result.  
- Sufficient heap memory is available for temporary arrays used during merge steps; if allocation fails, behavior is undefined.  
- The running sums and final difference must fit in the range of `long long`; if overflow occurs, behavior is undefined.

5. Computation Semantics (Postconditions)  
- Let the input multiset be sorted into a nondecreasing sequence `a[0] <= a[1] <= ... <= a[N-1]`.  
- Initialize `SumA = 0`, `SumB = 0`.  
- For indices from `N-1` down to `0`:
  - The element at the current index is added to `SumA` if it is the 1st, 3rd, 5th, ... element encountered in this descending traversal; otherwise it is added to `SumB`. Equivalently, `a[N-1]` goes to `SumA`, `a[N-2]` to `SumB`, `a[N-3]` to `SumA`, etc.  
- The program outputs `SumA - SumB`.  
- If `N` is odd, `SumA` receives exactly one more element than `SumB`; if `N` is even, they receive the same number of elements.

6. Ordering / Tie Handling  
- Sorting is nondecreasing. Equal values may appear in any relative order consistent with a stable merge procedure; however, because equal values are indistinguishable for the sum computation, the result depends only on the multiset of values, not on the relative order of equal elements.

7. Error Handling / Exceptional Behavior  
- No explicit validation of `N`, input completeness, or allocation success is performed. If any precondition is violated, the program’s behavior is undefined.

8. Environment / Portability Notes  
- The numeric I/O contract is specifically based on `int` with `%d` for `N` and `long long` with `%lld` for the values and output. The program does not rely on `<inttypes.h>` format macros.
