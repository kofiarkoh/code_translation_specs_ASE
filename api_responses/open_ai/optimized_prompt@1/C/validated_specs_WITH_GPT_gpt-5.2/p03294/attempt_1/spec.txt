1. Functional Description  
Reads an integer count and a sequence of that many integers, then computes and outputs the sum over all elements of (element value minus 1).

2. Inputs  
- One integer specifying the number of subsequent integers to read.  
- A sequence of that many integers.

3. Outputs  
- A single integer equal to the sum of all input integers minus the count.

4. Preconditions  
- The count is non-negative.  
- Exactly the specified number of integers are available as input.  
- The computed result fits within the range of the program’s integer type (no overflow/underflow).

5. Postconditions  
- The output value equals: (sum of the provided integers) − (count).  
- No other output is produced.

6. Invariants  
- After processing any prefix of the sequence of length k (0 ≤ k ≤ count), the running total equals the sum of the first k integers minus k.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If inputs are missing/invalid, behavior is unspecified.  
- If the count is negative or if arithmetic overflows/underflows, behavior is unspecified.

8. State Transitions (if applicable)  
- Not applicable (single-run computation with no externally visible persistent state).

9. Non-functional Constraints (if inferable)  
- Time grows linearly with the count of integers.  
- Memory usage grows linearly with the count (stores the sequence).
