1. Functional Description  
Computes the result of repeatedly applying a one-dimensional “influence spread” transformation to an integer sequence of length N, up to K iterations, with early termination when the sequence becomes pointwise maximal.  
In one transformation step, each position j contributes +1 to every position i whose distance from j is at most the value at position j in the previous sequence. The new value at each position i is the total number of contributing positions j. The final sequence after the performed iterations is output.

2. Inputs  
- An integer N: the sequence length.  
- An integer K: the maximum number of transformation iterations to perform.  
- A sequence of N integers: the initial values.

3. Outputs  
- A sequence of N integers: the values after applying the transformation for T iterations, where T is the number of iterations actually performed (0 ≤ T ≤ K), printed in order and separated by single spaces, terminated by a newline.

4. Preconditions  
- 1 ≤ N ≤ 200000.  
- K ≥ 0.  
- The input provides at least N + 2 integers in total (N, K, and N sequence values).  
- To avoid out-of-bounds behavior, each initial sequence value is assumed to be non-negative.

5. Postconditions  
Let A⁰ be the initial sequence. For each iteration t ≥ 1, define Aᵗ such that for every position i in [1..N]:  
- Aᵗ[i] = |{ j in [1..N] : |i − j| ≤ Aᵗ⁻¹[j] }|.  
The program outputs Aᵀ where:  
- T = min(K, the first t such that Aᵗ[i] = N for all i, if such a t occurs; otherwise K).  
Additionally, for all i, the output value satisfies 0 ≤ Aᵀ[i] ≤ N.

6. Invariants  
- Throughout execution after initialization, the maintained sequence length remains N.  
- After each completed transformation step, every sequence element is an integer in [0, N].  
- The number of performed iterations never exceeds K.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed for malformed or insufficient input.  
- If preconditions are violated (e.g., N out of range, negative sequence values), behavior is undefined (may include incorrect results or memory errors).

8. State Transitions (if applicable)  
- State is the current sequence A.  
- Transition: A ← F(A), where F is the transformation defined in Postconditions.  
- The transition is applied repeatedly up to K times, but stops early if the current sequence becomes pointwise equal to N (i.e., all positions have value N).

9. Non-functional Constraints (if inferable)  
- Designed to operate within fixed-size memory bounds consistent with N up to 200000.  
- Execution time grows approximately linearly with N per performed iteration, for up to K iterations (or fewer with early termination).
