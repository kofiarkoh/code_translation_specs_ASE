1. Functional Description  
Reads a sequence of records, each containing a label and an integer key, sorts the records in nondecreasing order by the key, determines whether the resulting order is stable with respect to the original input order for equal keys, then outputs the stability result followed by the sorted records.

2. Inputs  
- An integer `n`: the number of records.  
- `n` records, each consisting of:  
  - a single-character label  
  - an integer key

3. Outputs  
- A single line indicating whether the produced sorted order is stable (“Stable”) or not (“Not stable”).  
- Then `n` lines, each containing the label and key of a record in the produced sorted order.

4. Preconditions  
- `n` is nonnegative.  
- Exactly `n` records are provided after `n`, each with a valid label and integer key.  
- Sufficient memory is available to store `n` records.

5. Postconditions  
- The output list is a permutation of the input records (no records are created, lost, or duplicated).  
- The output list is sorted in nondecreasing order by key.  
- The reported stability result is consistent with the produced output order:  
  - “Stable” iff for every pair of input records with equal keys, their relative order in the output matches their relative order in the input.  
  - Otherwise “Not stable”.

6. Invariants  
- Each record’s label and key remain associated with each other throughout processing.  
- The stability check is based on the original input order of records.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed for invalid input, input exhaustion, or allocation failure; behavior is unspecified in such cases.

8. State Transitions (if applicable)  
- Records transition from “unsorted, with remembered original order” to “sorted, with original order still known for stability evaluation,” then to “reported and printed.”

9. Non-functional Constraints (if inferable)  
- Sorting is not guaranteed to be stable.  
- Uses recursion; very large `n` may risk stack exhaustion depending on environment.
