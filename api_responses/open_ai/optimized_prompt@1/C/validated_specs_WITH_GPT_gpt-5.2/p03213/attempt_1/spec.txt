1. Functional Description  
Computes and outputs the number of positive divisors of the factorial of a given integer that have exactly 75 positive divisors.

2. Inputs  
- One integer value representing the upper bound of the factorial argument.

3. Outputs  
- One integer value: the count of positive divisors of the factorial that have exactly 75 divisors.

4. Preconditions  
- The input integer is within a range such that all required internal counting fits within fixed-size storage for prime-related counts (implied upper bound: at most 100).  
- The input integer is at least 0; meaningful results are produced for nonnegative inputs.

5. Postconditions  
- The output equals the number of integers \(d\) such that \(d\) divides \(n!\) and the number of positive divisors of \(d\) is exactly 75.  
- For \(n < 2\), the output is 0.

6. Invariants  
- For each integer \(k\) in the supported range, the stored count associated with \(k\) equals the total exponent of \(k\) in the prime factorization of \(n!\) if \(k\) is prime; for non-prime \(k\), the stored value is not used to define the result.  
- The computed result depends only on the multiset of prime exponents in \(n!\), not on any other properties of the input.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed for invalid, missing, or out-of-range input. Behavior is unspecified if the input cannot be read as an integer or if it exceeds the supported range implied by fixed storage.

8. State Transitions (if applicable)  
- No externally visible state is maintained across executions. The program reads input once, computes the result, outputs it, and terminates.

9. Non-functional Constraints (if inferable)  
- Designed for small inputs (implied by fixed storage sized for values up to 100).  
- Uses integer arithmetic; correctness assumes intermediate values do not overflow the integer type for the supported input range.
