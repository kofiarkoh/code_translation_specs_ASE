1. Functional Description  
Reads a short string and computes a score equal to a base value plus an increment for each occurrence of the character `o` within the first three characters of the input. Outputs the computed score.

2. Inputs  
- A single whitespace-delimited string token intended to represent exactly three characters.

3. Outputs  
- One integer value followed by a line break: the computed score.

4. Preconditions  
- The provided input token contains at least three characters.  
- The input token fits within the available storage for the string (including its terminator).  
  - Assumption: the intended use is a three-character token; longer tokens may violate memory safety.

5. Postconditions  
- Let `m` be the count of positions among the first three characters of the input whose value is `o`.  
- The program outputs the integer `700 + 100 * m`.  
- The output is one of: 700, 800, 900, or 1000.

6. Invariants  
- The count `m` is always an integer in the range 0 to 3 inclusive.  
- The computed score is always `700 + 100 * m`.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If input is missing, shorter than three characters, or longer than the storage allows, behavior is undefined (may produce incorrect output or crash).

8. State Transitions (if applicable)  
- No persistent state is maintained; execution is a single read–compute–write operation and then terminates.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory.
