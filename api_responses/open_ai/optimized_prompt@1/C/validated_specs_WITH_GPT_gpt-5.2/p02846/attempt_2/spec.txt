1. Functional Description  
The program reads two phase durations and two pairs of per-unit values for entities A and B (one per phase). It compares the entities’ time-weighted totals over the two phases and outputs either:
- the literal `infinity` if the two entities’ combined totals over both phases are exactly equal, or
- otherwise, a nonnegative integer computed from time-weighted per-phase differences after a normalization step that may swap A and B.

2. Inputs  
Six signed integers (read as 64-bit integers) in this order:
- `T1`, `T2`: durations of phase 1 and phase 2  
- `A1`, `A2`: A’s per-unit values in phase 1 and phase 2  
- `B1`, `B2`: B’s per-unit values in phase 1 and phase 2

3. Outputs  
Exactly one line:
- `infinity` followed by a newline, or  
- a decimal integer followed by a newline.

4. Preconditions / Assumptions  
- All six values are present in the input and fit in signed 64-bit integers.  
- All intermediate arithmetic used (products and differences such as `Ai*Ti`, `Bi*Ti`, and derived expressions below) does not overflow signed 64-bit range.  
- No validation is performed; behavior is unspecified if inputs are missing or if overflow occurs.

5. Computation and Postconditions  

5.1 Total-equality check  
Compute the two-phase totals:
- `TotalA = A1*T1 + A2*T2`  
- `TotalB = B1*T1 + B2*T2`  
If `TotalA == TotalB`, output `infinity` and terminate.

5.2 Normalization (possible swap)  
If `A1 > B1`, the program swaps A’s and B’s per-unit values for *both* phases (i.e., swaps `(A1,A2)` with `(B1,B2)`).  
After this step, `A1 <= B1` holds.

5.3 Derived quantities and integer result  
Define time-weighted phase-difference quantities (after any swap):
- `X = (B1 - A1) * T1`  
- `Y = (A2 - B2) * T2`

Then:
- If `X > Y`, output `0`.  
- Otherwise, let `D = Y - X` (so `D >= 0` in this branch). The program computes an integer count using integer division and remainder of `X` by `D`:
  - If `X % D == 0`, output `2 * (X / D)`.  
  - Else, output `2 * (X / D) + 1`.  

This uses the language’s integer division and remainder semantics for the involved signed integers.

6. Notes on edge conditions  
- In the non-`infinity` path, the program may attempt to compute `X / D` and `X % D`. If `D == 0`, this results in division/modulo by zero and the program’s behavior is undefined. (The program does not guard against this case.)  
- Apart from the `infinity` case, the output is intended to be a nonnegative integer as produced by the above rules.

7. State / Termination  
- The program is stateless aside from local variables.  
- It always prints exactly one line and then terminates normally, except in cases of undefined behavior (e.g., overflow or division by zero).
