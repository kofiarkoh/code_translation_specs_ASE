1. Functional Description  
Reads three integers and determines which of two fixed winner names to print based solely on whether the difference between the third and second integers is even or odd.

2. Inputs  
- Three integers read from standard input in this order: `N`, `A`, `B`.  
- `N` is read but does not affect the decision.

3. Outputs  
- Prints exactly one line to standard output consisting of one of the following exact strings (including capitalization), followed by a newline:
  - `Alice` if `(B - A)` is even.
  - `Borys` if `(B - A)` is odd.  
- No other output is produced.

4. Preconditions  
- The input stream provides three integers in a readable form.  
- The computation of `B - A` and the subsequent parity check are well-defined for the execution environment’s `int` type; if overflow occurs in `B - A`, behavior is unspecified.

5. Postconditions  
- If `(B - A) % 2 == 0`, the program outputs `Alice` followed by a newline.  
- Otherwise, it outputs `Borys` followed by a newline.  
- The program then terminates normally.

6. Invariants  
- The output depends only on the parity of `B - A`; `N` has no influence on the result.

7. Error Handling / Exceptional Behavior  
- No explicit handling for missing/invalid input; behavior is unspecified if the required integers cannot be read.

8. State Transitions (if applicable)  
- Not applicable; the program performs a single read, a single decision, a single write, and terminates.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory.
