1. Functional Description  
Computes, over all strings in a first list, the maximum value of:  
(count of that string in the first list) minus (count of that string in a second list).  
If all such values are negative, the reported maximum is 0.

2. Inputs  
- An integer specifying the number of strings in the first list.  
- That many strings (each intended to be a single token).  
- An integer specifying the number of strings in the second list.  
- That many strings (each intended to be a single token).

3. Outputs  
- A single integer: the maximum net count as defined above, lower-bounded by 0.

4. Preconditions  
- The first count is non-negative.  
- The second count is non-negative.  
- Each provided string fits within a fixed maximum length of 10 characters (excluding terminator) and contains no whitespace.  
- Sufficient memory/stack space exists to store both lists of strings.

5. Postconditions  
- The output equals:  
  max(0, max over all strings x that appear in the first list of (occurrences of x in first list − occurrences of x in second list)).  
- No other externally visible state is modified.

6. Invariants  
- The tracked maximum net count is never negative.  
- At any point after processing some candidates from the first list, the tracked maximum equals the maximum net count (lower-bounded by 0) among the candidates processed so far.

7. Error Handling / Exceptional Behavior  
- No explicit handling of invalid or missing input is performed; behavior is unspecified if inputs are malformed or incomplete.  
- If any string exceeds the maximum supported length, behavior is unspecified.  
- If counts are negative or too large for available storage, behavior is unspecified.

8. State Transitions (if applicable)  
- Stateless beyond local computation: reads input, computes the result, outputs it, then terminates.

9. Non-functional Constraints (if inferable)  
- Time cost grows proportionally to (size of first list) × (size of first list + size of second list), with comparisons proportional to string length.  
- Memory usage grows proportionally to the total number of input strings stored.
