1. Functional Description  
Reads the centers and radii of two circles in a 2D plane and classifies their relative positional relationship. Produces a single integer code indicating whether the circles are separate, externally tangent, intersecting at two points, internally tangent, or one strictly contained within the other without intersection.

2. Inputs  
- Two circle descriptions, each consisting of:
  - An integer x-coordinate of the center  
  - An integer y-coordinate of the center  
  - An integer radius  

3. Outputs  
- A single integer (followed by a line break) in the set {0, 1, 2, 3, 4} with the following meaning:
  - 4: circles are disjoint (no intersection points)  
  - 3: circles are externally tangent (touch at exactly one point, outside)  
  - 2: circles intersect at exactly two points  
  - 1: circles are internally tangent (touch at exactly one point, one inside the other)  
  - 0: one circle lies strictly inside the other with no intersection  

4. Preconditions  
- Exactly two circle descriptions are provided as input.  
- All provided values fit within the integer range such that all intermediate squared computations and additions/subtractions do not overflow.  
- Radii are assumed to be non-negative. (If negative radii are provided, the classification may not correspond to geometric circles.)

5. Postconditions  
- Exactly one classification code is written to output, corresponding to the geometric relationship implied by the given centers and radii under the no-overflow assumption.

6. Invariants  
- The classification is determined solely by comparing:
  - the squared distance between centers, and
  - the squared sum of radii, and
  - the squared difference of radii.  
- The output code is always one of {0, 1, 2, 3, 4} if the preconditions hold.

7. Error Handling / Exceptional Behavior  
- No explicit handling for malformed/insufficient input; behavior is unspecified if input cannot be read as required.  
- No explicit handling for integer overflow; if overflow occurs, the output may be incorrect.

8. State Transitions (if applicable)  
- Not applicable; the program has no persistent state beyond a single execution.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory.  
- Uses integer arithmetic only (no floating-point computations).
