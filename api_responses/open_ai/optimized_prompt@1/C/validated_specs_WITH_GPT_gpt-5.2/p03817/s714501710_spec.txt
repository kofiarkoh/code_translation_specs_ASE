1. Functional Description  
Computes and outputs an integer value derived from the input integer by grouping it into blocks of 11 and assigning a cost of 2 per full block plus an additional cost based on the remainder when divided by 11.

2. Inputs  
- One signed integer.

3. Outputs  
- One signed integer representing the computed cost/value for the given input.

4. Preconditions  
- The input is a valid integer representable in the program’s integer range.  
- The computed result fits within the same integer range.  
- Assumption: The intended domain is non-negative integers; behavior for negative inputs follows the language’s integer division/remainder rules and is not meaningfully specified beyond that.

5. Postconditions  
Let the input be \( n \). Let \( q \) be the integer quotient of \( n \) divided by 11, and \( r \) be the corresponding remainder. The output \( ans \) satisfies:  
- If \( r = 0 \), then \( ans = 2q \).  
- If \( 1 \le r \le 6 \), then \( ans = 2q + 1 \).  
- If \( 7 \le r \le 10 \), then \( ans = 2q + 2 \).

6. Invariants  
- The additional cost component is always one of {0, 1, 2}.  
- For non-negative inputs, the output is non-decreasing as the input increases.

7. Error Handling / Exceptional Behavior  
- No explicit handling for invalid/missing input. If input cannot be read, the output is unspecified.  
- No explicit overflow checks; if intermediate or final arithmetic exceeds the integer range, behavior is unspecified.

8. State Transitions (if applicable)  
- None; the program is stateless aside from computing and emitting the single result.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory with respect to the input value.
