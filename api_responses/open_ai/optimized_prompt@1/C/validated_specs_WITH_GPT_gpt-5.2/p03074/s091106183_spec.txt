1. Functional Description  
Computes and outputs the maximum length of a contiguous segment of a binary sequence that can be made entirely `1` by changing (flipping) at most a given number of contiguous `0`-blocks into `1` (equivalently, flipping up to that many groups of consecutive zeros).

2. Inputs  
- An integer `N`: the length of the binary sequence.  
- An integer `K`: the maximum number of zero-blocks allowed to be flipped.  
- A binary sequence of length at least `N`, consisting of characters interpreted as `0` and `1`.

3. Outputs  
- A single integer: the maximum achievable length of a contiguous all-`1` segment after flipping at most `K` zero-blocks.

4. Preconditions  
- `0 < N ≤ 100000`.  
- `K ≥ 0`.  
- The provided sequence contains at least `N` binary characters.  
- The input is well-formed such that the required integers and sequence are present.

5. Postconditions  
- The output value equals the maximum, over all contiguous substrings of the first `N` bits, of the substring length after optionally converting up to `K` maximal contiguous groups of `0` within that substring into `1`.  
- The output is in the range `[0, N]`.

6. Invariants  
- The computation treats the sequence as alternating runs of equal bits (run-length representation).  
- Any candidate segment considered corresponds to a concatenation of an odd number of consecutive runs, starting and ending with a run of `1`, and containing at most `K` runs of `0` (hence at most `2K+1` runs total).  
- The reported maximum is the greatest total length among all such candidate segments.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed. If inputs violate preconditions (e.g., missing/invalid data, `N` out of bounds, insufficient sequence length), behavior is undefined (may produce incorrect output or access invalid memory).

8. State Transitions (if applicable)  
- Not applicable; the program is a single-shot computation with no persistent state across runs.

9. Non-functional Constraints (if inferable)  
- Time complexity is linear in `N` (plus fixed-size overhead bounded by the maximum supported input size).  
- Memory usage is bounded by arrays sized for the maximum supported `N` (on the order of a few hundred thousand integers plus the input buffer).
