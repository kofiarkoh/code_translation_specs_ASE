1. Functional Description  
Generates and outputs all permutations of the integers from 1 through a given positive integer, printing each permutation as a sequence of integers on its own line.

2. Inputs  
- One integer specifying the size of the set to permute.

3. Outputs  
- Zero or more lines to standard output.  
- Each line contains exactly the input count of integers, representing one permutation of the integers 1..N, separated by single spaces.

4. Preconditions  
- The input integer is provided and is non-negative.  
- Sufficient stack memory is available to support recursion and temporary storage proportional to the input size.  
- If the input is negative, behavior is undefined (assumption: not provided).

5. Postconditions  
- If the input is 0: exactly one empty line is output.  
- If the input is N > 0: exactly N! lines are output, each a distinct permutation of {1, 2, ..., N}.  
- Every permutation contains each integer from 1..N exactly once.

6. Invariants  
- During generation, the partially constructed sequence contains no duplicates.  
- At any point, the remaining available integers are exactly those not yet placed in the partial sequence.  
- All emitted lines (when any) have a consistent length equal to the input N.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed for invalid or missing input.  
- If input parsing fails or preconditions are violated (e.g., negative input, insufficient memory/stack), behavior is undefined.

8. State Transitions (if applicable)  
- Stateless aside from transient computation: no persistent state is maintained across runs.  
- Progresses from an initial state with the full set {1..N} available to a terminal state after all permutations have been output.

9. Non-functional Constraints (if inferable)  
- Time complexity grows factorially with the input size (proportional to N! permutations).  
- Uses recursion with depth N and additional temporary storage proportional to N per recursion level; may exhaust stack for large N.
