1. Functional Description  
Reads a single integer value and outputs the result of subtracting that value from 48.

2. Inputs  
- One integer provided via standard input.

3. Outputs  
- One integer written to standard output, followed by a line terminator.

4. Preconditions  
- Standard input provides a valid integer representable in the program’s integer range.

5. Postconditions  
- The program outputs exactly one integer equal to (48 − input_value).

6. Invariants  
- The constant 48 is not modified.  
- The computed output value is deterministically derived solely from the single input integer.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If the input is missing, malformed, or not representable, behavior is unspecified with respect to output correctness.

8. State Transitions (if applicable)  
- No persistent state is maintained; execution is a single read-compute-write operation and then terminates.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory relative to input size.
