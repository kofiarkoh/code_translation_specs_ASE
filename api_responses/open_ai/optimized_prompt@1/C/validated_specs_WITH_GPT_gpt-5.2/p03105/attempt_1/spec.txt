1. Functional Description  
Reads three integers and outputs the smaller of: (a) the integer quotient of the second value divided by the first value, and (b) the third value.

2. Inputs  
- Three signed integers provided via standard input: first value, second value, third value.

3. Outputs  
- One signed integer written to standard output, followed by a line terminator.

4. Preconditions  
- The first input integer is non-zero.  
- The input contains three valid integers.

5. Postconditions  
- Let `q` be the integer quotient of (second input) divided by (first input), using truncation toward zero.  
- The program outputs `min(q, third input)`.

6. Invariants  
- The output value is always less than or equal to the third input value.  
- The output value is always less than or equal to the computed quotient `q`.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If the first input is zero, behavior is undefined (division by zero).  
- If inputs are missing or not valid integers, behavior is unspecified.

8. State Transitions (if applicable)  
- Not applicable; the program is stateless aside from reading input and producing output.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory.
