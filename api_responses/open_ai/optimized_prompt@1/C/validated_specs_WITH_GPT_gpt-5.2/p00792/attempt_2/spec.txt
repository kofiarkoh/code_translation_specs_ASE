1. Functional Description  
For each test case, the program simulates the motion of a point (“ray”) on a fixed, discrete coordinate system with optional reflections caused by mirror segments placed on a small grid. The ray starts from a fixed initial state, moves in fixed diagonal increments, and on each step may reflect depending on an internal alternation state and whether the step crosses a stored mirror segment. The simulation terminates only under specific conditions (a special internal state mapping, or a boundary condition gated by whether the most recent step reflected). The program outputs the final reported coordinates at termination.

2. Inputs  
- A sequence of test cases.  
- Each test case begins with an integer `n`. Processing ends when `n < 0`.  
- If `n >= 0`, it is followed by `n` mirror descriptions. Each description consists of:  
  - A string token `s` (read as a word), and  
  - Two integers `x` and `y` (grid indices).

3. Mirror Representation and Interpretation  
- Mirrors are stored on a fixed 4D boolean grid indexed as `mir[a][b][c][d]` with each index expected to be within `0..8`.  
- For each mirror description:  
  - If the first character of `s` is `'x'`, the program marks a segment between grid points `(x, y)` and `(x+1, y)` by setting `mir[x][y][x+1][y] = 1`.  
  - Otherwise (any non-`'x'` token), it marks a segment between `(x, y)` and `(x, y+1)` by setting `mir[x][y][x][y+1] = 1`.  
- The specification assumes inputs keep all referenced indices valid (including `x+1` or `y+1` where applicable); otherwise behavior is unspecified.

4. Coordinate System and State  
- The simulated ray position is maintained as integer coordinates `(X, Y)` in a scaled lattice.  
- Initial state for each test case:  
  - `X = 50`, `Y = 0`  
  - Direction `d = 0` (one of four diagonal directions)  
  - Alternation flag `v` starts as `1` for the first step and toggles every iteration thereafter  
  - A flag `wall = 1` indicating “no reflection occurred on the most recent move” (see termination rules)

5. Movement per Step  
- The direction `d` selects one of four fixed diagonal increments (in `(X, Y)` units):  
  - `d=0`: `( +50, +50 )`  
  - `d=1`: `( -50, +50 )`  
  - `d=2`: `( -50, -50 )`  
  - `d=3`: `( +50, -50 )`  
- The simulation iterates steps with an iteration counter `i` starting at `0`. On each iteration:  
  1. The alternation flag is toggled for the next move (`v` alternates 1,0,1,0,...) as the loop progresses.  
  2. The ray advances by the increment for the current direction `d`.  
  3. `wall` is set to `1` for the new position, and may be cleared to `0` if a reflection occurs on this step.  
  4. Depending on the current alternation flag value, the program checks whether the move crosses a mirror segment using one of two index formulas (below). If a mirror is detected, the direction is updated by a fixed mapping and `wall` is set to `0`.

6. Mirror-Crossing Tests and Reflection Mapping  
- Exactly one mirror-crossing test is performed per step, chosen by the alternation flag `v` after toggling.  
- If `v == 1`, the program checks:  
  - `mir[X/100][(Y-50)/100][X/100][(Y+50)/100]`  
  If this is set, a reflection occurs: `d` becomes `tr[1][d]` where `tr[1] = {1, 0, 3, 2}`, and `wall = 0`.  
- If `v == 0`, the program checks:  
  - `mir[(X-50)/100][Y/100][(X+50)/100][Y/100]`  
  If this is set, a reflection occurs: `d` becomes `tr[0][d]` where `tr[0] = {3, 2, 1, 0}`, and `wall = 0`.  
- If the checked entry is not set, no reflection occurs and `d` is unchanged.

7. Termination and Special Mapping  
Termination checks are performed at the start of each loop iteration, before applying the movement of that iteration, and only once at least two iterations have already occurred (`i >= 2`):  
- Special internal-state termination: if `(X, Y, d) == (100, 50, 0)`, the simulation terminates immediately and the reported final position is forced to `(75, 25)` (regardless of mirrors).  
- Boundary termination (gated by `wall`): if `wall == 1` and any of the following holds: `X == 0`, `Y == 0`, `X == 800`, or `Y == 800`, the simulation terminates and the reported final position is the current `(X, Y)`.  
- If neither condition holds, the simulation continues.

8. Outputs  
- For each test case with `n >= 0`, the program prints one line containing two integers: the final reported `(X, Y)` as determined by the termination rules above.

9. Additional Notes / Assumptions  
- No error handling is performed; malformed input or out-of-range mirror indices lead to unspecified behavior.  
- The program assumes the simulation will eventually terminate under the given rules; it does not impose an explicit step limit.
