1. Functional Description  
Reads an integer `n` and then reads `n` real-valued height measurements. Each height is classified into exactly one of six fixed numeric ranges. After all heights are processed, the program prints a six-line histogram showing, for each range, how many heights fell into that range.

2. Inputs  
- An integer `n` indicating how many height values follow.  
- Exactly `n` floating-point height values.

3. Classification Rules (Bins)  
Each height is counted in exactly one of the following mutually exclusive ranges:  
1) `h < 165.0`  
2) `165.0 ≤ h < 170.0`  
3) `170.0 ≤ h < 175.0`  
4) `175.0 ≤ h < 180.0`  
5) `180.0 ≤ h < 185.0`  
6) `h ≥ 185.0`

4. Outputs (Exact Format)  
- The program prints exactly six lines, in order, corresponding to bins 1 through 6.  
- Each line begins with the fixed label `k:` where `k` is the bin number (`1:` through `6:`).  
- Immediately after the colon, the program prints zero or more `*` characters, with no spaces or other characters in between. The number of `*` characters equals the count of heights classified into that bin.  
- Each of the six lines ends with a newline.

5. Preconditions / Assumptions  
- The input provides an integer `n` followed by at least `n` valid floating-point tokens.  
- `n` is assumed to be non-negative.  
- No validation is performed on the numeric values beyond being readable as floating-point numbers.

6. Postconditions / Counting Properties  
- After processing all inputs, the sum of the six bin counts equals `n`.  
- If `n` is zero, the program still prints the six labeled lines, each with no `*` characters.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed. If input is missing, malformed, or `n` is negative, behavior is unspecified.

8. State Transitions  
- Initializes six counters to zero.  
- For each of the `n` heights read, increments exactly one counter according to the classification rules.  
- After reading all heights, prints the histogram lines and terminates normally.
