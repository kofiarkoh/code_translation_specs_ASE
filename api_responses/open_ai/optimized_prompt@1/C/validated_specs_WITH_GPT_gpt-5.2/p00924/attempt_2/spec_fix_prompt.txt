- The output equals the minimum possible total movement cost among the evaluated starting-bit options, where:

  - The movement cost is the sum, over each position from left to right, of the distance from that position to the position of the bit that is brought forward to satisfy the target at that position (equivalently, the number of positions the selected bit is moved left at each step).  
- If the input has equal numbers of 0s and 1s, the output is the minimum cost over both possible starting bits. Otherwise, the output corresponds to the unique starting bit that matches the required count of 1s implied by the run lengths.
