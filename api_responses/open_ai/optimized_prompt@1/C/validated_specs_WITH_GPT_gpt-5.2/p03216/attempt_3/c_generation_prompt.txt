1. Functional Description  
For each query window length \(k\), the program slides a contiguous window of length \(k\) from left to right across the first \(n\) characters of the input string \(s\). While sliding, it maintains three running 64-bit counters over the *current* window:

- \(d\): the number of `'D'` characters currently in the window.  
- \(m\): the number of `'M'` characters currently in the window.  
- \(dm\): a derived counter updated by the program’s specific transition rules (defined below), intended to represent an accumulated “`D` then `M`” contribution within the current window.

As the window is processed, whenever the program reads a character `'C'` at the right edge (during initialization of the first window and during each slide), it adds the current value of \(dm\) to an accumulator \(ans\). After the full scan for that query, it prints \(ans\).

Only the characters `'D'`, `'M'`, and `'C'` affect the counters; all other characters are ignored.

2. Inputs  
- An integer \(n\).  
- A string \(s\) read as a whitespace-delimited token.  
- An integer \(q\).  
- \(q\) integers \(k_0,\dots,k_{q-1}\), each a window length, processed in the given order.

3. Outputs  
For each query \(k\), print one line containing the computed total \(ans\) as a signed 64-bit integer.

4. Preconditions / Assumptions  
- The program assumes the string token has length at least \(n\) and accesses \(s[0]\) through \(s[n-1]\). If the token is shorter than \(n\), behavior is undefined.

- The string is stored in a fixed-size buffer of about \(10^6\) characters, and the query lengths are stored in a fixed-size array of length 102. Exceeding these capacities causes undefined behavior.

5. Exact Per-Query Computation (State Transitions)  
For a given query \(k\), the program computes \(ans\) using the following procedure.

**Initialization over the first window \([0, k-1]\):**  
Set \(ans = 0\), \(d = 0\), \(m = 0\), \(dm = 0\).  
For each index \(i = 0\) to \(k-1\) (left to right), update:
- If \(s[i] = 'D'\): \(d \leftarrow d + 1\).
- If \(s[i] = 'M'\): \(m \leftarrow m + 1\); \(dm \leftarrow dm + d\).
- If \(s[i] = 'C'\): \(ans \leftarrow ans + dm\).

- If \(s[i-k] = 'M'\): \(m \leftarrow m - 1\).

2) **Add the entering character \(s[i]\):**
- If \(s[i] = 'D'\): \(d \leftarrow d + 1\).
- If \(s[i] = 'M'\): \(m \leftarrow m + 1\); \(dm \leftarrow dm + d\).
- If \(s[i] = 'C'\): \(ans \leftarrow ans + dm\).

After processing all \(i\), output \(ans\).

In particular, when a `'D'` leaves the window, the program subtracts the *current total* number of `'M'` in the window from \(dm\), and this rule governs the meaning of \(dm\) and thus of the final \(ans\).
