1. Functional Description  
Reads a single integer and outputs an integer derived from dividing the input by 11 and adjusting based on the input’s remainder modulo 11. The output is always one of three values determined by whether the remainder is 0, greater than 6, or otherwise.

2. Inputs  
- One signed integer value.

3. Outputs  
- One signed integer value written to standard output, followed by a line terminator.

4. Preconditions  
- The input stream provides a valid integer representable in the program’s integer range.  
- The computed output value is representable in the program’s integer range (in particular, doubling the quotient and adding up to 2 does not overflow).

5. Postconditions  
Let \( q \) be the integer quotient of the input divided by 11 using truncation toward zero, and let \( r \) be the remainder such that \( \text{input} = 11q + r \). The program outputs:  
- \( 2q \) if \( r = 0 \)  
- \( 2q + 2 \) if \( r > 6 \)  
- \( 2q + 1 \) otherwise

6. Invariants  
- Exactly one output value is produced.  
- The output is always an integer in the set \( \{2q, 2q+1, 2q+2\} \) for the quotient \( q \) defined above.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed. If the input is missing or not a valid integer, behavior is unspecified (the program may produce no output or an arbitrary output).  
- If arithmetic overflows occur, behavior is unspecified.

8. State Transitions (if applicable)  
- Stateless: no persistent state is maintained beyond reading the input and producing the output.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory with respect to the input value.
