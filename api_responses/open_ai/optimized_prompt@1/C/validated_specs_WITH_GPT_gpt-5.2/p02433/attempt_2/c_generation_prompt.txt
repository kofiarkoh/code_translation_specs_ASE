1. Functional Description  
Maintains an ordered, mutable sequence of integers with a movable cursor. The sequence is implemented conceptually as a doubly linked list that always contains a distinguished internal end-marker element. The program processes a finite list of commands to insert integers immediately before the cursor, move the cursor left or right by a signed offset, and erase the element at the cursor (except the end marker). After all commands, it outputs the remaining non-marker integers in order from front to back, one per line.

2. Inputs  
- First line: a decimal integer `q` giving the number of subsequent command lines.  
- Next `q` lines: each line is interpreted by its first character (at position 0) as a command code:

  - Move command: first character is `'1'`. The signed integer offset is parsed starting at character position 2 of the line in the same way.  
  - Erase command: first character is `'2'`. Any remaining characters on the line are ignored.

3. Outputs  
- On normal completion: prints each stored integer in the sequence (excluding the internal end marker), one per line, in front-to-back order.

- The first line exists and contains a value that `atoi` can convert; `q` is intended to be non-negative.

- Inserted values and move offsets are within the range representable by C `int`.  
- Sufficient memory is available for insertions (no allocation-failure handling is performed).

5. Command Semantics / Postconditions  
State consists of the ordered sequence and the current cursor position (a pointer to a node in the sequence). Initially, the sequence contains only the internal end-marker node, and the cursor points to that end-marker node.

  - Inserts it immediately before the current cursor node (at the front if the cursor is currently at the front).

- During normal operation, the cursor always points to a node in the sequence (never becomes null).

- If an invalid move occurs, the program terminates immediately at that point and does not print the final sequence.
