	int data;

	struct Cell* next;

Cell* newCell(int data) {
    Cell* cell = malloc(sizeof(Cell));
    cell->data = data;

    cell->next = NULL;

		cell = cell->prev;

			cell = cell->next;
		}

int isEnd(Cell *cursor) {
	return (cursor != NULL && cursor->data == END);
}

int isFront(Cell *cursor) {
	return (cursor != NULL && cursor->prev == NULL);
}

Cell* insert(Cell *cursor, int data) {
	if (isFront(cursor)) {
		Cell *new = newCell(data);
		new->next = cursor;
		cursor->prev = new;
		return new;
	}

	Cell *new = newCell(data);
	Cell *prev = cursor->prev;
	new->prev = prev;
	new->next = cursor;
	prev->next = new;

		return cursor;

Maintains an ordered, mutable sequence of integers with a movable cursor. After all commands, outputs the remaining sequence elements in order from front to back, excluding an internal end marker.

2. Inputs

  - Move: includes a signed integer offset indicating cursor movement (negative = toward front, positive = toward back, zero = no movement).  
  - Erase: no additional value.

3. Outputs

4. Preconditions  
- The initial command count is a valid integer and is non-negative.  
- Each command line is present and conforms to one of the supported command types, with an integer argument where required.

- If the program completes normally, the output is exactly the final sequence contents after applying all commands in order, excluding the internal end marker.

6. Invariants

- The cursor always points to some element in the sequence (never becomes null) during normal operation.

7. Error Handling / Exceptional Behavior  
- If a move command attempts to move left when the cursor is already at the front element, the program emits an error message and terminates with a non-zero exit status.

- Insert(value): sequence gains one new element immediately before cursor; cursor transitions to that new element.
