1. Functional Description  
Reads three integers and outputs the same three values in non-decreasing (ascending) order.

2. Inputs  
- Three integer values provided via standard input.

3. Outputs  
- Three integers written to standard output, representing the input values sorted in non-decreasing order, separated by whitespace and terminated by a newline.

4. Preconditions  
- Exactly three integer inputs are available and are representable within the program’s integer range.  
- The input operation succeeds for all three values.

5. Postconditions  
- The output multiset of three integers is identical to the input multiset (no values are added, removed, or altered).  
- The three output integers satisfy: first ≤ second ≤ third.

6. Invariants  
- The three values designated for output are always a permutation of the three input values.  
- Ordering relation maintained for output: first ≤ second ≤ third.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If fewer than three valid integers are provided or input fails, behavior is undefined (output values may be indeterminate).

8. State Transitions (if applicable)  
- Stateless beyond local computation: transitions from “no inputs read” → “inputs read” → “sorted values determined” → “sorted values output” → “program terminates”.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory for all valid inputs.
