1. Functional Description  
Reads four integers and prints the outcome of a comparison between two participants, choosing which pair of values to compare based on whether either “result” value is negative.

2. Inputs  
- Four integers read from standard input, in this order:
  1) `T1` (first participant’s comparison value)  
  2) `T2` (second participant’s comparison value)  
  3) `R1` (first participant’s result value)  
  4) `R2` (second participant’s result value)

3. Outputs  
- If input is successfully read, writes exactly one line to standard output containing exactly one of the following case-sensitive tokens (followed by a newline):
  - `Alice`
  - `Bob`
  - `Draw`

4. Preconditions  
- Standard input must provide four parsable integers.  

5. Postconditions / Decision Logic  
- If fewer than four integers are successfully read, the program produces no output and terminates with a non-zero status.  
- Otherwise, the program determines the output as follows:
  - If `R1 < 0` **or** `R2 < 0`, compare `T1` and `T2`:
    - Print `Alice` if `T1 < T2`
    - Print `Bob` if `T1 > T2`
    - Print `Draw` if `T1 == T2`
  - Else (both `R1` and `R2` are non-negative), compare `R1` and `R2`:
    - Print `Alice` if `R1 > R2`
    - Print `Bob` if `R1 < R2`
    - Print `Draw` if `R1 == R2`
- After printing the selected token, the program terminates normally.

6. Invariants  
- On successful input, exactly one line is printed.  
- The printed line is always one of `Alice`, `Bob`, or `Draw`.

7. Error Handling / Exceptional Behavior  
- If the input does not contain four integers, the program exits with a non-zero status and prints nothing.

8. State Transitions  
- No persistent state; a single decision is made from the provided inputs and then the program terminates.

9. Non-functional Constraints  
- Runs in constant time and constant memory.
