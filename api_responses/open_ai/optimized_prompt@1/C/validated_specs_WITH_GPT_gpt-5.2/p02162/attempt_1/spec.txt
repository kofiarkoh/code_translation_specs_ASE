1. Functional Description  
Determines and outputs the winner between two participants or declares a draw based on two provided comparison values, selecting which comparison to use depending on whether either of two result values is negative.

2. Inputs  
- Four integers provided from standard input in a single read operation:
  - Two comparison values (one per participant).
  - Two result values (one per participant).

3. Outputs  
- Writes exactly one line to standard output containing one of:
  - The first participant’s name,
  - The second participant’s name,
  - Or a draw indicator.

4. Preconditions  
- Standard input must provide four integers.

5. Postconditions  
- If four integers are successfully read:
  - If at least one result value is negative, the output is determined by comparing the two comparison values:
    - First participant if the first comparison value is greater.
    - Second participant if the second comparison value is greater.
    - Draw if they are equal.
  - Otherwise (both result values are non-negative), the output is determined by comparing the two result values:
    - First participant if the first result value is greater.
    - Second participant if the second result value is greater.
    - Draw if they are equal.
- Program terminates after producing the output.

6. Invariants  
- At most one line is produced.
- The output is always one of the three fixed tokens: first participant, second participant, or draw.

7. Error Handling / Exceptional Behavior  
- If fewer than four integers are available/parsable from input, no output is produced and the program terminates with a non-zero status.

8. State Transitions (if applicable)  
- No persistent state; a single decision is made from the provided inputs and then the program terminates.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory relative to input size.
