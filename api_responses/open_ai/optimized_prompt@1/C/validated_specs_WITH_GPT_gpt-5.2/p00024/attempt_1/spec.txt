1. Functional Description  
Reads a sequence of real-valued inputs and, for each value, computes and outputs an integer derived from a quadratic function of the input, rounded to a multiple of 5 using truncation-based rounding, then incremented by 1.

2. Inputs  
- Zero or more real numbers provided from standard input, processed sequentially until end-of-input.

3. Outputs  
- For each successfully read input value, one line containing a single integer result written to standard output.

4. Preconditions  
- Each input token intended to be processed must be a valid real number representable in the program’s floating-point type.  
- The computed intermediate values must be representable without causing undefined behavior when converted to an integer.

5. Postconditions  
For each input value \(v\) successfully read:  
- Let \(x = \frac{4.9 \cdot v^2}{9.8^2}\).  
- Let \(k = \text{truncate}(x + 5)\) (truncation toward zero).  
- Let \(m = \text{truncate}(k / 5)\) (integer division truncation toward zero).  
- The program outputs \(m + 1\) as an integer on its own line.  
Processing continues until end-of-input is reached.

6. Invariants  
- Each successfully read input value produces exactly one corresponding output integer.  
- Output order matches input order.

7. Error Handling / Exceptional Behavior  
- Terminates normally upon reaching end-of-input.  
- If an input token is not a valid real number, behavior is not defined by this program’s contract (it may stop producing output or loop without progress).  
- If numeric overflow/invalid conversion occurs during computation or conversion to integer, behavior is undefined.

8. State Transitions (if applicable)  
- Repeats a read–compute–write cycle for each input value.  
- Transitions to a terminal state when end-of-input is encountered.

9. Non-functional Constraints (if inferable)  
- Time and memory usage are linear in the number of successfully read input values, with constant work and constant additional memory per value.
