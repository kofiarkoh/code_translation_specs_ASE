- Two integers: grid height and grid width.  
- A sequence of height text rows representing the grid contents, each providing at least width characters.

3. Outputs  
- A single non-negative integer equal to:  
  \[
  \sum_{\text{region } R} \bigl(\#\text{dot cells in }R\bigr)\times\bigl(\#\text{non-dot cells in }R\bigr)
  \]
  where regions are maximal sets of cells connected via 4-neighbor steps that always move between cells with different characters.

4. Preconditions  
- Height and width are provided successfully.  
- 0 ≤ height ≤ 512 and 0 ≤ width ≤ 512.  
- Each of the height grid rows is provided successfully and contains at least width characters.  
- The total number of cells (height × width) does not exceed 512 × 512.

5. Postconditions  
- If all inputs are successfully read and preconditions hold, the program outputs exactly one line containing the computed total as a 64-bit unsigned value.  
- Every grid cell is assigned to exactly one region under the “different-character 4-neighbor connectivity” rule used for region formation.

6. Invariants  
- Region membership is consistent: within a region, any two cells are connected by a path of 4-neighbor moves where each move crosses between unequal characters.  
- Regions are maximal: no cell outside a region can be added without violating the connectivity rule.  
- For each region, the counted dot and non-dot totals equal the number of cells in that region partitioned by whether the cell character is a dot.

7. Error Handling / Exceptional Behavior  
- If reading the dimensions fails, the program terminates with a non-zero exit status and produces no defined output.  
- If reading any grid row fails, the program terminates with a non-zero exit status and produces no defined output.

8. State Transitions (if applicable)  
- Initial state: no regions assigned; per-region dot/non-dot counts are zero.  
- After region assignment: each cell is labeled with a region identifier.  
- After counting: each region has accumulated dot and non-dot cell counts.  
- Final state: the total sum is computed from per-region counts and emitted.

9. Non-functional Constraints (if inferable)
