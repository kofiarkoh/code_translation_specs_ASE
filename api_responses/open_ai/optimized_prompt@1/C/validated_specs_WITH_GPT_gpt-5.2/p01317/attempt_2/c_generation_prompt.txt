1. Functional Description  
For each dataset, computes the minimum total cost to traverse a required sequence of locations in the given order on an undirected graph whose connections belong to one of two cost categories. Between each consecutive pair of required locations, travel is modeled as either:  
- a three-part route using only the first category from the current required location to a chosen intermediate location, then only the second category between two chosen intermediate locations, then only the first category from the second intermediate location to the next required location; or  
- a direct route using only the first category between the two required locations (this is treated as a special case of the above when the two intermediate locations are the same).

2. Inputs  
Each dataset (repeated until termination) consists of:  
- Two integers `N` and `M`: number of locations and number of connections. Input terminates when `N` is zero (the value of `M` on that line is ignored).  
- `M` connection records. Each record contains: two endpoint location identifiers, a nonnegative integer cost, and a single character type. The type character `'L'` denotes the first cost category; any other character denotes the second cost category. Connections are undirected.  
- An integer `R`: the length of the required visit sequence.  
- `R` location identifiers giving the required sequence in order.

3. Outputs  
For each dataset, prints one line containing a single integer: the minimum total cost achievable to traverse the required sequence under the movement rules described above.

5. Semantics and Edge Cases

- The total traversal cost is the sum over the `R-1` consecutive required pairs. For each step from required location `a` to next required location `b`, the step cost is the minimum over all choices of intermediate locations `j` and `i` of:
