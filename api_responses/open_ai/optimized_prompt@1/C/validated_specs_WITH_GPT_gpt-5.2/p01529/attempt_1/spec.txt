1. Functional Description  
Computes the minimum total cost to iteratively combine a sequence of `n` non-negative item weights into a single item, where each combine operation merges two adjacent groups and incurs a cost equal to the sum of weights in the merged group. The result is the minimum possible total cost over all valid sequences of adjacent merges.

2. Inputs  
- An integer `n`: the number of items.  
- A sequence of `n` integer weights.

3. Outputs  
- A single integer value: the minimum achievable total merge cost for combining all `n` items into one via adjacent merges.

4. Preconditions  
- `1 ≤ n ≤ 4000`.  
- Exactly `n` weights are provided.  
- Each weight is a non-negative integer representable within signed 64-bit range.  
- The minimum total cost and all intermediate sums fit within signed 64-bit range.  
- Input is well-formed (no missing or malformed numeric tokens).

5. Postconditions  
- The output equals the minimum, over all ways of repeatedly merging two adjacent groups until one group remains, of the sum of merge costs, where each merge cost is the sum of weights in the newly formed group.  
- If `n = 1`, the output is `0`.

6. Invariants  
- For any contiguous subrange of items, the computed subproblem value (when defined) represents the minimum total cost to merge exactly that subrange into one group using only adjacent merges within the subrange.  
- The cost contribution of a final merge for any subrange equals the sum of weights in that subrange.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed. If preconditions are violated (e.g., malformed input, out-of-range values, overflow), behavior is unspecified.

8. State Transitions (if applicable)  
- Not applicable; the program is a single-shot computation with no externally visible state beyond producing the output.

9. Non-functional Constraints (if inferable)  
- Designed to handle up to 4000 items using a dynamic programming approach with memory usage proportional to `n²`.  
- Execution time is intended to be feasible for the stated bounds by exploiting properties of the optimal partition structure (assumption: the optimization conditions required for this property hold for the given cost model).
