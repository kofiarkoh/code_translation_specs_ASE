1. Functional Description  
Reads three integers from standard input and outputs the area of a right triangle computed as half the product of the first two integers. The third integer does not affect the result.

2. Inputs  
- Standard input: three integer values provided in sequence.

3. Outputs  
- Standard output: a single numeric value representing the computed area, rounded to the nearest integer with no fractional part shown.

4. Preconditions  
- Three integer values are available on standard input and are readable as integers.  
- The product of the first two integers is representable in the implementation’s integer arithmetic domain (to avoid overflow before conversion to a real value).

5. Postconditions  
- If the preconditions hold, the program outputs the value: round( (a × b) / 2 ), where `a` and `b` are the first two input integers.  
- No other output is produced.

6. Invariants  
- The computed result depends only on the first two input integers.  
- The third input integer is ignored and does not influence the output.

7. Error Handling / Exceptional Behavior  
- If fewer than three integers are provided or input cannot be interpreted as integers, behavior is unspecified (the program does not guarantee a meaningful output).  
- If integer overflow occurs when forming the product of the first two integers, behavior is undefined.

8. State Transitions (if applicable)  
- No persistent state is maintained; the program performs a single read-compute-write operation and terminates.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory relative to input size.
