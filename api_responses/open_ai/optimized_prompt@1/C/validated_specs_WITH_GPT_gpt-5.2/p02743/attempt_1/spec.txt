1. Functional Description  
Determines whether a given third real number is strictly greater than the sum of the first two real numbers by more than twice the geometric mean of the first two numbers, under the additional requirement that the third number is strictly greater than that sum. Outputs an affirmative or negative decision accordingly.

2. Inputs  
- Three real-valued numbers provided from standard input.

3. Outputs  
- A single line to standard output indicating either an affirmative decision (“Yes”) or a negative decision (“No”).

4. Preconditions  
- Three input values are successfully provided and are representable as finite real numbers.  
- For the comparison to correspond to a real-valued “twice the geometric mean” interpretation, the product of the first two inputs is assumed to be non-negative. (If this is not true, the program’s decision is still defined by its arithmetic comparisons, but may not match that interpretation.)

5. Postconditions  
- Outputs “Yes” if and only if both conditions hold:  
  - The third input is strictly greater than the sum of the first two inputs.  
  - The square of (third − first − second) is strictly greater than four times (first × second).  
- Otherwise outputs “No”.

6. Invariants  
- The decision is based solely on the three input values and does not depend on any external state.  
- Exactly one of the two possible outputs is produced.

7. Error Handling / Exceptional Behavior  
- No explicit handling for missing/invalid input or non-finite values; behavior in such cases is unspecified by the program’s contract.  
- If arithmetic overflows, underflows, or produces non-finite results, the resulting comparison outcomes (and thus the output) are unspecified.

8. State Transitions (if applicable)  
- No persistent state is maintained; the program reads inputs, produces one decision output, and terminates.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory with respect to input size.
