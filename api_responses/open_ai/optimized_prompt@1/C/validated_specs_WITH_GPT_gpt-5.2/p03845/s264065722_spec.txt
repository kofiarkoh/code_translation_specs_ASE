1. Functional Description  
Computes the total of an initial list of integers, then for each query reports what the total would be if exactly one specified element of the list were replaced by a provided new value.

2. Inputs  
- An integer `n`: the number of elements in the initial list.  
- A sequence of `n` integers: the initial list values.  
- An integer `m`: the number of queries.  
- A sequence of `m` queries, each consisting of:  
  - An integer position `p` (1-based index into the initial list).  
  - An integer replacement value `x`.

3. Outputs  
- For each query, one integer on its own line: the modified total after replacing the element at position `p` with `x`.

4. Preconditions  
- `0 ≤ n ≤ 100`.  
- `0 ≤ m ≤ 100`.  
- Each query position `p` satisfies `1 ≤ p ≤ n`.  
- All provided integers fit within the range of the program’s integer type.  
- Input is well-formed and contains all required values.

5. Postconditions  
- Let `S` be the sum of the initial list. For each query `(p, x)`, the program outputs `S - original_value_at_position_p + x`.  
- The initial list is not permanently modified across queries; each query is evaluated against the original list.

6. Invariants  
- The computed initial total `S` remains constant for all queries.  
- Each query’s output depends only on `S`, the original value at the referenced position, and the query’s replacement value.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed. If preconditions are violated (e.g., out-of-range indices, too many elements/queries, malformed input, or integer overflow), behavior is undefined.

8. State Transitions (if applicable)  
- No persistent state beyond the program execution.  
- Internal state transitions: from “input collected” to “initial total computed” to “outputs produced for each query,” without altering the stored original list.

9. Non-functional Constraints (if inferable)  
- Supports at most 100 initial elements and 100 queries.  
- Time proportional to `n + m`; memory usage bounded by storage for the input lists and queries.
