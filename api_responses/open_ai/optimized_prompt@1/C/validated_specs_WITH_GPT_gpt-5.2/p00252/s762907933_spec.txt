1. Functional Description  
Reads three integer inputs representing a 3‑value state and emits a single textual decision. For a limited set of recognized input combinations, it outputs either “Open” or “Close”. For any other combination, it produces no decision output.

2. Inputs  
- Three integers provided from standard input.

3. Outputs  
- To standard output, either:
  - The word “Open” followed by a newline, or
  - The word “Close” followed by a newline, or
  - No output (if the input combination is not one of the recognized cases).

4. Preconditions  
- Three integers are available to be read from standard input.

5. Postconditions  
- If the input triple is one of the following, output is produced as specified:
  - (1, 0, 0) → “Close”
  - (0, 1, 0) → “Close”
  - (1, 1, 0) → “Open”
  - (0, 0, 1) → “Open”
  - (0, 0, 0) → “Close”
- For any other triple, the program terminates without producing “Open” or “Close”.

6. Invariants  
- At most one of the two decision words (“Open” or “Close”) is emitted.
- The program terminates after processing the single input triple.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed for missing/invalid input; behavior in such cases is unspecified by the code.
- Unrecognized input combinations are silently ignored (no decision output).

8. State Transitions (if applicable)  
- Stateless: no persistent state is maintained across executions.

9. Non-functional Constraints (if inferable)  
- Constant time and constant memory usage relative to input size (fixed number of integers).
