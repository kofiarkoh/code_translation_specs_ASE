1. Functional Description  
Reads a finite sequence of integers and counts how many non-overlapping adjacent equal pairs occur when scanning from the beginning to the end, where each counted pair consumes both elements (i.e., pairs do not share elements). Outputs the resulting count.

2. Inputs  
- An integer specifying the number of elements in the sequence.  
- A sequence of that many integers.

3. Outputs  
- A single integer: the number of non-overlapping adjacent equal pairs in the input sequence.

4. Preconditions  
- The provided sequence length is within the supported bound of the program’s fixed storage (assumed: 0 ≤ length ≤ 100).  
- The input contains at least the declared number of integers.  
- Input values fit within the integer range of the execution environment.

5. Postconditions  
- The output equals the number of indices k in the scan such that elements at positions k and k+1 are equal, and no element position participates in more than one counted pair.  
- If the sequence length is less than 2, the output is 0.

6. Invariants  
- Each element position in the sequence is considered at most once as part of a counted pair.  
- The count is never negative and never exceeds ⌊length / 2⌋.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed. If inputs are missing, malformed, or the length exceeds supported bounds, behavior is unspecified.

8. State Transitions (if applicable)  
- Stateless beyond local computation: consumes input, produces output, then terminates.

9. Non-functional Constraints (if inferable)  
- Uses fixed memory proportional to the maximum supported sequence length.  
- Runs in time proportional to the sequence length.
