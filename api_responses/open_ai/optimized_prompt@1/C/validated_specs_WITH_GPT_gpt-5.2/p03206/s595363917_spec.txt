1. Functional Description  
Reads a single integer representing a day number and, for specific recognized values, outputs the corresponding holiday-related label.

2. Inputs  
- One integer value.

3. Outputs  
- If the input equals 25: outputs the label for “Christmas”.  
- If the input equals 24: outputs the label for “Christmas Eve”.  
- If the input equals 23: outputs the label for “Christmas Eve Eve”.  
- If the input equals 22: outputs the label for “Christmas Eve Eve Eve”.  
- For any other input value: produces no output.

4. Preconditions  
- An integer input value is available to be read.

5. Postconditions  
- The program terminates normally after attempting to read the input.  
- If the input is one of {22, 23, 24, 25}, exactly one corresponding line of text is produced.  
- Otherwise, no text is produced.

6. Invariants  
- No persistent state is maintained beyond the single input value.  
- At most one of the specified outputs can be produced for any single input value.

7. Error Handling / Exceptional Behavior  
- No explicit handling is provided for missing/invalid input; behavior in such cases is unspecified.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Constant time and constant memory usage.
