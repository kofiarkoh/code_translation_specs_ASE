1. Functional Description  
Computes and outputs the arithmetic mean of two provided integers when their sum is even; otherwise reports that the mean is not representable as an integer.

2. Inputs  
- Two signed integer values provided via standard input.

3. Outputs  
- If the sum of the two input integers is even: outputs a single integer equal to half of their sum.  
- If the sum is odd: outputs the word “IMPOSSIBLE”.

4. Preconditions  
- Two integer values are available on standard input and are representable within the program’s chosen integer range.  
- The sum of the two input values is representable within that same range (to avoid overflow).

5. Postconditions  
- Exactly one of the following holds:  
  - The output is the integer average of the two inputs (when the sum is even).  
  - The output indicates impossibility (when the sum is odd).

6. Invariants  
- The decision of whether an integer average exists depends solely on the parity of the sum of the two inputs.  
- When an integer average is produced, it is an integer value whose double equals the sum of the inputs.

7. Error Handling / Exceptional Behavior  
- No explicit handling is provided for missing/invalid input or arithmetic overflow; behavior in such cases is unspecified.

8. State Transitions (if applicable)  
- Not applicable; the program is stateless aside from reading inputs and producing output.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and uses constant memory.
