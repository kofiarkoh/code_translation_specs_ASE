1. Functional Description  
Computes and outputs the largest positive integer \(x\) such that \(x^n\) divides the given integer \(p\). Equivalently, it outputs the integer formed by taking, for each prime factor of \(p\), the exponent in \(p\) divided by \(n\) (integer division) as the exponent in the result, and multiplying these contributions.

2. Inputs  
- Two signed integers:  
  - \(n\): the requested power.  
  - \(p\): the integer to be analyzed for divisibility by \(n\)-th powers.

3. Outputs  
- One signed integer value: the computed largest \(x\) satisfying \(x^n \mid p\), printed as a decimal integer followed by a newline.

4. Preconditions  
- Input provides two valid integers.  
- \(n \ge 1\).  
- \(p \ge 1\).  
- The mathematical result fits within the range of the signed integer type used for computation and output (otherwise behavior is not guaranteed).

5. Postconditions  
- Let the prime factorization of the original input \(p\) be \(p = \prod q_k^{e_k}\). The output equals \(\prod q_k^{\lfloor e_k / n \rfloor}\).  
- The output is the maximum integer \(x \ge 1\) such that \(x^n\) divides the original input \(p\).

6. Invariants  
- The output value remains a positive integer throughout execution.  
- At all times, the output divides the original input \(p\) (under the precondition that no overflow occurs).

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed. If input is missing/invalid, if \(n < 1\), if \(p < 1\), or if arithmetic overflows occur, the program’s behavior is unspecified by this contract.

8. State Transitions (if applicable)  
- Not applicable; the program is a single-shot computation with no persistent state beyond producing the output.

9. Non-functional Constraints (if inferable)  
- Runs in time proportional to the number of trial divisors up to approximately the square root of the (mutated) \(p\), with additional work proportional to the total multiplicity of factors removed.  
- Uses constant extra memory.
