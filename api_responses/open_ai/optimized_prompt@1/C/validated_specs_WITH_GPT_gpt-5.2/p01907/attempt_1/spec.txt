1. Functional Description  
Computes a single real-valued result from a weighted, undirected tree rooted at node 1. Each node contributes its incident edge weight from its parent (root contributes 0) scaled by a depth-dependent factor. The program outputs the product of (a) the sum of scaled edge weights over all nodes and (b) the sum of depth-dependent factors over all nodes.

2. Inputs  
- A real number \(P\).  
- An integer \(N\) denoting the number of nodes.  
- \(N-1\) undirected edges, each given by:  
  - two node indices \(x, y\) (intended to be in \([1, N]\)),  
  - an integer edge weight \(c\).

3. Outputs  
- One real number equal to:
  \[
  \left(\sum_{v=1}^{N} \text{parentEdgeWeight}(v)\cdot P^{\text{depth}(v)}\right)
  \cdot
  \left(\sum_{v=1}^{N} P^{\text{depth}(v)}\right)
  \]
  where \(\text{parentEdgeWeight}(1)=0\) and for \(v\neq 1\), \(\text{parentEdgeWeight}(v)\) is the weight of the unique edge connecting \(v\) to its parent in the tree rooted at 1.

4. Preconditions  
- The graph described by the \(N\) nodes and \(N-1\) edges is a tree (connected and acyclic).  
- Node indices used in edges are within \([1, N]\).  
- Node 1 exists and is the intended root.  
- Sufficient memory is available for internal storage proportional to \(N\).  
- The computed real-valued result is representable in the implementation’s floating-point type (no overflow/NaN/Inf) if a meaningful numeric output is expected.

5. Postconditions  
- The output equals the formula in Section 3, with depths defined as shortest-path edge counts from node 1 in the tree.  
- For every node \(v\), \(\text{depth}(v)\) is the number of edges on the unique path from node 1 to \(v\).  
- For every node \(v\neq 1\), \(\text{parentEdgeWeight}(v)\) is the weight of the edge on that unique path adjacent to \(v\).

6. Invariants  
- Depth values are non-negative integers.  
- Exactly one parent edge weight is associated with each non-root node, and it corresponds to the unique tree path to the root.  
- The depth-dependent factor for a node depends only on its depth and the input \(P\), specifically \(P^{\text{depth}}\).

7. Error Handling / Exceptional Behavior  
- No explicit error reporting or recovery is performed.  
- If the input does not form a tree rooted at 1 (e.g., disconnected, cyclic, or missing nodes), the produced value is not guaranteed to correspond to any well-defined tree-rooted computation.  
- If memory allocation fails, behavior is undefined (may crash or produce no valid output).  
- If floating-point overflow/invalid operations occur during computation, the output may be non-finite or otherwise unspecified.

8. State Transitions (if applicable)  
- Builds an internal representation of the undirected weighted graph from the input.  
- Derives a rooted tree at node 1 by traversing reachable nodes, assigning each node a depth and (for non-root nodes) a parent edge weight.  
- Computes aggregated sums based on assigned depths and parent edge weights, then outputs the final product.

9. Non-functional Constraints (if inferable)  
- Intended to run in time linear in \(N\) and memory linear in \(N\) for valid tree inputs.  
- Uses floating-point arithmetic; results are subject to typical rounding behavior of the underlying floating-point representation.
