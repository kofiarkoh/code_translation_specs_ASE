1. Functional Description  
Reads a sequence of integers from standard input, counts how many integers have been read, and for each non-zero integer outputs a labeled line containing its 1-based read position and its value. Terminates when a zero value is read.

2. Inputs  
- A stream of integer values from standard input, including a terminating zero.

3. Outputs  
- For each non-zero input integer, one line to standard output containing:
  - The ordinal position of that input within the overall sequence (starting at 1), and
  - The integer value itself.  
- No output is produced for the terminating zero.

4. Preconditions  
- The input stream provides integer values in a form that can be read as integers.
- A zero value eventually appears in the input stream to allow termination.

5. Postconditions  
- Program terminates after reading the first zero value.
- Let \(k\) be the position (1-based) of the first zero in the input sequence. Then:
  - Exactly \(k\) integers are read.
  - Exactly \(k-1\) output lines are produced, corresponding to the first \(k-1\) (non-zero) integers.
  - Each output line’s case number equals the position of its corresponding input integer in the read sequence.

6. Invariants  
- The case counter equals the total number of integers read so far.
- Output lines are produced only for non-zero integers and are labeled with strictly increasing case numbers starting from 1.

7. Error Handling / Exceptional Behavior  
- No explicit handling is performed for end-of-input, malformed input, or read failures; behavior in such cases is unspecified (may block, loop indefinitely, or use an indeterminate value).

8. State Transitions (if applicable)  
- Initial state: case counter is 0.  
- On each successful integer read: case counter increments by 1.  
- If the read value is non-zero: emits one output line and continues reading.  
- If the read value is zero: transitions to terminated state without emitting output for that value.

9. Non-functional Constraints (if inferable)  
- Processes inputs sequentially and produces outputs in the same order as corresponding inputs.
- Uses constant additional memory aside from the storage for the current integer and counter.
