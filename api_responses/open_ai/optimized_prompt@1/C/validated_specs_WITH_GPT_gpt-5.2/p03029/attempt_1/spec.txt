1. Functional Description  
Reads two integers representing counts of two item types, computes the total number of half-units obtainable by converting each unit of the first type into three half-units, adding the units of the second type as half-units, and then forming whole units from pairs of half-units. Outputs the resulting whole-unit count.

2. Inputs  
- Two integers from standard input:
  - First integer: count of the first item type.
  - Second integer: count of the second item type.

3. Outputs  
- One integer to standard output: the computed whole-unit count.

4. Preconditions  
- Two integer values are provided as input and are representable within the implementation’s integer range.
- The intermediate value (three times the first integer plus the second integer) is representable within the implementation’s integer range.

5. Postconditions  
- The program outputs the integer value equal to the floor of (3×first_input + second_input) divided by 2.

6. Invariants  
- The output is an integer and is deterministic for a given pair of input integers.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.
- If input is missing or not valid integers, the behavior is unspecified.
- If integer overflow occurs during computation, the behavior is undefined.

8. State Transitions (if applicable)  
- No persistent state is maintained; the program performs a single read-compute-write operation and terminates.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and uses constant memory.
