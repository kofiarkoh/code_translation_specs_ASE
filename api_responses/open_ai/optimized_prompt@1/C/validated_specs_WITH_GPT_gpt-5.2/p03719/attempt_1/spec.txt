1. Functional Description  
Reads three integers and determines whether the third integer lies within the inclusive range defined by the first two integers (from the first as lower bound to the second as upper bound). Outputs an affirmative response if it does, otherwise a negative response.

2. Inputs  
- Three integers provided via standard input:  
  - First integer: intended lower bound  
  - Second integer: intended upper bound  
  - Third integer: value to test for inclusion

3. Outputs  
- A single line to standard output indicating whether the third integer is within the inclusive range \[first, second\].

4. Preconditions  
- Standard input provides three integers in a readable form.  
- The intended meaning of “within range” assumes the first integer is the lower bound and the second is the upper bound (i.e., the range is not automatically normalized if the first is greater than the second).

5. Postconditions  
- If (first ≤ third ≤ second), the program outputs an affirmative indication.  
- Otherwise, the program outputs a negative indication.  
- Program terminates after producing exactly one such indication.

6. Invariants  
- The decision is based solely on the inclusive comparison between the three input integers.  
- No persistent state is maintained across executions.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed for malformed input or missing values; behavior in such cases is unspecified.

8. State Transitions (if applicable)  
- Not applicable (single-shot computation with no externally visible state transitions beyond producing output).

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory with respect to input size (fixed number of integers).
