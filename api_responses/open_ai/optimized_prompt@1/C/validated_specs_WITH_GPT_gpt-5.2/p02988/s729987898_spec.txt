1. Functional Description  
Reads an integer sequence and counts how many length-3 consecutive subsequences are strictly monotonic (either strictly increasing or strictly decreasing). Outputs that count.

2. Inputs  
- An integer `n`: the number of elements in the sequence.  
- A sequence of `n` integers.

3. Outputs  
- A single integer: the number of indices `i` (with `1 ≤ i ≤ n-2`) such that the triple `(a[i], a[i+1], a[i+2])` is strictly increasing or strictly decreasing.

4. Preconditions  
- `n` is provided and is an integer.  
- At least `n` subsequent integers are provided as the sequence.  
- `n` is within the supported storage capacity of the program (assumed `1 ≤ n ≤ 999`).  
- Input values fit within the range of the program’s integer type.

5. Postconditions  
- The output equals the count of all consecutive triples in the input sequence that satisfy either:  
  - `a[i] < a[i+1] < a[i+2]`, or  
  - `a[i] > a[i+1] > a[i+2]`,  
  for all valid `i` from `1` to `n-2`.  
- If `n < 3`, the output is `0`.

6. Invariants  
- The reported count is never negative.  
- The reported count is at most `max(0, n-2)`.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed. If inputs are missing, malformed, or `n` exceeds supported capacity, behavior is undefined (may produce incorrect output or fail).

8. State Transitions (if applicable)  
- No persistent state beyond the execution of the program. The only externally observable state change is producing the single output value.

9. Non-functional Constraints (if inferable)  
- Time complexity is linear in `n`.  
- Memory usage is bounded by storage for up to 999 sequence elements plus small constant overhead.
