1. Functional Description  
Reads a single lowercase alphabetic word and computes how many disjoint pairs of identical letters can be formed from it, considering only whether each letter occurs an even or odd number of times. The result equals half the number of distinct letters that occur an odd number of times.

2. Inputs  
- One whitespace-delimited string token intended to consist of lowercase letters.

3. Outputs  
- One non-negative integer representing the number of letter-pairs derivable under the rule: each letter contributes 1 to the count if it appears an odd number of times, 0 otherwise; the final output is half the total odd-letter count (integer division).

4. Preconditions  
- The input token length is at most 1009 characters.  
- Every character in the token is a lowercase letter in the range ‘a’ through ‘z’.  
- Input is present and readable.

5. Postconditions  
- The program outputs ⌊(number of distinct letters with odd occurrence count) / 2⌋.  
- No other output is produced.

6. Invariants  
- For each lowercase letter, its tracked parity is always either “even so far” or “odd so far” with respect to the processed prefix of the input.  
- The computed odd-letter total is between 0 and 30 inclusive.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If the input is missing, too long, or contains characters outside the expected lowercase range, behavior is undefined (may produce incorrect output or access invalid memory).

8. State Transitions (if applicable)  
- Not applicable; the program has no persistent state beyond a single execution.

9. Non-functional Constraints (if inferable)  
- Time complexity is linear in the input length plus a small constant amount of work.  
- Memory usage is bounded by a fixed-size buffer and fixed-size counters.
