1. Functional Description  
Reads two whitespace-delimited strings and outputs a longest common subsequence (LCS) of the two strings as a sequence of characters. If multiple LCS results exist, the program outputs one deterministically chosen by its internal tie-breaking.

2. Inputs  
- Two strings provided via standard input, each consisting of non-whitespace characters.

3. Outputs  
- Writes to standard output the characters of one longest common subsequence of the two input strings, with no additional required separators or terminator.

4. Preconditions  
- Both input strings are present in the input stream.  
- Each input string’s length is within the program’s fixed internal storage capacity (assumed ≤ 2999 characters).  
- Sufficient memory is available to allocate working storage proportional to the product of the two string lengths.

5. Postconditions  
- If the program completes normally, the output is a subsequence of the first input string and also a subsequence of the second input string.  
- The output length equals the maximum possible length among all common subsequences of the two input strings.  
- If the maximum common subsequence length is zero, no characters are output.

6. Invariants  
- The computed subsequence preserves the relative order of characters from each input string.  
- The reported subsequence length is consistent with the maximum common subsequence length for the given inputs.

7. Error Handling / Exceptional Behavior  
- No explicit error reporting or recovery is performed.  
- If input is missing or malformed, behavior is unspecified.  
- If an input string exceeds internal storage capacity, behavior is undefined (may overwrite memory).  
- If memory allocation fails, behavior is undefined (may crash or produce incorrect output).

8. State Transitions (if applicable)  
- Not applicable; the program has no persistent state beyond a single execution.

9. Non-functional Constraints (if inferable)  
- Time and memory usage grow proportionally to the product of the two input string lengths.  
- Output is deterministic for a given pair of inputs due to fixed tie-breaking when multiple LCS solutions exist.
