1. Functional Description  
Builds an index from a stream of (word, page-number) pairs. For each distinct word, it records the set of page numbers on which the word appears and the total number of occurrences read for that word. After all input is consumed, it outputs all distinct words in ascending lexicographic order, each followed by the page numbers associated with that word.

2. Inputs  
- A sequence of zero or more records, each containing:  
  - A word token (bounded length).  
  - A non-negative integer page number (bounded range).  
- Input ends at end-of-file.

3. Outputs  
For each distinct word (in ascending lexicographic order):  
- One line containing the word.  
- One line containing the page numbers associated with that word, in ascending numeric order, separated by single spaces.

4. Preconditions  
- The number of distinct words in the input does not exceed a fixed maximum capacity.  
- Each word’s length fits within a fixed maximum length (including terminator).  
- Each page number is within a fixed inclusive range starting at 0.  
- For each word, the number of input occurrences for that word does not exceed the number of distinct page numbers recorded for it (i.e., the input does not repeat the same (word, page-number) pair for a given word).  

5. Postconditions  
- For every distinct word present in the input, exactly one word entry is produced in the output.  
- For each output word entry, the printed page numbers are exactly the set of page numbers that appeared with that word in the input.  
- Output word entries are ordered lexicographically ascending by word.  
- Within each word entry, page numbers are printed in strictly ascending order.

6. Invariants  
- Each stored word entry corresponds to a unique word (no duplicates among stored words).  
- For each stored word entry, the recorded page-number set contains only page numbers that appeared with that word in the input.  
- The recorded occurrence count for a word is non-decreasing as input is processed.

7. Error Handling / Exceptional Behavior  
- No explicit error reporting is performed.  
- If any precondition is violated (e.g., too many distinct words, out-of-range page numbers, overly long words, or repeated (word, page-number) pairs for the same word), behavior is undefined and may include incorrect output or memory corruption.

8. State Transitions (if applicable)  
- Initial state: empty index.  
- For each input record:  
  - If the word is new, a new entry is created and associated with the given page number.  
  - If the word already exists, the given page number is added to that word’s page-number set.  
- Final state: index is sorted by word and then emitted to output.

9. Non-functional Constraints (if inferable)  
- Fixed upper bounds on: number of distinct words, word length, and page-number range.  
- Processing time grows quadratically with the number of distinct words due to sorting and lookup strategy.  
- Memory usage is bounded by the fixed capacities for stored words and page-number sets.
