1. Functional Description  
Reads a finite sequence of integers and computes the number of distinct values present in the sequence. Outputs that count.

2. Inputs  
- An integer specifying the number of elements in the sequence.  
- A sequence of that many integers.

3. Outputs  
- A single integer: the count of unique (distinct) values among the provided integers.

4. Preconditions  
- The provided element count is at least 1.  
- The provided element count does not exceed the fixed maximum capacity of the internal storage (100001).  
- The input contains at least that many integers following the count.  

5. Postconditions  
- The output equals the cardinality of the set of input values (i.e., the number of distinct integers in the input sequence).  
- The output is in the range [1, n].

6. Invariants  
- The distinct-count accumulator is always at least 1 and at most the number of processed elements.  
- After processing any prefix of the sorted sequence, the accumulator equals the number of value changes observed in that prefix plus one.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed for invalid, missing, or malformed input. Behavior is unspecified if input cannot be read as required or if preconditions are violated.

8. State Transitions (if applicable)  
- Not applicable; the program is a single-run computation with no externally observable persistent state.

9. Non-functional Constraints (if inferable)  
- Supports at most 100001 input integers due to fixed storage capacity.  
- Uses memory proportional to the number of input elements stored.
