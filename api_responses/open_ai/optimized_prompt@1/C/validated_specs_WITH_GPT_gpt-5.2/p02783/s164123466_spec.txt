1. Functional Description  
Computes and outputs the smallest integer greater than or equal to the quotient of two provided integers (i.e., the ceiling of the division of the first integer by the second), under the assumption of non-negative inputs.

2. Inputs  
- Two integers provided via standard input: a dividend and a divisor.

3. Outputs  
- One integer written to standard output: the ceiling of (dividend ÷ divisor), followed by a line terminator.

4. Preconditions  
- Exactly two integers are available on input.  
- The divisor is non-zero.  
- Assumption (required for correctness of “ceiling” interpretation): the dividend and divisor are non-negative integers.

5. Postconditions  
- If the dividend is exactly divisible by the divisor, the output equals the exact integer quotient.  
- Otherwise, the output equals the integer quotient rounded up to the next integer (ceiling).

6. Invariants  
- The produced result is an integer.  
- Under the non-negative input assumption, the result is the minimal integer value such that (result × divisor) is greater than or equal to the dividend.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If the divisor is zero, behavior is undefined (division by zero).  
- If input does not contain two valid integers, behavior is unspecified.  
- If intermediate arithmetic overflows the integer range, behavior is undefined.

8. State Transitions (if applicable)  
- None; the program is stateless aside from consuming input and producing output.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory.
