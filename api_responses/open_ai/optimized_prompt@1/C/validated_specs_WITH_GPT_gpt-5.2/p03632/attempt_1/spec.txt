1. Functional Description  
Computes the length of the overlap between two closed integer intervals and outputs that overlap length as a non-negative integer.

2. Inputs  
- Four integers representing two closed intervals: first interval endpoints and second interval endpoints.

3. Outputs  
- A single integer equal to the size (length) of the intersection of the two intervals, measured in the same units as the integer line.

4. Preconditions  
- All four input integers are within an implementation-defined bounded domain that supports indexing a fixed range of 0 through 100 inclusive.  
- Each interval’s start is less than or equal to its end.  
- The program receives all required input values.

5. Postconditions  
- If the two intervals do not overlap, the output is 0.  
- If the two intervals overlap, the output equals the number of integer units covered by their intersection (i.e., for intersection \[L, R\], output is R − L).  

6. Invariants  
- The computed overlap count is never negative.  
- The output depends only on the two input intervals.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If inputs violate the preconditions (e.g., endpoints outside the supported range or malformed input), behavior is undefined (may produce incorrect output or fail).

8. State Transitions (if applicable)  
- Not applicable; the program is a single-shot computation with no persistent state across runs.

9. Non-functional Constraints (if inferable)  
- Operates over a fixed, small bounded domain (0–100), implying constant-time and constant-memory usage relative to input size.
