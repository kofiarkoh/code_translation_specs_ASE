1. Functional Description  
Processes multiple scenarios of book requests by students and computes a total “movement cost” incurred by servicing each request under a fixed desk/capacity policy. Requests are serviced in a deterministic global order: increasing request position within a student’s list, with ties broken by increasing student index. Each service removes the requested book from its current desk and ultimately places it onto the primary desk (desk 1). If the primary desk is full at the moment of placement, a specific deterministic relocation sequence is performed. The total cost is the sum of desk indices charged by each removal/placement/relocation step as defined below.

2. Inputs  
For each scenario:  
- `m`: number of auxiliary desks (desks are indexed `1..m`, where desk 1 is the primary desk).  
- `c`: capacity of each desk (maximum number of books it can hold).  
- `n`: number of students.  
- For each student `i` from `0` to `n-1`: an integer `t` followed by `t` book identifiers.  

Scenarios repeat until a scenario header with `m <= 0` is read, at which point the program terminates.

3. Outputs  
For each scenario, outputs a single integer: the total accumulated movement cost for servicing all requests in that scenario according to the program’s rules.

4. Preconditions / Assumptions  
- `1 <= m <= 10` (fixed storage supports desks indexed up to `m+1`).  
- Total number of requests across all students is at most 5002.  
- Book identifiers are positive and at most 100.  
- `0 <= c <= 5000`.  
- Input is well-formed.  
- Additionally, whenever the relocation procedure requires selecting a non-full auxiliary desk among desks `2..m`, at least one such desk exists; otherwise behavior is undefined.

5. Initial State (per scenario)  
- All desks start empty.  
- While reading the students’ request lists, each *distinct* book identifier is “introduced” the first time it appears: it is immediately placed onto a special desk with index `m+1` (used only for this initial holding), appended at the end of that desk’s sequence. This initial placement does **not** add to the movement cost.  
- After input is read, the service order is formed by collecting all requests and sorting them by `(sequence-within-student, student-index)`.

6. Desk Model and Ordering  
- Each desk holds an ordered sequence of books.  
- Removing a book from a desk deletes it from its position and compacts the remaining books to close the gap, preserving their relative order.  
- Appending places a book at the end of the desk’s sequence.  
- When the relocation procedure inserts a book into an auxiliary desk, it is placed at a specific position defined in Section 8 (not necessarily at the end).

7. Cost Accounting (general)  
The total cost is an integer sum of desk indices charged by the following actions during servicing:  
- Removing the requested book from its current desk charges the index of that source desk.  
- Placing the requested book onto the primary desk charges `1`.  
- If the primary desk is full, additional charges occur exactly as described in the relocation sequence (Section 8).  
No other actions (including the initial introduction of distinct books onto desk `m+1`) contribute to the cost.

8. Servicing a Request and Full-Primary Relocation Sequence  
For each request in the global service order, let `id` be the requested book.

8.1 Remove requested book from its current desk  
- Let `from` be the desk currently holding `id`. Remove `id` from `from` (compacting that desk).  
- Add `from` to the total cost.

8.2 If the primary desk is full before placing `id`  
This step is performed iff the primary desk (desk 1) currently holds exactly `c` books.

The program performs the following deterministic sequence:

1) **Choose a temporary auxiliary desk `tmp`:**  
   Find the smallest index `tmp` in the range `2..m` such that desk `tmp` is not full (has fewer than `c` books).

2) **Temporarily place the requested book on `tmp`:**  
   Append `id` to the end of desk `tmp`.  
   Add `tmp` to the total cost.

3) **Evict the front book from the primary desk:**  
   Let `id2` be the book currently at the front of desk 1 (the oldest book there, i.e., position 0). Remove `id2` from desk 1 (compacting the remaining books).  
   Add `1` to the total cost.

4) **Choose a destination auxiliary desk `j` for the evicted book:**  
   Find the smallest index `j` in the range `2..m` such that desk `j` is not full *at the time of this selection* (after the above updates).

5) **Insert the evicted book into desk `j` at a defined position:**  
   Let `pos` be the current size of desk `j` (i.e., insertion at the end), except that if `j == tmp`, then `pos` is one less than that size (so the insertion occurs immediately before the temporarily placed `id`).  
   Place `id2` into desk `j` at position `pos` (shifting later elements right if needed). Update the tracked location of `id2` accordingly.

6) **Finalize the temporary placement bookkeeping:**  
   Add `j + tmp` to the total cost, and then remove the temporarily placed `id` from desk `tmp` by decreasing desk `tmp`’s size by one (so `id` is no longer considered to remain on `tmp` after this relocation block).

This relocation block is part of the servicing of `id` and occurs before `id` is placed onto the primary desk.

8.3 Place requested book onto the primary desk  
- Append `id` to the end of desk 1.  
- Add `1` to the total cost.  
- After this step, `id` is located on the primary desk.

9. Postconditions  
For each scenario:  
- All requests are serviced in the defined global order.  
- After each request is serviced, the requested book resides on the primary desk.  
- The printed total equals the sum of all desk-index charges incurred by the exact sequence of removals/placements/relocations described above.

- If any stated assumptions are violated (e.g., out-of-range identifiers, too many requests, desk indices exceeding fixed limits, or the relocation procedure cannot find a non-full auxiliary desk when required), behavior is undefined.

#include <stdlib.h>

#define MAX_M 10
#define MAX_BOOK_ID 100
#define MAX_REQ 5002
#define MAX_DESKS (MAX_M + 2) /* 1..m plus special m+1 */

typedef struct {
    int seq;     /* position within student's list (0-based) */
    int student; /* student index (0..n-1) */
    int id;      /* book identifier */
} Request;

static int cmp_request(const void *a, const void *b) {
    const Request *ra = (const Request *)a;
    const Request *rb = (const Request *)b;
    if (ra->seq != rb->seq) return (ra->seq < rb->seq) ? -1 : 1;
    if (ra->student != rb->student) return (ra->student < rb->student) ? -1 : 1;
    return 0;
}

int main(void) {
    int m, c, n;

    while (scanf("%d", &m) == 1) {
        if (m <= 0) return 0;
        if (scanf("%d %d", &c, &n) != 2) return 0;

        /* Desk storage: ordered sequences with compaction on removal.
           Capacity c can be 0..5000; total distinct books <= 100 by spec. */
        int desk[MAX_DESKS][MAX_BOOK_ID + 5];
        int dsz[MAX_DESKS];
        for (int i = 0; i < MAX_DESKS; i++) dsz[i] = 0;

        /* Track current desk location for each book id (1..100). 0 means unseen. */
        int loc[MAX_BOOK_ID + 1];
        for (int id = 0; id <= MAX_BOOK_ID; id++) loc[id] = 0;

        Request reqs[MAX_REQ];
        int reqCount = 0;

        int special = m + 1;

        for (int student = 0; student < n; student++) {
            int t;
            scanf("%d", &t);
            for (int k = 0; k < t; k++) {
                int id;
                scanf("%d", &id);

                /* Record request */
                if (reqCount < MAX_REQ) {
                    reqs[reqCount].seq = k;
                    reqs[reqCount].student = student;
                    reqs[reqCount].id = id;
                    reqCount++;
                }

                /* Introduce distinct book on first appearance: place on desk m+1, no cost */
                if (loc[id] == 0) {
                    desk[special][dsz[special]++] = id;
                    loc[id] = special;
                }
            }
        }

        qsort(reqs, (size_t)reqCount, sizeof(reqs[0]), cmp_request);

        long long total = 0;

        for (int r = 0; r < reqCount; r++) {
            int id = reqs[r].id;

            /* 8.1 Remove requested book from its current desk */
            int from = loc[id];
            /* Find and remove id from desk[from], compacting */
            int pos = -1;
            for (int i = 0; i < dsz[from]; i++) {
                if (desk[from][i] == id) { pos = i; break; }
            }
            if (pos >= 0) {
                for (int i = pos + 1; i < dsz[from]; i++) desk[from][i - 1] = desk[from][i];
                dsz[from]--;
            }
            total += from;

            /* 8.2 If primary desk is full before placing id */
            if (dsz[1] == c) {
                /* Step 1: choose tmp in 2..m smallest not full */
                int tmp = -1;
                for (int d = 2; d <= m; d++) {
                    if (dsz[d] < c) { tmp = d; break; }
                }

                /* Step 2: append id to tmp, cost tmp */
                desk[tmp][dsz[tmp]++] = id;
                total += tmp;

                /* Step 3: evict front book from desk 1, cost 1 */
                int id2 = 0;
                if (dsz[1] > 0) {
                    id2 = desk[1][0];
                    for (int i = 1; i < dsz[1]; i++) desk[1][i - 1] = desk[1][i];
                    dsz[1]--;
                }
                total += 1;

                /* Step 4: choose j in 2..m smallest not full after updates */
                int j = -1;
                for (int d = 2; d <= m; d++) {
                    if (dsz[d] < c) { j = d; break; }
                }

                /* Step 5: insert id2 into desk j at pos:

                int insertPos = dsz[j];
                if (j == tmp) insertPos = dsz[j] - 1; /* immediately before temp id */
                for (int i = dsz[j]; i > insertPos; i--) desk[j][i] = desk[j][i - 1];

                loc[id2] = j;

                /* Step 6: add j+tmp, then remove temporarily placed id from tmp by size-- */
                total += (j + tmp);
                dsz[tmp]--; /* removes the last element, which is the temporary id */
            }

            /* 8.3 Place requested book onto primary desk, cost 1 */
            desk[1][dsz[1]++] = id;
            total += 1;
            loc[id] = 1;
        }

        printf("%lld\n", total);
    }

    return 0;
}
