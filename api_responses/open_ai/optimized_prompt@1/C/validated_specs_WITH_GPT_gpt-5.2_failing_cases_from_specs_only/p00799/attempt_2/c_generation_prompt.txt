1. Functional Description  
Simulates, over a fixed number of discrete time units, a set of up to 102 batteries that repeatedly alternate between **using** and **charging** according to a per-battery cyclic list of `(use_duration, charge_duration)` pairs. Each time unit, every battery that is in the using state consumes one unit of its remaining use time. When a battery finishes a use segment, it switches to charging and is appended to a single global FIFO waiting queue. Charging service is **non-preemptive**: at most one battery can receive one unit of charging progress per time unit, and only the battery currently at the **front** of the queue can receive that progress; it remains at the front until its current charge segment completes.

The program outputs a count of “missed charging opportunities” accumulated during the simulation: in each time unit where the queue is non-empty, every battery that is in the charging state **and is not the current queue-front battery** contributes +1 to the count for that time unit (with the exception noted below for batteries that just transitioned to charging in that same time unit).
