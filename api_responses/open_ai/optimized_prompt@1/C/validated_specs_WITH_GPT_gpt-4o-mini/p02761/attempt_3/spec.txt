# Revised Specification

## 1. Functional Description
The program computes a numerical value based on user-provided inputs that represent digit positions and their corresponding values. It handles special cases for specific input configurations and ensures that the computed number adheres to defined rules regarding digit placement and value assignment.

## 2. Inputs
- Two integers, N and M, where:
  - N represents the number of digit positions (must be a positive integer).
  - M represents the number of specified digit-value pairs (must be a non-negative integer).
- M pairs of integers, each consisting of:
  - A position index (s[i]) indicating the digit's position (1-based, must be within the range [1, N]).
  - A corresponding value (c[i]) for that position (must be a non-negative integer).

## 3. Outputs
- A single integer representing the computed number based on the inputs.
- If the computation is invalid due to conflicting values or specific conditions, the output is -1.

## 4. Preconditions
- N must be a positive integer.
- M must be a non-negative integer.
- The position indices (s[i]) must be within the range [1, N].
- The values (c[i]) must be non-negative integers.

## 5. Postconditions
- If M is 0 and N is 1, the output is 0.
- If M is 0 and N is 2, the output is 10.
- If M is 0 and N is 3, the output is 100.
- If M > 0, the output is the sum of the computed digit values based on their specified positions, or -1 if any inconsistencies are found.
- If the first digit position is specified as 1 with a value of 0 and N > 1, the output is -1.
- Unassigned digit positions are treated as zeros when forming the final number, except when the first position is zero and there are more than one digit.

## 6. Invariants
- The digit array maintains a state where each index corresponds to a digit position, initialized to -1, indicating unassigned values.
- The computed number is updated only if all specified digit values are consistent with their positions.

## 7. Error Handling / Exceptional Behavior
- If any digit position is assigned multiple conflicting values, the output is -1.
- If the first digit position is specified as 1 with a value of 0 and N > 1, the output is -1.

## 8. State Transitions (if applicable)
- The state transitions occur when digit values are assigned based on input pairs, and the computed number is updated based on the validity of these assignments and the placement of digits according to their specified positions.

## 9. Non-functional Constraints (if inferable)
- The program must handle inputs efficiently, ensuring that the computation completes in a reasonable time for typical input sizes.

## 10. Additional Clarifications
- If multiple digit-value pairs are provided, the program checks for consistency among the assigned values. If a position is assigned a value more than once with differing values, the output will be -1.
- Unassigned digit positions contribute a value of zero to the final number unless the first position is zero in a multi-digit number, in which case the output will be -1.
