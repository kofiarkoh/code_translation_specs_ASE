# 1. Functional Description
The code reads a list of cards, each represented by a character and an integer value, sorts them based on their integer values using a quicksort algorithm, and checks the stability of the sorting process. It outputs whether the sorting is stable and prints the sorted list of cards.

# 2. Inputs
- An integer `n` representing the number of cards.
- A sequence of `n` pairs, each consisting of a character and an integer.

# 3. Outputs
- A string indicating whether the sorting is "Stable" or "Not stable".
- A sequence of `n` lines, each containing a character and an integer representing the sorted cards.

# 4. Preconditions
- The input integer `n` must be a non-negative integer.
- Each card input must consist of a valid character followed by a valid integer.

# 5. Postconditions
- The output sequence of cards is sorted in non-decreasing order based on the integer values.
- The stability of the sorting process is determined and reported.

# 6. Invariants
- The original order of cards with equal integer values is preserved if the sorting is stable.
- The array of cards is modified in place during the sorting process.

# 7. Error Handling / Exceptional Behavior
- If the input does not conform to the expected format, the behavior is undefined.
- No explicit error handling is implemented for invalid inputs.

# 8. State Transitions (if applicable)
- The state transitions from an unsorted array of cards to a sorted array of cards after the sorting operation is completed.

# 9. Non-functional Constraints (if inferable)
- The sorting operation is expected to have an average time complexity of O(n log n).
- The space complexity is O(log n) due to the recursive nature of the quicksort algorithm.
