# 1. Functional Description
The code generates and prints all possible permutations of a sequence of integers from 1 to n, where n is provided as input. Each permutation is printed on a new line.

# 2. Inputs
- An integer n, representing the number of elements in the sequence.
- An implicit sequence of integers from 1 to n, generated based on the input n.

# 3. Outputs
- A series of lines, each containing a unique permutation of the integers from 1 to n.

# 4. Preconditions
- The input integer n must be a non-negative integer.
- The input must be provided in a format that allows for successful reading as an integer.

# 5. Postconditions
- All permutations of the integers from 1 to n are printed, with each permutation appearing on a separate line.
- Each integer in the permutations is separated by a space.

# 6. Invariants
- The integers in each permutation are distinct and range from 1 to n.
- The total number of printed permutations is equal to n factorial (n!).

# 7. Error Handling / Exceptional Behavior
- If the input is not a valid integer, the behavior is undefined, and no output is guaranteed.
- If n is negative, the function does not handle this case explicitly, leading to undefined behavior.

# 8. State Transitions (if applicable)
- The state transitions involve moving from one depth of recursion to another, where each state represents a partial permutation being constructed.

# 9. Non-functional Constraints (if inferable)
- The time complexity is O(n!) due to the generation of all permutations.
- The space complexity is O(n) for storing the current permutation and the used integers.
