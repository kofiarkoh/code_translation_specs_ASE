# Revised Specification

## 1. Functional Description
The code computes and outputs the cube root of a series of integer inputs using an iterative method based on Newton's method. The program continues processing inputs until a termination condition is met. It guarantees that the output is a double-precision floating-point representation of the cube root, accurate to a specified precision.

## 2. Inputs
The program accepts a sequence of integers from standard input. The input terminates when the value -1 is encountered or when the end of input is reached. The integers must be non-negative, as the cube root is only defined for non-negative values.

## 3. Outputs
The program outputs the cube root of each valid input integer as a double-precision floating-point number, formatted to six decimal places. The output will not occur for the termination value -1.

## 4. Preconditions
The input integers must be valid and represent non-negative values for which a cube root can be computed. The input must not include the termination value -1 until all desired computations are complete.

## 5. Postconditions
For each valid input integer, the output will be the cube root of that integer, computed using an iterative method that converges to a solution within a defined precision. The output will not occur for the termination value -1.

## 6. Invariants
The computed cube root remains within a defined precision throughout the iterative calculation process. The program maintains the integrity of input and output until termination.

## 7. Error Handling / Exceptional Behavior
The program does not explicitly handle erroneous input. If non-integer values are provided, the behavior is undefined. The program assumes valid integer input as per the preconditions.

## 8. State Transitions
The program transitions between states of reading input, computing the cube root using an iterative refinement process, and outputting results. It enters a termination state upon encountering the value -1 or reaching the end of input.

## 9. Non-functional Constraints
The output precision is constrained to six decimal places, and the computation must converge within a defined tolerance level (EPS). The program operates in a loop until termination conditions are met, implying a potentially indefinite runtime based on input size. The iterative method ensures that the output is accurate to the specified precision before it is printed.
