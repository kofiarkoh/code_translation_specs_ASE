# 1. Functional Description
The program determines and outputs the result of a comparison based on two pairs of integer values. It identifies a winner or a draw based on the values provided.

# 2. Inputs
- Four integer values representing two time values and two result values.

# 3. Outputs
- A string indicating the winner ("Alice" or "Bob") or "Draw" based on the comparison of the input values.

# 4. Preconditions
- The input must consist of exactly four integers.
- The result values must be non-negative integers.

# 5. Postconditions
- The output will be one of the three strings: "Alice", "Bob", or "Draw", based on the comparison logic defined in the program.

# 6. Invariants
- The program maintains that the result values are non-negative throughout its execution.

# 7. Error Handling / Exceptional Behavior
- If fewer or more than four integers are provided as input, the program will terminate without producing output.

# 8. State Transitions (if applicable)
- The program transitions from an input state to an output state based on the evaluation of the input values.

# 9. Non-functional Constraints (if inferable)
- The program must complete execution in a timely manner, with a focus on efficient input handling and output generation.
