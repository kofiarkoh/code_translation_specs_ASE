# Revised Specification

## 1. Functional Description
The program determines and outputs the result of a comparison based on two pairs of integer values. It identifies a winner or a draw based on the values provided, with distinct logic for handling result values based on their sign.

## 2. Inputs
- Four integer values representing two time values (T1 and T2) and two result values (R1 and R2).

## 3. Outputs
- A string indicating the winner ("Alice" or "Bob") or "Draw" based on the comparison of the input values.

## 4. Preconditions
- The input must consist of exactly four integers.
- The result values (R1 and R2) may be negative or non-negative integers.

## 5. Postconditions
- The output will be one of the three strings: "Alice", "Bob", or "Draw", determined by the following logic:
  - If either result value (R1 or R2) is negative, the output is based on the comparison of the time values (T1 and T2):
    - If T1 is less than T2, the output is "Alice".
    - If T1 is greater than T2, the output is "Bob".
    - If T1 equals T2, the output is "Draw".
  - If both result values are non-negative, the output is based on the comparison of the result values (R1 and R2):
    - If R1 is greater than R2, the output is "Bob".
    - If R1 is less than R2, the output is "Alice".
    - If R1 equals R2, the output is "Draw".

## 6. Invariants
- The program maintains that the result values are considered in their entirety, whether negative or non-negative, to determine the output.

## 7. Error Handling / Exceptional Behavior
- If fewer or more than four integers are provided as input, the program will terminate without producing output.

## 8. State Transitions
- The program transitions from an input state to an output state based on the evaluation of the input values, with distinct paths depending on the sign of the result values.

## 9. Non-functional Constraints
- The program must complete execution in a timely manner, with a focus on efficient input handling and output generation.
