# Revised Specification

## 1. Functional Description
The system processes input dimensions for a ski resort course and analyzes the course data to compute a specific sum based on defined rules. It continues to operate until a termination condition is met.

## 2. Inputs
- Two integers representing the dimensions of the course (X and Y).
- A series of integers representing the course data, structured in a grid of size X by Y.

## 3. Outputs
- An integer sum printed to the standard output, representing the result of the analysis based on the course data.

## 4. Preconditions
- The input for dimensions (X and Y) must be non-negative integers.
- The course data must be provided in a valid format corresponding to the specified dimensions.

## 5. Postconditions
- The output sum reflects the analysis of the course data based on specific rules that consider the values in the grid.
- The program terminates when both X and Y are zero.

## 6. Invariants
- The dimensions X and Y remain consistent throughout the execution of the analysis for a single run.
- The course data is always processed in a grid format of size X by Y.

## 7. Error Handling / Exceptional Behavior
- If the input dimensions are zero, the program terminates without performing further analysis.
- The program does not handle invalid input formats or out-of-bounds errors explicitly.

## 8. State Transitions
- The system transitions from an input state (receiving dimensions and course data) to an output state (printing the analysis result) based on the successful completion of data processing.

## 9. Counting Logic
- The sum is computed based on specific conditions applied to the course data:
  - If a cell in the grid contains the value `0`, it contributes to the sum based on the patterns established by neighboring cells.
  - If a cell contains the value `1`, it resets the contribution from that path to zero, effectively blocking further contributions from that direction.
  - If a cell contains the value `2`, it allows for additional contributions based on the presence of `0` values in subsequent cells, following a specific pattern that may extend contributions further down the grid.
  - Contributions from neighboring cells are considered, and the program evaluates contributions from multiple paths, ensuring that the presence of `1`s appropriately resets contributions while `0`s and `2`s can extend them.

## 10. Termination Behavior
- The program will continue to prompt for new dimensions and course data until the termination condition (both X and Y being zero) is met. Upon termination, no further output is generated.

## 11. Non-functional Constraints
- The program must handle input and output operations efficiently to ensure responsiveness during data entry and result display.
