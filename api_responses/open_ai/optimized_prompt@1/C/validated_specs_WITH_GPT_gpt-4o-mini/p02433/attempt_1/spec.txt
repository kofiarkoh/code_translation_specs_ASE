# 1. Functional Description
The code implements a doubly linked list with operations to insert, move, and erase nodes. It allows for dynamic manipulation of the list and outputs the contents in order.

# 2. Inputs
- An integer indicating the number of operations to perform.
- A series of commands, each specifying an operation (insert, move, erase) followed by an integer value (if applicable).

# 3. Outputs
- The contents of the linked list printed in order, from the front to the end, excluding a sentinel value.

# 4. Preconditions
- The input must consist of valid commands and integers.
- The initial state of the list contains a sentinel node with a specific value.

# 5. Postconditions
- The linked list reflects the result of all operations performed.
- The output is a sequence of integers representing the data in the list, excluding the sentinel value.

# 6. Invariants
- Each node in the list maintains pointers to its previous and next nodes.
- The list can be traversed from the front to the end without encountering null pointers, except at the end of the list.

# 7. Error Handling / Exceptional Behavior
- If an attempt is made to move the cursor beyond the front of the list, an error message is printed, and the program exits.
- If an attempt is made to move the cursor beyond the end of the list, an error message is printed, and the program exits.

# 8. State Transitions (if applicable)
- The state of the list changes with each operation: insertion adds a node, movement changes the cursor position, and erasure removes a node.

# 9. Non-functional Constraints (if inferable)
- The program must handle a limited number of operations as specified by the input.
- Memory management is required to prevent leaks, as nodes are dynamically allocated and freed.
