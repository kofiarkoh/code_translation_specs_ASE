# 1. Functional Description
The code constructs a k-d tree from a set of points and allows for querying points within a specified rectangular region. It guarantees that all points within the defined bounds are identified and returned in sorted order.

# 2. Inputs
- An integer `n` representing the number of points.
- A list of `n` pairs of integers representing the coordinates (x, y) of each point.
- An integer `q` representing the number of queries.
- A list of `q` queries, each defined by four integers (sx, tx, sy, ty) representing the bounds of a rectangular region.

# 3. Outputs
- For each query, a list of point IDs corresponding to points within the specified rectangular region, printed in ascending order.

# 4. Preconditions
- The input integer `n` must be non-negative and less than or equal to a defined maximum.
- Each point's coordinates must be valid integers.
- The input integer `q` must be non-negative.

# 5. Postconditions
- The output for each query contains the IDs of all points that lie within the specified rectangular bounds, sorted in ascending order.
- The output is separated by a newline for each query.

# 6. Invariants
- The k-d tree structure remains valid throughout the execution, ensuring that each node correctly represents a partition of the point set.
- The point IDs are unique and correspond to their respective points.

# 7. Error Handling / Exceptional Behavior
- If `n` is zero, no points are processed, and no output is generated for queries.
- If a query's bounds do not encompass any points, the output will be empty for that query.

# 8. State Transitions (if applicable)
- The state transitions occur during the construction of the k-d tree and the querying process, where the state changes from an unprocessed set of points to a structured tree and then to a list of identified point IDs.

# 9. Non-functional Constraints (if inferable)
- The algorithm is expected to handle up to a million points efficiently, with time complexity primarily influenced by the logarithmic nature of the k-d tree for queries.
