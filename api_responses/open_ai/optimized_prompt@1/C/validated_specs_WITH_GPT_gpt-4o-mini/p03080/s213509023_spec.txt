# 1. Functional Description
The program evaluates a sequence of characters to determine if the count of a specific character exceeds the count of another character. It outputs a confirmation based on this evaluation.

# 2. Inputs
- An integer \( N \) representing the number of characters to evaluate.
- A string of characters, limited to a maximum length of 127, containing only the characters 'R' and any other characters.

# 3. Outputs
- A string output of "Yes" if the count of 'R' characters exceeds the count of other characters; otherwise, it outputs "No".

# 4. Preconditions
- The input integer \( N \) must be a non-negative integer.
- The input string must contain at least \( N \) characters.

# 5. Postconditions
- The output will be "Yes" if the number of 'R' characters in the first \( N \) characters of the string is greater than \( N - \text{count of 'R'} \); otherwise, it will be "No".

# 6. Invariants
- The variable tracking the count of 'R' characters is updated correctly throughout the evaluation process.
- The input string remains unchanged after reading.

# 7. Error Handling / Exceptional Behavior
- If the input for \( N \) is not a valid integer, or if the string input is not successfully read, the program terminates with a non-zero exit status.

# 8. State Transitions (if applicable)
- The program transitions from an initial state (waiting for input) to a processing state (evaluating the input) and finally to a terminal state (outputting the result).

# 9. Non-functional Constraints (if inferable)
- The program must handle input efficiently within the constraints of memory and processing time, particularly for the maximum input size.
