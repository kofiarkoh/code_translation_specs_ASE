# Revised Specification

## 1. Functional Description
The code processes a grid representation of a structure to determine its stability based on specific criteria. It identifies connected components in the grid and evaluates whether the structure meets defined stability conditions by analyzing the properties of these components.

## 2. Inputs
- A series of grids defined by their width and height.
- Each grid cell contains either a character representing a part of the structure or a placeholder indicating empty space.

## 3. Outputs
- A string indicating the stability of the structure: either "STABLE" or "UNSTABLE".

## 4. Preconditions
- The input grid dimensions (width and height) must be positive integers.
- The grid must be filled with valid characters representing the structure or empty spaces.

## 5. Postconditions
- The output will reflect the stability of the structure based on the evaluation of connected components and their properties.

## 6. Invariants
- The relationships between connected components are maintained throughout the processing.
- The properties of each component, such as size and maximum x-coordinate, are consistently updated during the evaluation.

## 7. Error Handling / Exceptional Behavior
- If the input dimensions are non-positive, the program terminates without processing.
- The program assumes valid input; no explicit error handling for malformed input is implemented.

## 8. State Transitions
- The state transitions occur as the program processes each grid cell, updating the relationships and properties of connected components based on their neighbors. The evaluation of stability involves checking the size of each component against its maximum x-coordinate, ensuring that the component's center of mass is within its bounds.

## 9. Stability Criteria
- A structure is considered "STABLE" if, for each connected component, the following condition holds: the center of mass (calculated as 0.5 plus the ratio of the total x-coordinates to the size of the component) must lie within the horizontal bounds defined by the minimum and maximum x-coordinates of that component. If this condition is violated for any component, the structure is deemed "UNSTABLE".
