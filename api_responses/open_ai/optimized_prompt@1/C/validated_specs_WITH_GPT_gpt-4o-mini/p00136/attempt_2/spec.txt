# Revised Specification

## 1. Functional Description
The program categorizes a series of height measurements into six distinct ranges based on specified criteria and outputs a visual representation of the counts for each range using asterisks.

## 2. Inputs
- An integer representing the number of height measurements, which must be a non-negative value.
- A series of floating-point numbers representing individual height measurements.

## 3. Outputs
- A textual representation of the counts of heights in six specified ranges, each preceded by a label. The counts are represented by asterisks, where the number of asterisks corresponds to the count of heights in each range.

## 4. Preconditions
- The input integer must be a non-negative value.
- The input heights must be valid floating-point numbers.

## 5. Postconditions
- The program outputs six lines, each corresponding to a height range, displaying the count of heights that fall within that range as asterisks.

## 6. Invariants
- The total count of heights processed equals the input integer.
- The counts for each height range are non-negative integers.

## 7. Error Handling / Exceptional Behavior
- The program does not handle invalid input formats or out-of-range values; it assumes all inputs are valid as per the preconditions.

## 8. State Transitions
- The program transitions from an initial state (waiting for input) to a processing state (counting heights) and finally to an output state (displaying results).

## 9. Height Ranges
- The height ranges are defined as follows:
  - Range 1: Heights less than 165.0
  - Range 2: Heights from 165.0 (inclusive) to 170.0 (exclusive)
  - Range 3: Heights from 170.0 (inclusive) to 175.0 (exclusive)
  - Range 4: Heights from 175.0 (inclusive) to 180.0 (exclusive)
  - Range 5: Heights from 180.0 (inclusive) to 185.0 (exclusive)
  - Range 6: Heights 185.0 and above (inclusive)

## 10. Non-functional Constraints
- The program must complete execution in a reasonable time frame relative to the number of height measurements provided.
