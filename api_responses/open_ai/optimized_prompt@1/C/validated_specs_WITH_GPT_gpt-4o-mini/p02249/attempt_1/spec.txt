# 1. Functional Description
The code performs a pattern search within a two-dimensional text grid, identifying all starting positions where a specified pattern grid matches the text grid. It computes hash values for both the text and the pattern to facilitate efficient comparison.

# 2. Inputs
- Two integers representing the height and width of the text grid.
- A two-dimensional character array representing the text grid.
- Two integers representing the height and width of the pattern grid.
- A two-dimensional character array representing the pattern grid.

# 3. Outputs
- A list of pairs of integers, each representing the row and column indices in the text grid where the pattern grid matches.

# 4. Preconditions
- The height and width of the text grid must be positive integers.
- The height and width of the pattern grid must be positive integers.
- The dimensions of the pattern grid must not exceed those of the text grid.

# 5. Postconditions
- The output will contain all valid starting positions of the pattern within the text, if any exist.
- If no matches are found, no output will be produced.

# 6. Invariants
- The hash values for the text and pattern grids are consistently computed based on their respective contents.
- The text and pattern grids remain unchanged throughout the execution of the program.

# 7. Error Handling / Exceptional Behavior
- The program does not explicitly handle input errors or invalid dimensions; it assumes valid input is provided.
- If the input does not conform to expected formats, behavior is undefined.

# 8. State Transitions (if applicable)
- The program transitions from reading input to computing hash values, and finally to outputting results based on comparisons of hash values.

# 9. Non-functional Constraints (if inferable)
- The algorithm is designed to operate efficiently with respect to time complexity, leveraging hashing to reduce the number of direct comparisons needed.
