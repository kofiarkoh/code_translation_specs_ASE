# 1. Functional Description
The program computes a specific transformation of an integer input based on its divisibility by 11. It returns a calculated value derived from the input integer.

# 2. Inputs
- A single integer input, which is a long long integer.

# 3. Outputs
- A single long long integer output, which is the result of the transformation based on the input.

# 4. Preconditions
- The input must be a valid long long integer.
- The input must be provided in a format that can be correctly interpreted as a long long integer.

# 5. Postconditions
- If the input is divisible by 11, the output is twice the quotient of the input divided by 11.
- If the input is not divisible by 11 and the remainder is greater than 6, the output is twice the quotient of the input divided by 11 plus 2.
- If the input is not divisible by 11 and the remainder is 6 or less, the output is twice the quotient of the input divided by 11 plus 1.

# 6. Invariants
- The output is always a non-negative integer.
- The output is determined solely by the input value and its properties with respect to 11.

# 7. Error Handling / Exceptional Behavior
- If the input cannot be read or is not a valid long long integer, the behavior is undefined; no specific error handling is implemented.

# 8. State Transitions (if applicable)
- The program transitions from an input state (waiting for user input) to an output state (displaying the computed result) based on the processing of the input.

# 9. Non-functional Constraints (if inferable)
- The program must complete execution in a finite time frame, assuming valid input is provided.
