# 1. Functional Description
The code computes the maximum sum of values collected by two entities moving through a grid from the top-left corner to the bottom-right corner, allowing for specific movement patterns. The result is output as a single integer.

# 2. Inputs
- A grid defined by its width and height, followed by the integer values in each cell of the grid.
- Input can be read from a file or standard input.

# 3. Outputs
- A single integer representing the maximum sum of values collected by the two entities upon reaching the bottom-right corner of the grid.

# 4. Preconditions
- The grid dimensions (width and height) must be positive integers.
- The grid must not exceed the defined maximum size.
- The input must be formatted correctly to allow for successful parsing.

# 5. Postconditions
- The output integer is the maximum sum of values collected by the two entities, calculated based on the defined movement rules.

# 6. Invariants
- The grid values remain unchanged throughout the execution.
- The maximum sum is updated only based on valid movements within the grid.

# 7. Error Handling / Exceptional Behavior
- If the movement of either entity goes out of the grid boundaries, the operation is aborted for that path.
- If the input format is incorrect, the behavior is undefined, but the program does not handle such errors explicitly.

# 8. State Transitions (if applicable)
- The state transitions occur as the entities move through the grid, updating their positions and the maximum sum collected based on valid movements.

# 9. Non-functional Constraints (if inferable)
- The program must operate within the constraints of memory and processing time suitable for the maximum grid size defined.
