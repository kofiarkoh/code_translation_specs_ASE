# 1. Functional Description
The program determines and outputs the name of a winner based on the difference between two integer inputs. If the difference is even, the output is "Alice"; if odd, the output is "Borys".

# 2. Inputs
- Three integers: N, A, and B.

# 3. Outputs
- A string indicating the winner: either "Alice" or "Borys".

# 4. Preconditions
- The input integers must be provided in a single line, separated by spaces.
- The input values must be valid integers.

# 5. Postconditions
- The output will be either "Alice" or "Borys" based on the parity of the difference between B and A.

# 6. Invariants
- The program maintains the integrity of the input values throughout its execution.

# 7. Error Handling / Exceptional Behavior
- The program does not handle invalid input formats or non-integer values; behavior is undefined in such cases.

# 8. State Transitions (if applicable)
- The program transitions from an input state to an output state based on the evaluation of the difference between B and A.

# 9. Non-functional Constraints (if inferable)
- The program must complete execution in a timely manner, with output produced immediately after input processing.
