# 1. Functional Description
The code reads an integer input and outputs a specific string based on the value of the input, corresponding to the days leading up to Christmas.

# 2. Inputs
An integer value representing a day relative to Christmas.

# 3. Outputs
A string indicating the holiday associated with the input integer:
- "Christmas" for input 25
- "Christmas Eve" for input 24
- "Christmas Eve Eve" for input 23
- "Christmas Eve Eve Eve" for input 22
No output for any other integer values.

# 4. Preconditions
The input must be an integer.

# 5. Postconditions
The output will be one of the specified strings if the input matches one of the defined values; otherwise, there will be no output.

# 6. Invariants
The program maintains the integrity of the input-output relationship, ensuring that only the specified strings are produced for the corresponding input values.

# 7. Error Handling / Exceptional Behavior
The program does not handle invalid input types or out-of-range values; it will not produce any output for inputs not explicitly defined.

# 8. State Transitions (if applicable)
The program transitions from an input state (waiting for user input) to an output state (displaying the corresponding holiday string or remaining silent).

# 9. Non-functional Constraints (if inferable)
The program operates with constant time complexity for the input-output operations, as it performs a fixed number of comparisons regardless of the input value.
