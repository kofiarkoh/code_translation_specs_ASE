# 1. Functional Description
The code simulates the movement of a point in a 2D space based on user-defined mirror placements. It calculates the final position of the point after a series of movements, reflecting off mirrors as specified.

# 2. Inputs
- An integer `n` representing the number of mirrors, followed by `n` entries.
- Each entry consists of a string indicating the mirror orientation ('x' for vertical, 'y' for horizontal) and two integers `x` and `y` representing the mirror's position.

# 3. Outputs
- The final coordinates of the point after processing all movements and mirror interactions, formatted as two integers.

# 4. Preconditions
- The input integer `n` must be non-negative.
- The mirror positions must be within the defined grid limits (0 to 800 for both coordinates).

# 5. Postconditions
- The output coordinates reflect the final position of the point after all movements and interactions with mirrors have been processed.

# 6. Invariants
- The point starts at the initial position (50, 0) and moves according to predefined directional vectors.
- The state of the mirror grid is maintained throughout the execution, ensuring accurate reflection behavior.

# 7. Error Handling / Exceptional Behavior
- The program terminates gracefully if a negative integer is provided for `n`.
- Movement stops if the point reaches the boundaries of the defined grid or if a specific exit condition is met.

# 8. State Transitions (if applicable)
- The state transitions occur based on the current position and direction of the point, influenced by the presence of mirrors which may change the direction of movement.

# 9. Non-functional Constraints (if inferable)
- The program must efficiently handle multiple mirror placements and movements without exceeding memory limits or processing time constraints.
