# 1. Functional Description
The program reads pairs of integers from input and outputs the difference between each pair.

# 2. Inputs
The program accepts a total of seven pairs of integers.

# 3. Outputs
The program outputs seven integers, each representing the difference between the first and second integer of each input pair.

# 4. Preconditions
The input must consist of exactly seven pairs of integers. Each integer must be valid and within the range of the integer type.

# 5. Postconditions
For each pair of integers read, the output will be the result of subtracting the second integer from the first. The output will be produced in the same order as the input pairs.

# 6. Invariants
The program maintains that the number of input pairs processed is exactly seven, and each output corresponds directly to an input pair.

# 7. Error Handling / Exceptional Behavior
The program does not handle invalid input or errors during input reading. If invalid input is provided, the behavior is undefined.

# 8. State Transitions (if applicable)
The program transitions from an initial state (waiting for input) to a final state (after processing all input and producing output).

# 9. Non-functional Constraints (if inferable)
The program is expected to complete execution in a timely manner, processing each input pair sequentially without significant delay.
