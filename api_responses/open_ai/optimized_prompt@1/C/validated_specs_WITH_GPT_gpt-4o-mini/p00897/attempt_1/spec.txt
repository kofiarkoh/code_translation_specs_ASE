# 1. Functional Description
The code implements a system to find the shortest path in a graph representing cities and roads, considering fuel capacity constraints. It allows for the addition of cities and roads, and identifies if a route exists from a starting city to a goal city, returning the minimum distance required.

# 2. Inputs
- A series of integers representing the number of cities, the number of roads, and the fuel capacity.
- Strings representing city names.
- Triplet inputs for each road, consisting of two city identifiers and the distance between them.
- A list of city names that have LPG stations.

# 3. Outputs
- An integer representing the minimum distance from the starting city to the goal city, or -1 if no route exists.

# 4. Preconditions
- The input must include at least two cities and one road.
- City names must be unique.
- The fuel capacity must be a positive integer.

# 5. Postconditions
- If a valid path exists, the output will be the minimum distance required to travel from the starting city to the goal city.
- If no valid path exists, the output will be -1.

# 6. Invariants
- The graph structure remains consistent throughout the execution, with cities and roads being correctly represented.
- The priority queue used for pathfinding maintains the correct order based on distance.

# 7. Error Handling / Exceptional Behavior
- If memory allocation fails during the creation of adjacency lists, the program may exhibit undefined behavior.
- If invalid input is provided (e.g., non-integer values for city or road counts), the behavior is unspecified.

# 8. State Transitions (if applicable)
- The state transitions occur as cities and roads are added, and as the shortest path algorithm processes nodes in the graph, updating distances and fuel capacities.

# 9. Non-functional Constraints (if inferable)
- The algorithm is expected to operate efficiently within the constraints of the input sizes, with a focus on minimizing time complexity for pathfinding. Memory usage is also a consideration due to dynamic allocations for adjacency lists.
