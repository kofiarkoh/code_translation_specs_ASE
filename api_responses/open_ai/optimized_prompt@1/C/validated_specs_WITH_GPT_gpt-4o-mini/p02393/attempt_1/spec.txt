# 1. Functional Description
The code reads three integer values and outputs them in non-decreasing order.

# 2. Inputs
Three integers provided by the user.

# 3. Outputs
Three integers in non-decreasing order, printed to the standard output.

# 4. Preconditions
The input must consist of exactly three integers.

# 5. Postconditions
The output will always reflect the three input integers sorted in non-decreasing order.

# 6. Invariants
The values of the output integers will always be a permutation of the input integers.

# 7. Error Handling / Exceptional Behavior
The code does not handle invalid input (e.g., non-integer values or fewer/more than three integers). Undefined behavior may occur if the input does not meet the preconditions.

# 8. State Transitions (if applicable)
The state transitions involve reading input values and transitioning to a sorted output state.

# 9. Non-functional Constraints (if inferable)
The output will be produced in a single operation after reading the input, with no specific performance constraints defined.
