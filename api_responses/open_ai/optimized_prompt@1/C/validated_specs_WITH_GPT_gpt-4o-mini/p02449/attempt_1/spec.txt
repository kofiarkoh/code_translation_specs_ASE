# 1. Functional Description
The code reads an integer sequence, computes the previous and next permutations of that sequence, and prints both the original sequence and the computed permutations.

# 2. Inputs
- An integer `n` representing the number of elements in the sequence.
- A sequence of `n` integers.

# 3. Outputs
- The previous permutation of the input sequence, if it exists.
- The original input sequence.
- The next permutation of the input sequence, if it exists.

# 4. Preconditions
- The input integer `n` must be between 1 and 9, inclusive.
- The input sequence must consist of `n` integers.

# 5. Postconditions
- If `n` is 1, the output will be "1".
- If a previous permutation exists, it will be printed before the original sequence.
- The original sequence will always be printed.
- If a next permutation exists, it will be printed after the original sequence.

# 6. Invariants
- The original sequence remains unchanged throughout the execution.
- The computed previous and next permutations are derived from the original sequence.

# 7. Error Handling / Exceptional Behavior
- If `n` is less than 1 or greater than 9, the behavior is undefined as the code does not handle such cases.
- If the input sequence contains invalid integers (non-integer values), the behavior is undefined.

# 8. State Transitions (if applicable)
- The state transitions occur when the previous and next permutations are computed based on the current sequence state.

# 9. Non-functional Constraints (if inferable)
- The program operates within a time complexity that is efficient for sequences of length up to 9.
