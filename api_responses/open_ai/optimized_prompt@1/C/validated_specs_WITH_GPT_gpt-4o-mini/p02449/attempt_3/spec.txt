# Revised Specification

## 1. Functional Description
The code reads an integer sequence, computes the previous and next permutations of that sequence, and prints both the original sequence and the computed permutations. The previous permutation is derived from the original sequence, and the next permutation is derived from the original sequence after the previous permutation has been computed.

## 2. Inputs
- An integer `n` representing the number of elements in the sequence, where `1 ≤ n ≤ 9`.
- A sequence of `n` integers.

## 3. Outputs
- The previous permutation of the input sequence, if it exists, printed before the original sequence.
- The original input sequence, printed unmodified.
- The next permutation of the input sequence, if it exists, printed after the original sequence.

## 4. Preconditions
- The input integer `n` must be between 1 and 9, inclusive.
- The input sequence must consist of `n` integers.

## 5. Postconditions
- If `n` is 1, the output will be "1".
- If a previous permutation exists, it will be printed before the original sequence, and the original sequence will remain unchanged.
- The original sequence will always be printed.
- If a next permutation exists, it will be printed after the original sequence.

## 6. Invariants
- The original sequence remains unchanged throughout the execution.
- The computed previous and next permutations are derived from the original sequence, and their outputs do not modify the original sequence.

## 7. Error Handling / Exceptional Behavior
- If `n` is less than 1 or greater than 9, the behavior is undefined as the code does not handle such cases.
- If the input sequence contains invalid integers (non-integer values), the behavior is undefined.

## 8. State Transitions
- The state transitions occur when the previous permutation is computed based on the original sequence. If a previous permutation exists, it is printed before the original sequence. The next permutation is computed based on the original sequence after the previous permutation has been computed, and if it exists, it is printed after the original sequence.
- The previous permutation is determined by identifying the rightmost pair of elements where the left element is greater than the right element, followed by finding the largest element to the right of this pair that is smaller than the left element, and then swapping these elements. The elements to the right of the swapped position are then reversed to form the previous permutation.
- The next permutation is determined by identifying the rightmost pair of elements where the left element is smaller than the right element, followed by finding the smallest element to the right of this pair that is larger than the left element, and then swapping these elements. The elements to the right of the swapped position are then reversed to form the next permutation.

## 9. Non-functional Constraints
- The program operates within a time complexity that is efficient for sequences of length up to 9.
