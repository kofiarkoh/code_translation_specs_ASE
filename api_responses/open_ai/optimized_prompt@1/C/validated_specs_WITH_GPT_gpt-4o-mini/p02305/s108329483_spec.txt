# 1. Functional Description
The program determines the spatial relationship between two circles based on their centers and radii. It categorizes the relationship into five distinct cases, which are output as integer values.

# 2. Inputs
- Two sets of integer values representing the coordinates of the centers of two circles and their respective radii. Each set consists of three integers: the x-coordinate, the y-coordinate, and the radius.

# 3. Outputs
- An integer value representing the relationship between the two circles, which can be one of the following:
  - 4: The circles are separate.
  - 3: The circles are tangent externally.
  - 2: The circles intersect.
  - 1: The circles are tangent internally.
  - 0: One circle is completely within the other without touching.

# 4. Preconditions
- The input must consist of exactly two sets of three integers.
- The radii must be non-negative integers.

# 5. Postconditions
- The output will be one of the specified integer values based on the relationship between the two circles.

# 6. Invariants
- The program maintains the integrity of the input data throughout its execution, ensuring that the calculations are based solely on the provided coordinates and radii.

# 7. Error Handling / Exceptional Behavior
- The program does not handle invalid input formats or values outside the expected range. It assumes that the input will always be valid as per the preconditions.

# 8. State Transitions (if applicable)
- The program transitions from an input state (waiting for user input) to an output state (displaying the relationship between the circles) after processing the input.

# 9. Non-functional Constraints (if inferable)
- The program operates in constant time relative to the input size, as it processes a fixed number of inputs (two circles). The output is generated immediately after input processing.
