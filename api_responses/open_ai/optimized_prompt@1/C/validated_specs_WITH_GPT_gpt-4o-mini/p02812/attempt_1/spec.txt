1. **Functional Description**  
   The code counts the occurrences of the substring "ABC" in a given string, allowing for overlapping occurrences.

2. **Inputs**  
   - An integer `n` representing the length of the string (must be at least 3).
   - A string of characters with a maximum length of 50.

3. **Outputs**  
   - An integer representing the count of occurrences of the substring "ABC" in the input string.

4. **Preconditions**  
   - The input integer `n` must be greater than or equal to 3.
   - The input string must be null-terminated and contain at least `n` characters.

5. **Postconditions**  
   - The output integer is non-negative and reflects the total number of times the substring "ABC" appears in the input string.

6. **Invariants**  
   - The count of occurrences is incremented only when the substring "ABC" is found.
   - The loop iterates through the string while ensuring that the index does not exceed the bounds defined by `n`.

7. **Error Handling / Exceptional Behavior**  
   - If `n` is less than 3, the behavior is undefined as the loop will not execute.
   - If the input string exceeds 50 characters, the behavior is undefined due to potential buffer overflow.

8. **State Transitions (if applicable)**  
   - The state transitions occur as the loop iterates through the string, updating the count based on the detection of the substring "ABC".

9. **Non-functional Constraints (if inferable)**  
   - The execution time is linear with respect to the length of the string, specifically O(n), where n is the input length.
