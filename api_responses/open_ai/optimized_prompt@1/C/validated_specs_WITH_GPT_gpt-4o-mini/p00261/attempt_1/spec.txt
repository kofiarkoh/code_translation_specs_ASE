# 1. Functional Description
The system processes a sequence of character inputs representing paths through a predefined state map. It determines if the final state after processing the input path corresponds to a specific target state.

# 2. Inputs
- A sequence of character strings, each representing a path, terminated by a string starting with a specific character indicating the end of input.

# 3. Outputs
- For each input path, the system outputs either "Yes" or "No" based on whether the final state corresponds to a designated target state.

# 4. Preconditions
- Input paths consist of characters representing valid indices within the range of the state map.
- The input must be terminated by a specific character indicating the end of input.

# 5. Postconditions
- The output reflects whether the final state after processing the input path is the designated target state.

# 6. Invariants
- The state transitions are governed by a fixed mapping that does not change during execution.
- The input path is processed sequentially until either the end of the path is reached or an invalid transition occurs.

# 7. Error Handling / Exceptional Behavior
- If an invalid character is encountered that does not correspond to a valid index, the processing of the current path is halted, and the output will be "No".

# 8. State Transitions (if applicable)
- The system transitions between states based on the input characters, following a predefined mapping until an invalid transition is encountered or the end of the input path is reached.

# 9. Non-functional Constraints (if inferable)
- The system is expected to handle input paths of varying lengths up to a specified maximum length efficiently.
