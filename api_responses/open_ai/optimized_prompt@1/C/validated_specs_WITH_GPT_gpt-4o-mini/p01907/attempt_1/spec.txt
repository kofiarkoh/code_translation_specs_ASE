# 1. Functional Description
The code computes a weighted sum based on the depth of nodes in a tree structure, where the weights are determined by a given probability factor. It reads input to construct the tree, performs a depth-first search to determine the depth of each node, and calculates a final result based on the accumulated costs and probabilities.

# 2. Inputs
- A floating-point number representing a probability factor.
- A non-negative integer representing the number of nodes in the tree.
- A series of triplets, each consisting of two integers (representing connected nodes) and a non-negative integer (representing the cost of the edge connecting them).

# 3. Outputs
- A single floating-point number representing the computed weighted sum, formatted to ten decimal places.

# 4. Preconditions
- The probability factor must be a valid floating-point number.
- The number of nodes must be a non-negative integer.
- Each triplet must consist of valid node indices and a non-negative cost.

# 5. Postconditions
- The output is a floating-point number that reflects the weighted sum of costs based on the depth of each node in the tree.

# 6. Invariants
- The tree structure remains consistent throughout the execution, with each node connected as specified by the input.
- The depth of each node is accurately calculated and stored during the depth-first search.

# 7. Error Handling / Exceptional Behavior
- The code does not explicitly handle invalid inputs or memory allocation failures. If invalid inputs are provided, the behavior is undefined.
- Memory allocated for the tree structure is not freed, which may lead to memory leaks.

# 8. State Transitions (if applicable)
- The state transitions occur during the depth-first search, where the state of each node changes from unvisited to visited, and the depth of each node is updated accordingly.

# 9. Non-functional Constraints (if inferable)
- The algorithm is expected to operate efficiently within the constraints of the input size, specifically handling up to 100,000 nodes and edges.
