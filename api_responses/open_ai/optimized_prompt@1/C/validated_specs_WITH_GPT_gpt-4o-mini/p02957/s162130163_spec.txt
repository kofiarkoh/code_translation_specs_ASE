# Revised Specification

## 1. Functional Description
The program computes the average of two long integers using integer division if their sum is even. If the sum is odd, it indicates that the average cannot be computed.

## 2. Inputs
Two long integers provided by the user.

## 3. Outputs
- The result of the integer division of the sum of the two long integers by two, represented as a long integer, if their sum is even.
- A message indicating "IMPOSSIBLE" if the sum is odd.

## 4. Preconditions
- The inputs must be valid long integers.

## 5. Postconditions
- If the sum of the inputs is even, the output is the long integer result of the integer division of the sum by two.
- If the sum of the inputs is odd, the output is the string "IMPOSSIBLE".

## 6. Invariants
The program maintains that the sum of the two long integers is either even or odd throughout its execution.

## 7. Error Handling / Exceptional Behavior
The program does not handle invalid input types or out-of-range values; it assumes valid long integer input.

## 8. State Transitions
- Initial state: Awaiting user input.
- Transition to output state based on the parity of the sum of inputs.

## 9. Non-functional Constraints
- The program must complete execution in a timely manner, ideally within a single user interaction cycle.
