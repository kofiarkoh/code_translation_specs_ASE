# 1. Functional Description
The program calculates a numerical result based on the comparison of two input strings of equal length. The result is derived from specific rules regarding character matches and is returned modulo a predefined constant.

# 2. Inputs
- An integer \( N \) representing the length of two strings.
- Two strings \( S1 \) and \( S2 \), each of length \( N \).

# 3. Outputs
- A single long integer value representing the computed result based on the input strings.

# 4. Preconditions
- The input integer \( N \) must be a positive integer.
- The lengths of both strings \( S1 \) and \( S2 \) must equal \( N \).

# 5. Postconditions
- The output value is a non-negative integer that is the result of the computation, constrained to be less than \( 1000000007 \).

# 6. Invariants
- The output value is consistently computed based on the character comparisons between \( S1 \) and \( S2 \).
- The result is updated based on specific conditions related to character equality and adjacency.

# 7. Error Handling / Exceptional Behavior
- If the input does not conform to the expected format (e.g., non-integer for \( N \), or strings of incorrect length), the behavior is undefined, and no output is guaranteed.

# 8. State Transitions (if applicable)
- The state transitions occur based on character comparisons between the two strings, affecting the value of the result during each iteration of the processing loop.

# 9. Non-functional Constraints (if inferable)
- The program must execute within a reasonable time frame for typical input sizes, with memory usage proportional to the input size \( N \).
