# 1. Functional Description
The program reads a grid of integers representing a map and calculates the number of grid cells that are adjacent to at least one cell marked as "2" after performing a specific traversal based on predefined movement vectors.

# 2. Inputs
- Two integers representing the width (`w`) and height (`h`) of the grid.
- A grid of integers with dimensions `(h x (2*w + 4))`, where each cell can contain various integer values.

# 3. Outputs
- A single integer representing the count of grid cells that are adjacent to at least one cell marked as "2".

# 4. Preconditions
- The input dimensions `w` and `h` must be positive integers.
- The grid must be populated with integers before the program processes it.

# 5. Postconditions
- The output integer reflects the total count of cells that are adjacent to cells marked as "2" after the traversal is complete.

# 6. Invariants
- The grid remains unchanged except for the cells that are marked as "2" during the traversal.
- The traversal only marks cells that are within the bounds of the grid and not already marked.

# 7. Error Handling / Exceptional Behavior
- The program does not handle invalid input formats or out-of-bounds errors explicitly. It assumes valid input is provided.

# 8. State Transitions (if applicable)
- The state transitions occur as the program marks cells in the grid during the traversal based on the defined movement vectors.

# 9. Non-functional Constraints (if inferable)
- The program operates within the constraints of memory for a grid of size `(h x (2*w + 4))` and is expected to complete in a reasonable time for typical input sizes.
