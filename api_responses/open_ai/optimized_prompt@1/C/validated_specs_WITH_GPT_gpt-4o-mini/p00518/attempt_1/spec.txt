# 1. Functional Description
The program processes a sequence of characters representing keys and computes a cumulative value based on the combinations of keys held over the sequence. The final result is printed as an integer modulo a predefined constant.

# 2. Inputs
- An integer \( N \) representing the number of characters in the input sequence.
- A string of length \( N \) consisting of characters from the set { 'J', 'O', 'I' }.

# 3. Outputs
- An integer representing the cumulative value derived from the input sequence, printed modulo 10007.

# 4. Preconditions
- The input integer \( N \) must be non-negative and less than or equal to 1000.
- The input string must contain exactly \( N \) characters, each being one of 'J', 'O', or 'I'.

# 5. Postconditions
- The output integer is the sum of valid combinations of keys represented by the input string, computed modulo 10007.

# 6. Invariants
- The program maintains a schedule array that tracks the number of ways to hold combinations of keys throughout the processing of the input string.
- The keys represented by 'J', 'O', and 'I' correspond to specific binary values that influence the combinations tracked in the schedule.

# 7. Error Handling / Exceptional Behavior
- The program does not handle invalid input formats or characters outside the specified set. It assumes valid input as per the preconditions.

# 8. State Transitions (if applicable)
- The state transitions occur with each character processed from the input string, updating the schedule based on the current and previous keys held.

# 9. Non-functional Constraints (if inferable)
- The program operates within a time complexity that is linear with respect to the input size, specifically \( O(N) \), where \( N \) is the length of the input string. The space complexity is constant, as the size of the schedule is fixed.
