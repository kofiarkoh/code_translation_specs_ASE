# 1. Functional Description
The program reads three integer values and computes the integer division of the first two values. It then compares this result with the third value and outputs the smaller of the two.

# 2. Inputs
Three integer values are provided as input.

# 3. Outputs
The program outputs a single integer, which is either the result of the integer division of the first two values or the third value, whichever is smaller.

# 4. Preconditions
- The first input value must be non-zero to avoid division by zero.
- All input values must be valid integers.

# 5. Postconditions
- The output is guaranteed to be the smaller of the integer division result of the first two inputs and the third input.

# 6. Invariants
- The output will always be an integer.
- The output will be less than or equal to the third input.

# 7. Error Handling / Exceptional Behavior
- If the first input is zero, the program will not produce a valid output due to division by zero, but this scenario is not explicitly handled in the code.
