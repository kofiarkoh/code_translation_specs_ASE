# 1. Functional Description
The program reads a sequence of characters representing boolean values ('T' for true and 'F' for false), processes them using a specific logical operation, and outputs a single character that represents the cumulative result of the operations.

# 2. Inputs
- An integer \( N \) indicating the number of boolean values to be processed.
- A sequence of \( N \) characters, each being either 'T' or 'F'.

# 3. Outputs
- A single character that is either 'T' or 'F', representing the result of the logical operations applied to the input characters.

# 4. Preconditions
- The input integer \( N \) must be a positive integer.
- The input characters must be limited to 'T' and 'F'.

# 5. Postconditions
- The output character reflects the result of applying the logical operation defined by the function to the sequence of input characters.

# 6. Invariants
- The program maintains that the input characters are always processed in the order they are received.
- The output character is determined solely based on the input characters and the defined logical operation.

# 7. Error Handling / Exceptional Behavior
- The program terminates with a return value of 1 if the input for \( N \) is not successfully read.
- The program terminates with a return value of 1 if any of the subsequent character inputs are not successfully read.

# 8. State Transitions (if applicable)
- The program transitions from an initial state (waiting for input) to a processing state (reading and evaluating inputs) and finally to a terminal state (outputting the result).

# 9. Non-functional Constraints (if inferable)
- The program must handle input sizes up to the defined limit of 114514 characters efficiently.
