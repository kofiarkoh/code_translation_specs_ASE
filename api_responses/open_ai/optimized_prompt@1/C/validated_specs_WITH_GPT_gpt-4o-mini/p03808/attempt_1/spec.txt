# 1. Functional Description
The code processes a sequence of integers to determine if a specific condition related to their sums and differences can be satisfied. It outputs a confirmation of whether the condition is met.

# 2. Inputs
- A single integer representing the number of elements, N.
- A sequence of N integers.

# 3. Outputs
- A string output of either "YES" or "NO" based on the evaluation of the input sequence against the specified condition.

# 4. Preconditions
- The input integer N must be a positive integer.
- The sequence must contain exactly N integers.

# 5. Postconditions
- If the condition is satisfied, the output will be "YES".
- If the condition is not satisfied, the output will be "NO".

# 6. Invariants
- The sum of the input integers is maintained throughout the processing.
- The differences between consecutive integers are calculated and stored.

# 7. Error Handling / Exceptional Behavior
- If the sum of the integers does not meet the divisibility condition, the output will be "NO".
- If any calculated difference is negative or exceeds a certain threshold, the output will be "NO".

# 8. State Transitions (if applicable)
- The state transitions occur through the evaluation of the sum and differences, leading to either a "YES" or "NO" output based on the conditions checked.

# 9. Non-functional Constraints (if inferable)
- The solution must operate within the constraints of handling up to 100,001 integers efficiently.
