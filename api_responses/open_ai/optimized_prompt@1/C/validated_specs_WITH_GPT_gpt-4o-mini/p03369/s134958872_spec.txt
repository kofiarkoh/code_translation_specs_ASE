1. **Functional Description**  
   The program reads a string of three characters and counts the occurrences of the character 'o'. It then calculates a score based on this count and outputs the result.

2. **Inputs**  
   A string consisting of exactly three characters.

3. **Outputs**  
   An integer value representing the calculated score, which is the sum of 700 and 100 times the count of 'o' characters in the input string.

4. **Preconditions**  
   The input string must contain exactly three characters.

5. **Postconditions**  
   The output is guaranteed to be an integer value that is at least 700 and increases by 100 for each occurrence of 'o' in the input string.

6. **Invariants**  
   The count of 'o' characters is always a non-negative integer and cannot exceed three.

7. **Error Handling / Exceptional Behavior**  
   The program does not handle inputs that do not meet the precondition of exactly three characters. Behavior is undefined for such inputs.

8. **State Transitions (if applicable)**  
   The program transitions from an initial state (waiting for input) to a final state (outputting the score) after processing the input.

9. **Non-functional Constraints (if inferable)**  
   The program must complete execution in a finite time frame, assuming valid input is provided.
