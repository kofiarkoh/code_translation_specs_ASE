# Revised Specification

## 1. Functional Description
The code processes multiple datasets of structured records, sorts them based on specific criteria, and outputs a limited selection of identifiers based on predefined rules regarding their associated attributes.

## 2. Inputs
- A series of datasets, each beginning with an integer `n` indicating the number of records.
- Each record consists of four integers representing attributes of a structure: `I`, `U`, `A`, and `P`.

## 3. Outputs
- A list of identifiers from the processed records, printed in a specific order, with a maximum of 25 identifiers based on selection criteria.

## 4. Preconditions
- The input must consist of valid integers.
- The first integer in each dataset must be non-negative, with `0` indicating the end of input.
- Each dataset must contain at most 300 records.

## 5. Postconditions
- The output will contain up to 25 identifiers from the records, selected based on sorting and frequency criteria.
- The identifiers are printed in the order determined by the sorting process.

## 6. Invariants
- The records are sorted primarily by the third attribute `A` in descending order, then by the fourth attribute `P` in ascending order, and finally by the first attribute `I` in ascending order.
- The selection of identifiers adheres to the frequency limits defined for each unique second attribute `U`:
  - Up to three identifiers can be selected for a second attribute that appears three times.
  - Up to two identifiers can be selected for a second attribute that appears twice.
  - Up to one identifier can be selected for a second attribute that appears once.

## 7. Error Handling / Exceptional Behavior
- The program terminates gracefully upon receiving a `0` as the first input, without processing further data.
- No explicit error handling for invalid input formats is implemented; behavior is undefined for such cases.

## 8. State Transitions (if applicable)
- The program transitions between states of reading input, processing records, sorting, and outputting results, with each dataset being processed independently until termination.

## 9. Non-functional Constraints (if inferable)
- The program is expected to handle up to 300 records efficiently within a single dataset.
- The output is limited to a maximum of 25 identifiers, ensuring concise results.
