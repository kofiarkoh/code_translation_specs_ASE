# Revised Specification

## 1. Functional Description
The code reads a sequence of non-negative integers from input, processes each pair of integers to compute a result based on their parity, and outputs the results as a sequence of strings, each followed by a newline. The computation involves specific arithmetic operations that depend on whether the first integer in the pair is odd or even.

## 2. Inputs
- A sequence of characters representing non-negative integers, read from standard input.
- Each integer must be represented in decimal format and can be separated by any non-digit character.

## 3. Outputs
- A sequence of strings, each representing the computed result for a pair of integers, followed by a newline character.

## 4. Preconditions
- The input must contain at least one pair of valid non-negative integers.
- The input must not exceed the buffer size limits (10,000 characters).

## 5. Postconditions
- The output will contain one line for each processed pair of integers, formatted as strings.
- Each line will represent the computed result based on the arithmetic operations defined by the parity of the first integer in the pair.

## 6. Invariants
- The output buffer will not exceed its maximum size of 20,000 characters.
- The input buffer will always be read completely before processing begins.

## 7. Error Handling / Exceptional Behavior
- If the input contains invalid characters (non-digit characters) before a valid integer, the processing will stop at that point.
- The program does not handle cases where the input is malformed or does not contain valid integers.

## 8. State Transitions
- The state transitions occur as the program reads input, processes integers, and updates the output buffer. Each successful read and computation results in a transition to the next integer pair.

## 9. Non-functional Constraints
- The program must complete execution within a reasonable time frame, given the constraints of input size and processing logic.

## 10. Arithmetic Operations
- For each pair of integers, the first integer \( N \) is evaluated for parity:
  - If \( N \) is odd, the result is computed as \( 127 \times (N - 1) + D \).
  - If \( N \) is even, the result is computed as \( 127 \times N - D \).
- The computed result is then formatted as a string and added to the output.
