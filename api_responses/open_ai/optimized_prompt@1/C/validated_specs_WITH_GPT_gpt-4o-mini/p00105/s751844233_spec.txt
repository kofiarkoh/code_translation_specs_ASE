# Revised Specification

## 1. Functional Description
The code processes a series of string and integer pairs, maintaining a collection of unique strings along with their associated page numbers and a count of occurrences. It sorts the unique strings in lexicographical order and outputs each string followed by its associated page numbers. The program allows for the same page number to be recorded multiple times for the same string, reflecting each occurrence in the output.

## 2. Inputs
- A sequence of string and integer pairs, where each string is a word and the integer represents a page number. Input continues until the end of the input stream.

## 3. Outputs
- A sorted list of unique strings, each followed by the page numbers associated with that string. Page numbers are printed in the order they were encountered, including duplicates, and the same page number may appear multiple times for a single string.

## 4. Preconditions
- The input must consist of valid strings and integers.
- The number of unique strings must not exceed the defined maximum limit.

## 5. Postconditions
- Each unique string is stored with its associated page numbers and occurrence count.
- The output is a sorted list of unique strings, each followed by its corresponding page numbers, including any duplicates.

## 6. Invariants
- The collection of strings remains unique throughout the processing.
- The page numbers for each string are correctly recorded and associated with the respective string, including duplicates.

## 7. Error Handling / Exceptional Behavior
- The program does not handle malformed input or memory allocation errors explicitly. It assumes valid input and sufficient memory availability.

## 8. State Transitions (if applicable)
- The state transitions occur as follows:
  1. Read input and update the collection of strings and page numbers, allowing for the same page number to be recorded multiple times for the same string.
  2. Sort the collection of strings.
  3. Output the sorted strings and their associated page numbers.

## 9. Non-functional Constraints (if inferable)
- The program operates within fixed memory limits defined by constants for maximum entries and page numbers.
- The sorting operation has a time complexity that is dependent on the number of unique strings processed.
