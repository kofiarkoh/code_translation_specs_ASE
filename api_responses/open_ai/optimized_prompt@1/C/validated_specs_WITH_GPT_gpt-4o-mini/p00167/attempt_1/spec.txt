# 1. Functional Description
The code reads a sequence of integers, sorts them in ascending order using a specific sorting algorithm, and counts the number of swaps made during the sorting process. It outputs the total swap count for each sequence until a termination condition is met.

# 2. Inputs
- A series of integers where the first integer indicates the number of subsequent integers to be sorted. 
- The input terminates when a zero is provided as the first integer.

# 3. Outputs
- An integer representing the number of swaps performed during the sorting of each sequence of integers.

# 4. Preconditions
- The first input integer must be non-negative and less than or equal to 100.
- If the first integer is greater than zero, there must be exactly that many subsequent integers provided.

# 5. Postconditions
- The output will reflect the total number of swaps made to sort the provided integers in ascending order.
- The program will continue to process input until a zero is encountered.

# 6. Invariants
- The array of integers is maintained in a state where it can be sorted correctly based on the input size specified.
- The swap count is incremented correctly for each swap made during the sorting process.

# 7. Error Handling / Exceptional Behavior
- If the input does not conform to the expected format (e.g., non-integer values), the behavior is undefined, and the program may not function as intended.
- The program does not handle negative values for the first integer, which may lead to unexpected behavior.

# 8. State Transitions (if applicable)
- The program transitions from reading input to processing the sorting and counting swaps, and finally to outputting the result for each sequence until termination.

# 9. Non-functional Constraints (if inferable)
- The sorting algorithm operates with a time complexity that is dependent on the number of elements being sorted, specifically O(n^2) in the worst case due to the nested loops.
