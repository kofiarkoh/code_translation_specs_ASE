# Revised Specification

## 1. Functional Description
The code processes a string input to count the number of unique characters. The output is a non-negative integer representing this count, which is adjusted based on the frequency of consecutive occurrences of characters. Specifically, if a character appears consecutively more than three times, the count of unique characters is decremented by the number of excess occurrences beyond three.

## 2. Inputs
- A string of characters, with a maximum length of 99 characters (excluding the null terminator).

## 3. Outputs
- A single non-negative integer representing the adjusted count of unique characters in the input string.

## 4. Preconditions
- The input string must be null-terminated and contain at most 99 characters.
- The input string may contain any characters, including non-alphabetic ones.

## 5. Postconditions
- The output integer reflects the count of unique characters, including all unique characters regardless of their consecutive occurrences. The count is adjusted only for characters that appear consecutively more than three times, decrementing the count by the number of excess occurrences beyond three.

## 6. Invariants
- The count of unique characters is non-negative throughout the execution.
- The frequency of each character is tracked accurately during processing.

## 7. Error Handling / Exceptional Behavior
- The code does not explicitly handle errors related to input size or format. It assumes valid input as per the preconditions.

## 8. State Transitions (if applicable)
- The state transitions occur as characters are processed, updating the counts of unique characters and their frequencies based on the input string. The count of unique characters is adjusted based on the number of consecutive occurrences of each character, specifically when those occurrences exceed three.

## 9. Non-functional Constraints (if inferable)
- The processing time is linear with respect to the length of the input string, as each character is processed a limited number of times.
