# 1. Functional Description
The code constructs a binary tree from user input, calculates the depth of each node, and prints the properties of each node, including its parent, depth, type (root, leaf, or internal), and its children.

# 2. Inputs
- An integer representing the number of nodes in the tree.
- For each node, an integer identifier and an integer indicating the number of children.
- A list of integers representing the identifiers of the children for each node.

# 3. Outputs
- For each node, a formatted string displaying:
  - The node's identifier.
  - The identifier of its parent.
  - The depth of the node.
  - The type of the node (root, leaf, or internal).
  - A list of the node's children identifiers.

# 4. Preconditions
- The number of nodes is a non-negative integer.
- Each node identifier is unique and within the range of the total number of nodes.
- The input for each node's children is valid and corresponds to existing node identifiers.

# 5. Postconditions
- Each node's parent, left child, and right child are correctly assigned based on the input.
- The depth of each node is accurately calculated and stored.
- The output correctly reflects the structure and properties of the constructed tree.

# 6. Invariants
- The parent of the root node is always -1.
- Each node's left and right children are either valid identifiers or -1, indicating the absence of a child.
- The depth of each node is non-negative and correctly represents its position in the tree.

# 7. Error Handling / Exceptional Behavior
- The code does not explicitly handle invalid input or errors. If invalid input is provided, the behavior is undefined.
- The code assumes that the input adheres to the expected format and constraints.

# 8. State Transitions (if applicable)
- The state transitions occur during the construction of the tree, where each node's parent and children are updated based on the input.
- The depth of nodes is updated recursively during the depth calculation.

# 9. Non-functional Constraints (if inferable)
- The implementation is limited to a maximum of 100,000 nodes.
- The performance is dependent on the input size, with a linear relationship to the number of nodes for both construction and output operations.
