# 1. Functional Description
The code implements a bipartite matching algorithm to determine if a perfect matching exists between two sets of nodes. It reads a grid of connections and outputs whether a perfect matching is possible, followed by the matched pairs if applicable.

# 2. Inputs
- A non-negative integer \( N \) representing the number of nodes in each set.
- A grid of size \( N \times N \) where each cell indicates a potential connection between nodes in the two sets.

# 3. Outputs
- A string "yes" if a perfect matching exists; otherwise, "no".
- If a perfect matching exists, the output includes \( N \) integers representing the matched nodes from the second set, each adjusted by a specific offset.

# 4. Preconditions
- The input grid must be well-formed, containing \( N \) rows and \( N \) columns.
- The input must be non-negative integers, and the grid must consist of binary values indicating connections.

# 5. Postconditions
- The output guarantees that if "yes" is printed, a perfect matching exists, and the subsequent integers represent valid matches.
- If "no" is printed, no perfect matching exists.

# 6. Invariants
- The matching state is maintained throughout the execution, ensuring that each node in the first set can be matched to at most one node in the second set.
- The algorithm consistently updates the state of seen nodes to avoid revisiting during the matching process.
