# 1. Functional Description
The program calculates and outputs half of the product of two integer inputs.

# 2. Inputs
- Three integers, denoted as `a`, `b`, and `c`.

# 3. Outputs
- A single double value representing half of the product of `a` and `b`, formatted as an integer.

# 4. Preconditions
- The first two inputs must be valid integers.
- The third input is not utilized in the computation.

# 5. Postconditions
- The output is the integer value of half the product of the first two inputs, rounded to the nearest integer.

# 6. Invariants
- The program maintains that the output is derived solely from the first two inputs.

# 7. Error Handling / Exceptional Behavior
- The program does not handle invalid input formats or types; undefined behavior may occur if inputs are not integers.

# 8. State Transitions (if applicable)
- The program transitions from an input state to an output state after processing the inputs.

# 9. Non-functional Constraints (if inferable)
- The output is displayed in a format that does not include decimal places, regardless of the computed value.
