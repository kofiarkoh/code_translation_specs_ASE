# 1. Functional Description
The code processes a string of numbers separated by characters and computes the maximum sum of selected numbers that does not exceed a specified target. It identifies the selection of numbers based on a bitmask representation and outputs the best sum along with the corresponding selected numbers.

# 2. Inputs
- An integer representing the target sum.
- A string containing numbers separated by non-numeric characters.

# 3. Outputs
- The maximum sum of selected numbers that does not exceed the target.
- The selected numbers in the order they appear in the input string.
- An error message if no valid selection exists or if multiple selections yield the same maximum sum.

# 4. Preconditions
- The input string must contain valid characters, including numeric characters and separators.
- The target must be a non-negative integer.

# 5. Postconditions
- If a valid selection exists, the output will include the maximum sum and the corresponding selected numbers.
- If no valid selection exists, an "error" message will be output.
- If multiple selections yield the same maximum sum, a "rejected" message will be output.

# 6. Invariants
- The sum of selected numbers is always calculated based on the current bitmask.
- The maximum sum tracked is always less than or equal to the target.

# 7. Error Handling / Exceptional Behavior
- If the input string does not contain any valid numbers, an "error" message is displayed.
- If multiple combinations yield the same maximum sum, a "rejected" message is displayed.

# 8. State Transitions (if applicable)
- The state transitions occur as the program iterates through different combinations of the input string based on the bitmask, updating the current best sum and selection as necessary.

# 9. Non-functional Constraints (if inferable)
- The algorithm must efficiently handle input strings of varying lengths, with a maximum length of 10 characters as indicated by the defined array size.
