# Revised Specification

## 1. Functional Description
The code reads a sequence of strings until the end of input and counts the occurrences of the substrings "JOI" and "IOI" within each string, including overlapping occurrences. It outputs the counts for each substring consecutively for each input string.

## 2. Inputs
- A sequence of strings, each containing a maximum of 10,000 characters, read until the end of input.

## 3. Outputs
- For each input string, two integers are printed: the count of occurrences of "JOI" and the count of occurrences of "IOI", including overlapping occurrences.

## 4. Preconditions
- The input strings must be valid and contain only characters that can be processed by the reading function.
- The input must be terminated by an end-of-file signal.

## 5. Postconditions
- The output consists of two integers for each input string, representing the counts of "JOI" and "IOI", respectively, including overlapping occurrences.

## 6. Invariants
- The counts of "JOI" and "IOI" are non-negative integers.
- The counts are reset to zero for each new input string.

## 7. Error Handling / Exceptional Behavior
- If the input is empty, no output is produced.
- The program does not handle malformed input or errors during reading; it assumes valid input until EOF.

## 8. State Transitions (if applicable)
- The program transitions from reading input to counting occurrences (including overlapping occurrences) and then to outputting results for each string until EOF is reached.

## 9. Non-functional Constraints (if inferable)
- The program operates within a time complexity that is linear with respect to the length of each input string, as it processes each string in a single pass to count occurrences.
