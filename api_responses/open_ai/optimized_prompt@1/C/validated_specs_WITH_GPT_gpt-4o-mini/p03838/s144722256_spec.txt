# 1. Functional Description
The program computes a specific integer value based on the relationship between two input integers, x and y, according to defined conditional logic.

- The inputs must be valid integers.
- The input values for x and y can be positive, negative, or zero.

    - If y is less than -x, the output is -y - x + 1.
  - If x is negative:
    - If y is greater than or equal to -x, the output is x + y + 1.
    - If y is positive and less than or equal to 0, the output is -x - y + 1.
    - If y is greater than or equal to x, the output is y - x.
    - If y is less than x, the output is x - y + 2.

# 6. Invariants
- The output is always a long long integer.
- The computation is deterministic based on the input values of x and y.
