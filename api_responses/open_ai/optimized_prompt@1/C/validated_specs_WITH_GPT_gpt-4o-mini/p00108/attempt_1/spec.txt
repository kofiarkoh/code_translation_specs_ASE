# 1. Functional Description
The code processes a series of integer sequences, transforming each sequence until it reaches a stable state where the transformation no longer changes the sequence. It counts the number of transformations required to reach this stable state and outputs the final transformed sequence.

- A series of integer sequences, where each sequence begins with an integer `n` (the number of elements in the sequence), followed by `n` integers. The input terminates when `n` is zero.

# 3. Outputs
- The number of transformations performed to reach a stable state for each sequence.
- The final transformed sequence of integers.

- The input must consist of valid integers.
- The first integer of each sequence must be non-negative and less than or equal to 100.

# 5. Postconditions
- The output includes the number of transformations and the final transformed sequence for each input sequence.
- The final transformed sequence is stable, meaning further transformations will not change it.

# 6. Invariants
- The transformation process maintains the integrity of the input sequence, ensuring that the output sequence is derived solely from the input values.
- The count of transformations is incremented only when a transformation occurs.

# 7. Error Handling / Exceptional Behavior
- The program does not handle invalid input formats or out-of-range values explicitly; it assumes all input adheres to the specified constraints.

# 8. State Transitions (if applicable)
- The state transitions occur between the input sequence and its transformed state, with each transformation being a step towards stabilization. The process continues until the transformed sequence no longer changes.
