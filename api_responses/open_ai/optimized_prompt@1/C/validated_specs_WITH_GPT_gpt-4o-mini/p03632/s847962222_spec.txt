# 1. Functional Description
The program reads four integer inputs representing two ranges and calculates the number of overlapping integers within those ranges. It outputs the count of overlapping integers, adjusted by one if there is at least one overlap.

# 2. Inputs
- Four integers: A, B, C, D, where:
  - A and B define the first inclusive range [A, B].
  - C and D define the second inclusive range [C, D].

# 3. Outputs
- An integer representing the count of overlapping integers between the two ranges, adjusted by one if there is at least one overlap.

# 4. Preconditions
- The input integers A, B, C, and D must be within the range of 0 to 100.
- A must be less than or equal to B.
- C must be less than or equal to D.

# 5. Postconditions
- The output is the count of integers that are present in both ranges, minus one if the count is greater than zero.

# 6. Invariants
- The arrays used to track the presence of integers are initialized to zero.
- The count of overlapping integers is calculated based on the presence of integers in both ranges.

# 7. Error Handling / Exceptional Behavior
- The program does not handle invalid input or out-of-bounds values; it assumes valid input as per the preconditions.

# 8. State Transitions (if applicable)
- The program transitions from reading input to processing the ranges and finally to outputting the result based on the calculated overlaps.

# 9. Non-functional Constraints (if inferable)
- The program operates within a fixed memory footprint, utilizing a constant amount of space for the arrays. The time complexity is linear with respect to the size of the range (constant in this case).
