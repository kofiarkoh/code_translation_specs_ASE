# Revised Specification

## 1. Functional Description
The program calculates a value based on three input integers, A, B, and X. The output is derived from these inputs according to specific conditions that depend on the relationships between A, B, and X.

## 2. Inputs
- Three integers: A, B, and X, where:
  - A and B represent thresholds for the calculation.
  - X represents a quantity that influences the output.

## 3. Outputs
- A single integer representing the calculated result based on the inputs.

## 4. Preconditions
- A, B, and X must be non-negative integers.
- At least one of A or B must be greater than zero.

## 5. Postconditions
- The output integer is guaranteed to be non-negative.
- The output reflects the calculation based on the following conditions:
  - If A is at least twice B, the output is calculated using a formula that incorporates B and the value of X.
  - If A is less than twice B, the output is calculated based on the integer division of X by 1000, with additional adjustments based on the remainder of this division.

## 6. Invariants
- The relationship between A and B determines the primary calculation path.
- The value of X influences the output based on its range, specifically through integer division and modulus operations.

## 7. Error Handling / Exceptional Behavior
- The program does not handle invalid input formats or out-of-range values explicitly. It assumes that valid input is provided.

## 8. State Transitions
- The program evaluates conditions involving A, B, and X to determine the calculation path:
  - If A >= 2 * B, the output is computed using a specific formula involving B.
  - If A < 2 * B, the output is computed based on the integer division of X by 1000, with further adjustments based on the remainder when X is divided by 1000.

## 9. Non-functional Constraints
- The computation is performed in constant time, regardless of the input values.
