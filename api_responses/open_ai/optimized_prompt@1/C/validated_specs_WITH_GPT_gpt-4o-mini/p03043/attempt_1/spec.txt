# 1. Functional Description
The program computes a specific mathematical expression based on two input integers, N and K. It generates an array of denominators and calculates a cumulative value derived from these denominators, ultimately outputting a formatted result.

# 2. Inputs
- Two integers, N and K, where:
  - N represents the size of an array and is expected to be a positive integer.
  - K is a positive integer that influences the computation of the denominators.

# 3. Outputs
- A single floating-point number, formatted to twelve decimal places, representing the result of a mathematical operation involving the generated denominators.

# 4. Preconditions
- The input integers N and K must be positive.
- N must be less than or equal to the maximum allowable size for the array.

# 5. Postconditions
- The output is a floating-point number that is the result of the cumulative sum of the ratios of the first denominator to each of the other denominators, divided by the first denominator.

# 6. Invariants
- The array of denominators is initialized to zero before being populated.
- The value of the first denominator remains constant throughout the computation.

# 7. Error Handling / Exceptional Behavior
- The program does not handle invalid input (e.g., non-integer values, negative integers).
- Division by zero is not explicitly handled; if the first denominator is zero, the output will be undefined.

# 8. State Transitions (if applicable)
- The program transitions from an input state to a computation state, where it populates the denominators and calculates the cumulative result, finally transitioning to an output state.

# 9. Non-functional Constraints (if inferable)
- The output precision is constrained to twelve decimal places.
- The program's performance may be affected by the size of N, as it directly influences the number of computations performed.
