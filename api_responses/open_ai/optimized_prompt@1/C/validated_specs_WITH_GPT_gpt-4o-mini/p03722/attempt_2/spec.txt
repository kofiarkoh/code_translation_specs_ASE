# Revised Specification

## 1. Functional Description
The code computes the minimum cost to reach a specified destination node in a directed graph with weighted edges. It detects negative weight cycles and determines if the destination is reachable with a finite cost.

## 2. Inputs
- Two integers representing the number of nodes (N) and the number of edges (M) in the graph, where both must be non-negative.
- A series of triplets for each edge, where each triplet consists of:
  - An integer representing the source node (u).
  - An integer representing the destination node (w).
  - An integer representing the cost of the edge (c), which is negated in the computation.

## 3. Outputs
- The minimum cost to reach the destination node from the source node, negated.
- If the destination node is unreachable or if there is a negative weight cycle affecting the path to the destination, the output is "inf".

## 4. Preconditions
- The number of nodes (N) and edges (M) must be non-negative integers.
- The edges must connect valid node indices within the range defined by the number of nodes (1 to N).
- The cost of each edge must be a valid integer.

## 5. Postconditions
- The output reflects the minimum cost to reach the destination node if reachable; otherwise, it indicates infinite cost due to either inaccessibility or negative weight cycles.

## 6. Invariants
- The minimum cost array is updated iteratively to reflect the least cost to reach each node based on the edges processed.
- The initial cost to reach the source node is set to zero, while all other nodes are initialized to a predefined upper limit.

## 7. Error Handling / Exceptional Behavior
- The program does not handle invalid input formats or out-of-bounds node indices explicitly; behavior is undefined in such cases.
- If the input does not conform to expected types or ranges, the output may be unpredictable, potentially leading to runtime errors.

## 8. State Transitions
- The state transitions occur as the minimum cost array is updated based on the edges processed, reflecting the evolving costs to reach each node.

## 9. Non-functional Constraints
- The algorithm operates within a time complexity that is polynomial with respect to the number of nodes and edges, specifically O(N * M) for the main computation.
