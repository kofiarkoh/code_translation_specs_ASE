# 1. Functional Description
The code generates and outputs a sequence of integers based on the input value. It handles different ranges of input values to produce specific sequences, ensuring that the output adheres to defined constraints.

# 2. Inputs
- A single integer input representing a value \( k \).

# 3. Outputs
- A sequence of integers based on the value of \( k \):
  - If \( k \geq 50 \): Outputs 50 integers.
  - If \( 2 \leq k < 50 \): Outputs \( k \) integers.
  - If \( k = 0 \): Outputs four integers.
  - If \( k < 0 \): Outputs three integers.

# 4. Preconditions
- The input must be a valid integer.
- The input can be any integer value.

# 5. Postconditions
- The output sequence is guaranteed to have a length based on the value of \( k \).
- The integers in the output sequence are generated according to specific rules based on the value of \( k \).

# 6. Invariants
- The output sequence will always contain non-negative integers.
- The total number of integers output will always match the expected count based on the input value.

# 7. Error Handling / Exceptional Behavior
- If the input is not a valid integer, the behavior is undefined.
- The program does not handle negative inputs explicitly beyond producing a fixed output.

# 8. State Transitions (if applicable)
- The program transitions between different output states based on the value of \( k \):
  - From input to output of 50 integers if \( k \geq 50 \).
  - From input to output of \( k \) integers if \( 2 \leq k < 50 \).
  - From input to output of four integers if \( k = 0 \).
  - From input to output of three integers if \( k < 0 \).
