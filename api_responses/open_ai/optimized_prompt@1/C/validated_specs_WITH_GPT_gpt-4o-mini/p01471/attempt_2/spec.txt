# Revised Specification

## 1. Functional Description
The code implements a solution to the fractional knapsack problem, calculating the maximum value that can be obtained given a set of items with specific weights and values, and a maximum weight capacity. It allows for the inclusion of fractional parts of items and handles items with negative weights and values appropriately.

## 2. Inputs
- An integer representing the number of items.
- A double representing the maximum weight capacity of the knapsack.
- For each item, an integer representing the weight and an integer representing the value.

## 3. Outputs
- A double representing the maximum value that can be obtained within the weight capacity of the knapsack.

## 4. Preconditions
- The number of items is a non-negative integer.
- The maximum weight capacity is a non-negative double.
- Each item's weight and value are integers. Weight can be negative, and value can be zero or negative.

## 5. Postconditions
- The output value is the maximum possible value that can be obtained without exceeding the specified weight capacity.
- If the knapsack can hold items, the output is a non-negative double reflecting the total value of items added. If all items are invalid or the knapsack capacity is zero, the output will be zero.

## 6. Invariants
- The total weight of items considered does not exceed the maximum weight capacity.
- Items with negative weights are treated as increasing the knapsack's capacity, while items with negative values contribute negatively to the total value.
- The items are sorted based on their value-to-weight ratio before processing for inclusion in the knapsack.

## 7. Error Handling / Exceptional Behavior
- Items with non-positive values and non-negative weights are ignored.
- If all items are invalid or the knapsack capacity is zero, the output will be zero.

## 8. State Transitions
- The state transitions involve updating the remaining weight capacity and the accumulated value as items are processed and added to the knapsack. Negative weights increase the remaining capacity, while negative values decrease the total value.

## 9. Non-functional Constraints
- The algorithm's performance is influenced by the sorting step, which has a time complexity of O(N log N), where N is the number of items. The overall space complexity is O(N) due to the storage of item data.
