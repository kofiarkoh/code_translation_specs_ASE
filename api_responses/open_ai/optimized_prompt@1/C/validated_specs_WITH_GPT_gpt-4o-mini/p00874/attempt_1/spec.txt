# 1. Functional Description
The program computes a weighted sum based on two sets of integer inputs, where each set represents counts of integers in a specified range. The output is the total sum of the maximum counts for each integer from both sets, multiplied by the integer value.

# 2. Inputs
- A series of pairs of integers, where each pair consists of:
  - An integer representing the number of elements in the first set.
  - An integer representing the number of elements in the second set.
- Followed by two sequences of integers:
  - The first sequence contains integers corresponding to the first set.
  - The second sequence contains integers corresponding to the second set.

# 3. Outputs
- A single integer output for each pair of input integers, representing the computed weighted sum.

# 4. Preconditions
- The first integer of each pair must be non-negative.
- The second integer of each pair must be non-negative.
- Each integer in the sequences must be within the range of 1 to 20.

# 5. Postconditions
- The output integer is the sum of the maximum counts of each integer from 1 to 20, where each count is multiplied by its respective integer value.

# 6. Invariants
- The counts for each integer from 1 to 20 are maintained in two separate arrays throughout the computation.
- The total sum is updated incrementally as each integer from 1 to 20 is processed.

# 7. Error Handling / Exceptional Behavior
- The program does not handle invalid input formats or out-of-range integers explicitly; it assumes valid input as per the preconditions.

# 8. State Transitions (if applicable)
- The program transitions between states based on the input pairs, resetting the count arrays for each new pair of inputs and accumulating the result for each processed pair.

# 9. Non-functional Constraints (if inferable)
- The program operates in a linear time complexity relative to the number of integers processed, with a fixed space complexity for the count arrays.
