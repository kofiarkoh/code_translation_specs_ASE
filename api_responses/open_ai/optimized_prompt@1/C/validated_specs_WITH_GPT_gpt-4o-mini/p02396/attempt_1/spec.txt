# 1. Functional Description
The program reads integer inputs from the user in a continuous loop until a zero is entered. For each non-zero integer input, it outputs the case number and the integer value.

# 2. Inputs
The program accepts a sequence of integers from the user, terminated by a zero.

# 3. Outputs
For each non-zero integer input, the program outputs a line indicating the case number and the integer value.

# 4. Preconditions
The program assumes that the user will provide valid integer inputs.

# 5. Postconditions
The program terminates when a zero is entered, having outputted the case number and value for each non-zero integer input received prior to termination.

# 6. Invariants
The case number is incremented with each non-zero integer input, and the output format remains consistent throughout the execution.

# 7. Error Handling / Exceptional Behavior
The program does not handle invalid inputs (non-integer values) and will exhibit undefined behavior if such inputs are provided.

# 8. State Transitions (if applicable)
The program transitions from an input state to an output state with each valid non-zero integer input, and transitions to a termination state upon receiving a zero.

# 9. Non-functional Constraints (if inferable)
The program operates in a continuous loop until termination, with no specified limits on the number of inputs or the range of integer values.
