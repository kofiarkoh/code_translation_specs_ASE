# 1. Functional Description
The code processes multiple datasets representing a network of students and their connections. For each dataset, it counts and outputs the number of students that are directly or indirectly connected to a specific student.

# 2. Inputs
- A series of datasets, each consisting of:
  - Two integers, `n` (number of students) and `m` (number of connections).
  - `m` pairs of integers representing connections between students.

# 3. Outputs
- For each dataset, an integer representing the count of students that are directly or indirectly connected to the first student.

# 4. Preconditions
- The input values for `n` and `m` must be non-negative integers.
- The maximum value for `n` and `m` is 500.
- The pairs of integers representing connections must be within the range of valid student indices (1 to `n`).

# 5. Postconditions
- The output integer is the count of unique students connected to the first student, excluding the first student itself.

# 6. Invariants
- The connection matrix is initialized to zero for all students at the start of processing each dataset.
- The list tracking connected students is reset for each dataset.

# 7. Error Handling / Exceptional Behavior
- The program terminates gracefully when both `n` and `m` are zero, indicating no further datasets to process.
- No explicit error handling for invalid input values is implemented; behavior is undefined for inputs outside specified ranges.

# 8. State Transitions (if applicable)
- The program transitions from reading input to processing connections, then to counting connected students, and finally to outputting the result for each dataset.

# 9. Non-functional Constraints (if inferable)
- The program operates within a time complexity that is manageable for the maximum input size, ensuring timely output for each dataset.
