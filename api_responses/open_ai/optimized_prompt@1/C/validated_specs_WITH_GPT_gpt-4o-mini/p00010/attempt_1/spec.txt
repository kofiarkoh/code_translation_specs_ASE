# 1. Functional Description
The program computes the circumcenter and circumradius of a triangle defined by three points in a 2D space. It processes multiple sets of triangle vertices and outputs the circumcenter coordinates and circumradius for each set.

# 2. Inputs
- An integer `n` representing the number of triangle vertex sets.
- For each triangle, six floating-point numbers representing the coordinates of three vertices: `(x1, y1)`, `(x2, y2)`, and `(x3, y3)`.

# 3. Outputs
- For each triangle, three floating-point numbers: the x-coordinate of the circumcenter, the y-coordinate of the circumcenter, and the circumradius, formatted to three decimal places.

# 4. Preconditions
- The input integer `n` must be a non-negative integer.
- Each set of six floating-point numbers must represent valid coordinates in a 2D space.

# 5. Postconditions
- The output will consist of `n` lines, each containing three floating-point numbers representing the circumcenter and circumradius of the corresponding triangle.

# 6. Invariants
- The circumcenter coordinates and circumradius are computed based on the geometric properties of the triangle formed by the input vertices.
- The output values are guaranteed to be formatted to three decimal places.

# 7. Error Handling / Exceptional Behavior
- The program does not handle invalid input formats or values that could lead to division by zero or undefined behavior. It assumes valid input is provided.

# 8. State Transitions (if applicable)
- The program transitions from reading input to processing each triangle's vertices, followed by computing and outputting the circumcenter and circumradius.

# 9. Non-functional Constraints (if inferable)
- The program must complete execution in a reasonable time frame for typical input sizes, though specific performance metrics are not defined.
