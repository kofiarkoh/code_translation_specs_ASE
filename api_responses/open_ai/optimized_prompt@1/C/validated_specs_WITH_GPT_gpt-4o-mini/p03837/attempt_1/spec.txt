# 1. Functional Description
The code computes the number of edges in a graph that are not part of any shortest path between any pair of nodes. It reads the number of nodes and edges, processes the edge weights, and applies the Floyd-Warshall algorithm to determine shortest paths.

# 2. Inputs
- Two integers representing the number of nodes \( N \) and the number of edges \( M \).
- \( M \) sets of three integers representing the edges, where each set contains:
  - Two integers representing the nodes connected by the edge.
  - An integer representing the weight of the edge.

# 3. Outputs
- An integer representing the count of edges that are not part of any shortest path in the graph.

# 4. Preconditions
- \( N \) and \( M \) are non-negative integers.
- Each edge connects valid node indices (0 to \( N-1 \)).
- Edge weights are non-negative integers.

# 5. Postconditions
- The output integer is less than or equal to \( M \).
- The output integer reflects the number of edges that do not contribute to any shortest path between any pairs of nodes.

# 6. Invariants
- The distance matrix is initialized such that the distance from a node to itself is zero, and the distance between different nodes is set to a large value.
- The distance matrix is updated to reflect the minimum distances based on the edges provided.

# 7. Error Handling / Exceptional Behavior
- The program does not handle invalid input formats or out-of-bounds indices explicitly.
- If the input does not conform to the expected format, behavior is undefined.

# 8. State Transitions (if applicable)
- The state transitions occur through the updates of the distance matrix as edges are processed and during the execution of the Floyd-Warshall algorithm.

# 9. Non-functional Constraints (if inferable)
- The algorithm operates with a time complexity of \( O(N^3) \) due to the Floyd-Warshall implementation, which may limit performance for large values of \( N \).
