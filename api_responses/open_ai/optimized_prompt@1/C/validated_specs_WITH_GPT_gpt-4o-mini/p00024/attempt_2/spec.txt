# Revised Specification

## 1. Functional Description
The program reads a series of floating-point values representing velocities, computes a derived integer value based on a specific formula involving physical constants, and outputs this integer value for each input.

## 2. Inputs
The input consists of a sequence of floating-point numbers, each representing a velocity. The input stream must be terminated by an end-of-file signal.

## 3. Outputs
The output is a sequence of integers, each corresponding to the computed value derived from the input velocities. Each output integer is calculated based on the formula described below.

## 4. Preconditions
The input must consist of valid floating-point numbers. The program does not handle invalid input formats or non-numeric values, and undefined behavior may occur if such inputs are encountered.

## 5. Postconditions
For each input velocity \( v \), an integer \( n \) is output, computed using the formula:
\[ n = \left\lfloor \frac{(4.9 \cdot v^2)}{(9.8 \cdot 9.8)} + 5 \right\rfloor / 5 + 1 \]
The output integer \( n \) is guaranteed to be greater than or equal to 1.

## 6. Invariants
The computation of the output integer is consistent for the same input velocity across multiple executions of the program, provided the input is valid.

## 7. Error Handling / Exceptional Behavior
The program does not handle invalid input formats or non-numeric values. If an invalid input is encountered, the behavior is undefined, and the program may terminate unexpectedly.

## 8. State Transitions
The program maintains a state of reading input until the end-of-file is reached. Each valid input results in a transition to the output state where the corresponding integer is printed immediately after computation.

## 9. Non-functional Constraints
The program operates in a continuous loop until the end-of-file is reached, processing inputs and producing outputs in real-time. Performance is dependent on the speed of input reading and output writing.
