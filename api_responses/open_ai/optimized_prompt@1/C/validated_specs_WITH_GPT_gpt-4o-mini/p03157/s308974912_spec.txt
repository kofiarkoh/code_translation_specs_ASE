# 1. Functional Description
The code processes a grid of characters to count the number of distinct groups formed by adjacent cells containing different characters. It calculates the total product of the counts of two specific character types (denoted as '.' and any other character) within each group and outputs the cumulative sum of these products.

# 2. Inputs
- Two integers representing the height (H) and width (W) of a grid.
- A grid of characters with dimensions H x W, where each cell contains a single character.

# 3. Outputs
- A single unsigned 64-bit integer representing the cumulative sum of products of counts of two character types across all distinct groups.

# 4. Preconditions
- The input dimensions H and W must be positive integers.
- The grid must be filled with valid characters, and each row must contain exactly W characters.

# 5. Postconditions
- The output is the total sum of products of counts of the two character types for all distinct groups identified in the grid.

# 6. Invariants
- Each cell in the grid is either part of a group or marked as processed.
- The grouping is consistent throughout the execution, ensuring that all adjacent cells with different characters are correctly identified.

# 7. Error Handling / Exceptional Behavior
- The program terminates with an error code if the input format is incorrect or if the expected number of characters is not read.

# 8. State Transitions (if applicable)
- The state transitions occur as the depth-first search explores the grid, marking cells as part of a group and updating counts based on character types.

# 9. Non-functional Constraints (if inferable)
- The algorithm operates within the constraints of a maximum grid size of 512 x 512.
- The execution time is dependent on the number of cells and their connectivity, with a worst-case scenario of visiting each cell once.
