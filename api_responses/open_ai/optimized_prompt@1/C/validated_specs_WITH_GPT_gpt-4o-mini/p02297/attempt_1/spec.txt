# 1. Functional Description
The code calculates the area of a polygon defined by a set of vertices provided as input. It reads the number of vertices and their coordinates, computes the area using the shoelace formula, and outputs the result formatted to one decimal place.

# 2. Inputs
- An integer representing the number of vertices of the polygon.
- A sequence of pairs of integers representing the x and y coordinates of each vertex.

# 3. Outputs
- A single floating-point number representing the area of the polygon, formatted to one decimal place.

# 4. Preconditions
- The number of vertices is a positive integer.
- Each vertex coordinate is an integer.

# 5. Postconditions
- The output area is a non-negative floating-point number.
- The area is calculated based on the provided vertices and adheres to the shoelace formula.

# 6. Invariants
- The number of vertices remains constant throughout the execution.
- The coordinates of the vertices are stored in a fixed-size structure.

# 7. Error Handling / Exceptional Behavior
- The code does not handle invalid input (e.g., non-integer values, negative numbers for the number of vertices).
- The behavior is undefined for inputs that do not conform to the preconditions.

# 8. State Transitions (if applicable)
- The state transitions from reading input to calculating the area and finally to outputting the result.

# 9. Non-functional Constraints (if inferable)
- The area calculation is performed in linear time relative to the number of vertices.
