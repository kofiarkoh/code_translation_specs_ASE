# 1. Functional Description
The code computes and outputs the expected value based on a given position and a probability rate. It reads input values, processes them to calculate the expected value, and outputs the result in a specified format.

# 2. Inputs
- An integer representing a position.
- A double representing a probability rate (as a percentage).

# 3. Outputs
- A formatted string representing the calculated expected value, with a precision of seven decimal places.

# 4. Preconditions
- The input must contain valid data: an integer followed by a double.
- The probability rate must be in the range [0, 100].

# 5. Postconditions
- The output will reflect the expected value calculated from the input position and probability rate.
- The output will be formatted to seven decimal places.

# 6. Invariants
- The probability rate is consistently divided by 100 to convert it from a percentage to a decimal.
- The expected value calculation is based on recursive calls that depend on the input position.

# 7. Error Handling / Exceptional Behavior
- If the input cannot be read or parsed correctly, the behavior is undefined.
- If the input files are not found in test mode, the program may not execute as intended.

# 8. State Transitions (if applicable)
- The program transitions from reading input to processing the input and finally to outputting the result.

# 9. Non-functional Constraints (if inferable)
- The output must be produced efficiently, with a focus on maintaining precision in the expected value calculation.
