# 1. Functional Description
The code computes a value based on two input integers, `n` and `m`, and outputs the result. The output value is derived from specific conditions related to the inputs.

# 2. Inputs
- Two integers, `n` and `m`, where both are expected to be long long integers.

# 3. Outputs
- A single long long integer representing the computed sum based on the input values.

# 4. Preconditions
- The inputs `n` and `m` must be valid long long integers.
- The input `m` must be greater than or equal to 1.

# 5. Postconditions
- The output value is guaranteed to be a long long integer that satisfies the following conditions based on the values of `n` and `m`:
  - If `m` equals 1, the output is 0.
  - If `m/2` is less than `n`, the output is `m/2`.
  - If `m/2` is greater than or equal to `n` but less than `n + 2`, the output is `n`.
  - Otherwise, the output is `n + (m/2 - n) / 2`.

# 6. Invariants
- The output is always a non-negative long long integer.
- The relationship between `n`, `m`, and the output is maintained according to the specified conditions.

# 7. Error Handling / Exceptional Behavior
- The code does not handle invalid input scenarios (e.g., non-integer input or overflow). It assumes that inputs are provided correctly as specified.

# 8. State Transitions (if applicable)
- The system transitions from an input state (receiving `n` and `m`) to an output state (producing the computed sum) based on the evaluation of conditions.

# 9. Non-functional Constraints (if inferable)
- The computation is performed in constant time, O(1), regardless of the input values.
