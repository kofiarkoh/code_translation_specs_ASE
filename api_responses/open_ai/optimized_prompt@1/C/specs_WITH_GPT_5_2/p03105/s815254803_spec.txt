1. Functional Description  
Reads three integers and outputs the smaller of: (a) the integer quotient of the second value divided by the first value, and (b) the third value.

2. Inputs  
- Three integers read from standard input: first value, second value, third value.

3. Outputs  
- Writes a single integer to standard output followed by a newline: the minimum of the integer quotient (second ÷ first) and the third value.

4. Preconditions  
- The first input integer is non-zero (division by zero must not occur).  
- All three inputs are valid integers representable in the program’s integer type.  
- The integer division of the second value by the first value does not overflow (if such overflow is possible on the target platform).

5. Postconditions  
- Exactly one integer value is written to standard output.  
- The written value equals:  
  - the integer quotient of (second ÷ first) if that quotient is less than or equal to the third value; otherwise  
  - the third value.

6. Invariants  
- The output value is less than or equal to the third input value.  
- The output value is less than or equal to the integer quotient of (second ÷ first).

7. Error Handling / Exceptional Behavior  
- If the first input is zero, behavior is undefined (division by zero).  
- If input cannot be read as three integers, behavior is not inferable from code.  
- If integer overflow occurs during division, behavior is not inferable from code.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory relative to input size.
