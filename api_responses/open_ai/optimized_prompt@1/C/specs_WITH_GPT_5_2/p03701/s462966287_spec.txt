1. Functional Description  
Reads a count and that many integers, then outputs the maximum possible sum of a selected subset of the integers such that the resulting sum is not divisible by 10. If no such non-empty subset exists, outputs 0.

2. Inputs  
- An integer representing the number of subsequent integers.  
- A sequence of that many integers.

3. Outputs  
- Writes a single integer to standard output: the computed maximum subset sum that is not divisible by 10, or 0 if impossible.

4. Preconditions  
- The first input value is a non-negative integer.  
- Exactly that many subsequent integer values are available on standard input.  
- The environment supports allocating storage proportional to the provided count.  
- To match the intended domain implied by constants used, each input integer is assumed to be within a range where treating values greater than 100 as irrelevant to the “minimum non-multiple-of-10” selection does not break correctness (otherwise behavior may not match the stated intent).

5. Postconditions  
Let the input integers be \(a_1, \dots, a_n\). Let \(S = \sum_{i=1}^{n} a_i\).  
- If \(S\) is not divisible by 10, the output equals \(S\).  
- If \(S\) is divisible by 10 and there exists at least one input integer not divisible by 10, the output equals \(S - m\), where \(m\) is the smallest input integer that is not divisible by 10.  
- If \(S\) is divisible by 10 and all input integers are divisible by 10, the output equals 0.  
- The output is never divisible by 10 unless it is 0.

6. Invariants  
- The computed candidate output is always less than or equal to the sum of all input integers.  
- If the output is non-zero, it equals the sum of all inputs minus either 0 or exactly one input value that is not divisible by 10.  
- If at least one input integer is not divisible by 10, the value subtracted (when subtraction occurs) is the minimum among those.

7. Error Handling / Exceptional Behavior  
- No explicit handling for malformed input, insufficient input values, or allocation failure; behavior is undefined or not inferable in such cases.  
- Potential integer overflow during summation is not handled; behavior is not inferable if overflow occurs.

8. State Transitions (if applicable)  
Not applicable.

9. Non-functional Constraints (if inferable)  
- Time proportional to the number of input integers.  
- Memory proportional to the number of input integers.
