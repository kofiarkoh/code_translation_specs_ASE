1. Functional Description  
Computes, over all distinct strings appearing in the first input list, the maximum value of: (count of that string in the first list) minus (count of that string in the second list). If all such values are negative or the first list is empty, the result is 0.

2. Inputs  
- An integer specifying the number of strings in the first list.  
- That many strings for the first list.  
- An integer specifying the number of strings in the second list.  
- That many strings for the second list.  
All inputs are read from standard input.

3. Outputs  
- Writes a single integer to standard output: the maximum non-negative difference described above, followed by a newline.

4. Preconditions  
- The first and second list sizes are non-negative.  
- Each provided string has length at most 10 characters (excluding any terminator), and contains no whitespace (as it is read as a single token).  
- Sufficient memory/stack space exists to store both lists of strings.

5. Postconditions  
- The printed value equals:  
  max(0, max over strings x that appear in the first list of (occurrences of x in the first list − occurrences of x in the second list)).  
- No other output is produced.

6. Invariants  
- The reported value is always an integer greater than or equal to 0.  
- The reported value is at least as large as the computed difference for every string appearing in the first list.

7. Error Handling / Exceptional Behavior  
- Not inferable from code. (No explicit handling for invalid input, overly long strings, negative sizes, or resource exhaustion.)

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Time cost grows proportionally to the product of the first list size with the sum of both list sizes.  
- Memory usage grows proportionally to the total number of input strings stored, with a fixed maximum per-string length of 10 characters.
