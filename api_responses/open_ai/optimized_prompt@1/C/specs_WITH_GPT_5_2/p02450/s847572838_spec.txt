1. Functional Description  
Generates and writes to standard output all permutations of the integers from 1 through a given positive integer, with each permutation printed on its own line.

2. Inputs  
- Reads a single integer value from standard input representing the size of the set to permute.

3. Outputs  
- Writes zero or more lines to standard output.  
- Each line contains a permutation of the integers 1 through the input value, presented as space-separated integers in a single line.

4. Preconditions  
- The input integer is non-negative.  
- Sufficient memory/stack space is available to generate all permutations for the given input size.

5. Postconditions  
- If the input integer is 0, exactly one empty line is written.  
- If the input integer is greater than 0, exactly (input)! lines are written.  
- Every written line contains exactly the input number of integers, each in the range [1, input], with no duplicates within a line.  
- Across all lines, each distinct permutation of {1, 2, ..., input} appears exactly once.

6. Invariants  
- Each produced sequence is a permutation of the set {1, 2, ..., input}.  
- No output line contains repeated values.  
- No permutation is printed more than once.

7. Error Handling / Exceptional Behavior  
- No explicit handling for invalid input, input failure, negative input, or resource exhaustion.  
- Behavior is not inferable from code for cases where the input is negative or cannot be read successfully.

8. State Transitions (if applicable)  
- Not applicable; the program has no persistent state beyond its execution.

9. Non-functional Constraints (if inferable)  
- Time and output size grow factorially with the input value.  
- Memory usage grows at least linearly with the input value, with additional call-stack usage proportional to the input value.
