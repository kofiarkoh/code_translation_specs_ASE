1. Functional Description  
Determines whether a given integer lies within a specified inclusive integer interval and reports the result.

2. Inputs  
- Reads three integers from standard input: a lower bound, an upper bound, and a query value.

3. Outputs  
- Writes exactly one line to standard output indicating whether the query value is within the inclusive range defined by the two bounds.

4. Preconditions  
- Standard input provides three integers parseable as the program’s expected numeric type.  
- No guarantee is made if the provided values exceed the representable range of that type.

5. Postconditions  
- If the query value is greater than or equal to the lower bound and less than or equal to the upper bound, the program outputs an affirmative result.  
- Otherwise, the program outputs a negative result.  
- The program terminates after producing the single-line result.

6. Invariants  
- The decision is based solely on the inclusive comparison between the three input integers; no other state influences the output.

7. Error Handling / Exceptional Behavior  
- No explicit error handling for missing, malformed, or out-of-range input is provided; behavior in such cases is not inferable from code.

8. State Transitions (if applicable)  
- Not applicable; the program is a single-run computation with no persistent state.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory with respect to input size (fixed number of integers).
