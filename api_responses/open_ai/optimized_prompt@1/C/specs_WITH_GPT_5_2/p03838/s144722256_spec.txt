1. Functional Description  
Computes and writes the minimum number of unit operations required to transform an initial integer into a target integer, where an operation is either incrementing/decrementing the current value by 1 or multiplying the current value by −1.

2. Inputs  
- Reads two signed integers from standard input: an initial value and a target value.

3. Outputs  
- Writes a single signed integer to standard output: the minimum number of operations required.

4. Preconditions  
- Two integers are provided as input and are representable within the implementation’s integer range.  
- The computed minimum operation count is representable within the implementation’s 64-bit signed integer range.

5. Postconditions  
- The output equals the minimum number of operations needed to transform the initial value into the target value using only:
  - adding 1,
  - subtracting 1,
  - multiplying by −1.  
- The output is non-negative.

6. Invariants  
- The reported operation count is an integer ≥ 0.  
- The reported operation count corresponds to some valid sequence of allowed operations achieving the transformation.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If input is missing or invalid, behavior is not inferable from code.  
- If arithmetic overflows occur, behavior is not inferable from code.

8. State Transitions (if applicable)  
- Not applicable; the program is a single-run computation with no persistent state.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory with respect to input size.
