1. Functional Description
- Repeatedly processes datasets of integers until a terminating dataset indicator is encountered.
- For each dataset, determines whether there exists a value that occurs more than half of the total number of values (a strict majority).
- If such a strict-majority value exists, outputs that value; otherwise outputs a fixed message indicating absence of a majority.

2. Inputs
- Reads from standard input a sequence of datasets.
- Each dataset begins with an integer specifying the number of following integers in that dataset.
- For each dataset with a positive size, reads exactly that many integers.

3. Outputs
- For each non-terminating dataset, writes exactly one line to standard output:
  - The strict-majority value if one exists, or
  - A fixed “no majority” message otherwise.

4. Preconditions
- Each dataset size is an integer.
- For each dataset with positive size, the input provides at least that many subsequent integers.
- Dataset size does not exceed 1,000,001.
- Integer values and intermediate arithmetic used for comparison do not overflow the integer range. (Otherwise behavior is not reliably inferable.)

5. Postconditions
- For each processed dataset of size n > 0:
  - If there exists a value whose frequency is strictly greater than n/2, the program outputs one such value (and, given the strict-majority property, it is unique).
  - If no value has frequency strictly greater than n/2, the program outputs the fixed “no majority” message.
- Processing continues until a dataset size of 0 is read, after which the program terminates without producing output for that terminating indicator.

6. Invariants
- For any dataset processed, the program’s decision is based solely on the multiset of the n input integers for that dataset.
- At most one output line is produced per non-terminating dataset.

7. Error Handling / Exceptional Behavior
- No explicit handling for malformed input, premature end of input, or I/O failures; behavior in such cases is not inferable from code.
- If dataset size exceeds the supported maximum, behavior is undefined/not inferable.
- If integer overflow occurs during internal comparisons, the resulting behavior is not reliably inferable.

8. State Transitions (if applicable)
- Transitions through repeated dataset-processing cycles:
  - Await dataset size → if size is 0: terminate; if size > 0: read dataset values → produce one line of output → return to awaiting next dataset size.

9. Non-functional Constraints (if inferable)
- Memory usage includes storage proportional to the dataset size up to a fixed maximum of 1,000,001 integers.
- Time per dataset is dominated by ordering/grouping operations and frequency evaluation; exact complexity is not inferable from code without relying on specific library guarantees.
