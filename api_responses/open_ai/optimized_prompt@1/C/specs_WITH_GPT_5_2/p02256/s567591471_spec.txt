1. Functional Description
- Reads two unsigned integer values from standard input.
- If both values are within an accepted positive range, computes and outputs their greatest common divisor (GCD) as a non-negative integer followed by a newline.
- If either value is outside the accepted range, produces no numeric output and terminates with a non-zero status.

2. Inputs
- Two integer values provided via standard input, intended to represent natural numbers.

3. Outputs
- On valid inputs: writes a single line to standard output containing the GCD of the two input values.
- On invalid inputs: no output is guaranteed.

4. Preconditions
- Two input values are available on standard input.
- For the GCD computation/output path: both input values are within the inclusive range [1, 1,000,000,000].

5. Postconditions
- If both inputs are within [1, 1,000,000,000]:
  - The program outputs a value `g` such that:
    - `g` divides both input values.
    - For any integer `d` that divides both input values, `d <= g`.
  - The program terminates with exit status 0.
- If either input is outside [1, 1,000,000,000]:
  - The program terminates with exit status 1.

6. Invariants
- During GCD computation (when reached), the current pair of working values always has the same set of common divisors as the original input pair; therefore, the final returned value is a common divisor of the original inputs.
- When the computation terminates normally, the returned value is the last non-zero divisor candidate and is the GCD of the original inputs (given the preconditions for that path).

7. Error Handling / Exceptional Behavior
- If either input value is outside the allowed range, the program signals failure via exit status 1 and does not print a GCD.
- Behavior when standard input does not contain two successfully readable integer values is not inferable from code (no explicit validation of read success).
- Division-by-zero is avoided in the GCD computation by terminating the computation if the divisor becomes zero; in that case, the function returns the current divisor value (which would be zero). Under the program’s valid-input preconditions, this case does not occur.

8. State Transitions (if applicable)
- Not applicable (no persistent state beyond process execution).

9. Non-functional Constraints (if inferable)
- Accepts only inputs within [1, 1,000,000,000] for successful operation.
- Terminates after a finite number of steps for all non-negative integer inputs, including those that lead to early termination of the GCD computation.
