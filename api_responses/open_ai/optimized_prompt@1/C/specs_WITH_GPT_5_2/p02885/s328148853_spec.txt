1. Functional Description  
Reads two integers and computes the non-negative value of the first integer minus twice the second integer; outputs that value.

2. Inputs  
- Two integer values read from standard input.

3. Outputs  
- Writes a single integer to standard output: the computed non-negative result.

4. Preconditions  
- Standard input provides two values that can be interpreted as integers.

5. Postconditions  
- The output value equals the maximum of 0 and (first input − 2 × second input).
