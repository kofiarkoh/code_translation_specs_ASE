1. Functional Description  
Reads a count of measurements and then reads that many real-valued heights. Classifies each height into one of six predefined ranges and outputs a six-line histogram where each line corresponds to a range and contains a number of marker characters equal to the count in that range.

2. Inputs  
- From standard input:  
  - An integer representing the number of height values to process.  
  - A sequence of that many real numbers representing heights.

3. Outputs  
- To standard output:  
  - Six lines labeled 1 through 6, each followed by a sequence of marker characters whose length equals the number of input heights falling into the corresponding range, and terminated by a newline.

4. Preconditions  
- The first input value is an integer.  
- If the count is positive, at least that many subsequent real-valued height inputs are available.  
- The count is within a range that allows processing and output without resource exhaustion.  
- Assumption: Heights are finite real numbers (not NaN or infinities), as behavior for non-finite values is not defined by the code.

5. Postconditions  
- Exactly six histogram lines are written.  
- Each input height is counted in exactly one of the following ranges:  
  1) height < 165.0  
  2) 165.0 ≤ height < 170.0  
  3) 170.0 ≤ height < 175.0  
  4) 175.0 ≤ height < 180.0  
  5) 180.0 ≤ height < 185.0  
  6) height ≥ 185.0  
- The total number of markers printed across all six lines equals the number of processed heights.

6. Invariants  
- All six category counts are non-negative integers.  
- At any point after processing k heights (0 ≤ k ≤ n), the sum of the six category counts equals k.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed for invalid, missing, or malformed input. If input cannot be read as required, subsequent behavior is not defined by the code.  
- No explicit handling for negative counts; if the count is negative, no heights are processed and the histogram is still printed with zero markers on all lines.

8. State Transitions (if applicable)  
- The program transitions from an initial state with all category counts at zero to a final state where counts reflect the classification of all successfully processed heights, then terminates after outputting the histogram.

9. Non-functional Constraints (if inferable)  
- Time complexity is linear in the number of heights processed.  
- Output size is proportional to the number of heights (one marker per height) plus a constant amount for labels and newlines.
