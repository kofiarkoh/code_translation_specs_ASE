1. Functional Description  
Computes and outputs the total weight (sum of edge weights) of the longest simple path in a connected, undirected, weighted tree (i.e., the tree’s diameter length).

2. Inputs  
- Reads an integer representing the number of vertices.  
- Reads exactly one fewer triples of integers, each triple representing an undirected edge between two vertices and its integer weight.

3. Outputs  
- Writes a single integer: the maximum possible sum of edge weights along any simple path between two vertices in the given tree.

4. Preconditions  
- The number of vertices is within the supported fixed capacity (at most 100,010).  
- Exactly (number of vertices − 1) edges are provided.  
- Vertex identifiers used in edges are valid indices for the vertex set (assumed to be in the range [0, number of vertices − 1]).  
- The input graph is a tree: connected and acyclic.  
- The diameter length fits within the range of a signed 32-bit integer (to avoid overflow).  
- Edge weights are assumed to be non-negative; otherwise, the notion of “longest path by sum of weights” is not reliably computed by this program.

5. Postconditions  
- The printed value equals the maximum, over all pairs of vertices, of the sum of weights along the unique simple path connecting the pair.  
- No other output is produced.

6. Invariants  
- During computation, each vertex is treated as visited at most once per traversal used to compute path lengths.  
- For any visited vertex during a traversal, its stored distance equals the sum of weights along the unique path from the traversal’s start vertex to that vertex (under the tree precondition).

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If input is malformed, vertex indices are out of range, the graph is not a tree, edge weights are negative, or integer overflow occurs, the output is unspecified and the program may exhibit incorrect results or undefined behavior.

8. State Transitions (if applicable)  
- Not applicable beyond internal computation; the program reads input once, computes a result, outputs it, and terminates.

9. Non-functional Constraints (if inferable)  
- Operates within fixed-size internal storage limiting the maximum number of vertices and edges as stated in Preconditions.  
- Runs in linear time with respect to the number of vertices/edges under the tree assumption.
