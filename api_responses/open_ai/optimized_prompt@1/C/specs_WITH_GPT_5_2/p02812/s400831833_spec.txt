1. Functional Description  
Reads an integer and a text token, then counts the number of non-overlapping occurrences of the contiguous substring `"ABC"` within the first specified number of characters, and writes the resulting count.

2. Inputs  
- One integer value.  
- One whitespace-delimited text token (a sequence of non-whitespace characters).

3. Outputs  
- Writes a single integer representing the count of non-overlapping `"ABC"` occurrences.

4. Preconditions  
- The integer is intended to represent the number of characters to consider from the provided text token.  
- The provided text token length is at most 50 characters.  
- The text token contains at least as many characters as the integer specifies (otherwise behavior is not well-defined by the code).  
- The integer is non-negative.

5. Postconditions  
- The output value equals the number of indices within the first `n` characters where `"ABC"` occurs, counting only non-overlapping matches (each counted match consumes three characters and prevents overlapping matches from being counted).

6. Invariants  
- The count is always an integer in the range `0` to `floor(n / 3)`.  
- Only exact, case-sensitive matches to `"ABC"` are counted.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If input is missing, malformed, exceeds the maximum token length, or if the integer exceeds the available characters in the token, the behavior is not defined by the code.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Uses a fixed maximum input token size of 50 characters.  
- Time cost grows linearly with the integer value specifying the number of characters considered.
