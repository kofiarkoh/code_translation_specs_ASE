1. Functional Description  
Reads one or more datasets describing teams and their match results, computes a points total for each team, orders teams by descending points, and writes the ordered list for each dataset. Processing ends when a dataset size of zero is provided.

2. Inputs  
- A sequence of datasets read from standard input.  
- Each dataset begins with an integer indicating the number of teams.  
- For each team in the dataset: a team name (single token) and three integers representing wins, losses, and draws.

3. Outputs  
- For each non-terminating dataset, writes to standard output one line per team containing the team name and its computed points total.  
- Teams are output in non-increasing order of points.  
- Inserts a single blank line between consecutive dataset outputs (but not before the first dataset output).

4. Preconditions  
- Each dataset size is an integer.  
- For each dataset with size > 0, exactly that many team records are present in the input.  
- Dataset size does not exceed 10.  
- Each team name fits within the program’s fixed storage for names and contains no whitespace.  
- Wins, losses, and draws are integers such that the computed points total fits within the integer range.

5. Postconditions  
- For every dataset with size > 0, each team’s points total equals (3 × wins) + draws as provided in the input.  
- The output for a dataset contains exactly the same number of teams as specified by the dataset size.  
- Output ordering is by descending points; ties are not guaranteed to preserve input order.

6. Invariants  
- Within a dataset, each team’s computed points total remains constant once computed.  
- The program continues reading datasets until a dataset size of zero is encountered.

7. Error Handling / Exceptional Behavior  
- Not inferable from code. (No explicit handling for malformed input, oversized dataset sizes, overly long names, or arithmetic overflow.)

8. State Transitions (if applicable)  
- Repeats the cycle: read dataset size → if zero, terminate; otherwise read team records → compute points → output sorted results → proceed to next dataset.  
- Maintains whether any prior dataset has been output to decide whether to emit a blank line before the next dataset’s output.

9. Non-functional Constraints (if inferable)  
- Supports at most 10 teams per dataset.  
- Team names are limited to a fixed maximum length (29 characters plus terminator).
