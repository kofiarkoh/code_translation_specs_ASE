1. Functional Description  
Reads a sequence of real numbers from standard input. For each value, computes an integer derived from a quadratic function of the input and writes that integer to standard output on its own line.

2. Inputs  
- Zero or more real-valued numbers provided via standard input.

3. Outputs  
- For each successfully read input value, writes one integer value to standard output, each on a separate line.

4. Preconditions  
- Input values must be representable as finite real numbers in the program’s numeric domain.  
- The computed intermediate values must be representable without overflow in the program’s numeric types.

5. Postconditions  
For each input value \(v\) successfully read, exactly one integer \(n\) is produced such that:  
- Let \(x = \frac{4.9 \cdot v^2}{9.8^2}\).  
- Let \(t = \text{truncate\_toward\_zero}(x + 5)\).  
- Let \(q = \text{truncate\_toward\_zero}(t / 5)\).  
- The output is \(n = q + 1\).  

6. Invariants  
- The program processes inputs independently: each output depends only on the corresponding input value.  
- The number of output lines equals the number of input values successfully read.

7. Error Handling / Exceptional Behavior  
- Terminates normally when end-of-input is reached.  
- If an input token cannot be interpreted as a real number, behavior is not inferable from code (may stop processing, loop indefinitely, or exhibit other behavior depending on the runtime environment).  
- If numeric overflow or invalid numeric values occur during computation or conversion, behavior is not inferable from code.

8. State Transitions (if applicable)  
- Repeats a read–compute–write cycle for each input value until end-of-input is encountered, then transitions to termination.

9. Non-functional Constraints (if inferable)  
- Time and space usage are linear in the count of successfully read input values, with constant additional memory.
