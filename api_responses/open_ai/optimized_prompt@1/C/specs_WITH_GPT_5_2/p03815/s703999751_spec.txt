1. Functional Description  
Reads a single integer and outputs an integer derived from dividing the input by 11 and adjusting based on the input’s remainder modulo 11.

2. Inputs  
- One signed integer value read from standard input.

3. Outputs  
- Writes one signed integer value to standard output, followed by a newline.

4. Preconditions  
- Standard input provides a value representable as a signed 64-bit integer.  
- The computed output value is representable as a signed 64-bit integer (to avoid overflow).

5. Postconditions  
Let the input be \(x\). Let \(q\) be the integer quotient of \(x\) divided by 11 using truncation toward zero, and let \(r\) be the corresponding remainder such that \(x = 11q + r\). The program outputs:  
- \(2q\) if \(r = 0\)  
- \(2q + 2\) if \(r > 6\)  
- \(2q + 1\) otherwise

6. Invariants  
- Exactly one output integer is produced if input is successfully read.  
- The output is always one of \(2q\), \(2q+1\), or \(2q+2\) as defined above.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If input cannot be read as a valid integer, behavior is not inferable from code.  
- If arithmetic overflows the signed 64-bit integer range, behavior is not inferable from code.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory for a single input value.
