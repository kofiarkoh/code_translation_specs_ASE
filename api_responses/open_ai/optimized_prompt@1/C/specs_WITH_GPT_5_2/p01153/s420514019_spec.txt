1. Functional Description  
Computes, for each test case, the maximum achievable total score obtained by repeatedly combining adjacent segments of a circular sequence of integers, where each combination contributes the absolute difference between the values at the two segment endpoints being combined. Outputs the maximum total score over all possible ways to fully combine the entire circular sequence into one segment.

2. Inputs  
- Reads an integer test case count from standard input.  
- For each test case:  
  - Reads an integer sequence length.  
  - Reads a circular sequence of that many integers.

3. Outputs  
- For each test case, writes a single integer to standard output: the maximum total score as defined in the Functional Description, followed by a newline.

4. Preconditions  
- The test case count is non-negative.  
- For each test case, the sequence length is within the supported fixed bounds of the program (at most 102).  
- Sufficient integers are provided in the input to populate each sequence.  
- Integer values and intermediate totals fit within the range of the program’s integer arithmetic (not inferable from code beyond using standard integer type).

5. Postconditions  
For each test case, the printed value equals:  
- The maximum, over all choices of a starting position on the circle and over all full parenthesizations (binary combination orders) that iteratively merge adjacent circular segments until one segment remains, of the sum of merge costs; where each merge cost is the absolute difference between the integer values at the two endpoints of the two segments being merged at that step.

6. Invariants  
- For any test case, the computed maximum score is non-negative.  
- The result depends only on the provided sequence values and length, and is independent across test cases.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed for malformed input, out-of-range sizes, or arithmetic overflow; behavior in such cases is not defined by the code.

8. State Transitions (if applicable)  
- No persistent state is carried between test cases beyond producing outputs; each test case is processed independently.

9. Non-functional Constraints (if inferable)  
- Time and memory usage grow polynomially with the sequence length; memory usage is bounded by fixed-size internal tables sized for a maximum length of 102.
