1. Functional Description  
Reads two circles defined by center coordinates and radius, then classifies their relative positional relationship in the plane and writes a single integer code representing that relationship.

2. Inputs  
- Six integers read from standard input, representing two circles:  
  - Circle A: center (x₁, y₁), radius r₁  
  - Circle B: center (x₂, y₂), radius r₂

3. Outputs  
- Writes exactly one line to standard output containing a single integer in {0,1,2,3,4}, interpreted as:  
  - 4: circles are externally separate (no intersection)  
  - 3: circles are externally tangent (touch at exactly one point externally)  
  - 2: circles intersect at two distinct points  
  - 1: circles are internally tangent (touch at exactly one point with one inside the other)  
  - 0: one circle lies strictly inside the other with no intersection

4. Preconditions  
- Standard input provides at least six integers.  
- Radii are assumed to be non-negative.  
- Arithmetic on squared distances and squared radius sums/differences is assumed not to overflow the integer range.

5. Postconditions  
- Exactly one classification code is written, determined solely by comparing:  
  - the squared distance between centers,  
  - the square of (r₁ + r₂), and  
  - the square of (r₁ − r₂).  
- The program terminates after producing the output.

6. Invariants  
- The classification depends only on the two input circles and is symmetric with respect to swapping the two circles.  
- The output is always one of {0,1,2,3,4} if preconditions hold.

7. Error Handling / Exceptional Behavior  
- No explicit error handling.  
- If input is missing/invalid, radii are negative, or integer overflow occurs, behavior is not defined by the code and the output is not guaranteed.

8. State Transitions (if applicable)  
- Not applicable (no persistent state beyond a single execution).

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory with respect to input size.
