1. Functional Description  
Computes and writes the number of distinct values obtainable from sums of the form  
\[
\sum_{k \in S} (X + kD)
\]
where \(S\) ranges over all subsets of \(\{0,1,\dots,N-1\}\).  

2. Inputs  
- Reads three signed integers from standard input:  
  - \(N\): the number of available terms (non-negative).  
  - \(X\): the base value of the arithmetic progression.  
  - \(D\): the common difference of the arithmetic progression.  

3. Outputs  
- Writes a single signed integer to standard output: the count of distinct subset sums as defined above.  

4. Preconditions  
- \(N\) is expected to be within a range that fits the program’s internal fixed storage (not inferable precisely from the contract, but bounded).  
- Intermediate arithmetic is expected not to overflow the signed integer range used by the program.  
- Input must contain three parseable signed integers.  

5. Postconditions  
- If \(X = 0\) and \(D = 0\), the output is \(1\).  
- Else if \(D = 0\), the output is \(N + 1\).  
- Else if \(X = 0\) (and \(D \neq 0\)), the output is \(\frac{N(N-1)}{2} + 1\).  
- Otherwise, the output equals the cardinality of the set of all subset sums of \(\{X + 0\cdot D, X + 1\cdot D, \dots, X + (N-1)\cdot D\}\).  

6. Invariants  
- The computed result is an integer in the range \([1, 2^N]\).  
- For fixed input \((N, X, D)\), the output is deterministic.  
- The result depends only on the mathematical values of \(N\), \(X\), and \(D\), not on input formatting beyond successful parsing.  

7. Error Handling / Exceptional Behavior  
- No explicit error reporting is performed.  
- If input parsing fails, behavior is not inferable from code.  
- If required arithmetic overflows or if \(N\) exceeds internal storage capacity, behavior is undefined (not handled).  

8. State Transitions (if applicable)  
- Not applicable; the program is a single-run computation with no externally observable state beyond its output.  

9. Non-functional Constraints (if inferable)  
- Uses fixed-size internal storage, implying an upper bound on supported \(N\) (exact bound not stated in the contract).  
- Time and memory usage grow with \(N\); exact complexity is not inferable from the contract.
