1. Functional Description  
Reads an integer length and a sequence of integers, then counts how many consecutive triples form a strictly monotonic run (either strictly increasing across both adjacent comparisons or strictly decreasing across both adjacent comparisons). Writes the resulting count.

2. Inputs  
- An integer representing the number of elements in the sequence.  
- A sequence of that many integers read from standard input.

3. Outputs  
- Writes a single integer to standard output: the number of indices where three consecutive elements are strictly increasing or strictly decreasing, followed by a newline.

4. Preconditions  
- The provided length is such that the program’s internal fixed-capacity storage is not exceeded.  
- The input contains at least as many integers as required by the declared length.  
- The length is non-negative.  
- For the counting behavior to be meaningful without relying on unspecified memory, the length should be at least 1; for triple-based counting, at least 3.

5. Postconditions  
- Let the sequence be indexed from 1 to the given length. The output equals the number of indices \(i\) with \(1 \le i \le \text{length} - 2\) such that either:  
  - element \(i\) < element \(i+1\) < element \(i+2\), or  
  - element \(i\) > element \(i+1\) > element \(i+2\).  
- If the length is less than 3, the output is 0.

6. Invariants  
- The reported count is an integer in the range \([0, \max(0, \text{length} - 2)]\).  
- Each qualifying triple contributes exactly 1 to the count; non-qualifying triples contribute 0.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If the length exceeds internal storage capacity or if insufficient/invalid input is provided, behavior is not defined by the code.

8. State Transitions (if applicable)  
- Not applicable beyond computing and emitting the final count.

9. Non-functional Constraints (if inferable)  
- Uses fixed-size storage for up to 1000 integers.  
- Time cost grows linearly with the sequence length.
