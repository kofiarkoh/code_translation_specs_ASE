1. Functional Description  
Determines whether the second input string occurs as a contiguous substring within the concatenation of the first input string with itself, and writes an affirmative or negative result to standard output.

2. Inputs  
- Reads two whitespace-delimited strings from standard input:
  - First string.
  - Second string.

3. Outputs  
- Writes exactly one line to standard output:
  - An affirmative response if the second string is a substring of the first string repeated twice.
  - Otherwise, a negative response.

4. Preconditions  
- Both input strings must be present on standard input.  
- The first input string length must be at most 100 characters.  
- The second input string length must be at most 100 characters.  
- The first input string length must be such that doubling it fits within the internal buffer used for concatenation (implied by the above bound).  
- Assumption: Inputs contain no embedded whitespace (since input is token-based).

5. Postconditions  
- If the second string appears at least once as a contiguous substring within the first string concatenated with itself, the program outputs the affirmative response.  
- Otherwise, the program outputs the negative response.

6. Invariants  
- The decision depends solely on the two input strings and is deterministic.  
- The output is always exactly one of the two possible responses followed by a newline.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If input is missing or exceeds the assumed maximum lengths, behavior is undefined (may include incorrect results, memory corruption, or program termination).

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)
