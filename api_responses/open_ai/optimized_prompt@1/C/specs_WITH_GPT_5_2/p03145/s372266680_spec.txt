1. Functional Description  
Computes the area of a right triangle using two provided integer side lengths and writes the result as a whole number.

2. Inputs  
- Reads three integer values from standard input.

3. Outputs  
- Writes a single whole-number representation of half the product of the first two input integers to standard output, with no guaranteed trailing newline.

4. Preconditions  
- Standard input provides at least three integers.  
- The product of the first two integers is representable without overflow in the program’s integer arithmetic.  
- The computed value is within the representable range of the program’s floating-point type.

5. Postconditions  
- The output value equals (first_integer × second_integer) ÷ 2, rounded to the nearest integer for display.  
- The third input integer does not affect the output.

6. Invariants  
- The computed result depends only on the first two input integers.  
- The third input value is ignored for all observable behavior.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If input is missing/invalid, or if arithmetic overflows occur, behavior is not defined by this specification (not inferable from code beyond lack of checks).

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and uses constant memory.
