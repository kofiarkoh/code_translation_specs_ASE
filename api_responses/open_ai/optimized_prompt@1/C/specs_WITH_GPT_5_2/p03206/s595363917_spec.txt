1. Functional Description  
Reads a single integer representing a day number and conditionally writes a corresponding holiday-related label for specific recognized values.

2. Inputs  
- One integer read from standard input.

3. Outputs  
- Writes to standard output exactly one line of text if the input equals one of the recognized values (22, 23, 24, or 25).  
- Writes nothing if the input is any other value.

4. Preconditions  
- Standard input provides an integer value parseable as an integer.

5. Postconditions  
- If the input is 25, the output is the label for “Christmas”.  
- If the input is 24, the output is the label for “Christmas Eve”.  
- If the input is 23, the output is the label for “Christmas Eve Eve”.  
- If the input is 22, the output is the label for “Christmas Eve Eve Eve”.  
- Otherwise, no output is produced.  
- Program terminates normally.

6. Invariants  
- At most one label is written, since the recognized input values are mutually exclusive.

7. Error Handling / Exceptional Behavior  
- No explicit error handling. Behavior is not inferable from code if input is missing, not an integer, or if input operations fail.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Constant time and constant memory usage relative to input size.
