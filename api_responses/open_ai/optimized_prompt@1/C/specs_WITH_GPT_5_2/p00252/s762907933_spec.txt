1. Functional Description  
Reads three integer values and, for a limited set of specific input combinations, writes either “Open” or “Close” to standard output.

2. Inputs  
- Three integers read from standard input.

3. Outputs  
- Writes one of the following lines to standard output for certain input combinations:  
  - “Open” followed by a newline  
  - “Close” followed by a newline  
- For all other input combinations, produces no output.

4. Preconditions  
- Standard input provides three integers.  
- No constraints on the integer ranges are enforced by the program.

5. Postconditions  
- If the input triple matches one of the specified combinations in Section 6, exactly one line is written as specified.  
- Otherwise, nothing is written.  
- The program terminates normally.

6. Invariants  
- Output, if produced, is exactly one line and is either “Open” or “Close”.  
- No persistent state is maintained across executions.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- Behavior is not inferable from code if fewer than three integers are successfully read.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Not inferable from code.
