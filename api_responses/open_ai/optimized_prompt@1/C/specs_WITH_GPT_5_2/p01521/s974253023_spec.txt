1. Functional Description  
Reads a line of text, counts the number of runs of consecutive identical characters for two specific characters, and writes a single-character result indicating which of those two characters has fewer such runs (or a fixed choice on ties).

2. Inputs  
- A single line of text read from standard input (may contain any byte-valued characters except the line terminator).

3. Outputs  
- Writes exactly one line to standard output containing either `x` or `o`.

4. Preconditions  
- The input line must fit within a fixed-size internal buffer; otherwise behavior is undefined.  
- The execution environment must provide standard input and standard output.

5. Postconditions  
- Let a “run” be a maximal contiguous sequence of identical characters in the input line.  
- The program outputs:
  - `x` if the number of runs of `o` is strictly less than the number of runs of `x`.  
  - `o` otherwise (including when the counts are equal).  
- No other output is produced.

6. Invariants  
- For each character value, the maintained count equals the number of run starts of that character encountered so far in the processed prefix of the input line.

7. Error Handling / Exceptional Behavior  
- No explicit error handling.  
- If input reading fails, or if the input exceeds the internal buffer capacity, behavior is undefined.  
- If writing to standard output fails, the program does not provide a defined recovery or alternate output.

8. State Transitions (if applicable)  
- Not applicable beyond processing a single input line and producing a single output.

9. Non-functional Constraints (if inferable)  
- Uses fixed, bounded internal storage for the input line and character counts.  
- Time and work are proportional to the length of the input line.
