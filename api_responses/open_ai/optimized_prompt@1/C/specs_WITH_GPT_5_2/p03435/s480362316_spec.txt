1. Functional Description  
Reads a 3×3 matrix of integers and determines whether, after subtracting the minimum value of each row from all elements in that row, all three rows become identical. Writes an affirmative or negative decision accordingly.

2. Inputs  
- Nine integers read from standard input, interpreted as a 3×3 matrix in row-major order.

3. Outputs  
- Writes to standard output either:
  - `Yes` followed by a newline if the condition holds, or
  - `No` followed by a newline otherwise.

4. Preconditions  
- Standard input provides at least nine integers parseable as the required numeric type.  
- All intermediate arithmetic (row-minimum selection and subtraction) does not overflow the numeric type.  

5. Postconditions  
- If the program outputs `Yes`, then for each column, the three values obtained by subtracting each row’s minimum from that row’s entries are equal across all rows.  
- If the program outputs `No`, then there exists at least one column where those normalized values are not all equal across the three rows.

6. Invariants  
- For each row, subtracting that row’s minimum makes at least one element in the row equal to zero.  
- The decision depends only on the input matrix values (subject to the no-overflow assumption).

7. Error Handling / Exceptional Behavior  
- No explicit handling for missing/invalid input; behavior is not inferable from code in such cases.  
- If arithmetic overflow occurs, behavior is not inferable from code.

8. State Transitions (if applicable)  
- Not applicable beyond producing a single decision output and terminating.

9. Non-functional Constraints (if inferable)  
- Operates on a fixed-size 3×3 input; time and memory usage are constant with respect to input size.
