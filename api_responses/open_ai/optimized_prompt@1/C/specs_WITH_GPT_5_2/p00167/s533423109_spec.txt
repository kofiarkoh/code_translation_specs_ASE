1. Functional Description  
Reads a sequence of test cases from standard input. For each test case consisting of a positive integer length followed by that many integers, computes and outputs the number of pairwise out-of-order index pairs in the sequence (i.e., the inversion count). Processing stops when a length value of zero is encountered or when input is exhausted.

2. Inputs  
- From standard input: zero or more test cases.  
- Each test case begins with an integer length. If the length is nonzero, it is followed by that many integers forming the sequence.

3. Outputs  
- To standard output: for each nonzero-length test case, outputs a single integer on its own line equal to the inversion count of the provided sequence.

4. Preconditions  
- For each processed test case, the length is an integer in the range 1 to 100 inclusive.  
- For each processed test case, at least that many subsequent integers are available in the input.  
- Integer values and the resulting inversion count fit within the implementation’s integer range.  

5. Postconditions  
For each processed test case with length \(n\) and sequence \(x[0..n-1]\), the program outputs a value equal to the number of pairs \((i, j)\) such that \(0 \le i < j < n\) and \(x[i] > x[j]\).  
No output is produced for the terminating length value of zero.

6. Invariants  
- The reported count for a test case is non-negative.  
- The reported count for a test case is at most \(n(n-1)/2\).  
- Each test case’s output depends only on that test case’s sequence and is independent of other test cases.

7. Error Handling / Exceptional Behavior  
- If input cannot provide the next required integer at any point, processing terminates immediately with no further output guarantees.  
- If a length outside 0..100 is provided, behavior is not defined by the code (may result in incorrect results or memory corruption).  
- If arithmetic overflows the integer range, behavior is not defined by the code.

8. State Transitions (if applicable)  
- Repeatedly transitions from “awaiting length” to “reading sequence” to “producing output” for each test case.  
- Transitions to “terminated” when a length of zero is read or when input is exhausted/invalid.

9. Non-functional Constraints (if inferable)  
- Uses a fixed maximum sequence capacity of 100 integers.  
- Time per test case grows on the order of the square of the length.  
- Memory usage is constant with respect to input size (bounded by the fixed capacity).
