1. Functional Description  
Computes how many integers within a given inclusive range are divisible by a given divisor, and writes that count to standard output.

2. Inputs  
- Three integers read from standard input:  
  - Lower bound of the range  
  - Upper bound of the range  
  - Divisor

3. Outputs  
- Writes a single integer to standard output followed by a newline: the count of integers in the inclusive range that are divisible by the divisor.

4. Preconditions  
- The three input values are successfully provided as integers.  
- The divisor is non-zero.  
- The lower and upper bounds satisfy lower bound ≤ upper bound.  
- All intermediate arithmetic required to compute the result fits within the integer range of the execution environment.  
- Assumption (due to integer-division semantics dependence): the lower bound and upper bound are non-negative.

5. Postconditions  
- The printed value equals the number of integers x such that lower bound ≤ x ≤ upper bound and x is divisible by the divisor.

6. Invariants  
- Not inferable from code.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If input is missing/invalid, behavior is not defined by the program’s contract.  
- If the divisor is zero, the program may exhibit undefined behavior (e.g., crash or incorrect result).  
- If arithmetic overflows occur, the result is not guaranteed.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory with respect to input values.  
- Produces exactly one line of output under the stated preconditions.
