1. Functional Description  
Determines whether every marked cell in a given rectangular character grid has at least one orthogonally adjacent marked neighbor (up, down, left, or right). Writes an affirmative result if the condition holds for all marked cells; otherwise writes a negative result.

2. Inputs  
- Reads two integers from standard input representing the grid height and width.  
- Reads a sequence of grid rows from standard input, each row providing characters for the corresponding row of the grid.

3. Outputs  
- Writes to standard output either:
  - `Yes` if every marked cell has at least one orthogonally adjacent marked cell, or
  - `No` if at least one marked cell has no orthogonally adjacent marked neighbors.  
- Terminates immediately after writing `No` upon detecting a violating cell.

4. Preconditions  
- The provided height is within the supported maximum number of rows (at most 51).  
- Each provided row contains at least the specified number of columns (at least the given width).  
- The width is within the supported maximum row storage capacity (at most 59 characters excluding any terminator).  
- To avoid out-of-bounds access implied by the behavior, the grid must be such that accessing the cell below the last row and the cell right of the last column is valid; otherwise behavior is undefined. (This effectively requires either extra padding in the provided data or that the height and width are strictly less than the allocated bounds and the unused boundary cells are safely readable.)

5. Postconditions  
- If the program outputs `Yes`, then for every position within the declared height and width whose character is `#`, at least one of its orthogonal neighbors within the grid is also `#`.  
- If the program outputs `No`, then there exists at least one position within the declared height and width whose character is `#` and none of its orthogonal neighbors (up, down, left, right) is `#`.

6. Invariants  
- Non-`#` cells do not affect the decision.  
- The decision depends only on the presence/absence of `#` in each cell and its orthogonal neighbors.

7. Error Handling / Exceptional Behavior  
- No explicit handling for malformed input, insufficient rows, or rows shorter than the declared width.  
- If the input dimensions or row lengths violate the storage limits or if boundary neighbor accesses are not valid as required by the preconditions, behavior is undefined (may crash or produce incorrect output).

8. State Transitions (if applicable)  
Not applicable.

9. Non-functional Constraints (if inferable)  
- Time complexity is proportional to the number of grid cells (height × width).  
- Memory usage is bounded by a fixed-size grid buffer.
