1. Functional Description  
Reads two integers and outputs the smallest positive multiple of the first integer that is divisible by the second integer, if such a multiple is found within a bounded search.

2. Inputs  
- Two signed integers read from standard input.

3. Outputs  
- Writes to standard output a single signed integer followed by a newline if a qualifying value is found.  
- Produces no output otherwise.

4. Preconditions  
- Exactly two integers are provided as input.  
- The second integer is nonzero.  
- Arithmetic operations performed during execution (multiplication and divisibility checks) do not overflow the integer range used by the program.

5. Postconditions  
- If the program writes a value, it is a positive multiple of the first input and is divisible by the second input.  
- If the program writes a value, it is the smallest such multiple among those with multipliers in the range 1 through (second input + 1), inclusive.  
- If no such multiple exists within that multiplier range, nothing is written.

6. Invariants  
- Any value that may be written (if written) is of the form (first input) × k for some integer k in the range 1 through (second input + 1), inclusive.  
- At most one value is written.

7. Error Handling / Exceptional Behavior  
- No explicit error handling for missing/invalid input.  
- If the second input is zero, behavior is undefined due to division-by-zero in the divisibility check.  
- If arithmetic overflows occur, behavior is undefined.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Performs a bounded number of divisibility checks proportional to (second input + 1) when the second input is nonnegative; behavior for negative second input results in no checks and no output.
