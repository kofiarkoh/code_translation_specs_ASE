1. Functional Description  
Computes and outputs the length of a longest strictly increasing subsequence of a given integer sequence.

2. Inputs  
- Reads an integer representing the sequence length.  
- Reads that many integers representing the sequence elements.

3. Outputs  
- Writes a single integer to standard output: the length of a longest strictly increasing subsequence of the input sequence, followed by a newline.

4. Preconditions  
- The sequence length is at least 1.  
- The sequence length does not exceed 100000.  
- All required input values are present and parseable as integers.  
- To ensure correctness for arbitrary integer inputs, the first sequence element must be greater than or equal to -1; otherwise, the reported length may be incorrect.

5. Postconditions  
- The printed value equals the maximum possible size of a subsequence (not necessarily contiguous) whose elements are strictly increasing, under the preconditions above.

6. Invariants  
- At all times during processing, the maintained candidate tail values for increasing subsequences are in non-decreasing order.  
- The reported length is always between 1 and the sequence length (inclusive), assuming the preconditions hold.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If preconditions are violated (e.g., length out of bounds, missing/invalid input, or first element less than -1), behavior is not guaranteed and may include incorrect output or undefined behavior.

8. State Transitions (if applicable)  
- Not inferable from code.

9. Non-functional Constraints (if inferable)  
- Uses memory proportional to the sequence length, bounded by fixed-size storage for up to 100000 elements.  
- Time complexity is proportional to the sequence length times the logarithm of the sequence length.
