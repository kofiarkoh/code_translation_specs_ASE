1. Functional Description  
Determines and outputs the winner between two participants or a draw based on four integer inputs. If either of the last two inputs is negative, the decision is based on the first two inputs; otherwise, it is based on the last two inputs.

2. Inputs  
- Reads four integers from standard input:
  - Two integers representing the first comparison basis.
  - Two integers representing the second comparison basis.

3. Outputs  
- Writes exactly one line to standard output containing one of:
  - “Alice” if the first participant wins,
  - “Bob” if the second participant wins,
  - “Draw” if neither wins (tie).

4. Preconditions  
- Standard input must provide four integers in a readable form; otherwise, behavior is defined under Error Handling.

5. Postconditions  
- If four integers are successfully read:
  - If at least one of the last two integers is negative:
    - Outputs “Alice” if the first of the first two integers is greater than the second.
    - Outputs “Bob” if the first of the first two integers is less than the second.
    - Outputs “Draw” if the first two integers are equal.
  - If both of the last two integers are non-negative:
    - Outputs “Alice” if the first of the last two integers is greater than the second.
    - Outputs “Bob” if the first of the last two integers is less than the second.
    - Outputs “Draw” if the last two integers are equal.

6. Invariants  
- At most one of the three possible outcomes (“Alice”, “Bob”, “Draw”) is produced.
- When input is successfully read, exactly one outcome line is produced.

7. Error Handling / Exceptional Behavior  
- If fewer than four integers can be read from standard input, the program terminates with a non-zero exit status and produces no guaranteed output.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory relative to input size.
