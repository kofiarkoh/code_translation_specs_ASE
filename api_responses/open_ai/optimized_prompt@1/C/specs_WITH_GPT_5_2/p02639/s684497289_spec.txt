1. Functional Description  
Reads five integer values and, if any of them is zero, writes a single digit indicating the position (1–5) of the first zero value among the five, in left-to-right order.

2. Inputs  
- Five integer values read from standard input.

3. Outputs  
- If at least one of the five input values is zero: writes one character representing an integer from 1 to 5 to standard output, indicating the 1-based position of the first zero input value.  
- If none of the five input values is zero: produces no output.

4. Preconditions  
- Standard input provides at least five values that can be interpreted as integers.

5. Postconditions  
- If the first input value is zero, the output is `1`.  
- Otherwise, if the second input value is zero, the output is `2`.  
- Otherwise, if the third input value is zero, the output is `3`.  
- Otherwise, if the fourth input value is zero, the output is `4`.  
- Otherwise, if the fifth input value is zero, the output is `5`.  
- Otherwise, no output is produced.

6. Invariants  
- At most one digit is written to standard output.  
- If output is produced, it corresponds to the earliest (lowest index) zero among the five inputs.

7. Error Handling / Exceptional Behavior  
- Behavior is not inferable from code if fewer than five integers are successfully provided via input.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Not inferable from code.
