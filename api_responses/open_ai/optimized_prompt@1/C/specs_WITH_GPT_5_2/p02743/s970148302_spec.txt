1. Functional Description  
Reads three real-valued inputs and determines whether the third value is strictly greater than the sum of the first two by more than twice the geometric mean of the first two (under the additional requirement that the third value exceeds the sum of the first two). Outputs an affirmative or negative decision accordingly.

2. Inputs  
- Three floating-point numbers read from standard input.

3. Outputs  
- Writes exactly one line to standard output: either an affirmative response or a negative response.

4. Preconditions  
- Standard input provides three values that can be interpreted as floating-point numbers.  
- The computation is intended to be meaningful when the first and second inputs are non-negative (assumption; otherwise the compared expression may not correspond to the intended mathematical inequality).

5. Postconditions  
Let the inputs be \(a\), \(b\), and \(c\). The program outputs the affirmative response if and only if both conditions hold:  
- \(c - a - b > 0\)  
- \((c - a - b)^2 > 4ab\)  
Otherwise, it outputs the negative response.

6. Invariants  
- The decision is deterministic for a given triple of input values, subject to floating-point arithmetic behavior.

7. Error Handling / Exceptional Behavior  
- No explicit handling for missing/invalid input; behavior is not inferable from code if fewer than three valid numbers are provided.  
- No explicit handling for floating-point overflow/underflow or non-finite values; resulting output in such cases is not inferable from code.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and constant memory.
