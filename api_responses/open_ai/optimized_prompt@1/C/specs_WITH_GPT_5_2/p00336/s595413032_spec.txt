1. Functional Description  
Computes the number of distinct ways the second input string can be obtained as a subsequence of the first input string (preserving character order but not requiring contiguity), and writes this count modulo 1,000,000,007.

2. Inputs  
- Reads two whitespace-delimited strings from standard input:  
  - A source string.  
  - A target string.

3. Outputs  
- Writes a single non-negative integer to standard output: the number of subsequence occurrences of the target within the source, reduced modulo 1,000,000,007, followed by a newline.

4. Preconditions  
- Both input strings are present and successfully read.  
- The source string length is at most 1000 characters.  
- The target string length is at most 1000 characters.  
- The strings contain no internal whitespace (as they are read as tokens).

5. Postconditions  
- The output value equals:  
  - The count of index sequences selecting characters from the source string in strictly increasing positions such that the selected characters, in order, exactly match the target string,  
  - Taken modulo 1,000,000,007.  
- If the target string is empty, the output is 1 (modulo 1,000,000,007).  
- If the target length exceeds the source length, the output is 0.

6. Invariants  
- All intermediate and final counts are maintained modulo 1,000,000,007 and therefore remain within the range [0, 1,000,000,006].  
- For any prefix of the source string, the number of ways to form an empty target prefix is 1.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is provided.  
- Behavior is not inferable from code if input is missing, malformed, or exceeds the maximum supported lengths; such cases may lead to incorrect results or memory corruption.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Time complexity is proportional to the product of the two string lengths.  
- Memory usage is proportional to the product of the two string lengths.  
- All arithmetic is performed with modular reduction by 1,000,000,007.
