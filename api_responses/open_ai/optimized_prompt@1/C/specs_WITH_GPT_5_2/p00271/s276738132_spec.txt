1. Functional Description  
Reads seven pairs of integers from standard input and, for each pair, outputs the arithmetic difference of the first integer minus the second integer on its own line.

2. Inputs  
- Standard input: exactly 7 pairs of integer values.

3. Outputs  
- Standard output: exactly 7 lines, each containing one integer equal to the difference of the corresponding input pair (first minus second).

4. Preconditions  
- Standard input provides at least 7 valid integer pairs in a form that can be interpreted as integers.  
- Each computed difference is representable within the integer range of the execution environment (otherwise behavior is not defined by the code).

5. Postconditions  
- After consuming 7 integer pairs, the program terminates normally.  
- Exactly 7 differences have been written to standard output, in the same order as the input pairs were read.

6. Invariants  
- For each processed pair, exactly one output line is produced.  
- The number of processed pairs and produced output lines is always equal and never exceeds 7.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed for invalid, missing, or insufficient input. If input cannot be read as required, subsequent behavior is not inferable from code.  
- If an arithmetic overflow occurs during subtraction, behavior is not inferable from code.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Performs a fixed amount of work proportional to 7 input pairs (constant time and constant additional memory).
