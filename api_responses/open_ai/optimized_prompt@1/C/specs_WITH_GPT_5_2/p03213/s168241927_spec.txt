1. Functional Description  
Reads a single integer and computes the number of positive divisors of the factorial of that integer that have exactly 75 positive divisors. Writes this count as an integer.

2. Inputs  
- One integer value read from standard input representing a non-negative bound used to form a factorial.

3. Outputs  
- Writes one integer to standard output: the count of divisors of the factorial of the input value whose divisor-count equals 75.

4. Preconditions  
- The input integer is within a range such that all internal fixed-size storage used for counting prime-factor exponents is sufficient (in particular, the input value does not exceed 100).  
- The input is a valid integer.

5. Postconditions  
- If preconditions hold, the program outputs the exact number of integers \(d\) such that \(d\) divides \(n!\) and \(d\) has exactly 75 positive divisors, where \(n\) is the input value.  
- The output is a non-negative integer.

6. Invariants  
- For each integer \(k\) in the supported range, the maintained exponent count for \(k\) equals the total number of times \(k\) appears as a prime factor across the product \(2 \times 3 \times \dots \times n\); for non-prime \(k\), this count remains 0.  
- The computed result depends only on the multiset of prime exponents in the prime factorization of \(n!\), not on any other external state.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If the input is missing/invalid or violates the supported range, behavior is not defined by the code (may produce incorrect output or exhibit runtime faults).

8. State Transitions (if applicable)  
- Transitions from an initial state with zeroed factor-exponent counts to a final state where those counts represent the prime-exponent vector of \(n!\). No other persistent state is produced.

9. Non-functional Constraints (if inferable)  
- Uses fixed, bounded memory for factor-exponent counts.  
- Execution time grows with the input value and performs factorization work for each integer from 2 through the input value.
