1. Functional Description
- Reads an integer length and an iteration limit, followed by an integer sequence of that length.
- Repeatedly transforms the sequence up to the given iteration limit, or stops early if the sequence becomes uniformly maximal.
- Each transformation replaces every position’s value with the count of positions in the previous sequence whose “influence range” covers that position, where a position influences all indices within a distance equal to its current value, clipped to the sequence bounds.
- Writes the final sequence.

2. Inputs
- From standard input:
  - An integer `N`: the sequence length.
  - An integer `K`: the maximum number of transformations to apply.
  - `N` integers: the initial sequence values.

3. Outputs
- To standard output:
  - `N` integers representing the final sequence after applying the transformation repeatedly (up to `K` times, possibly fewer due to early termination), separated by spaces and terminated by a newline.

4. Preconditions
- `N` is within the fixed internal capacity (must not exceed 200001).
- `N` is at least 1.
- Input provides at least `N + 2` integers in total.
- All intermediate and final values fit within the range of the program’s integer type (not inferable from code; assumed for defined behavior).

5. Postconditions
- Let the sequence before an iteration be `A_prev[1..N]` and after be `A_next[1..N]`. For each index `j` in `1..N`:
  - `A_next[j]` equals the number of indices `i` in `1..N` such that `|i - j| <= A_prev[i]`.
- The program outputs the sequence obtained after:
  - Exactly `t` iterations, where `t` is the smallest value such that either `t = K` or after iteration `t` every element equals `N` (uniform maximal coverage), whichever occurs first.

6. Invariants
- Throughout execution after any completed transformation:
  - Each sequence element is an integer in the range `[0, N]`.
- The sequence length remains `N`.
- The number of applied transformations never exceeds `K`.

7. Error Handling / Exceptional Behavior
- No explicit error handling is performed.
- If input is missing, malformed, or violates preconditions (e.g., `N` exceeds capacity), behavior is not defined by the code (may produce incorrect output or crash).

8. State Transitions (if applicable)
- State consists of the current sequence and the count of completed transformations.
- Transition rule (one iteration): current sequence is replaced by the coverage-count sequence defined in Postconditions.
- Termination condition: either `K` transitions have occurred, or the current sequence becomes all `N` immediately after a transition (early stop).

9. Non-functional Constraints (if inferable)
- Uses fixed-size internal storage proportional to `N` (bounded by the compiled-in maximum).
- Runtime is proportional to `N` times the number of performed iterations (at most `K`, possibly fewer due to early termination).
