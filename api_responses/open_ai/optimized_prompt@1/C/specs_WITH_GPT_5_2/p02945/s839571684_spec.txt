1. Functional Description  
Reads two integers and computes the maximum value among their sum, difference (first minus second), and product, then writes that maximum.

2. Inputs  
- Two integer values read from standard input.

3. Outputs  
- Writes a single integer to standard output: the maximum of (first + second), (first − second), and (first × second).

4. Preconditions  
- Standard input provides two integers in a readable form.  
- The computed sum, difference, and product are representable within the integer range of the execution environment (to avoid overflow/underflow).

5. Postconditions  
- Exactly one integer value is written to standard output.  
- The written value equals the greatest of the three computed results: sum, difference, and product.

6. Invariants  
- The selected result is always one of the three computed values (sum, difference, or product).  
- The selected result is greater than or equal to each of the other two computed values.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed for invalid or missing input.  
- If arithmetic overflow/underflow occurs, behavior is not defined by this specification.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Not inferable from code.
