1. Functional Description  
Reads three integers and outputs the same three integers in nondecreasing (ascending) order.

2. Inputs  
- Three integer values read from standard input.

3. Outputs  
- Writes three integers to standard output, representing the input values sorted in nondecreasing order, followed by a line terminator.

4. Preconditions  
- Standard input provides exactly three values that can be interpreted as integers within the supported integer range of the execution environment.

5. Postconditions  
- The three output integers are a permutation of the three input integers.  
- The output sequence satisfies: first ≤ second ≤ third.

6. Invariants  
- The multiset of values in the output equals the multiset of values in the input (no value is created or lost).  
- Ordering invariant on output: first ≤ second ≤ third.

7. Error Handling / Exceptional Behavior  
- Not inferable from code for cases where fewer than three integers are successfully read or input is invalid; behavior may be undefined in such cases.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Uses a fixed amount of memory and performs a constant amount of computation independent of input values.
