1. Functional Description  
Computes and outputs the largest positive integer whose n-th power divides the given integer p (i.e., the greatest integer x such that x^n is a divisor of p).

2. Inputs  
- Reads two signed integer values from standard input:  
  - n: the exponent parameter.  
  - p: the value to be analyzed for divisibility by n-th powers.

3. Outputs  
- Writes a single signed integer value to standard output: the computed largest integer x such that x^n divides the original input p, followed by a newline.

4. Preconditions  
- Input must contain two integers representable in the platform’s signed long integer range.  
- n is assumed to be positive (n ≥ 1).  
- p is assumed to be positive (p ≥ 1).  
- The computation assumes intermediate products fit within the platform’s signed long integer range (no overflow).

5. Postconditions  
- Let p₀ be the original input value of p. The output value ans satisfies:  
  - ans ≥ 1.  
  - ans^n divides p₀.  
  - For any integer y > ans, y^n does not divide p₀ (maximality).

6. Invariants  
- The output ans is always a positive integer.  
- At all times during computation, ans is a divisor of the original p₀.  
- The final ans is composed only of prime factors that appear in p₀, each raised to an exponent equal to the floor of that prime’s exponent in p₀ divided by n.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If input is missing/invalid, behavior is not defined by the code.  
- If n ≤ 0 or p ≤ 0, behavior is not defined by the code.  
- If arithmetic overflow occurs during computation, behavior is not defined by the code.

8. State Transitions (if applicable)  
- Not inferable from code (no persistent state beyond a single execution).

9. Non-functional Constraints (if inferable)  
- Time complexity grows roughly with the square root of the input p (based on trial division up to √p).  
- Uses constant extra memory aside from a small fixed number of integer variables.
