1. Functional Description  
Reads a single integer and computes its difference from 48, then writes the result.

2. Inputs  
- One integer value read from standard input.

3. Outputs  
- Writes one integer value to standard output followed by a newline: the value `48 − input`.

4. Preconditions  
- Standard input provides a value that can be interpreted as an integer within the supported range of the execution environment.

5. Postconditions  
- Exactly one integer result equal to `48 − m` (where `m` is the read input value) is written to standard output.

6. Invariants  
- The constant 48 is used as the minuend for the computation.
- The output depends solely on the single input value.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed. If input is missing, malformed, or cannot be read as an integer, the behavior is not inferable from code.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and uses constant memory.
