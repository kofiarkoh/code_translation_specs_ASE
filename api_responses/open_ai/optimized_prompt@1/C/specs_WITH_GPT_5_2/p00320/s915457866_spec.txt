1. Functional Description  
Determines whether six given rectangles can be assigned (with optional 90° rotation per rectangle) to the six faces of a rectangular box such that all shared edges between adjacent faces have equal lengths. Writes an affirmative result if such an assignment exists; otherwise writes a negative result.

2. Inputs  
- Reads 6 pairs of integers from standard input.  
  - Each pair represents the two side lengths of one rectangle.

3. Outputs  
- Writes to standard output exactly one line: either an affirmative response if a valid box construction exists, or a negative response otherwise.

4. Preconditions  
- Exactly 6 rectangle descriptions are provided, each consisting of two integers.  
- Side lengths are intended to represent physical lengths; behavior for non-positive values is not constrained by the program’s contract (it will still compute using the provided integers).

5. Postconditions  
- If the program outputs the affirmative response, then there exists:  
  - a one-to-one assignment of the 6 input rectangles to the 6 box faces, and  
  - an independent choice for each rectangle of whether its sides are swapped (rotation),  
  such that for every adjacency between faces in the fixed box topology, the corresponding edge lengths on the two faces are equal.  
- If the program outputs the negative response, then no such assignment and rotation choices exist.

6. Invariants  
- Each input rectangle is used at most once in any candidate assignment.  
- For any candidate assignment, each rectangle is considered in exactly one of two orientations (original or swapped sides).  
- The set of face adjacencies and which side of each face participates in each adjacency is fixed and does not depend on input.

7. Error Handling / Exceptional Behavior  
- If fewer than 6 rectangle pairs can be read from standard input, the program terminates early with a non-zero exit status and produces no guaranteed standard output.  
- No other error reporting is performed.

8. State Transitions (if applicable)  
- Not inferable from code beyond a single-pass decision procedure that terminates after printing one result.

9. Non-functional Constraints (if inferable)  
- Always terminates after exploring a finite search space bounded by all assignments of 6 items and all 2-orientation choices per item.  
- Uses a fixed, small amount of memory independent of input values.
