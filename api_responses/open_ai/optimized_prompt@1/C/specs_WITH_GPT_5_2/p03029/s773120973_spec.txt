1. Functional Description  
Reads two integers representing a count of whole units and a count of half-units, computes the total number of whole units obtainable by combining them, and writes the resulting integer.

2. Inputs  
- Two integers read from standard input:
  - An integer representing the number of whole units.
  - An integer representing the number of half-units.

3. Outputs  
- Writes a single integer to standard output followed by a newline: the computed number of whole units obtainable.

4. Preconditions  
- Standard input provides two integers in a readable form.  
- Integer arithmetic during computation does not overflow the implementation’s integer range.

5. Postconditions  
- The value written equals the integer quotient of (3 × whole-units + half-units) divided by 2, using truncation toward zero consistent with integer division.

6. Invariants  
- Not inferable from code.

7. Error Handling / Exceptional Behavior  
- No explicit error handling. If input cannot be read as two integers, or if arithmetic overflows, behavior is not defined by the program’s own logic.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)
