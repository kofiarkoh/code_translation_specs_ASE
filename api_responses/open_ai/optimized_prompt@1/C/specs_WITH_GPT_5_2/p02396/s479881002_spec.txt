1. Functional Description  
Continuously reads integers from standard input, counts how many integers have been read, and for each nonzero integer read, writes a labeled line containing its 1-based read position and its value. Terminates when a zero value is read.

2. Inputs  
- A sequence of integer values provided via standard input.

3. Outputs  
- For each nonzero input integer, writes one line to standard output containing:
  - A case label using the ordinal position of that input within the overall sequence read so far (starting at 1), and
  - The integer value itself.  
- Produces no output for the terminating zero.

4. Preconditions  
- Standard input must provide integer values in a form that can be read as integers.  
- At least one integer value is provided (otherwise behavior is not inferable from code).

5. Postconditions  
- The program terminates after reading the first zero value.  
- Let \(k\) be the position (1-based) of the first zero in the input sequence. The program writes exactly \(k-1\) output lines, corresponding to the first \(k-1\) nonzero integers, each labeled with its respective position.

6. Invariants  
- The case number associated with any printed line equals the count of integers read up to and including that value.  
- Case numbers in printed lines are strictly increasing by 1 starting from 1.  
- No line is printed for any input value equal to zero.

7. Error Handling / Exceptional Behavior  
- No explicit handling is performed for invalid input, end-of-input, or read failures; resulting behavior is not inferable from code.

8. State Transitions (if applicable)  
- Initial state: ready to read the first integer with an internal read counter at 0.  
- After each successful read: counter increments by 1.  
- If the read value is nonzero: emits one output line and returns to the reading state.  
- If the read value is zero: transitions to the terminated state without emitting output for that value.

9. Non-functional Constraints (if inferable)  
- Not inferable from code.
