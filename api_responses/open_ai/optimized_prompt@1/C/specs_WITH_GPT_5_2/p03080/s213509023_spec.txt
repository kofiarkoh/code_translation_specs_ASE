1. Functional Description  
Reads an integer and a text token, evaluates the first N characters of the token by treating one specific character as +1 and all other characters as −1, and writes an affirmative or negative response depending on whether the resulting total is positive.

2. Inputs  
- One integer value N read from standard input.  
- One whitespace-delimited text token read from standard input.

3. Outputs  
- Writes exactly one line to standard output: either an affirmative response or a negative response.

4. Preconditions  
- The integer N and the text token must be present and readable from standard input.  
- N must be non-negative.  
- The text token must contain at least N characters.  
- The text token length must not exceed 127 characters.

5. Postconditions  
- Let score start at 0. For each of the first N characters of the input token:  
  - If the character is the uppercase letter R, score is increased by 1.  
  - Otherwise, score is decreased by 1.  
- If the final score is strictly greater than 0, the program outputs the affirmative response; otherwise it outputs the negative response.  
- On successful completion, the program terminates with a success status.

6. Invariants  
- During evaluation, after processing k characters (0 ≤ k ≤ N), the score equals: (count of 'R' among the first k characters) minus (k minus that count).  
- The score changes by exactly ±1 per processed character.

7. Error Handling / Exceptional Behavior  
- If either required input value cannot be read, the program terminates immediately with a non-success status and produces no required output.  
- If preconditions about N or token length are violated, behavior is not defined by the code (may read beyond available characters or otherwise misbehave).

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Time complexity is linear in N.  
- Uses constant additional memory beyond the fixed-size storage for the input token.
