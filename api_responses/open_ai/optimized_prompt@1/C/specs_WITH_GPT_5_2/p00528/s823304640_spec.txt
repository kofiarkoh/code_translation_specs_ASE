1. Functional Description
- Computes and outputs the minimum total travel cost between the grid cell at the top-left corner and the grid cell at the bottom-right corner, using a graph derived from a given set of special grid points.
- Travel is only possible along connections induced by the special points (including the start and goal points, which are added if missing), with costs defined by Manhattan differences along shared coordinates and a fixed internal switching cost at each special point.

2. Inputs
- Reads three non-negative integers from standard input:
  - Grid width (number of columns).
  - Grid height (number of rows).
  - Count of special points.
- Reads that many pairs of integers, each pair representing the coordinates of a special point within the grid.

3. Outputs
- Writes a single integer value to standard output:
  - The minimum total cost to reach the bottom-right corner from the top-left corner under the induced connectivity rules, or
  - `-1` if the goal is unreachable.

4. Preconditions
- The number of special points does not exceed the program’s fixed internal capacity.
- All coordinates provided are assumed to be within the grid bounds.
- The induced graph degree per node is assumed to stay within the program’s fixed internal per-node adjacency capacity.
- Input is well-formed as integers; behavior for malformed input is not guaranteed.

5. Postconditions
- If a path exists in the induced graph from the start corner to the goal corner, the output equals the minimum possible sum of edge costs along any such path.
- If no such path exists, the output is `-1`.
- The start and goal corners are treated as special points even if not present in the input (they are implicitly added).

6. Invariants
- All edge costs used in path computation are non-negative integers.
- The computed result, when not `-1`, is the cost of some valid path in the induced graph and is minimal among all valid paths.
- The induced graph is undirected with symmetric costs for each connection.

7. Error Handling / Exceptional Behavior
- No explicit error reporting for invalid inputs, out-of-range values, or capacity overruns; such cases may lead to incorrect results or undefined behavior.
- If the induced graph cannot connect start to goal, the program outputs `-1`.

8. State Transitions (if applicable)
- Not inferable from code.

9. Non-functional Constraints (if inferable)
- Uses fixed-size internal storage, imposing hard limits on the number of special points, total nodes, total edges, and priority-queue size.
- Time complexity is dominated by sorting the special points and a shortest-path computation on the induced graph; exact bounds depend on input size within the fixed capacities.
