1. Functional Description  
Reads an integer count and a query year, then reads that many pairs of (year, name). Outputs the name associated with the last read year that is less than or equal to the query year. If no read year satisfies the condition, outputs a predefined default name.

2. Inputs  
- From standard input:  
  - An integer representing the number of subsequent (year, name) pairs.  
  - An integer representing the query year.  
  - A sequence of that many pairs, each consisting of:  
    - An integer year.  
    - A whitespace-delimited name string.

3. Outputs  
- To standard output:  
  - Exactly one line containing the selected name string (either the default name or one of the provided names).

4. Preconditions  
- The first integer (count) is non-negative.  
- The input provides exactly the declared number of (year, name) pairs.  
- Each provided name fits within the program’s fixed maximum name length (including terminator).  
- The declared number of pairs does not exceed the program’s fixed maximum capacity for stored names.

5. Postconditions  
- The output name equals:  
  - The name from the last input pair (in input order) whose year is less than or equal to the query year, if at least one such pair exists; otherwise  
  - The predefined default name.

6. Invariants  
- At any point after processing any prefix of the input pairs, the currently selected name is either the default name or the name from the most recently processed pair whose year is less than or equal to the query year.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If input is missing, malformed, exceeds fixed storage limits, or violates capacity constraints, behavior is not guaranteed (may produce incorrect output or terminate abnormally).

8. State Transitions (if applicable)  
- The selected name transitions from the default name to a provided name whenever a newly read pair has a year less than or equal to the query year; it may transition multiple times and always reflects the most recent qualifying pair.

9. Non-functional Constraints (if inferable)  
- Uses fixed, bounded storage for names; maximum number of storable names and maximum name length are fixed at compile time.  
- Time and memory usage scale linearly with the number of input pairs up to the fixed capacity.
