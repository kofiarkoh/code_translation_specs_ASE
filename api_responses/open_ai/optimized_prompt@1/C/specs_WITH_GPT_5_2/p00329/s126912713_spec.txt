1. Functional Description
Determines whether a perfect one-to-one pairing exists between two equally sized sets based on a provided binary relation, and:
- If no perfect pairing exists, reports failure.
- If a perfect pairing exists, reports success and outputs, for each element of the first set in order, a selected paired element from the second set (expressed as a 1-based index within the second set).

2. Inputs
- Reads an integer value from standard input representing a size parameter.
- Reads a square grid of binary indicators from standard input representing allowed pairings between elements of the first set (rows/columns as implied by the program’s interpretation) and elements of the second set.

3. Outputs
- Writes to standard output either:
  - A single line indicating that no perfect pairing exists, or
  - A line indicating that a perfect pairing exists, followed by exactly one integer per line for each element of the first set, giving the chosen partner’s 1-based index in the second set.

4. Preconditions
- The size parameter must be at least 1.
- The effective set size used by the program is one less than the input size parameter; this effective size must not exceed 1004.
- The provided grid must contain at least the number of binary indicators required to describe an effective-size-by-effective-size relation.
- The number of allowed pairings per element must not exceed the fixed internal capacity (bounded by the effective size).

5. Postconditions
- If the program outputs failure, then no perfect pairing was found for the given relation (within the program’s model).
- If the program outputs success, then:
  - Exactly one partner is output for each element of the first set.
  - Each output partner index is in the range 1 through the effective size.
  - The produced mapping is a bijection: no two elements of the first set are assigned the same partner, and every partner is assigned to exactly one element of the first set.
  - Each assigned pair corresponds to an allowed pairing indicated by the input relation.

6. Invariants
- At all times when a pairing is reported as successful, pairings are mutual and one-to-one between the two sets (no element is paired with more than one counterpart).
- The effective size of both sets is equal.

7. Error Handling / Exceptional Behavior
- No explicit error handling is performed for malformed input, insufficient input data, out-of-range sizes, or capacity overruns; behavior in such cases is not guaranteed.
- If the effective size is zero, the program will report success and produce no per-element partner lines.

8. State Transitions (if applicable)
- Not inferable from code (no persistent state beyond a single execution).

9. Non-functional Constraints (if inferable)
- Uses fixed maximum capacity corresponding to an effective size up to 1004.
- Execution time and memory usage scale with the square of the effective size in the worst case due to the relation representation and matching process.
