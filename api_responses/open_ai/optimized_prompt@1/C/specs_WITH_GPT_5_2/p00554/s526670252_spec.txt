1. Functional Description  
Reads two integers and then reads a sequence of integer pairs. It computes and outputs a non-negative integer derived from the first values of the pairs that are strictly less than the first integer, by summing a selected subset of their deficits relative to that first integer.

2. Inputs  
- Two integers from standard input:  
  - A reference integer.  
  - A count of subsequent pairs.  
- A sequence of that many integer pairs from standard input.

3. Outputs  
- Writes a single integer followed by a newline to standard output: the computed sum described in the Functional Description.

4. Preconditions  
- The pair count is within the fixed internal capacity (at most 999) to avoid out-of-bounds behavior.  
- Standard input provides the required number of integers.  
- The reference integer and all first elements of pairs are such that computing their difference does not overflow the integer range.  
- The pair count is non-negative.

5. Postconditions  
Let:  
- `S` be the multiset of values `(reference − firstValue)` for each input pair whose `firstValue` is strictly less than `reference`.  
- `k` be the number of such pairs (i.e., `|S|`).  

Then the program outputs:  
- `0` if `k ≤ 1`.  
- Otherwise, the sum of the smallest `k − 1` values in `S`.

6. Invariants  
- The output is always an integer greater than or equal to 0.  
- Pairs whose first value is greater than or equal to the reference do not contribute to the output.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If preconditions are violated (e.g., too many pairs, insufficient input, or arithmetic overflow), behavior is not defined/inferable from code.

8. State Transitions (if applicable)  
- Not applicable; the program is a single-run computation with no persistent state beyond execution.

9. Non-functional Constraints (if inferable)  
- Uses fixed-size storage for up to 999 pairs.  
- Time cost grows quadratically with the number of pairs due to ordering operations on derived values.
