1. Functional Description  
Reads a sequence of integers and computes the number of distinct values present in the sequence. Writes that count to standard output.

2. Inputs  
- An integer specifying the number of subsequent integers to read.  
- A sequence of that many integers read from standard input.

3. Outputs  
- Writes a single integer to standard output: the count of distinct values in the input sequence, followed by a newline.

4. Preconditions  
- The provided count is at least 1.  
- The provided count does not exceed 100001.  
- Standard input contains at least the specified number of integers.

5. Postconditions  
- The output value equals the cardinality of the set of integers provided in the sequence.

6. Invariants  
- The reported distinct count is always between 1 and the input count (inclusive), assuming the preconditions hold.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If the input count is 0, negative, exceeds 100001, or if insufficient/invalid input is provided, behavior is not defined by this specification (may produce incorrect output or exhibit runtime errors).

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Uses memory sufficient to store up to 100001 integers.  
- Execution time grows superlinearly with the number of input integers due to ordering-based distinct counting.
