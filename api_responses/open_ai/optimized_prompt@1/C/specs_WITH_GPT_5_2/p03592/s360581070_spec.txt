1. Functional Description  
Determines whether there exist two integers within given bounds such that a specific arithmetic expression computed from the three input integers equals a target value. Outputs an affirmative or negative decision accordingly.

2. Inputs  
- Reads three integers from standard input:  
  - A nonnegative height bound.  
  - A nonnegative width bound.  
  - A target integer value.

3. Outputs  
- Writes to standard output exactly one line containing either an affirmative decision or a negative decision.

4. Preconditions  
- The three input values are successfully provided as integers.  
- The height and width bounds are not negative.  
- Arithmetic performed during evaluation does not overflow the integer range used by the program.  

5. Postconditions  
- Outputs the affirmative decision if and only if there exist integers \(i\) and \(j\) such that:  
  - \(0 \le i \le\) height bound, and \(0 \le j \le\) width bound, and  
  - \((\text{width bound} \cdot i) + (\text{height bound} \cdot j) - 2 \cdot i \cdot j = \text{target}\).  
- Otherwise outputs the negative decision.

6. Invariants  
- The decision is based solely on the existence of at least one pair \((i, j)\) within the stated bounds satisfying the equation; no other state is preserved or reported.

7. Error Handling / Exceptional Behavior  
- No explicit error handling for invalid/missing input.  
- If integer overflow occurs during computation, behavior is not defined by this specification (not safely inferable as handled).

8. State Transitions (if applicable)  
- Terminates immediately after producing the affirmative decision upon finding a satisfying pair.  
- Otherwise terminates after exhausting all candidate pairs and producing the negative decision.

9. Non-functional Constraints (if inferable)  
- Time cost grows proportionally to the product of the two bounds plus one in each dimension (i.e., checks all pairs in the inclusive ranges).  
- Uses constant additional memory aside from input storage.
