1. Functional Description  
Reads an integer count and a sequence of that many integers, then computes and outputs the sum over all elements of (element value minus 1).

2. Inputs  
- One integer representing the number of subsequent integers to read.  
- A sequence of that many integers.

3. Outputs  
- Writes a single integer to standard output: the computed sum of (each input integer minus 1).

4. Preconditions  
- The first input value is a non-negative integer.  
- Exactly that many subsequent integers are available on standard input.  
- Sufficient memory is available to store the sequence of integers.  
- The arithmetic sum of (each input integer minus 1) fits within the range of the program’s integer type.

5. Postconditions  
- The output value equals: (sum of all input integers) minus (the count of input integers).  
- No other externally observable effects are produced besides the output.

6. Invariants  
- After processing any prefix of the sequence of length k (0 ≤ k ≤ count), the running total equals the sum of (first k integers minus 1 each).

7. Error Handling / Exceptional Behavior  
- Not inferable from code. (No explicit handling for invalid input, negative count, allocation failure, or integer overflow.)

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Time proportional to the number of integers read.  
- Memory proportional to the number of integers read (stores the entire sequence).
