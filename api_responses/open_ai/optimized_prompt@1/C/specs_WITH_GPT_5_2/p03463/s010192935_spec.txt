1. Functional Description  
Determines which of two names to output based on whether the difference between two provided integers is even or odd.

2. Inputs  
- Reads three integers from standard input: a first integer (unused for the decision), and two integers whose difference is evaluated.

3. Outputs  
- Writes exactly one line to standard output containing either “Alice” or “Borys”.

4. Preconditions  
- Standard input provides three values that can be interpreted as integers.

5. Postconditions  
- If the difference between the third and second input integers is an even integer, the output is “Alice”.  
- If the difference between the third and second input integers is an odd integer, the output is “Borys”.  
- The program terminates with a success status code.

6. Invariants  
- The first input integer does not affect the output.  
- Exactly one of the two possible names is produced when inputs are successfully read.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If fewer than three integers are successfully read, behavior is not inferable from code (may produce arbitrary output or none).

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Runs in constant time and uses constant memory.
