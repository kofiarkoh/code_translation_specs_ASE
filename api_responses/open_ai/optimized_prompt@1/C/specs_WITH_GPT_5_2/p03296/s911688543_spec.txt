1. Functional Description  
Reads a sequence of integers and counts the number of non-overlapping adjacent equal pairs in the sequence, then outputs that count.

2. Inputs  
- An integer representing the number of elements in the sequence.  
- A sequence of that many integers, in order, read from standard input.

3. Outputs  
- Writes a single integer to standard output: the count of non-overlapping adjacent equal pairs, followed by a newline.

4. Preconditions  
- The provided sequence length is within the supported bounds of the program (at most 100).  
- Standard input contains at least the declared number of integer values.  
- Input values fit within the range of the program’s integer type.

5. Postconditions  
- The output value equals the number of indices \(k\) such that:  
  - \(1 \le k < N\)  
  - the \(k\)-th and \((k+1)\)-th input values are equal  
  - no input element participates in more than one counted pair (i.e., counted pairs are disjoint and adjacent).

6. Invariants  
- The reported count is an integer in the range \([0, \lfloor N/2 \rfloor]\).  
- Each counted pair corresponds to two consecutive equal elements from the input sequence, and counted pairs do not overlap.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed. Behavior is undefined or not inferable if input is missing, malformed, or violates the stated bounds.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Uses memory proportional to the sequence length up to a fixed maximum of 100 elements.  
- Runs in time proportional to the sequence length.
