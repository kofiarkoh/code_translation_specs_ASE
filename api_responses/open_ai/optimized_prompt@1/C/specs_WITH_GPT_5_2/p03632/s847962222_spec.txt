1. Functional Description  
Computes the size of the overlap between two integer intervals and writes a single integer representing the count of integer points that lie in both intervals, with an adjustment that effectively reports the length of the overlap in unit segments rather than the number of overlapping integer points.

2. Inputs  
- Reads four integers from standard input representing two closed intervals: first interval endpoints and second interval endpoints.

3. Outputs  
- Writes one integer to standard output:  
  - If there is no overlap between the two intervals (no common integer points), outputs `0`.  
  - Otherwise outputs `(number of common integer points) − 1`.

4. Preconditions  
- The four input values are valid integers.  
- Each interval’s endpoints are within the inclusive range `[0, 100]`.  
- For each interval, the first endpoint is less than or equal to the second endpoint.  
- Behavior is only defined under these constraints.

5. Postconditions  
- Let the first interval be `[A, B]` and the second be `[C, D]`, interpreted as sets of integers.  
- Let `K` be the number of integers in the intersection `[A, B] ∩ [C, D]`.  
- The program outputs:
  - `0` if `K = 0`, else `K − 1`.

6. Invariants  
- The computed overlap count `K` is an integer in the range `[0, 101]` under the stated preconditions.  
- The final output is always a non-negative integer under the stated preconditions.

7. Error Handling / Exceptional Behavior  
- No explicit error handling is performed.  
- If inputs are missing, non-integer, out of range, or violate endpoint ordering, the behavior is not defined by the code and may result in incorrect output or memory errors.

8. State Transitions (if applicable)  
- Not applicable.

9. Non-functional Constraints (if inferable)  
- Uses fixed, small bounded memory.  
- Runs in constant time with respect to input magnitude due to fixed iteration bounds (assuming preconditions hold).
