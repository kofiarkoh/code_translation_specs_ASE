# Code Specification

- **High-level description of the purpose**: The code reads two long integers, calculates their average, and prints the result if the sum is even.
- **What problem it solves**: It determines whether the average of two numbers can be computed as an integer and outputs that average if possible.
- **Core behavior**: The program checks if the sum of the two integers is even; if so, it computes and prints the average; otherwise, it outputs "IMPOSSIBLE".

- **Valid ranges or constraints**:

- **Assumptions about inputs**:
