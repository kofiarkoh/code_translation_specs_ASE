# Code Specification

## 1. Functional Description
- **High-level description of the purpose**: The code identifies the smallest contiguous subarray (window) within an array of integers that contains all integers from 1 to K at least once.
- **What problem it solves**: It addresses the problem of finding the minimum length of a subarray that includes all specified integers (from 1 to K) in a given array.
- **Core behavior**: The program reads an array of integers and determines the length of the smallest subarray that contains all integers from 1 to K. If such a subarray does not exist, it outputs 0.

## 2. Inputs
- **Parameters**:
  - `N`: The number of elements in the array.
  - `K`: The maximum integer that must be included in the subarray.
  - `a[]`: An array of integers of size N.
- **Data types**:
  - `N` and `K`: Integer (int).
  - `a[]`: Array of integers (int[]).
- **Valid ranges or constraints**:
  - `1 <= K <= N <= 100,000`
  - Elements of `a[]` can be any integer.
- **Assumptions about inputs**: The input is assumed to be well-formed, with integers provided in a valid format.

## 3. Outputs
- **Return values**: The program outputs the length of the smallest subarray containing all integers from 1 to K, or 0 if no such subarray exists.
- **Side effects**: The program prints the result to the standard output.
- **Output format/schema**: A single integer on a new line.

## 4. Preconditions
- **Conditions that must hold before execution**:
  - The input must contain valid integers for N and K.
  - The array must be populated with N integers.
- **Explicit logical constraints**: N must be greater than or equal to K for a valid subarray to exist.

## 5. Postconditions
- **Conditions guaranteed after execution**:
  - The program will output either the length of the smallest valid subarray or 0.
- **State changes**: The internal state of the frequency array `f[]` will be modified during execution.
- **Return guarantees**: The output will always be a non-negative integer.

## 6. Invariants
- **Conditions that must always remain true**:
  - The frequency array `f[]` maintains the count of occurrences of integers from 1 to K.
  - The variable `s` tracks the count of unique integers from 1 to K found in the current window.

## 7. Error Handling / Exceptional Behavior
- **What happens on invalid input?**: The program does not handle invalid input explicitly; it assumes well-formed input.
- **Exceptions thrown?**: No exceptions are thrown; the program may terminate unexpectedly on malformed input.
- **Edge-case behavior**: If N < K, the program outputs 0 immediately.

## 8. State Transitions (if applicable)
- **Valid object states**: The program maintains a state defined by the current indices `i` and `j`, the count of unique integers `s`, and the frequency array `f[]`.
- **State changes caused by execution**: The indices `i` and `j` are updated as the program iterates through the array, and the frequency counts in `f[]` are modified based on the elements processed.

## 9. Non-functional Constraints (if inferable)
- **Time complexity**: O(N), as the algorithm processes each element of the array a limited number of times.
- **Space complexity**: O(K), due to the frequency array `f[]` which stores counts for integers from 1 to K.
- **Performance assumptions**: The program is expected to perform efficiently within the constraints provided (up to 100,000 elements).
