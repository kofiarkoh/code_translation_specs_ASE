# Code Specification

- **High-level description of the purpose**: The code evaluates mathematical expressions containing integers and the operators `+`, `-`, and `*`, while considering the order of operations and parentheses.
- **What problem it solves**: It computes the maximum result obtainable from a given expression by evaluating all possible operator arrangements.
- **Core behavior**: The program reads a string representation of a mathematical expression, processes it to evaluate the result based on operator precedence, and outputs the maximum value.

## 2. Inputs
- **Parameters**: A single string input representing a mathematical expression.
- **Data types**: The input is a string (`char[]`).
- **Valid ranges or constraints**: The string can contain digits (0-9), operators (`+`, `-`, `*`), and parentheses (`(`, `)`).
- **Assumptions about inputs**: The input string is well-formed, meaning it contains valid characters and balanced parentheses.

## 3. Outputs
- **Return values**: The program outputs a single long long integer representing the maximum result of the evaluated expression.
- **Side effects**: The program prints the result to the standard output.
- **Output format/schema**: The output is a single line containing a long long integer.
