# Code Specification

## 1. Functional Description
- **High-level description of the purpose**: The code calculates the number of edges in a graph that are not part of any shortest path between any pair of vertices.
- **What problem it solves**: It identifies and counts the edges that do not contribute to the shortest paths in a weighted undirected graph.
- **Core behavior**: The program reads the number of vertices and edges, initializes a distance matrix, updates it based on edge weights, and then determines which edges are redundant in terms of shortest paths.

## 2. Inputs
- **Parameters**:
  - `N`: Number of vertices in the graph.
  - `M`: Number of edges in the graph.
  - `a[i]`, `b[i]`, `c[i]`: Arrays representing the edges, where `a[i]` and `b[i]` are the vertices connected by the edge, and `c[i]` is the weight of the edge.
- **Data types**:
  - `N`, `M`: `int`
  - `a`, `b`, `c`: `int[]`
  - `dist`: `int[][]`
- **Valid ranges or constraints**:
  - `N` must be greater than 0.
  - `M` must be greater than or equal to 0.
  - `a[i]`, `b[i]` must be in the range `[1, N]` (1-based indexing).
  - `c[i]` must be non-negative.
- **Assumptions about inputs**: The input is assumed to be well-formed and adheres to the specified constraints.

## 3. Outputs
- **Return values**: The program outputs a single integer representing the count of edges that are not part of any shortest path.
- **Side effects**: The program prints the result to the standard output.
- **Output format/schema**: The output is a single integer followed by a newline.

## 4. Preconditions
- **Conditions that must hold before execution**:
  - The input must be provided in the expected format.
  - The number of vertices `N` and edges `M` must be valid integers as per the constraints.
- **Explicit logical constraints**: The graph must be undirected, and the weights must be non-negative.

## 5. Postconditions
- **Conditions guaranteed after execution**:
  - The output will reflect the count of edges that do not contribute to any shortest path.
- **State changes**: The distance matrix `dist` will be populated with the shortest path distances between all pairs of vertices.
- **Return guarantees**: The output will always be a non-negative integer.

## 6. Invariants
- **Conditions that must always remain true**:
  - The distance from any vertex to itself is always zero (`dist[i][i] == 0`).
  - The distance between any two vertices is updated correctly based on the edges provided.

- **What happens on invalid input?**: The behavior is undefined; the program may produce incorrect results or crash.

- **Valid object states**: The program maintains a state represented by the distance matrix `dist` and the arrays `a`, `b`, and `c`.

- **Performance assumptions**: The algorithm is suitable for small to medium-sized graphs, given the cubic time complexity.
