# Code Specification

## 1. Functional Description
- **High-level description of the purpose**: The code calculates and outputs the c-th common divisor of two integers, a and b.
- **What problem it solves**: It identifies the c-th largest common divisor of two given integers, which can be useful in mathematical computations involving divisibility.
- **Core behavior**: The program reads two integers and a count, then iteratively finds common divisors and outputs the c-th one.

## 2. Inputs
- **Parameters**: 
  - `a`: First integer
  - `b`: Second integer
  - `c`: The index of the common divisor to retrieve
- **Data types**: 
  - All inputs are of type `int`.
- **Valid ranges or constraints**: 
  - `a`, `b`, and `c` should be positive integers (greater than 0).
- **Assumptions about inputs**: 
  - It is assumed that `c` is less than or equal to the number of common divisors of `a` and `b`.

## 3. Outputs
- **Return values**: The program outputs the c-th common divisor of `a` and `b`.
- **Side effects**: The program prints the result to the standard output.
- **Output format/schema**: The output is a single integer printed on a new line.

## 4. Preconditions
- **Conditions that must hold before execution**: 
  - The integers `a`, `b`, and `c` must be provided via standard input.
  - `a`, `b`, and `c` must be positive integers.
- **Explicit logical constraints**:
