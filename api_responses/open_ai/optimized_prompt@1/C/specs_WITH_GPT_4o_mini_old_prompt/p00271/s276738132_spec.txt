# Code Specification

## 1. Functional Description
- **High-level description of the purpose**: The code reads pairs of integers from user input and computes the difference between each pair.
- **What problem it solves**: It allows users to perform multiple subtractions of integer pairs in a single execution.
- **Core behavior**: The program iterates seven times, each time reading two integers, calculating their difference, and printing the result.

## 2. Inputs
- **Parameters**: 
  - Two integers, `a` and `b`.
- **Data types**: 
  - Both `a` and `b` are of type `int`.
- **Valid ranges or constraints**: 
  - No explicit constraints on the values of `a` and `b;` they can be any valid integer.
- **Assumptions about inputs**: 
  - The user will provide valid integer inputs for each pair.

## 3. Outputs
- **Return values**: 
  - The program returns an integer value of `0` upon successful completion.
- **Side effects**: 
  - The program prints the result of the subtraction of `b` from `a` for each pair of integers.
- **Output format/schema**: 
  - Each output is a single integer printed on a new line.
