# Code Specification

## 1. Functional Description
- **High-level description of the purpose**: The program reads a number of names associated with years and outputs the most recent name based on a given year threshold.
- **What problem it solves**: It identifies and returns the name that corresponds to the latest year that is less than or equal to a specified year.
- **Core behavior**: The program accepts two integers, `N` (number of names) and `Q` (year threshold), followed by `N` pairs of year and name inputs. It outputs the name associated with the most recent year that does not exceed `Q`.

## 2. Inputs
- **Parameters**:
  - `N`: Number of names (integer).
  - `Q`: Year threshold (integer).
  - Each subsequent input consists of a year (integer) and a name (string).
- **Data types**:
  - `N`: `int`
  - `Q`: `int`
  - `year`: `int`
  - `names[i]`: `char[32]`
- **Valid ranges or constraints**:
  - `N` should be a non-negative integer (0 ≤ N ≤ 49).
  - `Q` should be a non-negative integer (Q ≥ 0).
- **Assumptions about inputs**: It is assumed that the input format is correct and that names do not exceed 31 characters (plus a null terminator).

## 3. Outputs
- **Return values**: The program outputs a single string, which is the name associated with the most recent year ≤ `Q`.
- **Side effects**: The program prints the output to the standard output.
- **Output format/schema**: The output is a single line containing the name.

## 4. Preconditions
- **Conditions that must hold before execution**: 
  - The program must receive valid integer inputs for `N` and `Q`.
  - The number of names provided must match `N`.
- **Explicit logical constraints**: `N` must be ≤ 49 to fit within the allocated array size.

## 5. Postconditions
- **Conditions guaranteed after execution**: 
  - The program will output a name that corresponds to the most recent year ≤ `Q`.
- **State changes**: No state changes occur outside of local variables.
- **Return guarantees**: The output will always be a valid name from the input, or the initial name if no valid year is found.

## 6. Invariants
- **Conditions that must always remain true**: 
  - The `names` array will always contain valid strings, with the first entry initialized to "kogakubu10gokan".
- **Class-level invariants**: Not applicable as the code is not object-oriented.

## 7. Error Handling / Exceptional Behavior
- **What happens on invalid input?**: The program does not handle invalid input gracefully; it may lead to undefined behavior or incorrect output.
- **Exceptions thrown?**: No exceptions are explicitly thrown; behavior is undefined for invalid inputs.
- **Edge-case behavior**: If `N` is 0, the program will output "kogakubu10gokan" since no names are processed.

## 8. State Transitions (if applicable)
- **Valid object states**: Not applicable as there are no objects; only local variables are used.
- **State changes caused by execution**: The variable `answer` may change to point to different names based on the input years.

## 9. Non-functional Constraints (if inferable)
- **Time complexity**: O(N), where N is the number of names, as it processes each name once.
- **Space complexity**: O(1) for additional variables, O(N) for the names array.
- **Performance assumptions**: The program assumes that input operations are efficient and that the maximum number of names (49) is manageable within the constraints of typical input/output operations.
