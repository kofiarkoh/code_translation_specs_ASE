# Code Specification for AOJ 0334 Amidakuji

## 1. Functional Description
- **High-level description of the purpose**: The code implements a solution to the Amidakuji problem, which involves determining if a perfect matching exists in a bipartite graph constructed from input data.
- **What problem it solves**: It solves the problem of finding a perfect matching in a bipartite graph, where the graph is represented by connections between two sets of nodes based on user input.
- **Core behavior**: The program reads a matrix of connections, constructs a bipartite graph, and checks if a perfect matching exists. If it does, it outputs the matching; otherwise, it indicates that no matching is possible.

## 2. Inputs
- **Parameters**: 
  - `N`: The number of nodes in each partition of the bipartite graph.
  - A matrix of size `N x N` indicating connections between nodes.
- **Data types**: 
  - `N`: Integer (non-negative).
  - Matrix entries: Integer (0 or 1, indicating absence or presence of a connection).
- **Valid ranges or constraints**: 
  - `N` must be a non-negative integer.
  - The matrix must contain only binary values (0 or 1).
- **Assumptions about inputs**: The input is well-formed and adheres to the expected format.

## 3. Outputs

  - Outputs "no" if a perfect matching does not exist.
- **Side effects**: Outputs are printed to the standard output.
- **Output format/schema**:
