# Code Specification

## 1. Functional Description
- **High-level description of the purpose**: The code concatenates two input strings and checks if the second string is a substring of the concatenated result.
- **What problem it solves**: It determines the presence of one string within another after concatenation, which can be useful in various string manipulation scenarios.
- **Core behavior**: The program reads two strings, concatenates the first string with itself, and checks if the second string exists within this concatenated string.

- **Parameters**:

  - `str2`: Second input string.
- **Data types**: 
  - `str1` and `str2` are character arrays (strings).
- **Valid ranges or constraints**: 
  - `str1` can be up to 100 characters long.
  - `str2` can be up to 100 characters long.
- **Assumptions about inputs**:

- **Return values**: The program does not return a value; it outputs directly to the console.
- **Side effects**: Outputs "Yes" or "No" to the console based on the substring check.
- **Output format/schema**:
