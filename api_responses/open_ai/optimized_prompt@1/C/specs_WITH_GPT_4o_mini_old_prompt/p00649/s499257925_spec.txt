# Code Specification for Yanagi's Comic

## 1. Functional Description
- **High-level description of the purpose**: The code processes a series of rectangular regions defined by their corner coordinates and determines a specific order of processing based on their spatial relationships.
- **What problem it solves**: It solves the problem of ordering rectangles based on their vertical overlap and horizontal positioning, which can be useful in graphical applications or computational geometry.
- **Core behavior**: The program reads multiple sets of rectangles, sorts them, and recursively determines an order of processing based on their overlapping properties.

## 2. Inputs
- **Parameters**: 
  - Number of rectangles `n` (integer).
  - Coordinates of rectangles: `x1`, `y1`, `x2`, `y2` (integers).
- **Data types**: 
  - `int` for rectangle coordinates and identifiers.
  - `char` for tracking usage status of rectangles.
- **Valid ranges or constraints**: 
  - `n` must be a positive integer.
  - Rectangle coordinates must be within a reasonable range for integer values.
- **Assumptions about inputs**: 
  - Input is provided in a specific format where each rectangle's coordinates are given sequentially after the number of rectangles.

## 3. Outputs
- **Return values**: The function does not return a value; it outputs results directly to standard output.
- **Side effects**: Modifies the global `ans` array to store the order of rectangles.
- **Output format/schema**: Outputs the order of rectangles as integers, one per line, corresponding to their processing order.

## 4. Preconditions
- **Conditions that must hold before execution**: 
  - The input must be correctly formatted and contain valid integers.
  - The number of rectangles `n` must be greater than zero.
- **Explicit logical constraints**: 
  - The coordinates must represent valid rectangles (i.e., `x1` should not equal `x2` and `y1` should not equal `y2`).

  - The `ans` array will always have the same length as the number of rectangles processed.

- **What happens on invalid input?**: The program does not handle invalid input gracefully; it may lead to undefined behavior or incorrect output.
