# Code Specification

## 1. Functional Description
- **High-level description of the purpose**: The code counts the occurrences of the substring "ABC" in a given string, where the search is constrained to a specified number of characters.
- **What problem it solves**: It identifies and counts non-overlapping instances of the substring "ABC" within a user-defined portion of a string.
- **Core behavior**: The program reads an integer `n` and a string, then counts how many times the substring "ABC" appears in the first `n` characters of the string, ensuring that overlapping occurrences are not counted.

## 2. Inputs
- **Parameters**:
  - `n`: An integer indicating the number of characters to consider in the string.
  - `string`: A character array (string) of up to 50 characters.
- **Data types**:
  - `n`: `int`
  - `string`: `char[51]`
- **Valid ranges or constraints**:
  - `n` must be greater than or equal to 3 and less than or equal to 51.
  - The string must be null-terminated and can contain up to 50 characters.
- **Assumptions about inputs**:
  - The input string is properly formatted and does not exceed the specified length.

## 3. Outputs
- **Return values**: The program outputs an integer representing the count of non-overlapping occurrences of "ABC".
- **Side effects**: The program prints the count to the standard output.
- **Output format/schema**: The output is a single integer followed by a newline.

## 4. Preconditions
- **Conditions that must hold before execution**:
  - The input must include a valid integer `n` followed by a valid string.
- **Explicit logical constraints**:
  - `n` must be within the valid range (3 to 51).

## 5. Postconditions
- **Conditions guaranteed after execution**:
  - The output will reflect the count of "ABC" found in the first `n` characters of the string.
- **State changes**: No state changes occur outside of local variables.
- **Return guarantees**: The program will always return 0 upon successful completion.

## 6. Invariants
- **Conditions that must always remain true**: 
  - The string remains unchanged throughout the execution.
  - The count variable accurately reflects the number of "ABC" substrings found.

## 7. Error Handling / Exceptional Behavior
- **What happens on invalid input?**: The behavior is undefined if `n` is outside the valid range or if the string is improperly formatted.
- **Exceptions thrown?**: No exceptions are explicitly handled; the program may exhibit undefined behavior.
- **Edge-case behavior**: If `n` is less than 3, the program will not count any occurrences, and the output will be 0.

## 8. State Transitions (if applicable)
- **Valid object states**: The program operates in a single state during execution, processing input and producing output.
- **State changes caused by execution**: Local variables `count` and `i` are modified during execution, but no external state is affected.

## 9. Non-functional Constraints (if inferable)
- **Time complexity**: O(n), where n is the value of the input parameter `n`, as it iterates through the string.
- **Space complexity**: O(1), as it uses a fixed amount of additional space regardless of input size.
- **Performance assumptions**: The program assumes that input operations (scanf) and output operations (printf) are efficient and do not introduce significant delays.
