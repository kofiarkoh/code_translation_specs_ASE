# Code Specification

## 1. Functional Description
- **High-level description of the purpose**: The code implements a program that counts the occurrences of integers in an input array and computes the sum of the counts of the smallest `N-K` unique integers.
- **What problem it solves**: It addresses the problem of determining how many times each integer appears in a list and aggregates the counts of the smallest unique integers, excluding the largest `K` counts.
- **Core behavior**: The program reads an array of integers, counts their occurrences, sorts these counts, and sums the counts of the smallest `N-K` unique integers.

## 2. Inputs
- **Parameters**:
  - `N`: The number of integers in the input array.
  - `K`: The number of largest counts to exclude from the sum.
  - `A[]`: An array of integers of size `N`.
- **Data types**:
  - `N` and `K`: `int`
  - `A[]`: `int[]`
  - `c[]`: `long long[]` (to store counts)
- **Valid ranges or constraints**:
  - `N` must be a positive integer.
  - `K` must be a non-negative integer and less than or equal to `N`.
  - Elements of `A[]` should be non-negative integers.
- **Assumptions about inputs**: It is assumed that the input integers are within a range that can be indexed by the count array `c[]`.

## 3. Outputs
- **Return values**: The program outputs a single `long long` integer representing the sum of the counts of the smallest `N-K` unique integers.
- **Side effects**: The program prints the result to the standard output.
- **Output format/schema**: The output is a single line containing a long long integer.

## 4. Preconditions
- **Conditions that must hold before execution**:
  - The input must be provided in the expected format (two integers followed by `N` integers).
  - `N` must be greater than `K`.
- **Explicit logical constraints**: The input values must be valid integers as per the defined ranges.

## 5. Postconditions
- **Conditions guaranteed after execution**:
  - The program will have printed the sum of the counts of the smallest `N-K` unique integers.
- **State changes**: The count array `c[]` will be populated with the counts of each integer from the input array.
- **Return guarantees**: The output will be a valid long long integer representing the computed sum.

## 6. Invariants
- **Conditions that must always remain true**:
  - The count array `c[]` will always have a size of `N+1` and will be initialized to zero.
  - The values in `c[]` will represent the counts of integers from the input array `A[]`.

## 7. Error Handling / Exceptional Behavior
- **What happens on invalid input?**: The program does not handle invalid input gracefully; it may lead to undefined behavior or incorrect results.
- **Exceptions thrown?**: No explicit exceptions are thrown; however, invalid input may cause runtime errors.
- **Edge-case behavior**: If `K` equals `N`, the program will attempt to sum counts of zero unique integers, which may lead to a result of zero.

## 8. State Transitions (if applicable)
- **Valid object states**: The program maintains a state where the count array `c[]` is populated and sorted.
- **State changes caused by execution**: The state of the count array `c[]` changes as it is populated with counts and subsequently sorted.

## 9. Non-functional Constraints (if inferable)
- **Time complexity**: The overall time complexity is O(N log N) due to the merge sort operation.
- **Space complexity**: The space complexity is O(N) for the count array and temporary arrays used in the merge function.
- **Performance assumptions**: The program assumes that the input size `N` is manageable within the constraints of memory and processing time for typical use cases.
