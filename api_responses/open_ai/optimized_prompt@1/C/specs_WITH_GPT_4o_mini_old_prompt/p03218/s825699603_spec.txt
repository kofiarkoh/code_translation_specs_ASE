# Code Specification

## 1. Functional Description
- **High-level description of the purpose**: The code reads a list of integers, sorts them, and computes a product of the greatest common divisor (GCD) of each integer with its index, modulo a predefined constant.
- **What problem it solves**: It provides a way to compute a specific mathematical product based on the GCD of sorted integers and their respective indices.
- **Core behavior**: The program reads an integer \( N \), allocates an array of size \( N \), populates it with integers, sorts the array, and calculates the product of GCDs of each element with its index, returning the result modulo \( 998244353 \).

## 2. Inputs
- **Parameters**: 
  - \( N \): Number of integers to be processed.
  - \( A[i] \): The array of integers.
- **Data types**: 
  - \( N \): `long long`
  - \( A[i] \): `long long`
- **Valid ranges or constraints**: 
  - \( N \) must be a positive integer.
  - Each \( A[i] \) can be any integer representable by `long long`.
- **Assumptions about inputs**: 
  - The input for \( N \) is provided correctly and is within reasonable limits for memory allocation.

## 3. Outputs
- **Return values**: The program outputs a single `long long` integer, which is the computed product.
- **Side effects**: The program allocates memory for an array and prints the result to standard output.
- **Output format/schema**: The output is a single line containing the computed product.

## 4. Preconditions
- **Conditions that must hold before execution**: 
  - The input must be provided in the expected format.
  - Sufficient memory must be available for the allocation of the array.
- **Explicit logical constraints**: 
  - \( N > 0 \).

## 5. Postconditions

- **State changes**:
