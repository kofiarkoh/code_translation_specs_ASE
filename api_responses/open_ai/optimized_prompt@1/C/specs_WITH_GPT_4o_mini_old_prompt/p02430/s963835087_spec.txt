# Code Specification

## 1. Functional Description
- **High-level description of the purpose**: The code generates and prints all combinations of bit patterns of a specified length `n` that contain exactly `k` bits set to 1.
- **What problem it solves**: It provides a way to enumerate all subsets of a set of size `n` with exactly `k` elements, which can be useful in combinatorial problems.
- **Core behavior**: The program reads two integers from standard input, `n` and `k`, and outputs all integers from `0` to `2^n - 1` that have exactly `k` bits set to 1, along with the positions of those bits.

## 2. Inputs
- **Parameters**: 
  - `n`: The total number of bits (length of the bit pattern).
  - `k`: The number of bits that must be set to 1.
- **Data types**: 
  - `n` and `k` are of type `int`.
- **Valid ranges or constraints**: 
  - `n` should be a non-negative integer.
  - `k` should be a non-negative integer and less than or equal to `n`.
- **Assumptions about inputs**: 
  - The input values are provided in a valid format and within the specified ranges.

## 3. Outputs
- **Return values**: 
  - The functions return `0` on success and `-1` on failure for input reading functions.
- **Side effects**: 
  - The program prints output directly to standard output (console).
- **Output format/schema**: 
  - Each valid bit pattern is printed in the format: `pattern_index: position1 position2 ...`, where `pattern_index` is the integer representation of the bit pattern and `position1`, `position2`, etc., are the indices of the bits that are set to 1.

## 4. Preconditions
- **Conditions that must hold before execution**: 
  - The program must be executed in an environment where standard input is available.
  - The input must be provided in the expected format (two integers).

## 5. Postconditions
- **Conditions guaranteed after execution**: 
  - The program will have printed all valid combinations of bit patterns with exactly `k` bits set to 1.
- **State changes**: 
  - No persistent state changes occur; the program operates statelessly.
- **Return guarantees**: 
  - The program returns `0` upon successful completion.

## 6. Invariants
- **Conditions that must always remain true**: 
  - The values of `n` and `k` must remain within their defined ranges throughout the execution.
- **Class-level invariants**: 
  - Not applicable as the code does not define any classes.

## 7. Error Handling / Exceptional Behavior
- **What happens on invalid input?**: 
  - If input reading fails, the functions return `-1` or `0`, indicating an error.
- **Exceptions thrown?**: 
  - No exceptions are thrown; the program handles errors through return values.
- **Edge-case behavior**: 
  - If `k` is greater than `n`, no output will be generated since it's impossible to have more bits set than available.

## 8. State Transitions
- **Valid object states**: 
  - The program does not maintain state across function calls; it operates in a single execution context.
- **State changes caused by execution**: 
  - The only state change is the output printed to the console.

## 9. Non-functional Constraints
- **Time complexity**: 
  - The time complexity is O(2^n) in the worst case, as it generates all possible combinations of `n` bits.
- **Space complexity**: 
  - The space complexity is O(n) for storing the bit pattern and the positions of set bits during output.
- **Performance assumptions**: 
  - The program assumes that the input size is manageable within the constraints of the execution environment.
