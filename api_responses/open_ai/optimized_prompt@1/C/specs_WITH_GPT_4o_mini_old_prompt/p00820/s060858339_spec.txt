# Code Specification for Lagrange's Four-Square Theorem Implementation

## 1. Functional Description
- **High-level description of the purpose**: The code implements a solution to determine the number of ways a given integer can be expressed as the sum of four square numbers, in accordance with Lagrange's Four-Square Theorem.
- **What problem it solves**: It solves the problem of finding all possible combinations of four square integers that sum up to a specified integer \( n \).
- **Core behavior**: The function recursively calculates the number of representations of \( n \) as a sum of squares, incrementing a counter for each valid representation found.

## 2. Inputs
- **Parameters**:
  - `n`: The integer to be expressed as a sum of squares.
  - `c`: A counter for the number of squares used in the current representation.
  - `low`: The lower bound for the next integer to consider as a square.
- **Data types**:
  - All parameters are of type `int`.
- **Valid ranges or constraints**:
  - `n` must be a non-negative integer.
  - `c` must be less than or equal to 4 (as per the theorem).
  - `low` must be a positive integer.
- **Assumptions about inputs**:
  - The input integer \( n \) is read from standard input until a zero is encountered, which indicates termination.

## 3. Outputs
- **Return values**: The function returns an integer representing the number of ways \( n \) can be expressed as the sum of four squares.
- **Side effects**: The function prints the result to standard output.
- **Output format/schema**: The output is a single integer per line, corresponding to each input \( n \).
