# Code Specification for AOJ 1634 Balance Scale

## 1. Functional Description
- **High-level description of the purpose**: The code implements a solution to the "Balance Scale" problem, where it determines the minimum difference between a set of weights and a given set of values.
- **What problem it solves**: It identifies the closest weight that can balance a given set of values, minimizing the absolute difference.
- **Core behavior**: The program reads a list of values and a list of weights, computes all possible sums and differences of the weights, and checks which values can be matched or approximated by these computed sums.

- **Parameters**:

  - `m`: Number of weights.

  - `w[i]`: Array of weights (size `m`).
- **Data types**:

  - `a[]`, `w[]`: Integer arrays.
- **Valid ranges or constraints**:

- **Assumptions about inputs**: The input values are assumed to be within reasonable limits for processing (e.g., not exceeding typical integer limits).

## 3. Outputs
- **Return values**: The program outputs a single integer representing the minimum difference or `-1` if no suitable weight is found.
- **Side effects**: Outputs to standard output.
- **Output format/schema**: A single integer followed by a newline.
