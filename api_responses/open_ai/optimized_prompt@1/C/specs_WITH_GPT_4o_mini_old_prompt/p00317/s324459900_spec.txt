# Code Specification

## 1. Functional Description
- **High-level description of the purpose**: The code processes a list of words and their corresponding reversed forms, allowing for pattern matching with wildcards and counting the number of matches based on user input.
- **What problem it solves**: It enables users to search for words that match specific patterns, including the use of wildcards ('*' and '?'), in a predefined list of words.
- **Core behavior**: The program reads a set of words, sorts them, and then allows the user to input patterns to find how many words match those patterns, considering wildcards.

## 2. Inputs
- **Parameters**:
  - `N`: Number of words in the list.
  - `M`: Number of search queries.
  - `slate`: A string representing the search pattern.
- **Data types**:
  - `N` and `M`: `int`
  - `slate`: `char[]`
- **Valid ranges or constraints**:
  - `N` must be a positive integer (1 ≤ N ≤ 50000).
  - `M` must be a non-negative integer (0 ≤ M).
  - Each word length must not exceed 204 characters.
- **Assumptions about inputs**: Input is assumed to be well-formed, with valid characters for words and patterns.

## 3. Outputs
- **Return values**: The program outputs an integer for each search query, representing the count of matching words.
- **Side effects**: The program prints results to the standard output.
- **Output format/schema**: Each output is a single integer printed on a new line.

## 4. Preconditions
- **Conditions that must hold before execution**:
  - The input must provide valid integers for `N` and `M`.
  - The list of words must be populated before any search queries are processed.
- **Explicit logical constraints**: The words must be unique and properly formatted.

## 5. Postconditions
- **Conditions guaranteed after execution**:
  - The program will output the correct count of matching words for each query.
- **State changes**: The internal state of the program includes sorted lists of words and their reversed forms.
- **Return guarantees**: Each search query will yield a non-negative integer count.

## 6. Invariants
- **Conditions that must always remain true**:
  - The arrays `W` and `R` will always contain the same number of entries as specified by `N`.
  - The words in `W` and `R` will remain sorted after the sorting operation.

## 7. Error Handling / Exceptional Behavior
- **What happens on invalid input?**: The behavior on invalid input is not explicitly defined; the program may exhibit undefined behavior or crash.
- **Exceptions thrown?**: No exceptions are explicitly handled in the code.
- **Edge-case behavior**: If `N` is 0, the program may not function as intended since it expects at least one word.

## 8. State Transitions
- **Valid object states**: The program maintains a state where it has a list of words and their reversed forms, both sorted.
- **State changes caused by execution**: The state changes when words are read, sorted, and when search queries are processed.

## 9. Non-functional Constraints
- **Time complexity**: The sorting operation is O(N log N), and each search operation is O(log N) due to binary search.
- **Space complexity**: The program uses O(N) space for storing the words and their reversed forms.
- **Performance assumptions**: The program is expected to handle the upper limits of input sizes efficiently within reasonable time constraints.
