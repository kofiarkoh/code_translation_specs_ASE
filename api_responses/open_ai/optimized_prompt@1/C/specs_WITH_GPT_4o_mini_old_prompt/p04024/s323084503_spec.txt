# Code Specification

## 1. Functional Description
- **High-level description of the purpose**: The code processes a grid of characters to compute a specific mathematical result based on the arrangement of '#' characters within the grid.
- **What problem it solves**: It determines the number of valid configurations or arrangements based on the presence and distribution of '#' characters in a given grid, influenced by a parameter \( K \).
- **Core behavior**: The program reads dimensions and a grid, checks specific conditions related to the grid's borders, and computes a result using modular arithmetic and combinatorial logic.

## 2. Inputs
- **Parameters**:
  - `H`: Height of the grid (number of rows).
  - `W`: Width of the grid (number of columns).
  - `K`: A parameter influencing the output calculation.
- **Data types**: All inputs are of type `long long` (defined as `int` in the code).
- **Valid ranges or constraints**: 
  - \( H \geq 0 \)
  - \( W \geq 0 \)
  - \( K \geq 0 \)
- **Assumptions about inputs**: The grid is expected to be filled with characters, specifically '#' and other characters, and the dimensions \( H \) and \( W \) should be consistent with the input grid.

## 3. Outputs
- **Return values**: The program outputs a single `long long` integer result.
- **Side effects**: The program prints the result to the standard output.
- **Output format/schema**: The output is a single integer, representing the computed result based on the grid analysis.
