# Code Specification

## 1. Functional Description
- **High-level description of the purpose**: The program reads a list of names associated with years and outputs the most recent name based on a given year threshold.
- **What problem it solves**: It identifies and returns the name that corresponds to the latest year that is less than or equal to a specified year (Q).
- **Core behavior**: The program accepts two integers (N and Q) and a list of N names with their associated years, then outputs the name associated with the most recent year that does not exceed Q.

## 2. Inputs
- **Parameters**:
  - `N`: Number of names to read.
  - `Q`: Year threshold.
- **Data types**:
  - `N`: Integer.
  - `Q`: Integer.
  - `year`: Integer (associated with each name).
  - `names`: Array of strings (up to 50 names, each up to 31 characters).
- **Valid ranges or constraints**:
  - `N`: 1 ≤ N ≤ 50.
  - `Q`: Any integer value.
- **Assumptions about inputs**: The input for names and years is well-formed and does not exceed the defined limits.

## 3. Outputs
- **Return values**: The program outputs a single string (the name).
- **Side effects**: Outputs to standard output (console).
- **Output format/schema**: A single name string followed by a newline.

## 4. Preconditions
- **Conditions that must hold before execution**: 
  - The input must provide valid integers for N and Q.
  - The input must provide N pairs of integers (year) and strings (names).

## 5. Postconditions
- **Conditions guaranteed after execution**: 
  - The output is the name associated with the most recent year that is less than or equal to Q.
- **State changes**: No state changes occur outside of local variables.
- **Return guarantees**: The output will always be one of the names provided, or the initial name if no valid year is found.

## 6. Invariants
- **Conditions that must always remain true**: 
  - The array `names` will always contain at least one name.
  - The variable `answer` will always point to a valid name from the `names` array.

## 7. Error Handling / Exceptional Behavior
- **What happens on invalid input?**: The program does not handle invalid input gracefully; it may lead to undefined behavior or incorrect output.
- **Exceptions thrown?**: No exceptions are thrown; the program relies on correct input.
- **Edge-case behavior**: If no years are less than or equal to Q, the output will be the first name in the list.

## 8. State Transitions (if applicable)
- **Valid object states**: The program operates in a single state with local variables.
- **State changes caused by execution**: The variable `answer` may change to point to different names based on the input years.

## 9. Non-functional Constraints (if inferable)
- **Time complexity**: O(N), where N is the number of names.
- **Space complexity**: O(1) for additional variables, O(N) for the names array.
- **Performance assumptions**: The program is expected to perform efficiently within the constraints of N ≤ 50.
