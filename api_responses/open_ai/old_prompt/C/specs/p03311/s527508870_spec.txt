# Code Specification

## 1. Functional Description
- **High-level description of the purpose**: The code reads a sequence of integers, processes them to compute a minimum "sadness" value based on their adjusted differences, and outputs this value.
- **What problem it solves**: It calculates a minimum value representing a form of "sadness" based on the differences between adjusted integers in a list.
- **Core behavior**: The program adjusts each integer by subtracting its index, sorts the adjusted integers, and computes the minimum sadness based on the differences between these integers.

- **Parameters**: 
  - `n`: The number of integers to be processed.
  - `a[]`: An array of integers to be adjusted and analyzed.
- **Data types**: 
  - `n`: `long`
  - `a[]`: Array of `long`
- **Valid ranges or constraints**: 
  - `n` must be a positive integer (greater than 0).

- **Assumptions about inputs**:

- **Side effects**: The program prints the result to the standard output.
- **Output format/schema**: The output is a single line containing a `long` integer.
