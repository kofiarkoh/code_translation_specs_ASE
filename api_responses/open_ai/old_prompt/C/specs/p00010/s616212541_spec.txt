# Code Specification

## 1. Functional Description
- **High-level description of the purpose**: The code calculates the circumcenter and circumradius of a triangle defined by three points in a 2D space.
- **What problem it solves**: It determines the center and radius of the circle that passes through all three vertices of a triangle, which is useful in various geometric and computational applications.
- **Core behavior**: For a given number of triangles, the program reads the coordinates of their vertices, computes the circumcenter and circumradius, and outputs these values.

## 2. Inputs
- **Parameters**: 
  - `n`: Number of triangles to process.
  - `x1, y1, x2, y2, x3, y3`: Coordinates of the triangle vertices.
- **Data types**: 
  - `n`: `int`
  - `x1, y1, x2, y2, x3, y3`: `double`
- **Valid ranges or constraints**: 
  - `n` must be a positive integer.
  - Coordinates can be any real number (no explicit constraints).
- **Assumptions about inputs**: 
  - The input for `n` is provided correctly as an integer.
  - The triangle formed by the three points is non-degenerate (i.e., the points are not collinear).

## 3. Outputs
- **Return values**: The program does not return a value; it outputs results directly to the console.
- **Side effects**: Outputs the circumcenter coordinates and circumradius for each triangle to standard output.
- **Output format/schema**: Each output line contains three `double` values formatted to three decimal places: `px`, `py`, and `r`.

## 4. Preconditions
- **Conditions that must hold before execution**: 
  - The program must receive valid input for `n` and the triangle coordinates.
  - The input must be provided in the expected format.
- **Explicit logical constraints**: 
  - The triangle must not be degenerate (the three points must not be collinear).

## 5. Postconditions
- **Conditions guaranteed after execution**: 
  - The circumcenter coordinates (`px`, `py`) and circumradius (`r`) are calculated and printed for each triangle.
- **State changes**: No internal state changes; the program operates statelessly.
- **Return guarantees**: Outputs are guaranteed to be formatted to three decimal places.

## 6. Invariants
- **Conditions that must always remain true**: 
  - The values of `px`, `py`, and `r` are computed based on the input coordinates and are valid geometric representations of the circumcenter and circumradius.

## 7. Error Handling / Exceptional Behavior
- **What happens on invalid input?**: The program does not handle invalid input gracefully; it may produce undefined behavior or incorrect results.
- **Exceptions thrown?**: No exceptions are explicitly handled; the program assumes valid input.
- **Edge-case behavior**: If the points are collinear, the calculations may lead to division by zero or incorrect circumcenter/radius values.

## 8. State Transitions (if applicable)
- **Valid object states**: Not applicable; the program does not maintain state across executions.
- **State changes caused by execution**: No state changes occur; the program is stateless.

## 9. Non-functional Constraints (if inferable)
- **Time complexity**: O(n) where n is the number of triangles, as each triangle's circumcenter and circumradius are computed in constant time.
- **Space complexity**: O(1) as the program uses a fixed amount of space regardless of the input size.
- **Performance assumptions**: The program assumes that the input can be processed in a reasonable time frame for typical values of `n`.
