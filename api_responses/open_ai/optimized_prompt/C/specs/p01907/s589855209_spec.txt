- A double value representing a probability factor.  
- A non-negative integer representing the number of nodes in the tree.  
- A series of triplets, each consisting of two integers (representing connected nodes) and a third integer (representing the cost of the edge connecting them).

3. **Outputs**  
- A double value representing the weighted sum of costs adjusted by the depth of each node, formatted to ten decimal places.

- The number of nodes must be a non-negative integer.  
- The input values for node connections and costs must be valid integers.  
- The tree must be connected, meaning all nodes can be reached from the root.

5. **Postconditions**  
- The output value is computed based on the costs associated with each node and their respective depths, influenced by the probability factor.

- The depth of each node is non-negative.  
- The probability factor is a non-negative double.  
- The costs associated with edges are non-negative integers.
