1. **Functional Description**  
   The program calculates the area difference between a polygon defined by a series of vertices and a rectangular bounding box defined by four corner points. It processes multiple sets of polygon data until a termination condition is met.

2. **Inputs**  
   - A series of integers representing the number of vertices of a polygon followed by pairs of integers for the coordinates of each vertex.
   - Four additional pairs of integers representing the coordinates of the corners of a bounding box.

3. **Outputs**  
   - For each polygon input, the program outputs a single integer representing the area difference between the polygon and the bounding box.

4. **Preconditions**  
   - The input must start with a positive integer indicating the number of vertices.
   - Each vertex must be defined by a pair of integers.
   - The bounding box must be defined by exactly four pairs of integers.

5. **Postconditions**  
   - The output is a long long integer representing the calculated area difference for each polygon input.
   - The program continues to process inputs until a non-positive integer is encountered.

6. **Invariants**  
   - The coordinates of the vertices and bounding box corners are maintained within the defined limits throughout the calculations.
   - The area calculations are based on the current state of the vertices and bounding box inputs.

7. **Error Handling / Exceptional Behavior**  
   - If the input does not conform to the expected format (e.g., non-integer values), the behavior is not defined.
   - The program does not handle negative or zero values for the number of vertices gracefully; it terminates processing upon encountering such values.

8. **State Transitions (if applicable)**  
   - The program transitions from reading input data to processing the area calculations and finally to outputting results for each polygon until termination.

9. **Non-functional Constraints (if inferable)**  
   - The program is expected to handle multiple sets of input efficiently, with performance dependent on the number of vertices and the complexity of the polygon shapes.
