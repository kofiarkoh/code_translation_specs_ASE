1. **Functional Description**  
The program computes the minimum number of moves required to reach a target position from a starting position on a grid, where movement is constrained by a maximum step size and obstacles.

2. **Inputs**  
- Two integers representing the height and width of the grid.  
- An integer representing the maximum step size.  
- Four integers representing the starting position and the target position on the grid.

3. **Outputs**  
- An integer representing the minimum number of moves required to reach the target position from the starting position. If the target is unreachable, it outputs -1.

4. **Preconditions**  
- The grid dimensions are positive integers.  
- The starting and target positions are within the bounds of the grid.  
- The grid contains valid characters representing either free spaces or obstacles.

5. **Postconditions**  
- The output is either a non-negative integer indicating the minimum moves or -1 if the target position is unreachable.

6. **Invariants**  
- The distance array maintains the minimum number of moves required to reach each position on the grid, initialized to a predefined constant for unreachable positions.

7. **Error Handling / Exceptional Behavior**  
- If the input values for grid dimensions or positions are invalid (e.g., out of bounds), the behavior is not defined.  
- If the grid contains invalid characters, the behavior is not defined.

8. **State Transitions (if applicable)**  
- The state transitions occur as the program explores the grid, updating the distance array and queue based on valid moves from the current position.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a time complexity that is dependent on the grid size and the maximum step size, ensuring efficient exploration of reachable positions.
