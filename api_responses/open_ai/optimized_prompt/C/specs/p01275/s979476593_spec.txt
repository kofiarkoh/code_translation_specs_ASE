1. **Functional Description**  
The program calculates the minimum number of rotations required to transform an initial sequence of digits into a target sequence of digits, considering the digits as circular values (0-9). It reads multiple test cases until a termination condition is met.

2. **Inputs**  
- An integer representing the number of digits, `n`, where `1 <= n <= 10`.  
- Two strings of digits, `init` and `unlock`, each of length `n`.

3. **Outputs**  
- For each test case, the program outputs the minimum number of rotations required to match the `init` sequence to the `unlock` sequence. If the sequences are identical, it outputs `0`.

4. **Preconditions**  
- The input integer `n` must be positive and less than or equal to 10.  
- The strings `init` and `unlock` must consist of valid digit characters (0-9) and must be of length `n`.

5. **Postconditions**  
- The output is a non-negative integer representing the minimum rotations needed. If the sequences are identical, the output is `0`.

6. **Invariants**  
- The difference array, derived from the `init` and `unlock` sequences, remains valid throughout the calculations, representing the necessary adjustments for each digit.

7. **Error Handling / Exceptional Behavior**  
- If the input integer `n` is `0`, the program terminates without processing further input.  
- If the input strings do not match the expected format (e.g., non-digit characters), behavior is not defined.

8. **State Transitions (if applicable)**  
- The program transitions between states based on the input values, processing each test case until a termination condition is met. The state includes the current difference array and the accumulated rotation count.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a time complexity that is manageable for the input size, given the constraints on `n`. The maximum number of operations is limited by the nested processing of the difference array.
