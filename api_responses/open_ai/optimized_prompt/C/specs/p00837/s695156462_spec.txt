1. **Functional Description**  
The program simulates a book replacement system for students using a fixed number of desks. It processes requests for books, manages their allocation, and calculates a total cost based on the desk assignments.

2. **Inputs**  
- A series of test cases, each consisting of three integers: the number of desks, the capacity of each desk, and the number of students.  
- For each student, a sequence of integers representing the IDs of the books they request.

3. **Outputs**  
- For each test case, the program returns a single integer representing the total cost incurred for book replacements.

4. **Preconditions**  
- The number of desks, capacity, and number of students must be positive integers.  
- The total number of book requests does not exceed the maximum capacity of the desks.

5. **Postconditions**  
- The program guarantees that all book requests are processed, and the total cost is calculated based on the desk assignments and replacements made during the process.

6. **Invariants**  
- At any point, the number of books on each desk does not exceed its capacity.  
- Each book ID is uniquely associated with a desk and its position on that desk.

7. **Error Handling / Exceptional Behavior**  
- If the input values for desks, capacity, or students are invalid (e.g., non-positive), the program terminates without processing further.  
- The program does not handle cases where the number of book requests exceeds the total capacity of the desks.

8. **State Transitions (if applicable)**  
- The state transitions occur as books are assigned to desks, replaced, or removed based on student requests, affecting the total cost and the configuration of books on desks.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a time complexity that allows for sorting and processing of requests efficiently, suitable for the given constraints on the number of desks and students.  
- Memory usage is constrained by the fixed sizes of arrays used for desks and books, ensuring that it operates within predefined limits.
