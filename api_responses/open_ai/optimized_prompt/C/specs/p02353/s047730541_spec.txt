1. **Functional Description**  
The code implements a segment tree to manage and query a range of integers. It supports two primary operations: updating a range of values and retrieving the sum of values within a specified range.

2. **Inputs**  
- Two integers representing the number of elements and the number of queries.
- For each query, an integer indicating the command type (update or get sum), followed by two integers representing the start and end of the range. If the command is an update, an additional integer specifying the value to update the range with is also provided.

3. **Outputs**  
- For each "get sum" command, the code returns the sum of the specified range, printing each result on a new line.

4. **Preconditions**  
- The number of elements must be greater than zero.
- The number of queries must be non-negative.
- The ranges specified in the queries must be valid within the bounds of the number of elements.

5. **Postconditions**  
- After processing all queries, the segment tree reflects the updated values for any ranges that were modified.
- The output contains the correct sums for all "get sum" queries based on the current state of the segment tree.

6. **Invariants**  
- The segment tree maintains the correct lazy propagation state, ensuring that updates are applied only when necessary.
- The sum of values in any queried range is accurately represented in the segment tree.

7. **Error Handling / Exceptional Behavior**  
- If invalid input is provided (e.g., non-integer values), behavior is not defined.
- If the range specified in a query is out of bounds, the function will not perform any updates or return sums for that query.

8. **State Transitions (if applicable)**  
- The state transitions occur during the execution of update and get sum commands, modifying the segment tree's internal structure and values based on the operations performed.

9. **Non-functional Constraints (if inferable)**  
- The implementation is expected to handle a maximum of 100,000 queries efficiently.
- The segment tree is designed to operate within the constraints of memory and performance suitable for the specified maximum input sizes.
