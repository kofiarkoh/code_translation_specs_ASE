1. **Functional Description**  
The program computes the minimum number of transitions required to move from a starting point marked by a specific character to the edges of a grid, where each transition is counted based on the character type encountered.

2. **Inputs**  
The program reads multiple pairs of integers representing the width and height of a grid, followed by the grid itself, which consists of characters. The input terminates when both width and height are zero.

3. **Outputs**  
The program outputs the minimum number of transitions required to reach any edge of the grid from the starting point. Each transition is counted based on character changes.

4. **Preconditions**  
- The width and height of the grid must be positive integers or zero to terminate input.
- The grid must contain at least one starting point marked by a specific character.

5. **Postconditions**  
- The output is a non-negative integer representing the minimum number of transitions to reach the grid's edge from the starting point.

6. **Invariants**  
- The grid remains unchanged throughout the execution of the program.
- The transition count for each cell is updated based on the character type encountered.

7. **Error Handling / Exceptional Behavior**  
- If the input grid dimensions are zero, the program terminates without processing further.
- The program does not handle invalid characters or malformed input; behavior is not defined in such cases.

8. **State Transitions (if applicable)**  
- The program transitions through the grid based on the current position and character type, updating the transition count and exploring neighboring cells.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a fixed memory limit for the grid size (maximum 101x101).
- The execution time is dependent on the grid size and the number of transitions processed.
