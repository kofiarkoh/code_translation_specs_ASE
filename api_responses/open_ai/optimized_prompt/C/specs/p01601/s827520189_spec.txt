1. **Functional Description**  
The program identifies and outputs the nearest palindrome integer to a given input integer.

2. **Inputs**  
The program reads a single integer value from standard input.

3. **Outputs**  
The program outputs the nearest palindrome integer to the standard output.

4. **Preconditions**  
The input integer must be a non-negative integer.

5. **Postconditions**  
The output is guaranteed to be a palindrome integer that is closest to the input integer. If two palindromes are equidistant, the smaller one is selected.

6. **Invariants**  
The program maintains the property that the current candidate for the nearest palindrome is either the input integer or an integer incremented or decremented from it.

Not inferable from code.

8. **State Transitions (if applicable)**  
The program transitions between states by incrementing or decrementing a counter to explore potential palindrome candidates.
