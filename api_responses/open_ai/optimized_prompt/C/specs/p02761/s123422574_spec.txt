1. **Functional Description**  
The program computes a numerical value based on input parameters that represent digits and their corresponding values. It handles special cases for zero digits and ensures that the constructed number adheres to specified constraints.

2. **Inputs**  
- Two integers, N and M, where N represents the number of digits and M represents the number of digit-value pairs.
- M pairs of integers, each consisting of a digit position and its corresponding value.

3. **Outputs**  
- Returns a computed integer value based on the inputs.
- If certain conditions are met, outputs "-1" as a string.

4. **Preconditions**  
- N must be a positive integer.
- M must be a non-negative integer.
- The digit positions provided in the M pairs must be valid indices within the range of 1 to N.

5. **Postconditions**  
- If M is zero, the output is determined solely by the value of N.
- If M is greater than zero, the output is the sum of the values assigned to the specified digit positions, or -1 if there is a conflict in the values.

6. **Invariants**  
- The digit array is initialized to -1 for all positions.
- Each digit position can only be assigned a value once; subsequent assignments to the same position must match the initial value.

7. **Error Handling / Exceptional Behavior**  
- If M is zero and N is greater than 3, the output is not defined.
- If a digit position is assigned a conflicting value, the output is set to -1.
- If the first digit is specified as zero when N is greater than 1, the output is "-1".

8. **State Transitions (if applicable)**  
- The state transitions occur based on the input values and the conditions checked during processing, leading to either a valid number computation or an error state.

9. **Non-functional Constraints (if inferable)**  
- The program must handle input and output efficiently, ensuring that the operations complete in a reasonable time frame relative to the size of N and M.
