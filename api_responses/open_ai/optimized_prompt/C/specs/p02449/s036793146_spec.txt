1. **Functional Description**  
The program reads a sequence of integers and computes both the previous and next permutations of that sequence, printing each permutation along with the original sequence.

2. **Inputs**  
The program reads an integer \( n \) representing the number of elements in the sequence, followed by \( n \) integers that make up the sequence.

3. **Outputs**  
The program outputs three lines:  
- The previous permutation of the sequence, if it exists; otherwise, no output for this line.  
- The original sequence.  
- The next permutation of the sequence, if it exists; otherwise, no output for this line.

4. **Preconditions**  
- The input integer \( n \) must be between 1 and 9, inclusive.  
- The sequence must consist of \( n \) integers.

5. **Postconditions**  
- If \( n = 1 \), the output will be "1" followed by the original sequence.  
- If a previous permutation exists, it is printed; otherwise, nothing is printed for that line.  
- The original sequence is always printed.  
- If a next permutation exists, it is printed; otherwise, nothing is printed for that line.

6. **Invariants**  
- The original sequence remains unchanged throughout the execution of the program.  
- The previous and next permutations, if computed, are valid permutations of the original sequence.

7. **Error Handling / Exceptional Behavior**  
- If \( n \) is less than 1 or greater than 9, the behavior is not defined.  
- If the input is not an integer, the program may not behave as expected, but this is not explicitly handled.

8. **State Transitions (if applicable)**  
- The program transitions from reading input to computing permutations, and finally to outputting results.  
- The state of the sequence changes only when computing the previous or next permutations.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a time complexity that is manageable for \( n \) up to 9, ensuring prompt output for valid inputs.
