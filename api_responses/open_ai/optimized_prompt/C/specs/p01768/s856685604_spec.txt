1. **Functional Description**  
The program initializes a graph structure representing ingredients and their associated costs, builds connections between them, and computes the minimum cost of each ingredient based on its connections. It returns the total minimum cost across all ingredients.

2. **Inputs**  
- An integer representing the number of ingredients.  
- A list of ingredient names (up to 10 characters each) and their associated costs.  
- An integer representing the number of connections between ingredients.  
- Pairs of ingredient names representing connections.

3. **Outputs**  
- An integer representing the total minimum cost of all ingredients, printed to standard output.

4. **Preconditions**  
- The number of ingredients is a positive integer.  
- Each ingredient name is unique and does not exceed 10 characters.  
- The cost associated with each ingredient is a non-negative integer.  
- The number of connections is a non-negative integer.

5. **Postconditions**  
- The total minimum cost of all ingredients is calculated and printed.  
- Each ingredient's minimum cost is updated based on its connections.

6. **Invariants**  
- The graph structure maintains valid connections between ingredients.  
- The size of each adjacency list does not exceed its capacity.  
- The minimum cost for each ingredient is correctly computed based on its reachable connections.

7. **Error Handling / Exceptional Behavior**  
- If an ingredient name is not found during connection addition, the behavior is not defined.  
- Memory allocation failures during initialization or connection addition may lead to undefined behavior.

8. **State Transitions (if applicable)**  
- The state transitions occur during the addition of connections and the computation of minimum costs, where the state of the adjacency list and the minimum cost values are updated.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a fixed maximum number of ingredients (5000).  
- Memory usage is proportional to the number of ingredients and connections, with potential doubling of adjacency list capacity as needed.
