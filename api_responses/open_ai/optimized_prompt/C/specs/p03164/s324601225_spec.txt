1. **Functional Description**  
The program computes the maximum value of a knapsack that can be achieved without exceeding a specified weight limit, given a set of items with associated weights and values.

2. **Inputs**  
- Two integers representing the number of items and the maximum weight capacity of the knapsack.
- For each item, two integers representing the weight and value of the item.

3. **Outputs**  
- The maximum value that can be achieved without exceeding the weight limit, or an error message if no valid configuration exists.

4. **Preconditions**  
- The input must consist of valid integers for the number of items, maximum weight, and each item's weight and value.
- The number of items must be non-negative and within the bounds of the defined array size.

5. **Postconditions**  
- If a valid configuration exists, the output will be the maximum value that can be achieved without exceeding the weight limit.
- If no valid configuration exists, an error message will be output.

6. **Invariants**  
- The array used to track the minimum weights for each possible value remains consistent throughout the execution, ensuring that it only contains valid weight configurations.

7. **Error Handling / Exceptional Behavior**  
- The program will terminate with a return code indicating failure if the input format is incorrect or if the number of items exceeds the predefined limit.

8. **State Transitions (if applicable)**  
- The state transitions occur as the program processes each item, updating the array that tracks the minimum weights for each possible value based on the current item being considered.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a fixed memory limit defined by the constant for the maximum weight, which may affect performance and scalability.
