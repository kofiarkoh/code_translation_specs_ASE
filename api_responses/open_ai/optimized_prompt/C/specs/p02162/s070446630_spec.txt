1. **Functional Description**  
The program determines and outputs the winner of a game based on two sets of scores. It compares two time values and two result values to decide the outcome, which can be either "Alice", "Bob", or "Draw".

2. **Inputs**  
The program reads four integer values representing two time values and two result values.

3. **Outputs**  
The program outputs a string indicating the winner ("Alice", "Bob", or "Draw") based on the input values.

4. **Preconditions**  
The program requires exactly four integer values to be provided as input. The result values must be non-negative integers for the second comparison.

5. **Postconditions**  
The program guarantees that one of the three strings ("Alice", "Bob", or "Draw") is output based on the comparison of the input values.

6. **Invariants**  
The program maintains that the output is determined solely by the input values and follows the specified comparison logic.

7. **Error Handling / Exceptional Behavior**  
If fewer than four integer values are provided as input, the program terminates without producing output. If the result values are negative, the program still produces an output based on the time values.

8. **State Transitions (if applicable)**  
Not applicable.

9. **Non-functional Constraints (if inferable)**  
The program must complete execution in a timely manner, with output produced immediately after input is processed.
