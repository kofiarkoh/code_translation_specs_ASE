1. **Functional Description**  
   The program calculates the maximum value obtainable from a fractional knapsack problem given a set of items with specific weights and values, allowing for the inclusion of fractional parts of items.

2. **Inputs**  
   - An integer representing the number of items.  
   - A double representing the total weight capacity of the knapsack.  
   - For each item, an integer representing the weight and an integer representing the value.

3. **Outputs**  
   - A double representing the maximum value that can be obtained, printed to standard output.

4. **Preconditions**  
   - The number of items is a non-negative integer.  
   - The total weight capacity is a non-negative double.  
   - Each item's weight and value are integers, where weight can be negative, and value can be zero or negative.

5. **Postconditions**  
   - The output value is the maximum obtainable value based on the provided weights and values, adhering to the knapsack capacity constraints.

6. **Invariants**  
   - The total weight of selected items does not exceed the specified weight capacity.  
   - The value of selected items is maximized based on their weight-to-value ratio.

7. **Error Handling / Exceptional Behavior**  
   - Items with non-positive values and positive weights are ignored.  
   - Items with negative weights and positive values are treated as adding value to the total while reducing the weight capacity.

8. **State Transitions (if applicable)**  
   - The state transitions involve updating the total weight capacity and the accumulated value as items are processed and selected for inclusion in the knapsack.

9. **Non-functional Constraints (if inferable)**  
   - The program must handle up to 100,000 items efficiently, ensuring that sorting and selection operations are performed within acceptable time limits.  
   - The output value is formatted as a double with precision, ensuring clarity in representation.
