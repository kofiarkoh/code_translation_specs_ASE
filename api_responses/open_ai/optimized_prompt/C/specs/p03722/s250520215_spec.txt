1. **Functional Description**  
   The program computes the minimum cost to reach a specified node in a directed graph with weighted edges, detecting negative cycles that may affect the result.

2. **Inputs**  
   - Two integers representing the number of nodes and the number of edges in the graph.
   - A series of triplets representing directed edges, where each triplet consists of two integers (source node, destination node) and an integer (cost of the edge).

3. **Outputs**  
   - The minimum cost to reach the specified node from the starting node, or "inf" if the cost is affected by a negative cycle.

4. **Preconditions**  
   - The number of nodes and edges must be non-negative integers.
   - The edges must be valid, with node indices within the range defined by the number of nodes.

5. **Postconditions**  
   - If no negative cycle affects the path to the specified node, the output is the negative of the minimum cost.
   - If a negative cycle is detected that can influence the path to the specified node, the output is "inf".

6. **Invariants**  
   - The minimum cost to reach each node is updated iteratively based on the edges processed.
   - The minimum cost for each node remains less than a predefined upper limit unless a negative cycle is detected.

8. **State Transitions (if applicable)**  
   - The state transitions occur as the minimum costs for nodes are updated based on the edges processed in each iteration.
