1. **Functional Description**  
The program processes a series of input strings representing paths through a predefined mapping of cities. It determines if the final city reached after following the path is a specific target city.

2. **Inputs**  
The program reads multiple strings from standard input, each representing a sequence of digits. Input terminates when a string starting with the character '#' is encountered.

3. **Outputs**  
For each input string, the program outputs "Yes" if the final city reached is the target city; otherwise, it outputs "No". The output is printed to standard output.

4. **Preconditions**  
Each input string must consist solely of digits representing valid transitions, and the input must not exceed a length of 109 characters (excluding the null terminator).

5. **Postconditions**  
The program guarantees that for each valid input string, it will output either "Yes" or "No" based on whether the final city reached is the target city.

6. **Invariants**  
The mapping of cities remains constant throughout the execution of the program. The program maintains a valid state of the current city based on the transitions defined in the mapping.

7. **Error Handling / Exceptional Behavior**  
If an input string contains invalid characters (non-digit characters), the program will terminate the path processing prematurely without producing an output for that string. The program does not handle malformed input explicitly.

8. **State Transitions (if applicable)**  
The program transitions between states (cities) based on the digits read from the input string, following the predefined mapping until an invalid transition is encountered or the end of the string is reached.

9. **Non-functional Constraints (if inferable)**  
The program operates in a loop until a termination condition is met, and it processes each input string in a linear fashion, ensuring that the time complexity is proportional to the length of the input strings. The program does not impose constraints on the number of input strings processed, aside from the termination condition.
