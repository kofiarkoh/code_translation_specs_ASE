1. **Functional Description**  
The program reads a sequence of integers, sorts them in ascending order using a specific sorting algorithm, and counts the number of swaps made during the sorting process. It continues to process sequences until a terminating condition is met.

2. **Inputs**  
The program reads multiple sequences of integers from standard input. Each sequence begins with an integer indicating the number of elements, followed by the elements themselves. The input terminates when a zero is read as the number of elements.

3. **Outputs**  
The program outputs the total number of swaps made during the sorting of each sequence to standard output, with each count printed on a new line.

4. **Preconditions**  
The input must consist of valid integers. The first integer of each sequence must be non-negative, and the sequence must contain at least one integer (greater than zero) to be processed.

5. **Postconditions**  
After processing each sequence, the program guarantees that the output reflects the total number of swaps made during the sorting of that sequence.

6. **Invariants**  
Throughout the execution, the program maintains that the array of integers is progressively sorted with each swap operation, and the swap count accurately reflects the number of swaps performed.

7. **Error Handling / Exceptional Behavior**  
The program does not explicitly handle erroneous input. If non-integer values are provided, the behavior is undefined. The program assumes valid input as per the preconditions.

8. **State Transitions (if applicable)**  
The program transitions between states based on the input read. It moves from an initial state (waiting for input) to a processing state (sorting and counting swaps) and finally to an output state (printing the swap count) for each sequence until termination.

9. **Non-functional Constraints (if inferable)**  
The program is expected to operate within a reasonable time frame for small to moderate input sizes, as it employs a sorting algorithm with a time complexity that is dependent on the number of elements in the input sequence. The maximum number of elements is constrained to 100.
