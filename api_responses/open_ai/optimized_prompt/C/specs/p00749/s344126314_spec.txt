1. **Functional Description**  
The program analyzes a grid representation of a structure to determine if it is "STABLE" or "UNSTABLE" based on specific connectivity and geometric properties of the filled cells.

2. **Inputs**  
The program reads multiple grids defined by their width and height, followed by the grid contents, where each cell is either filled or empty.

3. **Outputs**  
The program outputs either "STABLE" or "UNSTABLE" for each grid based on the analysis of the filled cells.

4. **Preconditions**  
- The width and height of the grid must be positive integers.
- The grid must consist of valid characters representing filled and empty cells.

5. **Postconditions**  
- The program guarantees that it will output a stability status ("STABLE" or "UNSTABLE") for each grid processed.

6. **Invariants**  
- The relationships between filled cells are maintained throughout the processing, ensuring that connectivity is accurately represented.
- The geometric properties of the filled cells are consistently updated during the analysis.

7. **Error Handling / Exceptional Behavior**  
- If the input width is zero or negative, the program terminates without processing further grids.
- The program does not handle malformed input explicitly; it assumes valid input as per the preconditions.

8. **State Transitions (if applicable)**  
- The program transitions through states of reading input, processing the grid, and determining stability, with each state leading to the next based on successful completion of the previous state.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a fixed memory limit defined by the maximum grid size and the number of filled cells, ensuring efficient use of resources.
