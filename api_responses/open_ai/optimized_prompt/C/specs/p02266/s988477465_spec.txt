1. **Functional Description**  
The program processes a sequence of characters to calculate and output the total area and count of pools formed by the characters, while managing a stack to track the heights of the characters.

2. **Inputs**  
The program reads a sequence of characters from standard input, which may include the characters '\\', '_', and '/'.

3. **Outputs**  
The program outputs three values:  
- The total area of all pools formed.  
- The count of pools formed.  
- The areas of each pool in reverse order.

4. **Preconditions**  
The input must consist of valid characters as specified. The program assumes that memory allocation will succeed.

5. **Postconditions**  
After execution, the program guarantees that the total area and count of pools are correctly calculated and printed, along with the areas of the pools in reverse order.

6. **Invariants**  
Throughout execution, the stack maintains the heights of characters processed, and the pool list accurately reflects the areas and heights of pools formed.

7. **Error Handling / Exceptional Behavior**  
If memory allocation fails, the program may exhibit undefined behavior. The program does not handle invalid input characters or malformed sequences.

8. **State Transitions (if applicable)**  
The program transitions between states based on the input characters, modifying the stack and pool structures accordingly. Each character processed may result in the creation, modification, or deletion of stack and pool elements.

9. **Non-functional Constraints (if inferable)**  
The program operates in linear time relative to the number of input characters, with space complexity dependent on the number of pools and stack elements created.
