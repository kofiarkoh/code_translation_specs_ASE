1. **Functional Description**  
The program reads a list of cards, each with a character and an integer value, sorts them based on the integer values, and checks the stability of the sorting algorithm. It then outputs whether the sorting is stable and prints the sorted list of cards.

2. **Inputs**  
- An integer representing the number of cards.  
- A sequence of pairs consisting of a character and an integer value for each card.

3. **Outputs**  
- A message indicating whether the sorting is "Stable" or "Not stable".  
- A list of sorted cards, each represented by its character and integer value.

4. **Preconditions**  
- The input must contain a valid integer followed by the specified number of character-integer pairs.  
- The integer must be non-negative.

5. **Postconditions**  
- The output will indicate the stability of the sorting process.  
- The cards will be printed in ascending order based on their integer values.

6. **Invariants**  
- The original order of cards with equal integer values is preserved if the sorting is stable.  
- The number of cards processed matches the input count.

7. **Error Handling / Exceptional Behavior**  
- If the input does not conform to the expected format, behavior is not defined.  
- No explicit error messages or handling mechanisms are implemented for invalid inputs.

8. **State Transitions (if applicable)**  
- The state transitions from an unsorted list of cards to a sorted list after the sorting operation.  
- The state also transitions to a stability check after sorting.

9. **Non-functional Constraints (if inferable)**  
- The sorting operation is expected to be efficient, as it employs a quicksort algorithm.  
- The program assumes sufficient memory is available to store the input cards.
