1. **Functional Description**  
The program computes the largest common divisor of two integers that occurs at a specific position in the sequence of common divisors.

2. **Inputs**  
The program reads three integer values: two integers for which the common divisors are to be calculated, and a third integer indicating the desired position of the common divisor.

3. **Outputs**  
The program outputs the largest common divisor at the specified position, or an undefined value if the position exceeds the number of common divisors.

4. **Preconditions**  
The input integers must be non-negative. The third input must be a positive integer.

5. **Postconditions**  
If the specified position is valid, the output will be the largest common divisor at that position. If the position is invalid (greater than the number of common divisors), the output will be undefined.

6. **Invariants**  
The program maintains that the common divisors are calculated correctly based on the input integers throughout its execution.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or negative integers. If the position exceeds the number of common divisors, the output will be undefined.

8. **State Transitions (if applicable)**  
Not applicable.

9. **Non-functional Constraints (if inferable)**  
The program operates with a time complexity that is dependent on the smaller of the two input integers, as it iterates through potential divisors.
