1. Functional Description  
The program calculates the average of two integers if their sum is even; otherwise, it indicates that the operation is impossible.

2. Inputs  
The program reads two long integer values from standard input.

3. Outputs  
The program either prints the average of the two integers or outputs a message indicating that the operation is impossible.

4. Preconditions  
The input values must be valid long integers.

5. Postconditions  
If the sum of the two integers is even, the output is the integer result of their average. If the sum is odd, the output is a message indicating that the operation is impossible.

6. Invariants  
The program maintains that the sum of the two integers is either even or odd throughout its execution.

If the input values are not valid long integers, the behavior is not defined. The program does not handle input errors explicitly.
