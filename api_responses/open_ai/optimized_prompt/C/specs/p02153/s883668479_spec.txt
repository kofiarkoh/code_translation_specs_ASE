1. **Functional Description**  
The code implements a pathfinding algorithm using Dijkstra's method to determine the minimum cost to traverse a grid from a starting point to a target point, while considering obstacles and variable movement costs.

2. **Inputs**  
- Two integers representing the height and width of the grid.  
- Two integers representing the costs associated with moving through different types of terrain.  
- A grid of characters representing the map, where specific characters denote the start point, target point, bombs, and obstacles.

3. **Outputs**  
- A long integer representing the minimum cost to reach the target point from the starting point, or a string indicating that the target is unreachable.

4. **Preconditions**  
- The grid dimensions must be positive integers.  
- The grid must be properly formatted with valid characters representing the start, target, bombs, and obstacles.

5. **Postconditions**  
- If a path exists, the output will be the minimum cost to reach the target point.  
- If no path exists, the output will indicate that the target is unreachable.

6. **Invariants**  
- The algorithm maintains a priority queue of positions to explore, ensuring that the position with the lowest cost is always processed next.  
- The visited status of each grid cell is consistently updated to prevent re-exploration.

7. **Error Handling / Exceptional Behavior**  
- If the input grid is malformed or contains invalid characters, behavior is not defined.  
- If the starting or target positions are not found in the grid, the output will indicate that the target is unreachable.

8. **State Transitions (if applicable)**  
- The state transitions occur as the algorithm explores the grid, moving from one cell to adjacent cells based on the defined movement rules and updating the cost accordingly.

9. **Non-functional Constraints (if inferable)**  
- The algorithm is expected to operate within a time complexity suitable for grids of size up to 1005x1005, given the constraints of Dijkstra's algorithm.  
- Memory usage is constrained by the maximum grid size and the priority queue implementation.
