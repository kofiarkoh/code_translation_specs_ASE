1. **Functional Description**  
The program processes a sequence of characters and computes a cumulative score based on specific character occurrences over multiple queries, each defined by a length parameter.

2. **Inputs**  
- An integer representing the length of a character sequence.  
- A character sequence consisting of 'D', 'M', and 'C'.  
- An integer representing the number of queries.  
- A sequence of integers, each representing the length of a substring to evaluate for the corresponding query.

3. **Outputs**  
- For each query, the program returns a long integer representing the computed score based on the specified substring.

4. **Preconditions**  
- The character sequence must be non-empty and contain only the characters 'D', 'M', and 'C'.  
- The number of queries must be a positive integer.  
- Each query length must be a positive integer and less than or equal to the length of the character sequence.

5. **Postconditions**  
- The output for each query is a non-negative long integer that reflects the cumulative score based on the occurrences of 'D', 'M', and 'C' in the specified substring.

6. **Invariants**  
- The counts of 'D', 'M', and the cumulative score are maintained accurately throughout the processing of each query.  
- The program processes each query independently, ensuring that previous computations do not affect subsequent queries.

7. **Error Handling / Exceptional Behavior**  
- If the input does not meet the preconditions (e.g., invalid characters, negative or zero lengths), the behavior is not defined.  
- The program does not handle input errors or invalid states explicitly.

8. **State Transitions (if applicable)**  
- The state transitions occur as the program processes each character in the sequence, updating counts and scores based on the current character and the defined query length.

9. **Non-functional Constraints (if inferable)**  
- The program is expected to operate within reasonable time limits for input sizes up to the maximum defined by the character sequence length and the number of queries.  
- Memory usage is constrained by the size of the character sequence and the number of queries.
