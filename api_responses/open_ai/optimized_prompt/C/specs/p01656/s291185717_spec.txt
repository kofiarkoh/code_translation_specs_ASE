1. Functional Description  
The program identifies and outputs the name associated with the most recent year that is less than or equal to a specified threshold.

2. Inputs  
The program reads two integers, N and Q, followed by N pairs of values consisting of an integer (year) and a string (name).

3. Outputs  
The program outputs a string representing the name associated with the most recent year that is less than or equal to Q.

4. Preconditions  
- N must be a non-negative integer.  
- Q must be a non-negative integer.  
- The number of names provided must not exceed the predefined limit.

5. Postconditions  
- The output string is guaranteed to be one of the names provided, corresponding to the most recent year that meets the specified condition.

6. Invariants  
- At least one name is guaranteed to be present in the input.  
- The program maintains a reference to the name associated with the most recent year that is less than or equal to Q throughout its execution.

7. Error Handling / Exceptional Behavior  
- If no year is found that is less than or equal to Q, the output will be the first name in the list.  
- Input values must be valid; otherwise, behavior is not defined.

8. State Transitions (if applicable)  
- The state transitions occur as the program processes each input pair, updating the reference to the name based on the year comparison.

9. Non-functional Constraints (if inferable)  
- The program operates within a fixed memory limit for names and years, defined by the maximum array sizes.  
- The program assumes that input is provided in a valid format and within the specified constraints.
