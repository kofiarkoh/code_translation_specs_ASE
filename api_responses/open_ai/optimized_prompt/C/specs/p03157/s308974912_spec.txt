1. **Functional Description**  
The program processes a grid of characters to count the number of distinct groups formed by adjacent cells containing different characters. It calculates the total number of pairs of cells from different groups, where one cell contains a specific character and the other contains a different character.

2. **Inputs**  
- Two integers representing the height and width of the grid.  
- A grid of characters with dimensions specified by the height and width, where each cell contains a single character.

3. **Outputs**  
- A single integer representing the total count of pairs of cells from different groups, where one cell contains a specific character and the other contains a different character.

4. **Preconditions**  
- The input must consist of valid integers for height and width.  
- The grid must be filled with characters, and the number of characters in each row must match the specified width.

5. **Postconditions**  
- The output will be a non-negative integer representing the calculated count of pairs.  
- The program will terminate successfully if the input is valid.

6. **Invariants**  
- The grid remains unchanged throughout the execution of the program.  
- The grouping of cells is consistent, ensuring that all cells in a group are marked with the same identifier.

7. **Error Handling / Exceptional Behavior**  
- The program will return an error code if the input for height and width is not valid.  
- The program will return an error code if any row of the grid does not contain the expected number of characters.

8. **State Transitions (if applicable)**  
- The state transitions occur as the program processes each cell in the grid, marking groups and counting character occurrences based on adjacency.

9. **Non-functional Constraints (if inferable)**  
- The program operates within the constraints of a maximum grid size of 512x512.  
- The execution time is dependent on the size of the grid and the number of distinct groups formed.
