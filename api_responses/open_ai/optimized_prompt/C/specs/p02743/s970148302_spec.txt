1. **Functional Description**  
The program determines whether a specific mathematical condition involving three input values is satisfied, returning a binary response indicating the result.

2. **Inputs**  
The program reads three long double values from standard input.

3. **Outputs**  
The program outputs a string indicating either "Yes" or "No" based on the evaluation of the mathematical condition.

The inputs must be valid long double representations. The program assumes that the input values are provided in a single line, separated by whitespace.

5. **Postconditions**  
The output will be "Yes" if the condition \( d^2 > 4ab \) and \( d > 0 \) holds true, where \( d = c - a - b \). Otherwise, the output will be "No".

6. **Invariants**  
The values of \( a \), \( b \), and \( c \) remain unchanged throughout the execution of the program after being read from input.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or out-of-range values. If invalid input is provided, the behavior is not defined.

Not applicable.
