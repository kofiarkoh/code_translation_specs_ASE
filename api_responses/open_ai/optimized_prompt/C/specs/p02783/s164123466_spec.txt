1. Functional Description  
Calculates the ceiling of the division of two integers.

2. Inputs  
Reads two integer values from standard input.

3. Outputs  
Returns an integer value representing the ceiling of the division of the first integer by the second integer, followed by a newline.

4. Preconditions  
The second integer must not be zero.

5. Postconditions  
The output integer is the smallest integer greater than or equal to the result of the division of the first integer by the second integer.

6. Invariants  
The output integer is always greater than or equal to the result of the division of the first integer by the second integer.

7. Error Handling / Exceptional Behavior  
If the second integer is zero, the behavior is undefined.

8. State Transitions (if applicable)  
Not applicable.

9. Non-functional Constraints (if inferable)  
Not inferable from code.
