1. Functional Description  
The program counts the number of pairs of consecutive equal integers in a sequence of integers provided by the user.

2. Inputs  
The program reads an integer \( N \) representing the number of integers to follow, and then reads \( N \) integers.

3. Outputs  
The program outputs a single integer representing the count of pairs of consecutive equal integers.

4. Preconditions  
The input integer \( N \) must be a positive integer, and the subsequent integers must be within the defined range of the data type used.

5. Postconditions  
The output integer reflects the total number of pairs of consecutive integers that are equal in the provided sequence.

6. Invariants  
The count of pairs is non-negative and is incremented only when consecutive integers are equal.

7. Error Handling / Exceptional Behavior  
If \( N \) is less than 1, the behavior is not defined. The program does not handle invalid input formats or out-of-range values.

8. State Transitions (if applicable)  
The program transitions from reading input to processing the input to producing output, maintaining the count of pairs throughout.

9. Non-functional Constraints (if inferable)  
The program operates within a fixed memory limit for storing integers, specifically accommodating up to 101 integers. The time complexity is linear with respect to \( N \).
