1. Functional Description  
The program reads a string from standard input, modifies each character based on its ASCII value, and outputs the modified string.

2. Inputs  
The program reads a single string consisting of characters.

3. Outputs  
The program outputs a modified string to standard output.

4. Preconditions  
The input string must not exceed 999 characters in length.

5. Postconditions  
The output string is derived from the input string such that:
- For each uppercase letter (A-Z), the character is shifted backward by 3 positions in the ASCII table.
- For all other characters, the character is shifted forward by 23 positions in the ASCII table.

6. Invariants  
The program maintains the integrity of the input string's length, ensuring that the output string will have the same length as the input string.

9. Non-functional Constraints (if inferable)
