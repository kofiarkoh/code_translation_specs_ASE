1. **Functional Description**  
The code implements Dijkstra's algorithm to compute the shortest path costs from a source node to all other nodes in a directed graph represented by a set of nodes, each containing edges and their associated costs.

2. **Inputs**  
- A non-negative integer representing the number of nodes in the graph.  
- For each node, a non-negative integer representing the number of outgoing edges, followed by pairs of non-negative integers representing the destination node and the cost of each edge.

3. **Outputs**  
- For each node, the index of the node followed by the computed shortest path cost from the source node. The output is printed in a specific format, with each node's information on a new line.

4. **Preconditions**  
- The input must consist of valid non-negative integers.  
- The number of nodes must be greater than zero.  
- Each node's outgoing edges must not exceed the predefined limit.

5. **Postconditions**  
- Each node's cost is updated to reflect the shortest path cost from the source node.  
- Nodes that are unreachable from the source node will have a cost of -1.

6. **Invariants**  
- The cost of the source node is always initialized to zero.  
- Nodes that have been visited will not be processed again.  
- The algorithm guarantees that once a node's cost is set, it will not be updated to a higher value.

7. **Error Handling / Exceptional Behavior**  
- If the input contains invalid values (e.g., negative integers or non-integer values), the behavior is not defined.  
- If the number of edges exceeds the predefined limit, the behavior is not defined.

8. **State Transitions (if applicable)**  
- The state transitions occur as nodes are visited and their costs are updated based on the edges leading from them.  
- The algorithm transitions from an unvisited state to a visited state for each node processed.

9. **Non-functional Constraints (if inferable)**  
- The algorithm operates in a time complexity that is dependent on the number of nodes and edges, specifically O(n^2) in the absence of a priority queue.  
- Memory usage is constrained by the number of nodes and the maximum number of edges per node.
