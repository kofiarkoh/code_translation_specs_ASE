1. Functional Description  
The program reads integer values from standard input until a zero is encountered. For each non-zero integer read, it outputs the case number and the integer value.

2. Inputs  
The program reads a sequence of integers from standard input.

3. Outputs  
The program outputs a string for each non-zero integer read, formatted to indicate the case number and the integer value. The output occurs until a zero is read.

4. Preconditions  
The program assumes that the input consists of valid integers.

5. Postconditions  
The program terminates after reading a zero. All non-zero integers read prior to the zero are output with their corresponding case numbers.

6. Invariants  
The case number is incremented for each non-zero integer read. The output is consistent with the order of input integers.

7. Error Handling / Exceptional Behavior  
The program does not handle invalid input or errors in reading integers. It will continue to read until a zero is encountered, regardless of input validity.

8. State Transitions (if applicable)  
The program transitions from reading input to outputting results upon reading a non-zero integer, and transitions to termination upon reading a zero.
