1. **Functional Description**  
The program processes a series of non-negative integers and weights to determine the minimum absolute difference between the integers and a set of computed values derived from the weights. It outputs the minimum difference or -1 if no valid difference is found.

2. **Inputs**  
- A sequence of non-negative integers, where the first integer indicates the number of subsequent integers.
- A sequence of weights, where the first integer indicates the number of subsequent weights.

3. **Outputs**  
- A single integer representing the minimum absolute difference between the input integers and the computed values, or -1 if no valid difference exists.

4. **Preconditions**  
- The input integers and weights are non-negative.
- The first input integer for both sequences correctly indicates the number of subsequent integers and weights, respectively.

5. **Postconditions**  
- The output is either the minimum absolute difference or -1, based on the conditions evaluated during processing.

6. **Invariants**  
- The computed values derived from the weights are always non-negative.
- The program maintains a record of previously computed values to avoid redundant calculations.

7. **Error Handling / Exceptional Behavior**  
- If no valid absolute difference is found for any input integer, the output will be -1.
- The program does not handle invalid input formats or negative integers, as it assumes all inputs are valid as per the preconditions.

8. **State Transitions (if applicable)**  
- The program transitions through states based on the processing of input integers and weights, updating the set of computed values and tracking the minimum absolute difference found.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a time complexity that allows it to handle a reasonable number of input integers and weights efficiently, given the constraints on the size of the arrays used for storage.
