1. **Functional Description**  
   The program calculates the probability of successfully moving a specified number of steps in a game scenario, considering obstacles and special squares that affect movement.

2. **Inputs**  
   - Four integers: N (total squares), T (number of turns), L (number of special squares of type 'L'), and B (number of special squares of type 'B').
   - A list of integers representing the positions of special squares of type 'L'.
   - A list of integers representing the positions of special squares of type 'B'.

3. **Outputs**  
   - A double value representing the probability of successfully completing the movement within the given turns, printed to standard output.

4. **Preconditions**  
   - N, T, L, and B must be non-negative integers.
   - The input must terminate with a line where all four integers are zero.

5. **Postconditions**  
   - The output probability is a value between 0.0 and 1.0, inclusive, representing the likelihood of success based on the provided game configuration.

6. **Invariants**  
   - The memoization structure maintains the maximum probability values for each state until they are computed.
   - The special squares are correctly identified and influence the movement probabilities as defined.

7. **Error Handling / Exceptional Behavior**  
   - If the input values for N, T, L, or B are invalid (e.g., negative), the behavior is not defined.
   - The program assumes valid input for special square positions; out-of-bounds values are not handled.

8. **State Transitions (if applicable)**  
   - The state transitions occur based on the current number of remaining steps and turns, influenced by the type of square encountered.

9. **Non-functional Constraints (if inferable)**  
   - The program operates within a time complexity that allows for the computation of probabilities based on the maximum values of N and T, constrained by the limits of the memoization array.
