1. **Functional Description**  
The program reads a target integer and a string of characters, then computes the maximum sum of integer values derived from substrings of the input string, constrained by the target. It identifies the specific combination of characters that yields this maximum sum and outputs the result.

2. **Inputs**  
- An integer representing the target sum.  
- A string of characters, with a maximum length of 10.

3. **Outputs**  
- If no valid combinations are found, outputs "error".  
- If multiple valid combinations yield the same maximum sum, outputs "rejected".  
- If exactly one valid combination is found, outputs the maximum sum followed by the characters that form this combination.

4. **Preconditions**  
- The target integer must be greater than zero.  
- The input string must be non-empty and contain at most 10 characters.

5. **Postconditions**  
- The output will reflect either an error, rejection, or the maximum sum and corresponding character combination based on the input constraints.

6. **Invariants**  
- The computed sum will always be less than or equal to the target sum for valid combinations.  
- The maximum sum is derived from valid substrings of the input string.

7. **Error Handling / Exceptional Behavior**  
- If no valid combinations are found, the program outputs "error".  
- If multiple combinations yield the same maximum sum, the program outputs "rejected".

8. **State Transitions (if applicable)**  
- The program transitions between reading input, processing combinations, and producing output based on the results of the computations.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a time complexity that is exponential relative to the length of the input string due to the combinatorial nature of the substring evaluations.  
- The program handles a maximum of 10 characters, limiting the number of combinations evaluated.
