1. **Functional Description**  
The program calculates a modified sum of a list of integers based on specific conditions related to divisibility by ten and the minimum value in the list.

2. **Inputs**  
The program reads an integer representing the number of subsequent integers, followed by the integers themselves.

3. **Outputs**  
The program outputs a single integer, which is the modified sum based on the input values.

4. **Preconditions**  
The input integer must be a positive value indicating the number of integers to follow. Each subsequent integer must be within the range of valid integer values.

5. **Postconditions**  
The output integer is guaranteed to be non-negative. It represents either the total sum of the input integers, the total sum minus the smallest non-zero integer, or zero, depending on the conditions met.

6. **Invariants**  
Throughout the execution, the sum of the integers is maintained, and the minimum value is updated only if it is less than the current minimum.

7. **Error Handling / Exceptional Behavior**  
If the input for the number of integers is non-positive or if the input integers are invalid, the behavior is not defined. The program does not handle such cases explicitly.

8. **State Transitions (if applicable)**  
The program transitions from reading input values to calculating the sum and minimum, and finally to producing the output based on the computed values.

9. **Non-functional Constraints (if inferable)**  
The program operates within a time complexity that is linear with respect to the number of input integers. Memory usage is proportional to the number of integers read.
