1. **Functional Description**  
The program computes a minimum cost based on a series of queries that involve updating and querying two data structures. It maintains a dynamic programming array to track the minimum costs associated with specific indices and returns the overall minimum cost after processing all queries.

2. **Inputs**  
- An integer representing the number of elements, `n`.  
- An integer representing the number of queries, `q`.  
- Two integers, `i` and `j`, representing initial indices.  
- A series of `q` integers representing subsequent index queries.

3. **Outputs**  
- A single long long integer representing the minimum cost after processing all queries.

4. **Preconditions**  
- `n` must be a positive integer.  
- `q` must be a non-negative integer.  
- The indices `i` and `j` must be within the range [0, n-1].  
- Each query index must also be within the range [0, n-1].

5. **Postconditions**  
- The output is the minimum cost calculated based on the updates and queries processed.  
- The program guarantees that the output is a valid long long integer.

6. **Invariants**  
- The dynamic programming array maintains valid minimum cost values for each index throughout the execution.  
- The two data structures used for updates always contain valid minimum values based on the most recent updates.

7. **Error Handling / Exceptional Behavior**  
- If the input values for `n`, `q`, `i`, `j`, or query indices are out of bounds, the behavior is not defined.  
- The program does not handle invalid input formats or types explicitly.

8. **State Transitions (if applicable)**  
- The state transitions occur with each query processed, updating the dynamic programming array and the two data structures based on the current index and the minimum cost calculations.

9. **Non-functional Constraints (if inferable)**  
- The program operates within a time complexity that is efficient for the given constraints, handling up to 200,000 elements and queries.  
- Memory usage is constrained to the size of the arrays defined, which is proportional to `n`.
