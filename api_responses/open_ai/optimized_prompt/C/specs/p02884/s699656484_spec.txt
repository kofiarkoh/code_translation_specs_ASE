1. **Functional Description**  
The program computes the minimum average distance from a starting node to all other nodes in a directed graph, while allowing for the exclusion of specific edges during the calculation.

2. **Inputs**  
- Two integers representing the number of nodes and the number of edges in the graph.  
- A series of pairs of integers representing directed edges between nodes.

3. **Outputs**  
- A single floating-point value representing the minimum average distance from the starting node to all other nodes, formatted to ten decimal places.

4. **Preconditions**  
- The number of nodes and edges must be non-negative integers.  
- The edges must be valid pairs of node indices within the range defined by the number of nodes.

5. **Postconditions**  
- The output value is a valid floating-point number representing the minimum average distance, or remains unchanged if no valid paths exist.

6. **Invariants**  
- The distance array is initialized such that all distances are set to a large value, except for the distance to the starting node, which is set to zero.  
- The edge array maintains the directed connections between nodes throughout the execution.

7. **Error Handling / Exceptional Behavior**  
- If no valid paths exist from the starting node to other nodes, the output will reflect this by returning a large value or remaining unchanged.  
- The program does not handle invalid input formats or out-of-bounds indices explicitly.

8. **State Transitions (if applicable)**  
- The state transitions occur as the program processes edges and updates the distance values based on the current node being evaluated and its connections.

9. **Non-functional Constraints (if inferable)**  
- The program is expected to execute within a reasonable time frame for graphs of moderate size, though performance may degrade with a large number of nodes and edges.  
- The output precision is constrained to ten decimal places.
