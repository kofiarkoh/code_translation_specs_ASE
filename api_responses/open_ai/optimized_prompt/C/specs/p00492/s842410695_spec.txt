1. **Functional Description**  
The program processes a grid defined by width and height, marking certain cells based on specific movement rules, and counts the number of cells that are adjacent to marked cells.

2. **Inputs**  
- Two integers representing the width and height of the grid.  
- A grid of integers with dimensions defined by the width and height, where each cell can contain specific integer values.

3. **Outputs**  
- An integer representing the count of unmarked cells that are adjacent to marked cells.

4. **Preconditions**  
- The width and height must be positive integers.  
- The grid must be populated with integers as specified by the input dimensions.

5. **Postconditions**  
- The output integer reflects the count of unmarked cells adjacent to marked cells after processing the grid.

6. **Invariants**  
- The grid remains within the defined dimensions throughout processing.  
- Marked cells are consistently updated based on the defined movement rules.

7. **Error Handling / Exceptional Behavior**  
- If the input dimensions are invalid (non-positive), the behavior is not defined.  
- If the grid input does not match the specified dimensions, the behavior is not defined.

8. **State Transitions (if applicable)**  
- The state transitions occur as cells are marked based on movement from previously marked cells, and the count of adjacent unmarked cells is updated accordingly.

9. **Non-functional Constraints (if inferable)**

- The time complexity is influenced by the grid size and the number of movements processed.
