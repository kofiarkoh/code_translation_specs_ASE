1. Functional Description  
The program reads five integer values and determines the first value among them that is zero. It outputs a corresponding integer indicating the position of the first zero value.

2. Inputs  
Five integer values are read from standard input.

3. Outputs  
The program outputs a single integer:  
- "1" if the first input is zero,  
- "2" if the second input is zero,  
- "3" if the third input is zero,  
- "4" if the fourth input is zero,  
- "5" if the fifth input is zero.  
If none of the inputs are zero, no output is produced.

4. Preconditions  
The input must consist of exactly five integers.

5. Postconditions  
If at least one of the five integers is zero, the program guarantees that an integer corresponding to the position of the first zero is output. If none are zero, no output occurs.

6. Invariants  
The program maintains that it only checks the values of the five integers in the order they are provided and outputs the position of the first zero encountered.

7. Error Handling / Exceptional Behavior  
If the input does not consist of five integers, the behavior of the program is not defined. No error messages or handling mechanisms are implemented.

8. State Transitions (if applicable)  
Not applicable.

9. Non-functional Constraints (if inferable)  
Not inferable from code.
