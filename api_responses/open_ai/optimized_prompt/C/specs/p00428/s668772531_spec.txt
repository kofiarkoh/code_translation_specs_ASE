1. **Functional Description**  
The program processes multiple matrices of integers, computes the sum of each column, and identifies the index of the column with the maximum sum in a specified order.

2. **Inputs**  
The program reads pairs of integers representing the dimensions of matrices (n, m) until a pair of zeros is encountered. For each valid pair, it reads n rows of m integers each, forming a matrix.

3. **Outputs**  
The program outputs the 1-based indices of the columns in descending order of their sums, separated by spaces, followed by a newline for each matrix processed.

4. **Preconditions**  
The input must consist of valid integers for dimensions and matrix elements. The dimensions n and m must be positive integers for valid matrices.

5. **Postconditions**  
For each matrix processed, the output will correctly reflect the indices of the columns sorted by their sums in descending order.

6. **Invariants**  
The sum of each column is maintained throughout the processing of the matrix, and the output order is determined solely by these sums.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or out-of-bounds values. It assumes that the input will always conform to the expected structure.

8. **State Transitions (if applicable)**  
The program transitions between states based on the input of matrix dimensions and the subsequent reading of matrix data, resetting state upon encountering the termination condition (0, 0).

9. **Non-functional Constraints (if inferable)**  
The program operates in a loop until termination conditions are met, and it processes matrices sequentially, implying a linear time complexity relative to the number of elements in the matrices.
