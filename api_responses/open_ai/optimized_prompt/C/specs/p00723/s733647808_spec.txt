1. **Functional Description**  
   The program processes a specified number of strings, generating and counting unique variations of each string through a series of transformations, including reversals and swaps.

2. **Inputs**  
   - An integer indicating the number of strings to process.  
   - A series of strings, each with a maximum length of 79 characters.

3. **Outputs**  
   - For each input string, the program outputs the count of unique variations generated.

4. **Preconditions**  
   - The input integer must be non-negative.  
   - Each input string must be null-terminated and not exceed 79 characters in length.

5. **Postconditions**  
   - The output for each string is the total number of unique variations generated from that string.

6. **Invariants**  
   - The array used to store unique variations is maintained without exceeding its defined capacity.  
   - The count of unique variations is accurately updated throughout the processing of each string.

7. **Error Handling / Exceptional Behavior**  
   - If the input string exceeds the maximum length, behavior is not defined.  
   - If memory limits are exceeded, behavior is not defined.

8. **State Transitions (if applicable)**  
   - The state transitions occur as the program processes each string, updating the count of unique variations and the contents of the storage array.

9. **Non-functional Constraints (if inferable)**  
   - The program operates within a time complexity that is dependent on the length of the input strings and the number of transformations applied.  
   - The maximum number of unique variations is constrained by the size of the storage array.
