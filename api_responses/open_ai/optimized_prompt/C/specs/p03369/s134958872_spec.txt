1. Functional Description  
The program reads a string of three characters, counts the occurrences of the character 'o', and calculates a score based on this count. The score is computed as 700 plus 100 times the count of 'o' characters.

2. Inputs  
The program reads a string consisting of exactly three characters.

3. Outputs  
The program outputs a single integer value representing the calculated score.

4. Preconditions  
The input string must consist of exactly three characters.

5. Postconditions  
The output value is guaranteed to be an integer that is at least 700 and increases by 100 for each occurrence of the character 'o' in the input string.

6. Invariants  
The count of 'o' characters is always a non-negative integer and cannot exceed three.
