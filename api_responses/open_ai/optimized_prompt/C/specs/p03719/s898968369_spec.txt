1. **Functional Description**  
The program reads three integer values and determines if the third value lies within the inclusive range defined by the first two values. It outputs a confirmation message based on this condition.

2. **Inputs**  
Three integers, denoted as `a`, `b`, and `c`, are read from standard input.

3. **Outputs**  
The program outputs "Yes" if the value of `c` is greater than or equal to `a` and less than or equal to `b`. It outputs "No" otherwise.

4. **Preconditions**  
The input values must be valid integers. There are no specific constraints on the range of these integers.

5. **Postconditions**  
After execution, the output will reflect whether `c` is within the range [a, b]. The program guarantees that exactly one of the two possible outputs ("Yes" or "No") will be produced.

6. **Invariants**  
The relationship between the three integers remains unchanged throughout the execution of the program. The program does not modify the input values.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input or errors related to input reading. It assumes that the input will always be valid integers.

8. **State Transitions (if applicable)**  
Not applicable.

9. **Non-functional Constraints (if inferable)**  
The program operates in constant time with respect to the input size, as it performs a fixed number of operations regardless of the input values.
