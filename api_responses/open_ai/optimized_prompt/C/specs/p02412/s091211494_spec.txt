1. **Functional Description**  
The program counts the number of unique combinations of three distinct integers from the range 1 to n that sum to a specified value x. It continues to process input until both n and x are zero.

2. **Inputs**  
The program reads pairs of integers, n and x, from standard input. The input terminates when both integers are zero.

3. **Outputs**  
The program outputs the count of unique combinations of three distinct integers that sum to x, divided by six, to standard output for each valid input pair.

4. **Preconditions**  
The input integers n and x must be non-negative. The program assumes that n is at least 0.

5. **Postconditions**  
For each pair of inputs (n, x) where n > 0, the output is the integer count of unique combinations of three distinct integers from the set {1, 2, ..., n} that sum to x, divided by six. If n = 0 and x = 0, the program terminates without output.

6. **Invariants**  
The count of combinations is always a non-negative integer. The program maintains the condition that the integers considered for combinations are distinct and within the specified range.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input formats or values outside the expected range. It assumes valid integer input as specified.

8. **State Transitions (if applicable)**  
The program transitions between states based on the input pairs (n, x). It processes each pair, computes the count of combinations, and outputs the result until the termination condition (n = 0 and x = 0) is met.

9. **Non-functional Constraints (if inferable)**  
The program operates in a time complexity that is cubic with respect to n, as it involves three nested iterations over the range 1 to n. The output is produced immediately after processing each input pair.
