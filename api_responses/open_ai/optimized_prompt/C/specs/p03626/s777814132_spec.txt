1. **Functional Description**  
   The program calculates a value based on the comparison of two input strings of equal length. The output value is derived from specific rules regarding character matches and is computed modulo a predefined constant.

2. **Inputs**  
   - An integer \( N \) representing the length of two strings.  
   - Two strings \( S1 \) and \( S2 \) of length \( N \).

3. **Outputs**  
   - A single long long integer value representing the computed result, printed to standard output.

4. **Preconditions**  
   - The input integer \( N \) must be a positive integer.  
   - The lengths of both strings \( S1 \) and \( S2 \) must equal \( N \).

5. **Postconditions**  
   - The output value is guaranteed to be a non-negative integer less than \( 1000000007 \).

6. **Invariants**  
   - The value of the output is consistently updated based on the character comparisons between \( S1 \) and \( S2 \) as well as within \( S1 \) itself.

7. **Error Handling / Exceptional Behavior**  
   - If the input does not conform to the expected format (e.g., non-integer for \( N \), strings of incorrect length), the behavior is not defined. No explicit error handling is implemented.

8. **State Transitions (if applicable)**  
   - The state transitions occur based on character comparisons between the two strings and within the first string, affecting the computed result.

9. **Non-functional Constraints (if inferable)**  
   - The computation must complete in a time complexity proportional to \( O(N) \).  
   - The output value is constrained to be within the range of a long long integer.
