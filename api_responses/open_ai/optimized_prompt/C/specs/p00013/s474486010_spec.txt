1. Functional Description  
The program simulates a railroad car management system, allowing cars to enter and exit a railroad track. It maintains a record of the cars currently on the track and outputs the car number that exits.

2. Inputs  
The program reads integer values from standard input until the end of input is reached. Each integer represents either a car entering the track or a command for a car to exit.

3. Outputs  
The program outputs the integer value of the car that exits the track each time a car exit command is issued.

4. Preconditions  
The input must consist of integers, where a positive integer indicates a car entering the track and a zero indicates a car exiting. The program assumes that the number of exit commands does not exceed the number of cars currently on the track.

5. Postconditions  
For each exit command, the program guarantees that the corresponding car number is outputted, and the internal record of cars is updated accordingly.

6. Invariants  
The internal record of cars on the track is maintained such that it only contains the most recent cars that have entered, and the index tracking the number of cars is always non-negative.

7. Error Handling / Exceptional Behavior  
If an exit command is issued when no cars are present on the track, the behavior is not defined. The program does not handle invalid input or provide feedback for erroneous commands.

8. State Transitions (if applicable)  
- On receiving a positive integer, the state transitions to include that car in the internal record and increments the count of cars.
- On receiving a zero, the state transitions to remove the most recently added car from the internal record and decrements the count of cars.

9. Non-functional Constraints (if inferable)  
The program operates under the constraint of a fixed-size internal record, limiting the number of cars that can be managed to ten.
