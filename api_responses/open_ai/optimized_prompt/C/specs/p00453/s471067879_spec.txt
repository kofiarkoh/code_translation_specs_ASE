1. **Functional Description**  
The program computes the minimum cost to traverse a series of points defined by their coordinates and associated weights, based on user-defined input. It processes multiple datasets until a termination condition is met.

2. **Inputs**  
The program reads multiple datasets, each consisting of:  
- Two integers, `n` and `m`, where `n` is the number of point sets and `m` is the maximum number of transitions allowed.  
- For each point set, an integer indicating the number of points followed by pairs of integers representing the coordinates and weights of each point.

3. **Outputs**  
The program outputs the minimum traversal cost for each dataset, printed as a single integer.

4. **Preconditions**  
- The input must contain valid integers for `n` and `m`, where `n` and `m` are non-negative.  
- Each point set must have a non-negative integer count of points.  
- The coordinates and weights must be valid integers.

5. **Postconditions**  
- The output is the minimum cost of traversing from the first to the last point set, considering the defined weights and coordinates.  
- The program terminates upon reading a dataset where both `n` and `m` are zero.

6. **Invariants**  
- The cost matrix is initialized to a high value, ensuring that any valid cost computed will be lower.  
- The minimum cost is updated only if a lower cost is found during the traversal calculations.

7. **Error Handling / Exceptional Behavior**  
- The program does not explicitly handle invalid input formats or out-of-range values; behavior is undefined for such cases.  
- If no valid traversal exists, the output may reflect the initialized high value, indicating no feasible path.

8. **State Transitions (if applicable)**  
- The program transitions between states based on the input datasets, recalculating the cost matrix for each dataset until termination conditions are met.
