1. **Functional Description**  
The code implements a solution to determine the reachability of nodes in a weighted undirected graph based on user-defined queries. It utilizes Dijkstra's algorithm to compute the shortest paths from a starting node and performs a topological sort to facilitate the processing of queries regarding node reachability.

2. **Inputs**  
- An integer representing the number of nodes in the graph.  
- An integer representing the number of edges in the graph.  
- A list of edges, each defined by two nodes and a weight.  
- An integer representing the starting node for shortest path calculations.  
- An integer representing the goal node for reachability checks.  
- A list of queries, each consisting of a pair of nodes to check for reachability.

3. **Outputs**  
- For each query, outputs "Yes" if the destination node is reachable from the source node, otherwise outputs "No".

4. **Preconditions**  
- The number of nodes and edges must be non-negative.  
- The edges must connect valid node indices within the range of the number of nodes.  
- The starting and goal nodes must be valid indices within the range of the number of nodes.  
- The queries must consist of valid node indices.

5. **Postconditions**  
- The shortest path distances from the starting node to all other nodes are computed and stored.  
- The reachability of each queried node pair is determined based on the computed shortest paths.

6. **Invariants**  
- The graph structure remains consistent throughout the execution, with edges correctly representing the connections and weights between nodes.  
- The distance array is updated only when a shorter path to a node is found.

7. **Error Handling / Exceptional Behavior**  
- If memory allocation fails during graph construction, the program may terminate unexpectedly.  
- If invalid input is provided (e.g., out-of-bounds node indices), the behavior is not defined.

8. **State Transitions (if applicable)**  
- The state transitions occur during the execution of Dijkstra's algorithm and the topological sort, where the state of the distance array and the reachability information is updated based on the graph's structure and the queries.

9. **Non-functional Constraints (if inferable)**  
- The algorithm is expected to operate efficiently within the constraints of the input size, with a focus on minimizing time complexity for pathfinding and query processing.  
- Memory usage is constrained by the number of nodes and edges, with dynamic allocation based on input size.
