1. Functional Description  
The program counts the occurrences of the substring "ABC" in a given string and returns the total count.

2. Inputs  
- An integer value representing the length of the string (n).  
- A string of characters with a maximum length of 50.

3. Outputs  
- An integer representing the count of non-overlapping occurrences of the substring "ABC" in the input string.

4. Preconditions  
- The integer input (n) must be greater than or equal to 3.  
- The string input must contain at least n characters.

5. Postconditions  
- The output integer reflects the total number of non-overlapping occurrences of "ABC" in the input string.

6. Invariants  
- The count of occurrences is non-negative.  
- The input string is not modified during processing.

7. Error Handling / Exceptional Behavior  
- If the integer input (n) is less than 3, the program may not function as intended, but this is not explicitly handled.  
- If the string input is shorter than n characters, behavior is not defined.

8. State Transitions (if applicable)  
- The program transitions from an initial state (before input) to a final state (after output) with the count of occurrences as a key state variable.

9. Non-functional Constraints (if inferable)  
- The program operates within a time complexity that is linear with respect to the length of the string.  
- Memory usage is constrained to the size of the input string and a few integer variables.
