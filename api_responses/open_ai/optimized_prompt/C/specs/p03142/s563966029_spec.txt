1. **Functional Description**  
The program processes a directed graph defined by edges between nodes, identifying and outputting the parent node for each node in a topological order. It guarantees that for each node, the output reflects the immediate predecessor in the directed acyclic graph (DAG).

2. **Inputs**  
The program reads two integers representing the number of nodes and the number of edges, followed by pairs of integers that define directed edges between nodes.

3. **Outputs**  
The program outputs a sequence of integers, where each integer corresponds to the parent node of each node in the graph, printed in order from node 1 to node N.

4. **Preconditions**  
- The input must consist of valid integers for the number of nodes and edges.
- The edges must form a directed acyclic graph (DAG) with nodes indexed from 1 to N.

5. **Postconditions**  
- Each node from 1 to N has a corresponding output that indicates its parent node.
- If a node has no parent (i.e., it is the root), the output for that node will be 0 or undefined based on the implementation.

6. **Invariants**  
- The count of incoming edges for each node is maintained accurately throughout the processing.
- The output array is populated only with valid parent nodes as determined by the graph structure.

7. **Error Handling / Exceptional Behavior**  
- The program exits with an error code if the input format is invalid or if memory allocation fails during edge addition.

8. **State Transitions (if applicable)**  
- The program transitions between phases of processing nodes based on the current count of nodes with no incoming edges, updating the state of the graph as nodes are processed.

9. **Non-functional Constraints (if inferable)**  
- The program operates within memory constraints defined by the maximum number of nodes and edges, and it performs efficiently for the input size specified.
