1. **Functional Description**  
The code performs a pattern search within a two-dimensional text grid, identifying all starting positions where a specified pattern grid matches the text grid.

2. **Inputs**  
- Two integers representing the height and width of the text grid.  
- A two-dimensional character array representing the text grid.  
- Two integers representing the height and width of the pattern grid.  
- A two-dimensional character array representing the pattern grid.

3. **Outputs**  
- Outputs the row and column indices of each occurrence of the pattern within the text grid, printed as pairs of integers.

4. **Preconditions**  
- The height and width of the text grid must be positive integers.  
- The height and width of the pattern grid must be positive integers.  
- The dimensions of the pattern grid must not exceed those of the text grid.

5. **Postconditions**  
- The output will contain zero or more pairs of integers, each representing a valid starting position of the pattern within the text grid.  
- If no matches are found, no output will be produced.

6. **Invariants**  
- The text and pattern grids remain unchanged throughout the execution of the program.  
- The hash values generated for the text and pattern grids are consistent with their respective contents.

7. **Error Handling / Exceptional Behavior**

- If the input data is malformed or does not conform to expected formats, the behavior is not defined.

8. **State Transitions (if applicable)**
