1. **Functional Description**  
The program calculates and outputs two time values based on the input of hours, minutes, and seconds. The first output represents the remaining time until a two-hour mark from the input time, while the second output represents three times that remaining time.

2. **Inputs**  
The program reads three integer values representing hours, minutes, and seconds. Input terminates when the values -1 are provided for any of the time components.

3. **Outputs**  
The program outputs two formatted time values for each valid input set. The first output indicates the remaining time until the next two-hour mark, and the second output indicates three times that remaining time.

4. **Preconditions**  
The input values must be non-negative integers representing valid time components (hours, minutes, seconds) and must be provided in sets of three. The input must not contain -1 for any of the time components unless signaling termination.

5. **Postconditions**  
For each valid input, the program guarantees that two time values are printed. The first value is the time remaining until the next two-hour mark, and the second value is three times that remaining time.

6. **Invariants**  
The program maintains that the input values must always be within the range of valid time components. The outputs are always formatted as hours, minutes, and seconds.

7. **Error Handling / Exceptional Behavior**  
If the input does not consist of three integers or contains invalid time components, the program will not produce any output and will terminate without error messages. The program does not handle negative time values other than the termination signal.

8. **State Transitions (if applicable)**  
The program transitions from reading input to processing and outputting results for each valid set of time components until termination is signaled by the input of -1.

9. **Non-functional Constraints (if inferable)**  
The program operates in a loop until termination, ensuring that it can handle multiple sets of input efficiently. The output format is consistent and adheres to a two-digit representation for each time component.
