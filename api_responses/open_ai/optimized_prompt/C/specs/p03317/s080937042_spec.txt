1. Functional Description  
Calculates and returns the minimum number of groups required to partition a sequence of values based on specified constraints.

2. Inputs  
Reads two integer values representing the total number of elements and a grouping parameter, followed by a sequence of integer values.

3. Outputs  
Returns a single integer value representing the minimum number of groups needed.

4. Preconditions  
The first input value must be a positive integer representing the number of elements. The second input value must be a positive integer greater than one. The number of elements provided must match the first input value.

5. Postconditions  
The output value is a positive integer that satisfies the grouping constraints based on the input values.

6. Invariants  
The total number of elements is always greater than or equal to the number of groups multiplied by the grouping parameter minus one.
