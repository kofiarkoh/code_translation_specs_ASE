1. **Functional Description**  
The code implements a solution for the Eleven Puzzle, determining the minimum number of moves required to reach a goal state from a given initial state of the puzzle.

2. **Inputs**  
The program reads a sequence of thirteen integers representing the current state of the puzzle, where each integer corresponds to a tile or an empty space.

3. **Outputs**  
The program outputs the minimum number of moves required to solve the puzzle or indicates that the puzzle is not solvable.

4. **Preconditions**  
The input must consist of exactly thirteen integers, with the first integer being non-negative. The integers must represent valid tile values within the range defined by the puzzle.

5. **Postconditions**  
The output will either be a non-negative integer representing the minimum number of moves to solve the puzzle or a specific indication that the puzzle is unsolvable.

6. **Invariants**  
The state of the puzzle remains consistent throughout the execution, and the data structures used to track states and moves maintain their integrity.

7. **Error Handling / Exceptional Behavior**  
If the first input integer is negative, the program terminates without further processing. If the puzzle state is unsolvable, the program outputs a specific indication of this condition.

8. **State Transitions (if applicable)**  
The program transitions between different states of the puzzle based on valid moves, updating the current state and tracking the number of moves taken.

9. **Non-functional Constraints (if inferable)**  
The program is designed to handle a maximum of 500,000 states efficiently, and it operates within a defined limit of moves for solving the puzzle.
