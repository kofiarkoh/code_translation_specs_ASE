3. **Outputs**

   - A string "yes" followed by \( N \) integers representing the matched nodes in the second partition for each node in the first partition if a perfect matching is possible.

   - The input must consist of a valid non-negative integer followed by an \( N \times N \) adjacency matrix.  
   - The adjacency matrix must contain only binary values (0 or 1).
