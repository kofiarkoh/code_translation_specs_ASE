1. **Functional Description**  
The program calculates the number of overlapping indices between two specified ranges and returns the count of these overlaps, adjusted by one if there is at least one overlap.

2. **Inputs**  
The program reads four integer values representing two ranges: the first range is defined by two integers (A and B), and the second range is defined by two integers (C and D).

3. **Outputs**  
The program outputs a single integer value representing the count of overlapping indices between the two ranges, adjusted by one if overlaps exist.

4. **Preconditions**  
The input integers A, B, C, and D must be within the range of 0 to 100, with A ≤ B and C ≤ D.

5. **Postconditions**  
The output is guaranteed to be a non-negative integer. If there are no overlaps, the output is 0. If there are overlaps, the output is the count of overlaps minus one.

6. **Invariants**  
The arrays used to track the ranges are initialized to zero and maintain their values within the bounds of their defined sizes throughout the execution.

7. **Error Handling / Exceptional Behavior**  
The program does not handle invalid input or out-of-bounds values. It assumes that the input will always be valid as per the preconditions.

8. **State Transitions (if applicable)**  
Not applicable.

9. **Non-functional Constraints (if inferable)**  
The program operates within constant time complexity relative to the fixed size of the input ranges, ensuring efficient execution.
