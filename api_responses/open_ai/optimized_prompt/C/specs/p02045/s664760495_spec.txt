1. **Functional Description**  
The program calculates a total cost based on the movement between a series of points, considering boundary constraints and potential penalties for moving outside specified limits.

2. **Inputs**  
- A positive integer \( N \) representing the number of points.  
- Four integers \( A, B, C, D \) defining the boundary limits.  
- \( N + 1 \) pairs of integers representing the coordinates \( (X[i], Y[i]) \) of the points.

3. **Outputs**  
- A single integer representing the total calculated cost, printed to standard output.

4. **Preconditions**  
- The input for \( N \) must be a positive integer.  
- The input for \( A, B, C, D \) must be valid integers.  
- The input for the coordinates must consist of \( N + 1 \) valid pairs of integers.

5. **Postconditions**  
- The output integer reflects the minimum cost of movement between the points, considering the defined boundaries and penalties.

6. **Invariants**  
- The values of \( A, B, C, D \) remain constant throughout the execution after being read.  
- The coordinates \( (X[i], Y[i]) \) are valid and within the bounds of the input constraints.

7. **Error Handling / Exceptional Behavior**  
- The program terminates with a return value of 1 if the input for \( A, B, C, D \) or the coordinates is invalid.  
- The program does not produce output if \( N \) is non-positive or if input reading fails.

8. **State Transitions (if applicable)**  
- The program transitions from reading input to processing the coordinates and finally to outputting the calculated cost.

9. **Non-functional Constraints (if inferable)**  
- The program is expected to handle a maximum of 128 points efficiently.  
- The output is guaranteed to be a non-negative integer, as it represents a cost.
