1. Functional Description  
Calculates and outputs half the product of two integer inputs.

2. Inputs  
Reads three integer values from standard input.

3. Outputs  
Returns a single floating-point value representing half the product of the first two input integers, formatted as an integer.

4. Preconditions  
The first two input values must be valid integers. The third input value is not used in the computation.

5. Postconditions  
The output is the integer representation of half the product of the first two input integers.

6. Invariants  
The output will always be non-negative if both input integers are non-negative.

Not inferable from code.

Not applicable.
