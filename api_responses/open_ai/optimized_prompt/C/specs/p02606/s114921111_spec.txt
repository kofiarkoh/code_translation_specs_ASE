1. Functional Description  
Calculates the count of integers divisible by a specified divisor within a given inclusive range.

2. Inputs  
Three integer values representing the lower bound, upper bound, and the divisor.

3. Outputs  
An integer representing the count of integers within the specified range that are divisible by the divisor, followed by a newline.

4. Preconditions  
The lower bound must be less than or equal to the upper bound. The divisor must be a positive integer.

5. Postconditions  
The output integer is non-negative and represents the total count of integers divisible by the divisor within the inclusive range defined by the lower and upper bounds.

6. Invariants  
The count of divisible integers remains consistent across multiple invocations with the same input values.
