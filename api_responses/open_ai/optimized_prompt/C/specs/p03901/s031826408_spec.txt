1. **Functional Description**  
The program calculates and outputs the expected value based on a given position and a probability rate. It reads input values, processes them to compute the expected value, and outputs the result.

2. **Inputs**  
- An integer representing a position.
- A double representing a probability rate (as a percentage).

3. **Outputs**  
- A formatted string representing the computed expected value, printed to standard output.

4. **Preconditions**  
- The input must contain a valid integer followed by a valid double percentage.
- The probability rate must be between 0 and 100.

5. **Postconditions**  
- The output will be a string formatted to seven decimal places representing the expected value calculated from the input position and probability rate.

6. **Invariants**  
- The probability rate remains constant throughout the execution after being read from input.
- The expected value is computed based on the current position and the fixed probability rate.

7. **Error Handling / Exceptional Behavior**  
- If the input cannot be read or parsed correctly, the behavior is not defined.
- If the computed expected value cannot be represented accurately, the output may not reflect the true value.

8. **State Transitions (if applicable)**  
- The program transitions from reading input to computing the expected value and finally to outputting the result.

9. **Non-functional Constraints (if inferable)**  
- The output must be produced in a timely manner, with a focus on precision in the representation of the expected value.
