5. Core Computation (Exact Feasibility Predicate)  

5.1. High-level search for \(k\)

5.2. The function `ispossible(R,B,k)`  
`ispossible` decides feasibility by searching over an integer parameter \(t\) (named `te` in the code) in the range \([1, \texttt{prime}-1]\). For each candidate \(t\), it computes a required resource pair \((Z_R, Z_B)\) via `calc(t, prime - t, k, &Z_R, &Z_B)` and compares it to the available \((R,B)\).

- If for some \(t\), the computed pair satisfies \(Z_R \le R\) and \(Z_B \le B\), then `ispossible` returns true immediately.
- If during the search it encounters a \(t\) where both requirements exceed the available resources (\(Z_R > R\) and \(Z_B > B\)), it returns false immediately.
- Otherwise, it continues a binary search on \(t\), moving the search interval based on whether \(Z_R\) exceeds \(R\) (move upward in \(t\)) or not (move downward in \(t\)). While doing so, it records two “bounding” computed points:
  - one point from a case where \(Z_R > R\) (stored as \((S_R,S_B)\)), and
  - one point from a case where \(Z_R \le R\) (stored as \((F_R,F_B)\)).
- If the binary search finishes without returning, `ispossible` performs a final geometric check: it returns true iff the input point \((R,B)\) lies on or to one particular side of the directed line through the two recorded points \((F_R,F_B)\) and \((S_R,S_B)\). Concretely, it computes a 2D cross product
  \[
    \text{cross}((S-F),(T-F)) \ge 0
  \]
  where \(F=(F_R,F_B)\), \(S=(S_R,S_B)\), and \(T=(R,B)\). If the cross product is nonnegative it returns true; otherwise false. (This is exactly the code’s “on/above the line” test.)

5.3. The function `calc(p,q,k,&Z_R,&Z_B)`  
Given positive integers \(p\) and \(q\) (in this program always \(p=t\), \(q=\texttt{prime}-t\)), `calc` searches for an integer \(z\) such that `calcul(p,q,z,&Z_R,&Z_B)` returns a count equal to \(k\). It performs an integer binary search on \(z\) over the fixed range:
- \(z \in [0, \texttt{prime} \cdot 2000]\).

At each midpoint \(z\), it calls `calcul(p,q,z,...)` which returns a count `c`.  
- If `c == k`, `calc` stops and leaves \((Z_R,Z_B)\) as produced by that call.  
- If `c < k`, it increases the lower bound; if `c > k`, it decreases the upper bound.  
- If the loop ends without finding `c == k`, the function terminates without any additional correction step; the final \((Z_R,Z_B)\) are simply whatever values were last written by the most recent `calcul` call executed during the search.

5.4. The function `calcul(p,q,z,&outR,&outB)`  
This function computes three values from integers \(p,q,z\):  
- a returned count `cnt`, and  
- two accumulated quantities written to `*outR` and `*outB`.

Behavior:
- It initializes `cnt = 0`, `*outR = 0`, `*outB = 0`.  
- If \(p < q\), it swaps \(p\) and \(q\) for the computation and remembers that it swapped; at the end it swaps the two outputs `outR` and `outB` back (so the output components correspond to the original \(p,q\) order).
- It then iterates with an index \(i = 0,1,2,\dots\) while the current \(z \ge 0\). In each iteration:
  - \(w = \left\lfloor z / q \right\rfloor\) (integer division),
  - `cnt` increases by \(w+1\),
  - `*outR` increases by \(i \cdot (w+1)\),
  - `*outB` increases by the triangular number \(\frac{(w+1)w}{2}\),
  - then \(z\) is decreased by \(p\) and \(i\) is incremented.
- The function returns `cnt` and leaves `*outR`, `*outB` as accumulated (possibly swapped back as described).

void llswap(long long *a,long long *b){long long c;c=(*a);(*a)=(*b);(*b)=c;}
long long llsankaku(long long x){return ((1+x)*x)/2;}

long long calcul(long long p,long long q,long long z,long long *r,long long *b){
  long long f=0,cnt=0,w,i;
  (*r)=0;(*b)=0;
  if(p<q){f=1;llswap(&p,&q);}
  i=0;
  while(z>=0){
    w=z/q;
    cnt+=(w+1);
    (*r)+=i*(w+1);
    (*b)+=llsankaku(w);
    z-=p;
    i++;
  }
  if(f){llswap(r,b);}
  return cnt;
}

void calc(long long p,long long q,long long k,long long *r,long long *b){

typedef struct{

  point r;

long long crossproduct(point a,point b){
  return a.xz*b.yz-a.yz*b.xz;
}

bool ispossible(long long r,long long b,long long k){
  long long st,fi,te,zr,zb;
  long long fr,fb,sr,sb;
  st=1;fi=prime-1;
  while(st<=fi){
    te=(st+fi)/2;
    calc(te,prime-te,k,&zr,&zb);
    if(zr<=r && zb<=b){return true;}
    if(zr>r && zb>b){return false;}
    if(zr>r){st=te+1;sr=zr;sb=zb;}
    else{fi=te-1;fr=zr;fb=zb;}
