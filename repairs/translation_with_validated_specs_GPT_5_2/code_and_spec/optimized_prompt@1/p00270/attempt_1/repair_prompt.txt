1. Functional Description  
Given an undirected weighted graph, a fixed source node `a`, a fixed destination node `b`, and multiple queries `(x, y)`, the program determines for each query whether there exists at least one shortest path from `a` to `b` such that `x` appears on the path and `y` appears at the same position or after `x` along that path (i.e., `y` is reachable from `x` by continuing forward along edges that can lie on some shortest `a`→`b` path).

“Shortest” is with respect to the sum of nonnegative edge weights.

2. Inputs  
- Integer `S`: number of nodes. Nodes are identified by indices in the input as 1-based values.

- Two node indices `a b` (1-based): the fixed source and destination.  
- Integer `Q`: number of queries.  
- `Q` pairs: `c[i] d[i]` (1-based) describing query nodes `(x, y)`.

5. Core Semantics (What is being decided)  
Let `dist[v]` be the minimum total weight from `a` to `v`. Consider only edges `(e, s)` that satisfy the shortest-path equality with respect to `dist`:
`dist[s] == dist[e] + w(e,s)`.  
Such an edge can be traversed from `e` to `s` while staying on some shortest path from `a` to `s`.

The program answers `Yes` for query `(x, y)` exactly when, within the directed graph formed by these shortest-path-consistent transitions and restricted to nodes that can participate in reaching `b` via such transitions, there is a directed path from `x` to `y`. If `x` is not in that relevant region, or `y` is not reachable from `x` within it, the answer is `No`.

6. Construction of the Relevant Directed Acyclic Subgraph  
- First, compute `dist[]` from `a` to all nodes using Dijkstra’s algorithm.  
- Then, starting from `b`, perform a reverse exploration over the original undirected edges to find nodes that can lie on at least one shortest path from `a` to `b`. During this exploration, whenever an undirected edge between `e` and `s` satisfies `dist[s] == dist[e] + w(e,s)`, record a directed edge `e → s` in an auxiliary adjacency structure.  
  - This ensures the auxiliary directed graph contains only “forward” steps that preserve shortest-path optimality and that are relevant to reaching `b`.  
- The resulting directed graph is acyclic because every directed edge strictly increases `dist` (given nonnegative weights and the strict equality form used).

- To propagate reachability for queries, the program computes an explicit topological order of the constructed directed graph using an indegree-based queue procedure (Kahn-style), starting from `a`.  
- This order is derived from the graph structure (indegrees and queue processing), not by sorting nodes by distance and not by using library sorting callbacks.

#define QMAX 200000
typedef struct { int t, s; } QUE;
QUE que[QMAX+2]; int qsize;

#define PARENT(i) ((i)>>1)
#define LEFT(i)   ((i)<<1)
#define RIGHT(i)  (((i)<<1)+1)

void min_heapify(int i)
{
	int l, r, min;
	QUE qt;

	l = LEFT(i), r = RIGHT(i);
	if (l < qsize && que[l].t < que[i].t) min = l; else min = i;
	if (r < qsize && que[r].t < que[min].t) min = r;
	if (min != i) {
		qt = que[i], que[i] = que[min], que[min] = qt;
		min_heapify(min);
	}
}

void deq()
{
	que[0] = que[--qsize];
	min_heapify(0);
}

void enq(int s, int t)
{
	int i, min;
	QUE qt;

	i = qsize++;
	que[i].s = s, que[i].t = t;
	while (i > 0 && que[min = PARENT(i)].t > que[i].t) {
		qt = que[i], que[i] = que[min], que[min] = qt;
		i = min;
	}
}

void dijkstra(int start)
{
	int i, s, e, d;

	memset(dist, INF, S << 2);
	qsize = 0;
	enq(start, 0), dist[start] = 0;
	while (qsize) {
		s = que[0].s, deq();
		for (i = 0; i < hi[s]; i++) {
			e = to[s][i];
			d = dist[s] + w[s][i];
			if (dist[e] > d) dist[e] = d, enq(e, d);
		}
	}
}

void tsort(int start, int goal)

    int i, s, e;

	memset(mk, 0, S);
	q[0] = goal, top = 0, tail = 1;
	while (top < tail) {
		s = q[top++];

		for (i = 0; i < hi[s]; i++) {
			e = to[s][i];
			if (dist[s] == dist[e] + w[s][i]) {
				q[tail++] = e;
				to2[e][hi2[e]++] = s;
			}
		}
		mk[s] = 1;
	}

	for (s = 0; s < S; s++) for (i = 0; i < hi2[s]; i++) deg[to2[s][i]]++;

	}
}
