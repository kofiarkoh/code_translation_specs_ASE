1. Functional Description  
Reads two signed integers `n` and `m`, computes a value using a two-dimensional dynamic program with an auxiliary accumulated table, and prints the final value reduced modulo a fixed prime modulus.

2. Inputs  
- Two signed integers read from standard input: `n` and `m`.

3. Outputs  
- Prints exactly one line to standard output containing `dp[n][m]` as a signed decimal integer followed by a newline, where all computations are performed modulo `MOD = 1,000,000,007`.

4. Computation (Definition of the Recurrence)  
All arithmetic below is performed modulo `MOD = 1,000,000,007`.

The program maintains:
- `pow2[x] = 2^x mod MOD` for `x = 0..(n+m)`
- `inv2[x] = (1/2)^x mod MOD` for `x = 0..(n+m)`, where `1/2 mod MOD` is computed as `(MOD + 1) / 2`.

Initialization for these sequences:
- `pow2[0] = 1`, `inv2[0] = 1`
- For `x = 1..(n+m)`:
  - `pow2[x] = (pow2[x-1] * 2) mod MOD`
  - `inv2[x] = (inv2[x-1] * ((MOD + 1)/2)) mod MOD`

Dynamic programming tables:
- `dp[i][j]` and `dq[i][j]` are conceptually defined for `i = 0..n` and `j = 0..m`.
- `dq[i][0]` is treated as `0` for all `i` (this holds due to zero-initialization of the global table).
- `dp[i][0]` is not explicitly filled by the recurrence loops; its value is whatever results from the program’s initialization (zero-initialized in this program).

Filling order and formulas:
- For each `i` from `0` to `n` (inclusive), and for each `j` from `1` to `m` (inclusive):
  - If `i == 0`:
    - `dp[0][j] = 1`
  - Else (`i > 0`):
    - `dp[i][j] = ((j + 1) * dp[i-1][j] + dq[i-1][j-1] * pow2[j-1]) mod MOD`
  - Then update the auxiliary accumulation:
    - `dq[i][j] = (dq[i][j-1] + (dp[i][j] * j mod MOD) * inv2[j]) mod MOD`

Final result:
- The printed value is exactly `dp[n][m]` modulo `MOD` (represented in the program using a signed 64-bit integer type).

- The program does not validate that `n` and `m` are nonnegative; negative values may lead to out-of-bounds access or other undefined behavior.

6. Edge Cases
