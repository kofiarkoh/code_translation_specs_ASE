1. Functional Description  
Computes a single real-valued result from a weighted, undirected graph intended to be a tree, using node 1 as the traversal root. Each node contributes the weight of the edge by which it is first reached from node 1 (node 1 contributes 0), scaled by a depth-dependent factor \(P^{\text{depth}}\). The program outputs the product of (a) the sum of these scaled edge-weight contributions over all nodes and (b) a second factor equal to an additional constant 1 plus the sum of the same depth-dependent factors over all nodes.

2. Inputs  
- A real number \(P\).  
- A non-negative integer \(N\) denoting the number of nodes.  
- \(N-1\) undirected edges, each given by:
  - two node indices \(x, y\) (assumed to be in \([1, N]\)),
  - an integer edge weight \(c\).

3. Outputs  
- One real number printed in fixed-point format with 10 digits after the decimal point, equal to:
  \[
  \left(\sum_{v=1}^{N} \text{parentEdgeWeight}(v)\cdot P^{\text{depth}(v)}\right)
  \cdot
  \left(1 + \sum_{v=1}^{N} P^{\text{depth}(v)}\right)
  \]
  where:
  - \(\text{parentEdgeWeight}(1)=0\),
  - for \(v\neq 1\), \(\text{parentEdgeWeight}(v)\) is the weight of the edge used when \(v\) is first discovered during traversal from node 1,
  - \(\text{depth}(v)\) is the number of edges from node 1 to \(v\) along the discovered parent links.

4. Preconditions  
- The input is intended to describe a tree on nodes \(\{1,\dots,N\}\) (connected and acyclic).  
- Node indices used in edges are within \([1, N]\).  
- Node 1 exists and is the intended root.  
- Sufficient memory is available for internal storage proportional to \(N\).  
- The computed real-valued result is representable in the implementation’s floating-point type if a meaningful numeric output is expected.

5. Postconditions  
- Depths and parent-edge weights are determined by a traversal starting at node 1 that assigns each newly reached node a parent (the node it was reached from) and a depth one greater than its parent.  
- For valid tree inputs, this traversal-derived parent relation corresponds to the unique simple paths from node 1.  
- The output equals the formula in Section 3 using these depths and parent-edge weights.

6. Invariants  
- Depth values are non-negative integers for visited nodes.  
- Exactly one parent edge weight is associated with each visited non-root node, corresponding to the edge by which it was first reached.  
- The depth-dependent factor for a node depends only on its depth and the input \(P\), specifically \(P^{\text{depth}}\).

- If the input does not form a tree rooted at 1 (e.g., disconnected or cyclic), the produced value is based on the traversal from node 1 and may not correspond to a well-defined tree-rooted computation for all nodes. Unreached nodes retain default-initialized depth and parent-edge weight values.

int in()   // 非負整数の入力
{
	int n = 0, c = gc();
	do n = 10 * n + (c & 0xf), c = gc(); while (c >= '0');
	return n;
}

double dbl()    // 実数の入力
{
	int minus = 0;
	double x, y;
	int n = 0, c = gc();
	if (c == '-') minus = 1, c = gc();
	do n = 10 * n + (c & 0xf), c = gc(); while (c >= '0');

	if (c == '.') {
		x = 0;
		y = 1, c = gc();
		do y *= 0.1, x += y * (c & 0xf), c = gc(); while (c >= '0');
		x += n;
	}
	else x = n;
	if (minus) x = -x;
	return x;
}

#define MAX 100005
typedef struct { int to, c; } T;
int hi[MAX]; T *t[100005]; int N;
int cost[MAX], depth[MAX], depth_max;
double p[MAX], P;

typedef struct { int n, d; } Q;
Q q[MAX]; int top;
char vis[MAX];

void dfs()
{
	int i, node, d, to;

	q[0].n = 1, q[0].d = 0, top = 1;
	while (top) {
		node = q[--top].n, d = q[top].d;

		if (vis[node]) continue;
		vis[node] = 1;

		depth[node] = d;
		if (d > depth_max) depth_max = d;
		for (i = 0; i < hi[node]; i++) {
			to = t[node][i].to;
			if (!vis[to]) {
				cost[to] = t[node][i].c;
				q[top].n = to, q[top++].d = d + 1;
			}
		}
	}
}
