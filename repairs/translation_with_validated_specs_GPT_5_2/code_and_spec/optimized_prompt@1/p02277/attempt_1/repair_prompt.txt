5. Sorting Semantics (Order Produced)

- The sort is applied to the entire array of records.

- Partitioning uses the last element of the subarray as the pivot. Let `x` be the pivot key.  
- The partition procedure scans the subarray from left to right (excluding the pivot position). Each time it encounters an element with key `<= x`, it advances a boundary index and swaps the encountered element into the left partition.  
- After the scan, it swaps the pivot element into the position immediately after the left partition and returns that pivot index.  
- Recursion then sorts the left and right partitions around the pivot index.

This procedure fully determines the final permutation, including the relative order of records with equal keys (which is not guaranteed to match input order).

- Each record is tagged with its original input position.  
- After sorting, the program reports `Stable` iff there is no pair of records with equal keys that appear in an order inconsistent with their original input positions.

void quicksort(card *A,int p,int r){

  int q;
  if(p<r){
    q=partition(A,p,r);
    quicksort(A,p,q-1);
    quicksort(A,q+1,r);
  }
}
int partition(card *A,int p,int r){

  int i,j;
  int x;
  card swap;

  i=p-1;
  x=A[r].val;

  for(j=p;j<r;j++){
    if(A[j].val<=x){
      i++;
      swap=A[i];
      A[i]=A[j];
      A[j]=swap;
    }
  }
  swap=A[i+1];
  A[i+1]=A[r];
  A[r]=swap;
  return i+1;
}
