1. Functional Description  
Processes multiple datasets of straight line segments whose endpoints lie on an integer grid. For each dataset, it counts how many segments belong to each digit class 0–9 according to a fixed set of hardcoded “templates” based on (a) connectivity via shared endpoints, (b) how many endpoint occurrences in a component are at shared points, and (c) a small number of additional geometric tests. Segments that are not part of any recognized template are counted as digit 1.

2. Inputs  
For each dataset:  
- An integer `n` = number of segments.  
- Then `n` segments, each given by four integers `(x1, y1, x2, y2)` describing its two endpoints.

Datasets repeat until a dataset with `n = 0`, which terminates the program.

3. Outputs  
For each dataset:  
- One line with 10 non-negative integers: counts for digit 0, digit 1, …, digit 9, in that order.

4. Preconditions / Assumptions  
- `n` is within the program’s fixed capacity (at most 1001 segments).  
- Endpoint coordinates are integers within the fixed grid range supported by the program’s internal arrays (indices must be valid).  
- Input is well-formed and contains all required integers.  
- The program stores only up to 5 segments per connected component for later analysis; if a component contains more than 5 segments, behavior is undefined.

5. Definitions Used for Classification  
- Two segments are in the same connected component if they are connected by a chain of segments where consecutive segments share an endpoint with exactly equal coordinates. Connectivity is computed over shared endpoints only (segment crossings without shared endpoints do not connect components).  
- A grid point is “shared” if it is used as an endpoint by more than one segment in the dataset (multiplicity > 1).  
- For a connected component, let:  
  - `m` = number of segments in the component.  
  - `p` = the number of endpoint occurrences in the component that lie at shared points, counted with multiplicity (i.e., each segment endpoint contributes 1 to `p` if its coordinate is shared in the dataset). Thus `p` ranges from 0 to `2m`.  
- “Point on segment interior” test: a point is considered to lie on a segment only if it is collinear with the segment and lies within the segment’s bounding box, and it is strictly not equal to either endpoint of that segment.

6. Classification Logic (Template-Based)  
Classification is performed per connected component, but only components matching one of the specific templates below contribute to digits other than 1. All other segments (including those in components of any size/pattern not listed) are counted as digit 1.

Only components with `m >= 2` are considered for template matching. For each such component:

A. Digit 4 template  
- If `m == 2` and `p == 2`, then the component contributes 1 to the count for digit 4 (i.e., both segments are accounted for as a “4” component).

B. Digit 9 template  
- If `m == 4` and `p == 6`, then the component contributes 1 to the count for digit 9.

C. Digit 0 / 8 template (requires geometric check)  
- If `m == 4` and `p == 8`, then exactly one of the following applies:  
  - If there exists any segment endpoint (from any segment in the dataset) that lies strictly in the interior of any segment of this component, then the component contributes 1 to digit 8.  
  - Otherwise, the component contributes 1 to digit 0.  
  (The interior test excludes equality with the tested segment’s endpoints.)

D. Digit 3 / 7 template (requires geometric check)  
- If `m == 3` and `p == 4`, then exactly one of the following applies:  
  - If there exists an endpoint of any segment (from any component) that lies strictly in the interior of a segment of this component whose both endpoints are shared points (i.e., both endpoints have multiplicity > 1), then the component contributes 1 to digit 3.  
  - Otherwise, the component contributes 1 to digit 7.

E. Digit 2 / 5 / 6 template (requires orientation-based check)  
- If `m == 5` and `p == 8`, then the component contributes 1 to exactly one of digits 2, 5, or 6. The choice is determined by an orientation/sidedness computation derived from the component’s endpoint-sharing structure: two “junction” segments are identified via endpoints that are not shared, and the relative sidedness of corresponding “branch” points with respect to those junction segments determines whether the digit is 2, 5, or 6.

7. Catch-All Digit 1  
- After accounting for all components that match one of the templates above, every remaining segment (including isolated segments, components with `m < 2`, and components with `m >= 2` that do not match any listed `(m, p)` template) is counted as digit 1.  
- The program ensures the total of all digit counts equals `n` by defining digit 1 as “all segments not otherwise accounted for.”

8. State and Termination  
- For each dataset, all internal counters and connectivity structures are reset before reading segments.  
- The program terminates immediately after reading a dataset with `n = 0`.

9. Error Handling / Exceptional Behavior  
- No explicit error handling is performed. If the preconditions are violated (out-of-range coordinates, too many segments, or a component exceeding the stored-per-component limit), results are undefined.

#include <stdio.h>
#include <string.h>

#define MAX 1002

/* UNION-FIND library */
int id[MAX], size[MAX];
void init(int n) { int i; for (i = 0; i < n; i++) id[i] = i, size[i] = 1; }
int root(int i) { while (i != id[i]) id[i] = id[id[i]], i = id[i]; return i; }
int connected(int p, int q) { return root(p) == root(q); }
void unite(int p, int q)
{
    int i = root(p), j = root(q); if (i == j) return;
    if (size[i] < size[j]) id[i] = j, size[j] += size[i]; else id[j] = i, size[i] += size[j];
}

#define PeqP(a,b)  (((a.x)==(b.x))&&((a.y)==(b.y)))
typedef struct { int x, y; } PP;
typedef struct { PP s, e; } SEG;
typedef struct { char n; SEG u[5]; char p; } T;
T t[MAX];
SEG   u[MAX]; int n;
char  f[MAX][MAX];
short uid[MAX][MAX];
short ans[10];

PP vset(int x, int y) { PP r; r.x = x, r.y = y; return r; }
PP vsub(PP p1, PP p2) { PP r; r.x = p1.x - p2.x, r.y = p1.y - p2.y; return r; }
PP vmul(PP p1, PP p2) { PP r;
	r.x = p1.x * p2.x - p1.y * p2.y, r.y = p1.x * p2.y + p1.y * p2.x; return r; }
int dot(PP a, PP b) { return a.x * b.x + a.y * b.y; };

//#define getchar_unlocked()  getchar()
int in()
{
	int n = 0, c = getchar_unlocked();
	do n = 10*n + (c & 0xf), c = getchar_unlocked(); while (c >= '0');
	return n;
}

void check256(T *id)
{
	int i, j, k1, k2;
	PP p0[2], p1[2], p2[2];
	PP p;

	j = 0;
	for (i = 0; i < id->n; i++) {
		if (f[id->u[i].s.x][id->u[i].s.y] == 1) {
			p0[j] = id->u[i].s, p1[j++] = id->u[i].e;
		} else if (f[id->u[i].e.x][id->u[i].e.y] == 1) {
			p0[j] = id->u[i].e, p1[j++] = id->u[i].s;
		}
	}
	for (i = 0; i < id->n; i++) {
		if      (!PeqP(id->u[i].s, p0[0]) && PeqP(id->u[i].e, p1[0]))
			p2[0] = id->u[i].s;
		else if (!PeqP(id->u[i].e, p0[0]) && PeqP(id->u[i].s, p1[0]))
			p2[0] = id->u[i].e;
		if      (!PeqP(id->u[i].s, p0[1]) && PeqP(id->u[i].e, p1[1]))
			p2[1] = id->u[i].s;
		else if (!PeqP(id->u[i].e, p0[1]) && PeqP(id->u[i].s, p1[1]))
			p2[1] = id->u[i].e;
	}
	p = vmul(vsub(p0[0],p1[0]), vset(0,1));
	k1 = dot(vsub(p2[0], p1[0]), p);

	p = vmul(vsub(p0[1],p1[1]), vset(0,1));
	k2 = dot(vsub(p2[1], p1[1]), p);

	if      (k1 > 0 && k2 > 0) ans[2]++;
	else if (k1 < 0 && k2 < 0) ans[5]++;
	else                       ans[6]++;
}

int pOnSeg(PP p, SEG u)
{
	int x1 = u.s.x, y1 = u.s.y, x2 = u.e.x, y2 = u.e.y;
	int d;

	if (PeqP(p, u.s) || PeqP(p, u.e)) return 0;
	if (x1 > x2) { d = x1, x1 = x2, x2 = d; d = y1, y1 = y2, y2 = d; }
	return x1 <= p.x && p.x <= x2 &&
		((y1 <= y2 && y1 <= p.y && p.y <= y2) ||
		(y1 > y2 && y2 <= p.y && p.y <= y1))
		&& (p.y - y1)*(x2 - x1) == (y2 - y1)*(p.x - x1);
}

void check08(T *id)
{
	int i, j;
	for (i = 1; i <= n; i++) if (root(i) == i) {
		for (j = 0; j < id->n; j++) {
			if (pOnSeg(u[i].s, id->u[j])) { ans[8]++; return; }
			if (pOnSeg(u[i].e, id->u[j])) { ans[8]++; return; }
		}
	}
	ans[0]++;
}

void check37(T *id)
{
	int i, j;

	for (i = 0; i < id->n; i++) {
		if (f[id->u[i].s.x][id->u[i].s.y] > 1 && f[id->u[i].e.x][id->u[i].e.y] > 1) {
			for (j = 1; j <= n; j++) if (root(j) == j) {
				if (pOnSeg(u[j].s, id->u[i])) { ans[3]++; return; }
				if (pOnSeg(u[j].e, id->u[i])) { ans[3]++; return; }
			}
		}
	}
	ans[7]++;
}

	int i, j, k, s;
	int x1, y1, x2, y2;

	while (n = in()) {
		memset(ans, 0, sizeof(ans));
		memset(t, 0, sizeof(T)*(n+1));
		memset(f, 0, sizeof(f));
		memset(uid, 0, sizeof(uid));
		init(n+1);

		for (i = 1; i <= n; i++) {
			x1 = in(), y1 = in(), x2 = in(), y2 = in();
			u[i].s.x = x1, u[i].s.y = y1;
			u[i].e.x = x2, u[i].e.y = y2;
			if (f[x1][y1]) unite(uid[x1][y1], i);
			else uid[x1][y1] = i;
			f[x1][y1]++;
			if (f[x2][y2]) unite(uid[x2][y2], i);
			else uid[x2][y2] = i;
			f[x2][y2]++;
		}
		for (i = 1; i <= n; i++) {
			j = root(i);
			k = t[j].n++, t[j].u[k] = u[i];
			if (f[u[i].s.x][u[i].s.y] > 1) t[j].p++;
			if (f[u[i].e.x][u[i].e.y] > 1) t[j].p++;
		}

		s = 0;
		for (i = 1; i <= n; i++) if (t[i].n >= 2) {
			s += t[i].n;
			if      (t[i].n == 2 && t[i].p == 2) ans[4]++;
			else if (t[i].n == 4 && t[i].p == 6) ans[9]++;
			else if (t[i].n == 4 && t[i].p == 8) check08(t+i);

			else if (t[i].n == 3 && t[i].p == 4) check37(t+i);
		}
		s += ans[4] + ans[3] + ans[8];
		ans[1] = n-s;
		printf("%d", ans[0]);
