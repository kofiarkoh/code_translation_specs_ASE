Processes one or more test cases. For each test case, it evaluates a sequence of queries over a rooted structure of `N` nodes labeled `1..N` with a designated root `1`. Queries are of two kinds: one kind marks a node, and the other kind asks, for a given node, which marked node is reached by repeatedly moving from the node to its parent until a marked node is encountered. The program outputs the sum of the answers to all such “ask” queries.

- An integer `N`: number of nodes.

3. Outputs
