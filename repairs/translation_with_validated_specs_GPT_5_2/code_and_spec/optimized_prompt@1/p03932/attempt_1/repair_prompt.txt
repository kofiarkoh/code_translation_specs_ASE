1. Functional Description  
Computes the maximum total value collectable by two agents traversing a rectangular grid from the top-left cell to the bottom-right cell in the same number of steps, where each step moves either one cell right or one cell down. The total includes the values of all visited cells, counting a cell only once if both agents occupy it at the same time.

2. Inputs  
- Two integers specifying the grid height and width.  
- A height-by-width matrix of integers representing the value in each grid cell.

3. Outputs  
- A single integer: the maximum achievable total value under the traversal rules.

4. Preconditions  
- Grid height and width are positive and do not exceed the supported maximum size.

5. Postconditions  
- The output equals the maximum possible sum of collected cell values over two valid paths from the top-left to the bottom-right, where:  
  - Each agent starts at the top-left and ends at the bottom-right.

  - At each time step, both agents move simultaneously (one move each).  
  - If both agents are in the same cell at the same time, that cell’s value contributes only once for that time step.
