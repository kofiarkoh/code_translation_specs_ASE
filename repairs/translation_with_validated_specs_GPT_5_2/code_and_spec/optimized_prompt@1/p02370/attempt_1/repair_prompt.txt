1. Functional Description  
Reads a directed graph and performs a topological-sort traversal using an indegree-based (Kahn-style) algorithm. It prints vertices in the exact order they are removed from a FIFO queue of currently zero-indegree vertices. If the graph is acyclic, all vertices are printed once in a valid topological order. 5. Algorithmic Semantics and Tie-Breaking  
The program maintains an indegree counter for each vertex (counting all incoming edges, including duplicates and self-loops). It then:

- Initializes a FIFO queue by scanning vertices in increasing index order from `0` to `V-1` and enqueuing every vertex whose indegree is zero at that time, in that scan order.  
- Repeatedly dequeues the front vertex `u`, prints `u`, and processes all outgoing edges `u -> v`. For each such edge, it decrements `v`’s indegree; if `v`’s indegree becomes exactly zero due to this decrement, `v` is enqueued at the back of the queue immediately.  
- Outgoing edges of a vertex are processed in the same relative order as the corresponding edges appear in the input among edges with the same source vertex.

This fully determines the output order when multiple vertices are eligible: eligibility is discovered and enqueued in FIFO order, with initial eligibility determined by increasing vertex index, and later eligibility determined by the order in which edges are processed.

- If the graph contains a directed cycle (including self-loops), the program may print fewer than `V` vertices; any vertex that remains with positive indegree after the queue becomes empty is not printed.
