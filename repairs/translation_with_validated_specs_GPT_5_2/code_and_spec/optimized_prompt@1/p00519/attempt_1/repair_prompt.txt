1. Functional Description  
Computes the minimum total taxi fare required to travel from the start town to the destination town in an undirected road network. Travel is modeled as repeatedly (optionally) paying for a taxi in the current town to obtain a fixed “remaining free-move allowance,” and then traversing road segments without additional fare while that allowance remains positive. The program outputs the minimum total fare upon first reaching the destination under these rules.

2. Inputs  
- Two integers `N` and `K`: the number of towns and the number of undirected roads.  
- For each town `i` from 1 to `N`: two integers giving the taxi fare and the maximum number of road segments allowed after paying that fare in that town.

3. Outputs  
- If the destination town is reachable from the start under the taxi rules, prints a single integer followed by a newline: the minimum total fare to reach the destination.  
- If the destination is unreachable, the program terminates normally without printing any route-cost output.

4. Preconditions / Assumptions

- Road endpoints are provided in 1-based form (`1..N`); if not, behavior is not as specified.

- **Free road traversal (only if `r > 0`)**: move along any road from `t` to an adjacent town `t'`, producing state `(t', r−1)` with the same fare `C`.

This action is allowed regardless of the current `r` (including when `r > 0`), and may be taken multiple times.

If a cost is printed, it equals the minimum possible sum of paid taxi fares over all valid travel plans that reach the destination.

void update_cost(status_t stat,int cost) {
	if(status_mincost[stat.town][stat.kaisu]==0 ||
	status_mincost[stat.town][stat.kaisu]-1>cost) {
		status_mincost[stat.town][stat.kaisu]=cost+1;

}

void adjust_heap(int idx) {
	int min_idx=idx;
	if(idx*2+1<heap_size) {
		if(read_cost(status_heap[min_idx])>read_cost(status_heap[idx*2+1])) {
			min_idx=idx*2+1;
		}
		if(idx*2+2<heap_size) {

				min_idx=idx*2+2;

		}

	if(min_idx!=idx) {
		status_t tmp=status_heap[idx];
		status_heap[idx]=status_heap[min_idx];
		status_heap[min_idx]=tmp;
		adjust_heap(min_idx);
	} else {
		if(idx>0)adjust_heap(idx/2);
	}
}

void insert_heap(status_t stat,int cost) {
	int prev_cost=read_cost(stat);
	if(prev_cost<0 || cost<prev_cost) {
		update_cost(stat,cost);
		if(!in_heap[stat.town][stat.kaisu]) {
			in_heap[stat.town][stat.kaisu]=1;
			status_heap[heap_size]=stat;

		}
	}
}

	in_heap[ret.town][ret.kaisu]=0;
	status_heap[0]=status_heap[--heap_size];

}
