1. Functional Description  
Maintains a conceptual integer array indexed from `0` and logically of length `num`, supporting two operations over **inclusive** index ranges:  
- **Range assignment**: set every element in a specified range to a given integer value `x`.  
- **Range sum query**: return the sum of elements in a specified range.  
Sum query results are produced in the same order as the corresponding queries appear in the input.

2. Inputs  
- Two integers:  
  - `num`: logical length of the array.  
  - `queries`: number of subsequent operations.  
- Then `queries` operations, each consisting of:  
  - `type`, `start`, `end` (three integers).  
  - If `type` denotes an update, one additional integer `x` follows.  
Ranges are interpreted as inclusive `[start, end]` in the logical array.

3. Outputs  
- For each sum query operation, output one line containing the computed range sum as a signed 64-bit value (mathematically), printed in query order.

4. Preconditions / Assumptions  
- `0 <= num <= 100000`.  
- `0 <= queries <= 100000`.  
- For every operation: `0 <= start <= end < num`.  
- The number of sum queries is at most `100000`.  
- Input is well-formed and provides all required integers.  
- Update values `x` are provided as (and fit in) a 32-bit signed `int` as read from input; sums are accumulated using signed 64-bit arithmetic.

(Equivalently, avoid update values and segment lengths whose product equals the sentinel constant used internally.)

- **Sum query (type = 1)** on inclusive range `[start, end]`: compute and record `sum_{i=start..end} A[i]`. The array state is unchanged.

int is_overlap(struct range r1, struct range r2) {

int is_contain(struct range this, struct range box) {

#define INIT_VAL (2e+9)

void unlazy(struct pair *seg, int node, struct range nr) {
    int64_t lazy = seg[node].lazy;
    if(lazy == INIT_VAL) return;
    seg[node].val = lazy; //update
    seg[node].lazy = INIT_VAL;

        seg[node*2].lazy = lazy/2;

    return;
}


void update_range(struct pair *seg, int x, struct range r, int node, struct range nr) {
    unlazy(seg, node, nr);
    if(!is_overlap(r, nr)) return;
    if(is_contain(nr, r)) {
        seg[node].lazy = x * (nr.end - nr.start);

int64_t get_sum(struct pair *seg, struct range r, int node, struct range nr) {
