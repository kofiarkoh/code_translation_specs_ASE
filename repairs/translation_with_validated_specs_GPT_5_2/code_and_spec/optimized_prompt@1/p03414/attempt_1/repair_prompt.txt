1. Functional Description  
Given a directed graph with `n` vertices and `m` directed edges (in input order), the program classifies each edge as either **`same`** or **`diff`**.

The classification is based on strongly connected components (SCCs) and on whether an edge is the only “direct” way to realize reachability under the program’s checks:

### A) Edges whose endpoints are in different SCCs (inter-SCC edges)  
Let `S = SCC(u)` and `T = SCC(v)` with `S != T`. Consider the SCC condensation graph (a DAG) whose nodes are SCCs and whose arcs are induced by original edges that go from one SCC to another.

An original inter-SCC edge `u -> v` is classified **`diff`** if **either** of the following holds:

1) **Parallel SCC-arc duplication:** there is more than one original edge whose endpoints lie in the same ordered SCC pair `(S, T)` (i.e., multiple original edges induce the same condensation-graph arc from `S` to `T`). In that case, all such original edges for that ordered SCC pair are marked **`diff`**.

2) **Existence of a longer SCC-level route:** in the condensation graph, there exists a directed path from `S` to `T` that uses at least one intermediate SCC (i.e., a path of length ≥ 2). If so, the original edge(s) inducing `S -> T` are marked **`diff`**.

If neither condition holds, the inter-SCC edge is classified **`same`**.

Notes on what “longer SCC-level route” means in this program:
- It is evaluated on the condensation DAG using the SCC indices produced by the SCC computation.
- The program’s check corresponds to whether `T` is reachable from `S` via at least two condensation arcs (not merely via the direct arc `S -> T`).

### B) Edges whose endpoints are in the same SCC (intra-SCC edges)  
For an edge `u -> v` with `SCC(u) == SCC(v)`, the edge is classified **`diff`** if there exists a directed path from `u` to `v` that stays within that SCC and **does not use the edge being classified**. If no such alternative path exists, it is classified **`same`**.
