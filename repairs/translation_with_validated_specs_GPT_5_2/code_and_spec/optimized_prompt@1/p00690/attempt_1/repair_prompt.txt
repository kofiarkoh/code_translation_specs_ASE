1. Functional Description  
For each dataset, computes a maximum-total-length route in an undirected weighted graph under the constraint that no edge is traversed more than once (i.e., the route is an edge-simple trail). The program outputs the maximum achievable total length and one corresponding sequence of vertices in traversal order that attains that length.

2. Inputs  
For each dataset:  
- An integer `n`: the number of vertices.  
- An integer `m`: the number of edges.  
- `m` edge descriptions, each consisting of two endpoint vertex labels and an integer length.  
Datasets repeat until a dataset with `n = 0` is encountered; at that point the program terminates (the value of `m` on that terminating line is read but not otherwise used).

3. Outputs  
For each dataset, the program prints exactly two lines:  
- Line 1: a single integer, the maximum total length among all valid routes.  
- Line 2: a vertex sequence for one maximum-length route, printed as vertex labels separated by single spaces (no extra tokens on the line).

- Vertex labels appearing in edges are intended to be in the range `1..n`.

5. Route Validity and Optimization Criteria  
- A route is a sequence of vertices where each consecutive pair is connected by an input edge.  
- No individual edge may be used more than once in the route; vertices may repeat as long as edges do not.  
- The total length of a route is the sum of the lengths of the traversed edges.  
- The reported maximum length is the greatest total length over all such routes in the dataset.  
- The reported vertex sequence corresponds to a route whose total length equals the reported maximum.

typedef struct { int a, b, d, f; } T;
T tbl[25]; int n, m;
int ans[12], tmp[12], len, num;

void combi(int k, int a, int w)
{
	int i, b;

	for (b = 1; b <= n; b++) {
		if (b == a) continue;
		for (i = 0; i < m; i++) {
			if ((tbl[i].a == a && tbl[i].b == b || tbl[i].a == b && tbl[i].b == a) && !tbl[i].f) {
				tbl[i].f = 1, tmp[k] = b;
				combi(k+1, b, w + tbl[i].d);
				tbl[i].f = 0;
			}
		}
	}
	if (w > len) num = k, len = w, memcpy(ans, tmp, sizeof(int)*num);
}
