1. Functional Description  
Enumerates all integer bitmask values representable with `n` bits (from `0` up to `2^n - 1`) and outputs those that contain exactly `k` set bits. For each qualifying bitmask, it outputs the bitmask value followed by the list of zero-based bit positions that are set in that bitmask.

2. Inputs  
- Two integers read from standard input on a single line (whitespace-separated):  
  - `n`: the number of bit positions considered.  
  - `k`: the required number of set bits in each generated bitmask.

3. Outputs  
- To standard output, zero or more lines, in increasing numeric order of the bitmask value.  
- Each output line corresponds to one bitmask with exactly `k` set bits and has the following exact textual format:  
  - The decimal integer value of the bitmask, immediately followed by a colon character `:` (with no space before the colon),  
  - Then, for each set bit position `i` in ascending order, the position printed in decimal and preceded by a single space,  
  - Then a terminating newline.

4. Preconditions / Assumptions  
- Input provides two integers; if not, the program’s behavior is not defined by this specification.  
- `n` is assumed to be non-negative.  
- `n` is assumed to be small enough that `(1 << n)` is well-defined for the platform’s `int` type and that iterating over all values from `0` to `(1 << n) - 1` is feasible.

- For every integer bitmask `p` in the range `[0, 2^n - 1]` with exactly `k` set bits (as counted by the platform’s popcount on an `int`), exactly one output line is produced describing `p` and its set bit positions.
