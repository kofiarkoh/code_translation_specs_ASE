1. Functional Description  
Reads a planning horizon length, per-category penalty weights, and per-day per-category satisfaction values. Produces a schedule assigning one category to each day. The produced schedule is initialized by choosing, for each day independently, the category with the highest satisfaction for that day, then iteratively attempts to improve the overall objective score by randomly swapping two days’ assigned categories and keeping the swap only if it strictly increases the objective score. The program outputs the final schedule after a fixed time-bounded improvement phase.

2. Inputs  
- An integer number of days.  
- A fixed-size set of penalty weights, one per category (26 categories).  
- A matrix of satisfaction values: for each day and each category, an integer satisfaction value.

3. Outputs  
- A sequence of integers of length equal to the number of days, where each integer denotes the chosen category for that day (categories are numbered 1 through 26).

4. Preconditions  
- The number of days is positive.  
- All required penalty weights and satisfaction values are present in the input.  
- Satisfaction values are such that, for every day, at least one category has a strictly positive satisfaction value; otherwise the initial schedule selection is not well-defined.  
- The environment provides a monotonic notion of elapsed processor time sufficient to bound the improvement phase.

5. Postconditions  
- The output schedule assigns exactly one category to each day, and each assigned category is within 1..26.  
- Let `Score(schedule)` be defined as: for each day in order, add that day’s satisfaction for the scheduled category; then subtract, for every category, its penalty weight multiplied by the number of days since that category was last scheduled (with “last scheduled” initially treated as day 0). The program guarantees that the final schedule’s score is greater than or equal to the score of the initial schedule constructed by per-day maximum satisfaction selection.  
- The final schedule is the result of applying zero or more accepted swaps, where each accepted swap strictly increases the score relative to the immediately preceding schedule.

6. Invariants  
- Throughout execution after initialization, the schedule remains a length‑D assignment with values restricted to 1..26.  
- The tracked “best-so-far” score value is non-decreasing over time.  
- Any schedule change that is retained corresponds to a strict improvement in the objective score; non-improving attempted swaps do not change the schedule.

7. Error Handling / Exceptional Behavior  
- No explicit handling is provided for invalid, missing, or out-of-range input; behavior is undefined if preconditions are violated.  
- If any day has no strictly positive satisfaction value across categories, the initial schedule selection is undefined and subsequent behavior is undefined.  
- If the number of days is so large that required memory cannot be allocated on the stack, behavior is undefined.  
- The improvement phase is time-bounded but not iteration-bounded; if time measurement behaves unexpectedly, runtime may deviate from the intended bound.

8. State Transitions (if applicable)

- Initialization transitions state from “no schedule” to the initial schedule and its computed score.

int max(int D, int s[][type+1]) // D日目の満足度が一番高いタイプを返す
{
    int i;
    int max_score = 0, max_type;
    
    for(i=1; i<type+1 ;i++){
        if(s[D][i] > max_score){
            max_score = s[D][i];
            max_type = i;
        }
    }
    return max_type;
}

int score_calc(int D, int s[][type+1], int schedul[], int c[type+1], int last[type+1])
{
    int i,j;
    int score = 0;
    
    for(i=1; i<D+1; i++){
        score += s[i][schedul[i]];
        last[schedul[i]] = i;
        for(j=1; j<type+1; j++){
            score -= c[j] * (i-last[j]);
        }
    }
    
    return score;
}

void swap(int D, int s[][type+1], int schedul[], int c[type+1], int last[type+1], int *ini)
{
    int i;
    int a, b, tmp, imp = 0;
    
    a = rand()%D+1;
    b = rand()%D+1;
    tmp = schedul[a];
    schedul[a] = schedul[b];
    schedul[b] = tmp;
    
    for(i=1; i<type+1; i++){
        last[i] = 0;
    }
    imp = score_calc(D, s, schedul, c, last);
    
    if(imp > *ini){
        *ini = imp;
        
    }else{
        schedul[b] = schedul[a];
        schedul[a] = tmp;
    }
}
