1. Functional Description  
For each dataset, determines whether there exists a smallest-size set of distinct people (size 1 through 5) such that:  
- Every group contains at least one person from the set, and  
- Considering only the chosen people, the groups form a single connected component under the relation “two chosen people are connected if they appear together in at least one group (possibly via a chain of such co-appearances).”  
If such a set exists, outputs its size and the names in that set; otherwise outputs that no solution exists.

2. Inputs  
For each dataset:  
- An integer count of candidate people.  
- An integer count of groups.  
- A list of candidate people names (strings). Duplicate names may appear.  
- For each group: an integer count of listed names followed by that many names (strings).  
Datasets repeat until a terminating dataset with a non-positive candidate count is encountered.

3. Outputs  
Per dataset:  
- If no valid set of size 1–5 exists: a single line indicating impossibility.  
- Otherwise:  
  - A line containing the size of the selected set.  
  - Then one line per selected person, printing their name.  
Between consecutive datasets’ outputs, a blank line is emitted.

4. Preconditions  
- The number of distinct candidate people is at most 20.  
- The number of groups is at most 22.  
- Each name length fits within the fixed internal storage limits.  
- Each group lists at most 20 names.  
- All names referenced in groups are assumed to be among the candidate people; otherwise behavior is not reliably defined by the program’s contract.

5. Postconditions  
For each dataset:  
- If a solution is printed, the printed set satisfies:  
  - Coverage: every group contains at least one printed person.  
  - Connectivity: all printed people are mutually connected via co-membership in groups when restricted to printed people.  
  - Minimality by size: no solution exists with fewer printed people (within sizes 1–5).  
- If “Impossible” is printed, then no set of size 1–5 satisfies both coverage and connectivity.

6. Invariants  
- Candidate people are treated as a set of unique names; repeated candidate names do not create additional distinct people.  
- Group membership is evaluated only with respect to the unique candidate people.  
- The selected set size, if any, is always between 1 and 5 inclusive.

7. Error Handling / Exceptional Behavior  
- No explicit recovery for malformed input, out-of-range sizes, overly long names, or group names not present among candidates. Under such conditions, results are unspecified.  
- If the number of distinct candidates exceeds 20, correctness is not guaranteed.

8. State Transitions (if applicable)  
- The program processes datasets sequentially. For each new dataset, all accumulated state from the previous dataset is discarded and recomputed from the new input.

9. Non-functional Constraints (if inferable)  
- Searches only for solutions of size up to 5; larger solutions are intentionally not considered.  
- Runtime is bounded by enumerating combinations of up to 5 out of at most 20 candidates, multiplied by the number of groups, which is feasible for the stated limits.

#define HASHSIZ 61
typedef struct { char *s; int id; } HASH;
HASH hash[HASHSIZ+2], *hashend = hash+HASHSIZ;			// Hash table

int lookup(char *s)
{
	int w = strlen(s);
	int i = (101 * *s + 103 * *(s+w-1) + 107 * w) % HASHSIZ;
	HASH *tp = hash + i;

	while (tp->s != NULL) {
		if (!strcmp(tp->s, s)) return tp->id;
		if (++tp == hashend) tp = hash;
	}
	return -1;
}

int insert(char *s, int id)
{
	int w = strlen(s);
	int i = (101 * *s + 103 * *(s+w-1) + 107 * w) % HASHSIZ;
	HASH *tp = hash + i;

	while (tp->s != NULL) {
		if (!strcmp(tp->s, s)) return 0;
		if (++tp == hashend) tp = hash;
	}
	tp->s = s, tp->id = id;
	return 1;
}

int f[22], m;
char name[31][22]; int sz;

int check(int pat)
{
	int i, j, k, s;
	int g[6];

	for (i = 0; i < m; i++) {
		if (!(f[i] & pat)) return 0;
	}

	for (s = 0, k = pat, i = 0; k; i++, k >>= 1) if (k & 1) g[s++] = 1 << i;  
	for (i = 0; i < m; i++) {
		for (j = 0; j < s; j++) {
			if (g[j] & f[i]) g[j] |= f[i] & pat;
		}
	}
	for (k = g[0], i = 1; i < s; i++) if (g[i] & k) k |= g[i]; 
	return k == pat;
}
