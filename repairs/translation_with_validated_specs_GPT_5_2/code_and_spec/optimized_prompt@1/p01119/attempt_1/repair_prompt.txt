1. Functional Description  
For each dataset, the program evaluates a two-pan balance scale problem with a fixed multiset of available weights. Each available weight may be placed on the same pan as the object, on the opposite pan, or not used.  

- If every requested target weight can be balanced exactly using the available weights, the program outputs `0`.  
- Otherwise, consider only those targets that are **not** exactly balanceable. The program finds the **smallest non-negative integer** `d` such that **each** of these unbalanceable targets can be made consistent with the scale outcomes by allowing an absolute deviation of exactly `d`: for every such target `u`, there exists some achievable signed net outcome `q` (depending on `u`) with `|u − q| = d`.  
- If no single common `d` satisfies this condition for all unbalanceable targets, the program outputs `-1`.

2. Inputs  
The input consists of multiple datasets, processed sequentially until termination. For each dataset:  
- An integer `n`: number of target weights.  
- An integer `m`: number of available weights.  
- `n` non-negative integers: the target weights.  
- `m` non-negative integers: the available weights.  
Input terminates when `n` is zero (in that case, the dataset is not processed).

3. Outputs  
For each dataset, output a single integer on its own line:  
- `0` if all targets are exactly balanceable; otherwise the minimal common deviation `d` as defined above; or `-1` if no such `d` exists.

4. Preconditions / Assumptions  
- All inputs are non-negative integers and each dataset is well-formed with exactly `n + m` subsequent integers after `n` and `m`.

5. Semantics and Edge Cases  
- Let `Q` be the multiset of all signed net outcomes obtainable from the available weights by assigning each weight a coefficient in `{−1, 0, +1}` and summing. (This includes `0` and may include negative values.)  
- A target `t` is considered **exactly balanceable** if there exists some `q ∈ Q` with `q = t` and `t > 0`. (Targets equal to `0` are not treated as exactly balanceable by this program’s check.)  
- If at least one target is not exactly balanceable, the program computes the set of candidate deviations `d` for each such target as `{ |t − q| : q ∈ Q }` and outputs the minimum `d` that lies in the intersection of these sets across all unbalanceable targets.  
- If there are no unbalanceable targets, the output is `0`. If there are unbalanceable targets but the intersection is empty, the output is `-1`.

		if (n < 0) pc('-'), n = -n;

		while (i--) pc(b[i]);
		
	}
	pc('\n');
}

#define HASHSIZ 1000003
typedef struct { int n, b; } HA;
int ha1[HASHSIZ+5], *hae1 = ha1 + HASHSIZ;
HA  ha2[HASHSIZ+5], *hae2 = ha2 + HASHSIZ;

int lookup1(int n) {
	int *p = ha1 + n % HASHSIZ;
	while (*p) {
		if (*p == n) return 1;
		if (++p == hae1) p = ha1;
	}
	return 0;
}

void insert1(int n) {
	int *p = ha1 + n % HASHSIZ;
	while (*p) {
		if (*p == n) return;
		if (++p == hae1) p = ha1;
	}
	*p = n;
}

int lookup2(int n, int b) {
	HA *p = ha2 + n % HASHSIZ;
	while (p->n) {
		if (p->n == n) {
			if (p->b == b-1) { p->b = b; return 1; }
			return 0;
		}
		if (++p == ha2) p = ha2;
	}
	return 0;
}
