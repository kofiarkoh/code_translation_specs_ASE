1. Functional Description  
Computes, for each problem instance, the minimum achievable total cost of assigning all demand points to a chosen subset of facilities subject to facility capacity limits. The total cost is the sum of:  
- a fixed opening cost for each chosen facility, and  
- an assignment cost for each demand point to a facility, where the assignment cost is based on Manhattan distance with a nonnegative offset determined by an optimized shared parameter.  
Outputs the minimum total cost over all facility subsets for which a feasible assignment exists.

2. Inputs  
For each instance (repeated until termination):  
- An integer count of demand points.  
- An integer count of facilities and an integer scaling factor.  
- For each demand point: two integers representing its coordinates.  
- For each facility: two integers representing its coordinates, an integer capacity, and an integer fixed opening cost.

3. Outputs  
For each instance:  
- One integer: the minimum total cost among all feasible choices of facility subset and assignments.

4. Preconditions  
- The input stream contains complete instances in the expected order and numeric form.  
- The number of demand points is within the supported fixed limits (at most 101).  
- The number of facilities is within the supported fixed limits (at most 5).  
- Facility capacities and the scaling factor are such that intermediate arithmetic fits within signed 32-bit integer range (assumption; not checked).  
- Termination is indicated by a demand-point count of zero.

5. Postconditions  
For each non-terminating instance, the program outputs a value equal to:  
- the minimum, over all subsets of facilities, of  
  - (sum of fixed opening costs of facilities in the subset)  
  + (minimum feasible total assignment cost of assigning every demand point to exactly one facility in the subset, respecting facility capacities)  
  + (an additional term proportional to the scaling factor, the number of chosen facilities, and an optimized integer offset parameter),  
where each demand-to-facility assignment cost equals the nonnegative part of (Manhattan distance between the demand point and facility minus the chosen offset parameter).  
If a subset cannot support assigning all demand points within capacities, that subset is excluded from the minimum.

6. Invariants  
- Each demand point is assigned to at most one facility, and in the computed optimum it is assigned to exactly one facility when a feasible solution exists for the chosen subset.  
- For any chosen facility, the number of assigned demand points does not exceed its capacity.  
- Assignment costs are always nonnegative.  
- The reported answer is the minimum over all facility subsets that admit a feasible full assignment.

7. Error Handling / Exceptional Behavior  
- If, for a given facility subset, it is impossible to assign all demand points within the subset’s capacities, that subset is skipped and does not contribute to the final minimum.  
- No explicit handling is provided for malformed input, out-of-range sizes, or integer overflow; behavior is undefined in those cases.  
- If no subset is feasible, the program will still output a numeric value derived from its internal initialization (assumption: problem instances guarantee at least one feasible subset).

8. State Transitions (if applicable)  
- Processes instances sequentially until a terminating instance is read.  
- For each instance, iterates over all facility subsets; for each subset, evaluates feasibility and cost and updates the current best answer.  
- After outputting the answer for an instance, all per-instance state is effectively discarded and recomputed for the next instance.

#define QMAX 3005
typedef struct { int t, s; } QUE;
QUE que[QMAX]; int qsize;

#define PARENT(i) ((i)>>1)
#define LEFT(i)   ((i)<<1)
#define RIGHT(i)  (((i)<<1)+1)

void min_heapify(int i)
{
	int l, r, min;
	QUE qt;

	l = LEFT(i), r = RIGHT(i);
	if (l < qsize && que[l].t < que[i].t) min = l; else min = i;
	if (r < qsize && que[r].t < que[min].t) min = r;
	if (min != i) {
		qt = que[i], que[i] = que[min], que[min] = qt;
		min_heapify(min);
	}
}

void deq()
{
	que[0] = que[--qsize];
	min_heapify(0);
}

void enq(int s, int t)
{
	int i, min;
	QUE qt;

	i = qsize++;
	que[i].s = s, que[i].t = t;
	while (i > 0 && que[min = PARENT(i)].t > que[i].t) {
		qt = que[i], que[i] = que[min], que[min] = qt;
		i = min;
	}
}

#define INF 0x10101010
#define MAX 110
typedef struct { int to, rev; int cap, cost; } EDGE;
EDGE edge[MAX][MAX]; int hi[MAX];
int V;				// 頂点数
int potential[MAX], dist[MAX], prevv[MAX], preve[MAX];

void add_edge(int from, int to, int cap, int cost)
{
	int f, t;
	EDGE *ep;

	f = hi[from]++, t = hi[to]++;
	ep = &edge[from][f], ep->to = to, ep->cap = cap, ep->cost = cost, ep->rev = t; 
	ep = &edge[to][t], ep->to = from, ep->cap = 0, ep->cost = -cost, ep->rev = f;
}

int minCostFlow(int S, int T, int F)
{
	int i, v, nv, t, nt, ret;
	EDGE *ep;

	ret = 0;
	memset(potential, 0, V << 2);
  
	while (F > 0) {
		memset(dist, INF, V << 2);
		qsize = 0;
		enq(S, 0), dist[S] = 0;
		while (qsize) {
			v = que[0].s, t = que[0].t, deq();
			if (dist[v] < t) continue;
			for (i = 0; i < hi[v]; i++) {
				ep = &edge[v][i];
				if (ep->cap <= 0) continue;
				nv = ep->to;
				nt = t + ep->cost - potential[nv] + potential[v];
				if(dist[nv] > nt) {
					dist[nv] = nt;
					prevv[nv] = v, preve[nv] = i;
					enq(nv, nt);
				}
			}
		}
		if (dist[T] == INF) return -1;
		for (v = 0; v < V; v++) potential[v] += dist[v];

		t = F;
		for (v = T; v != S; v = prevv[v]) {
			ep = &edge[prevv[v]][preve[v]];
			if (t > ep->cap) t = ep->cap;
		}
		F -= t;

		ret += t * potential[T];
		for (v = T; v != S; v = prevv[v]) {
			ep = &edge[prevv[v]][preve[v]];
			ep->cap -= t;
			edge[v][ep->rev].cap += t;
		}
	}
	return ret;
}
