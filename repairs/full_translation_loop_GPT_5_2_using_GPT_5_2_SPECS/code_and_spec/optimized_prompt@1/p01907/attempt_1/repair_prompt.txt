1. Functional Description
Computes a scalar value derived from a weighted, undirected tree rooted at node 1. Each node contributes its incident edge weight from its parent (root contributes 0) scaled by a depth-dependent factor. The program outputs the product of (a) the sum of scaled parent-edge weights over all nodes and (b) the sum of depth-dependent scaling factors over all nodes.

2. Inputs
- A real number representing a depth scaling base.
- An integer representing the number of nodes.
- Exactly (number of nodes − 1) undirected edges, each given by:
  - Two integers denoting endpoint node indices.
  - An integer denoting the edge weight.

3. Outputs
- Writes one real number to standard output:  
  (Σ over all nodes of (parent-edge-weight(node) × scaling(depth(node)))) × (Σ over all nodes of scaling(depth(node))).

4. Preconditions
- The node count is at least 1.
- Node indices in edges are within the range [1, node count].
- The edges form a connected, acyclic undirected graph (a tree) so that every node is reachable from node 1 and has a well-defined depth and parent (except the root).
- The input is well-formed and provides all required values.
- The depth scaling base is such that repeated multiplication up to the maximum depth does not cause undefined numeric behavior in the execution environment (e.g., catastrophic overflow/NaN), if meaningful output is expected.

5. Postconditions
- For every node reachable from node 1 (under the tree precondition, all nodes):
  - A unique depth is established as the number of edges on the path from node 1.
  - A parent-edge weight is established as the weight of the edge connecting the node to its predecessor on that path (root’s parent-edge weight is 0).
- The printed value equals:
  - Let s(d) = (depth scaling base)^(d).
  - Let A = Σ_{v=1..N} (parent-edge-weight(v) × s(depth(v))).
  - Let B = Σ_{v=1..N} s(depth(v)).
  - Output is A × B.

6. Invariants
- Depth values are non-negative integers.
- The root node (node 1) has depth 0 and parent-edge weight 0.
- Under the tree precondition, each non-root node has exactly one parent-edge weight corresponding to the unique path from the root.

7. Error Handling / Exceptional Behavior

- If the input violates preconditions (e.g., disconnected graph, cycles, invalid indices, insufficient data), the output is not defined by this specification.
- If memory allocation fails or numeric overflow/NaN occurs, behavior is not defined by this specification.

	int n = 0, c = gc();
	do n = 10 * n + (c & 0xf), c = gc(); while (c >= '0');
	return n;

double dbl()    // 実数の入力
{
	int minus = 0;
	double x, y;
	int n = 0, c = gc();
	if (c == '-') minus = 1, c = gc();
	do n = 10 * n + (c & 0xf), c = gc(); while (c >= '0');

	if (c == '.') {
		x = 0;
		y = 1, c = gc();
		do y *= 0.1, x += y * (c & 0xf), c = gc(); while (c >= '0');
		x += n;
	}
	else x = n;
	if (minus) x = -x;
	return x;
}

#define MAX 100005
typedef struct { int to, c; } T;
int hi[MAX]; T *t[100005]; int N;
int cost[MAX], depth[MAX], depth_max;
double p[MAX], P;

typedef struct { int n, d; } Q;
Q q[MAX]; int top;
char vis[MAX];

void dfs()
{
	int i, node, d, to;

	q[0].n = 1, q[0].d = 0, top = 1;
	while (top) {
		node = q[--top].n, d = q[top].d;

		if (vis[node]) continue;
		vis[node] = 1;

		depth[node] = d;
		if (d > depth_max) depth_max = d;
		for (i = 0; i < hi[node]; i++) {
			to = t[node][i].to;
			if (!vis[to]) {
				cost[to] = t[node][i].c;
				q[top].n = to, q[top++].d = d + 1;
			}
		}
	}
}
