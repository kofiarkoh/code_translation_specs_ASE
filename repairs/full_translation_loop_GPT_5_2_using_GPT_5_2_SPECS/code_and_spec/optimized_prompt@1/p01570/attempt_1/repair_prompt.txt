1. Functional Description  
Computes, for each rooted tree in a forest, a value derived from node weights and parent-child relationships, then outputs the sum of these values over all roots. For each node, the computed value depends on the total weights of its descendant subtrees and is minimized by ordering child subtrees by non-increasing total subtree weight.

2. Inputs  
- Reads an integer `N`: the number of nodes.  
- Reads `N` pairs of integers:  
  - A node weight (integer).

3. Outputs  
- Writes a single integer value to standard output: the sum, over all roots, of the computed per-root value described in the Functional Description.

4. Preconditions  
- `N` is non-negative and does not exceed the program’s fixed maximum capacity (1,000,002).  
- Each non-root parent reference is a valid node index in `[0, N-1]`.  
- The parent references define a forest (i.e., no cycles); otherwise the computation is not guaranteed to terminate or be meaningful.  
- Sufficient memory is available for all required internal storage.  
- The final result fits within a signed 64-bit integer.

5. Postconditions  
- For every node `u`, a subtree total weight `S(u)` is defined as the node’s weight plus the total weights of all descendants.  
- For every node `u`, a value `D(u)` is defined as:  
  - `D(u) = sum over children v of D(v) + sum over children v of S(v) * rank(v)`

- The program outputs `sum of D(r)` over all roots `r`.

#define MAX 1000002
int  N;
int  m[MAX];
int  *base, bsz;
int  hi[MAX], *to[MAX];
int  que[MAX], top;
int  a[MAX];
long long s[MAX], b[MAX], dp[MAX];

int cmp(long long *a, long long *b)
{
	if (*a == *b) return 0;
	if (*a < *b) return 1;
	return -1;
}

void calc(int u)
{
	int i, v, sz;

	sz = 0, s[u] = m[u], dp[u] = 0;
	for (i = 0; i < hi[u]; i++) {
		v = to[u][i];
		b[sz++] = s[v], s[u] += s[v], dp[u] += dp[v];
	}
	qsort(b, sz, sizeof(long long), cmp);
	for (i = 0; i < sz; i++) dp[u] += b[i]*i;
}
