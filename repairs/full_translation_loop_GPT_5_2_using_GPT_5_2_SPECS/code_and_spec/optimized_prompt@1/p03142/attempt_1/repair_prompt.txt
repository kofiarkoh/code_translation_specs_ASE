1. Functional Description  
Reads a directed graph over vertices labeled 1 through N with exactly (N−1+M) directed edges. It repeatedly identifies vertices with zero current incoming-edge count, conceptually removes their outgoing edges, and records for each vertex the most recently processed predecessor that caused its incoming-edge count to become zero. Finally, it outputs this recorded predecessor value for every vertex.

2. Inputs  
- Two integers:  
  - N: number of vertices.  
  - M: an additional edge-count parameter used only to determine how many edges follow.  
- A sequence of (N−1+M) directed edges, each given as two integers (source, destination), with vertex labels intended to be in the range 1..N.

3. Outputs  
- Writes N lines to standard output.  
- Line i (for vertex i) contains an integer value representing the recorded predecessor that caused vertex i to become newly zero-incoming during the process, or 0 if no such predecessor was recorded.

4. Preconditions  
- The first two input integers are present and parseable.  
- Exactly (N−1+M) edge pairs are present and parseable.  
- All vertex labels appearing in edges are within 1..N.  
- Sufficient memory is available to store all edges and auxiliary data.

5. Postconditions  
- For every vertex v in 1..N, an output value is produced.  
- If vertex v ever transitions from positive incoming-edge count to zero due to the removal of edges from some processed vertex u, then the output for v equals u corresponding to the transition that first made v reach zero.  
- If vertex v never reaches zero incoming-edge count during the process (including the case where it starts with nonzero incoming count and never becomes zero), then the output for v is 0.  
- Vertices that start with zero incoming-edge count are eligible for processing, but their output remains 0 unless later set by the rule above (which requires them to have had positive incoming count immediately before becoming zero).

6. Invariants  
- Incoming-edge counts maintained during processing never increase.  
- A vertex is processed only when its current incoming-edge count is zero.  
- Once a vertex’s output value becomes nonzero, it is not changed thereafter.  
- Each directed edge contributes at most once to decreasing the incoming-edge count of its destination during the process.

7. Error Handling / Exceptional Behavior  
- If the initial N and M cannot be read, the program terminates with a nonzero exit status.  
- If any required edge pair cannot be read, the program terminates with a nonzero exit status.

int N, M;
int ec[114514];
int* es[114514];

void ae(int f, int t) {
	es[f] = realloc(es[f], sizeof(*es[f]) * (ec[f] + 1));
	if (es[f] == NULL) exit(2);
	es[f][ec[f]++] = t;
}

int sansyo[114514];

int next_count[2];
int next_buffer[2][114514];

int answer[114514];

int main(void) {
	int i;
	int phase;
	if (scanf("%d%d", &N, &M) != 2) return 1;
	for (i = 1; i <= N - 1 + M; i++) {
		int A, B;
		if (scanf("%d%d", &A, &B) != 2) return 1;
		ae(A, B);
		sansyo[B]++;
	}
	next_count[0] = 0;
	for (i = 1; i <= N; i++) {
		if (sansyo[i] == 0) next_buffer[0][next_count[0]++] = i;
	}

	phase = 0;
	while (next_count[phase] > 0) {
		next_count[1 - phase] = 0;
		for (i = 0; i < next_count[phase]; i++) {
			int target = next_buffer[phase][i];

	}

}
