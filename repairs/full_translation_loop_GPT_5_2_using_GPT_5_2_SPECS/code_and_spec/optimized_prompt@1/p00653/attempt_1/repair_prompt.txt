1. Functional Description
Processes one or more datasets consisting of a 2D grid of integers and a set of axis-aligned rectangular range queries. For each query, outputs the minimum value contained in the specified rectangle of the grid.

2. Inputs
- Repeated datasets read from standard input.
- For each dataset:
  - Three integers: number of rows, number of columns, and number of queries.
  - A sequence of row×column integers representing the grid values.
  - For each query: four integers representing two corners of a rectangle (row/column coordinates).

3. Outputs
- For each query in each dataset, writes one integer line to standard output: the minimum grid value within the queried rectangle.

4. Preconditions

- Grid coordinates in each query are assumed to be within the valid grid index ranges.

- For every query, the printed value equals the minimum of all grid cell values whose row index is between the two query row indices (inclusive) and whose column index is between the two query column indices (inclusive).
