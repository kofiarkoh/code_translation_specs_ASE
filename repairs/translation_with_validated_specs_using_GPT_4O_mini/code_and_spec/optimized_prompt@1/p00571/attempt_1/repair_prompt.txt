## 1. Functional Description
The code processes a list of pairs of integers, where each pair consists of a long integer and a regular integer. It computes a maximum value based on the differences between the cumulative sums of the regular integers and the minimum long integer encountered during the processing of the pairs at each step.

## 2. Inputs
- An integer \( N \) representing the number of pairs.
- \( N \) pairs of integers, where each pair consists of:
  - A long integer.
  - A regular integer.

## 3. Outputs

## 4. Preconditions

- Each long integer and regular integer in the pairs must be valid integers within the range of their respective types.

## 5. Postconditions
- The output is the maximum value derived from the differences between the cumulative sums of the regular integers and the minimum long integer encountered up to each point in the processing.

## 6. Invariants
- The cumulative sum of the regular integers is maintained throughout the processing.
- The minimum value of the long integers is updated as new pairs are processed.

## 7. Error Handling / Exceptional Behavior

## 8. State Transitions
- The state transitions occur as each pair is processed, updating the cumulative sum of regular integers and the minimum long integer accordingly. The maximum value is recalculated at each step based on the current cumulative sum and the minimum long integer encountered up to that point.

## 9. Non-functional Constraints

int in()	/* 整数値の入力 */
{
	int n = 0, c = getchar_unlocked();
	do n = 10*n + (c & 0xf), c = getchar_unlocked(); while (c >= '0');
	return n;
}

long long big()		/* long long 整数値の入力 */
{
	long long n = 0, c = getchar_unlocked();
	do n = 10*n + (c & 0xf), c = getchar_unlocked(); while (c >= '0');
	return n;
}

#define INF 0x1010101010101010LL
typedef struct { long long a; int b; } T;
T tbl[500002];
long long s[500002];

int cmp(T *a, T *b) {
	if (a->a == b->a) return a->b - b->b;
	if (a->a < b->a) return -1;
	return 1;
}

int main()
{
	int N, i;
	long long t, min, max;

	N = in();
	for (i = 1; i <= N; i++) tbl[i].a = big(), tbl[i].b = in();
	qsort(tbl+1, N, sizeof(T), cmp);

	min = INF, max = -INF;
	for (i = 1; i <= N; i++) {
		t = s[i-1] - tbl[i].a;
		if (t < min) min = t;
		s[i] = s[i-1] + tbl[i].b;
		t = s[i] - tbl[i].a - min;
		if (t > max) max = t;
	}
	printf("%lld\n", max);
	return 0;
}
