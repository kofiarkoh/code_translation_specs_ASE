# Revised Specification

## 1. Functional Description
The program calculates a total movement cost based on the distance between a series of points, while considering boundary constraints that may increase or decrease the cost. The result is the minimum cost of movement across the specified points, determined by comparing direct distances and adjusted costs due to boundary violations.

## 2. Inputs
- An integer \( N \) representing the number of points (must be positive).
- Four integers \( A, B, C, D \) defining the boundary constraints for the coordinates.
- Two arrays of integers \( X \) and \( Y \) of size \( N+1 \) representing the coordinates of the points.

## 3. Outputs
- An integer representing the minimum cost of movement between the points, calculated based on both direct distances and boundary adjustments.

## 4. Preconditions
- \( N \) must be a positive integer.
- The input for \( A, B, C, D \) must consist of exactly four integers.
- The coordinates \( X[i] \) and \( Y[i] \) must be provided for all \( i \) from 0 to \( N \).

## 5. Postconditions
- The output integer reflects the minimum cost calculated based on the provided points and boundary constraints, incorporating both direct distances and adjustments for boundary violations.

## 6. Invariants
- The values of \( A, B, C, D \) remain constant throughout the execution of the program after being read.
- The arrays \( X \) and \( Y \) are populated with valid integer coordinates before cost calculations.

## 7. Error Handling / Exceptional Behavior

- The program returns an error code if the input for any coordinate pair is invalid (not two integers).

## 8. State Transitions
- The program transitions from reading input to processing the coordinates and calculating costs, ultimately transitioning to outputting the result.

## 9. Cost Calculation Logic
- The cost between two points \( (X[i-1], Y[i-1]) \) and \( (X[i], Y[i]) \) is determined by comparing the direct distance to a potentially adjusted cost that accounts for boundary constraints.
- The `nigeru` function computes the cost based on the following rules:
  - If the x-coordinate \( x \) is less than \( A \), the cost increases by \( A - x \).
  - If the x-coordinate \( x \) exceeds \( C \), the cost increases by \( x - C \).
  - If the y-coordinate \( y \) is less than \( B \), the cost increases by \( B - y \).
  - If the y-coordinate \( y \) exceeds \( D \), the cost increases by \( y - D \).
  - If the point is the source (indicated by the `isSrc` flag being true) and the calculated cost is greater than zero, the cost is decremented by one.
- The minimum cost for moving between two points is determined by selecting the lesser of the direct distance and the adjusted cost calculated using the `nigeru` function for both points involved in the transition.

#include <stdio.h>
#include <stdlib.h>

int A, B, C, D;

int nigeru(int x, int y, int isSrc) {
	int cost = 0;
	if (x < A) cost += A - x;
	if (C < x) cost += x - C;
	if (y < B) cost += B - y;
	if (D < y) cost += y - D;
	if (isSrc && cost > 0) cost--;
	return cost;
}
