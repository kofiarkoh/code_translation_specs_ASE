# Revised Specification

## 1. Functional Description
The program processes multiple sets of team data, calculating scores based on wins, losses, and draws, and outputs the teams sorted by their scores in descending order. Each set of team data is processed independently until a termination condition is met.

## 2. Inputs
- An integer `n` representing the number of teams. Input of `0` terminates the program.
- For each team, a string representing the team name, followed by three integers representing the number of wins, losses, and draws.

## 3. Outputs
- For each set of teams, the program outputs the team names and their corresponding scores, formatted as "name,score", sorted in descending order of scores.
- A blank line is printed between the outputs of different sets of teams, except after the last set of teams.

## 4. Preconditions
- The input must consist of valid integers and strings as specified.
- The number of teams `n` must be between 1 and 10 for valid processing.

## 5. Postconditions
- The output will display the teams sorted by their calculated scores after processing each set of input until a terminating condition is met.

## 6. Invariants
- The score for each team is consistently calculated as `wins * 3 + draws`.
- The sorting of teams is maintained throughout the processing of each input set.

## 7. Error Handling / Exceptional Behavior
- If `n` is less than 0 or greater than 10, the behavior is undefined as the program does not handle such cases.
- The program does not handle malformed input gracefully; it assumes all input is correctly formatted.

## 8. State Transitions
- The program transitions between states of input collection, score calculation, sorting, and output generation for each set of teams until termination.

## 9. Non-functional Constraints
- The program must handle up to 10 teams efficiently within a single execution cycle.
- The output must be generated in a timely manner after processing each input set.

#include <string.h>

typedef struct {
	char name[30];
	int score;
} TEAM;
	
	
int main(void)
{
	int n, i, j, f = 0;
	int win, lose, draw;
	TEAM team[10], temp;
	

	while (1){
		scanf("%d", &n);
		
		if (n == 0){
			break;
		}
		
		for (i = 0; i < n; i++){
			scanf("%s %d %d %d", team[i].name, &win, &lose, &draw);
			team[i].score = win * 3 + draw;
		}
		
		for (i = 0; i < n; i++){
			for (j = n - 1; j > i; j--){
				if (team[j].score > team[j-1].score){
					strcpy(temp.name, team[j-1].name);
					temp.score = team[j-1].score;
					
					strcpy(team[j-1].name, team[j].name);
					team[j-1].score = team[j].score;
					
					strcpy(team[j].name, temp.name);
					team[j].score = temp.score;
				}
			}
		}
		if (f == 1){
			puts("");
		}
		for (i = 0; i < n; i++){
