# Revised Specification

## 1. Functional Description
The code implements Dijkstra's algorithm to compute the shortest path costs from a specified source node to all other nodes in a directed graph represented by a set of nodes, each with associated edges and costs. It reads the graph structure from input, processes it, and outputs the shortest path costs.

## 2. Inputs
- An integer representing the number of nodes in the graph.
- For each node:
  - An integer representing the node index.
  - An integer representing the number of edges connected to the node.
  - For each edge:
    - An integer representing the destination node index.
    - An integer representing the cost of the edge.
- The source node index must be specified as the first node in the input.

## 3. Outputs
- For each node, the output consists of:
  - The node index.
  - The shortest path cost from the specified source node to that node.

## 4. Preconditions
- The input must provide a valid integer for the number of nodes.
- Each node index must be within the range of valid node indices (0 to n-1).
- The number of edges for each node must be a non-negative integer.
- The destination node indices must be valid and within the range of valid node indices.
- The first node specified in the input is treated as the source node.

## 5. Postconditions
- Each node's cost is updated to reflect the shortest path cost from the specified source node.
- If a node is unreachable from the source node, its cost remains as initialized (-1).

## 6. Invariants
- The cost of the source node is always initialized to 0.
- Nodes that have been visited will not be processed again.
- The algorithm guarantees that once a node's cost is finalized, it will not change.

## 7. Error Handling / Exceptional Behavior
- If the input for the number of nodes is invalid (e.g., negative), the behavior is undefined.
- If the input for edges or costs is invalid, the behavior is also undefined.
- The algorithm does not handle cycles or negative edge costs explicitly.
- The algorithm does not guarantee that all nodes will be reachable from the source node, especially in cases where the graph is not fully connected.

## 8. State Transitions
- The state transitions occur as nodes are marked as visited and their costs are updated based on the edges processed.

## 9. Non-functional Constraints
- The algorithm operates in O(n^2) time complexity in the worst case, where n is the number of nodes, due to the lack of a priority queue.

int get_uint() {
    int n = 0;
    int c = getchar_unlocked();
    if(c < 48 || 57 < c) return c;
    while(47 < c && c < 58) n = 10 * n + (c & 0xf), c = getchar_unlocked();

}
void put_uint(int n) {
    if(!n) {
        putchar_unlocked('0');
        return;
    }
    char buf[11];
    int i = 0;
    while(n) buf[i++] = (char)(n % 10 + '0'), n /= 10;
    while(i--)putchar_unlocked(buf[i]);
}

typedef struct Node {
    int edge_to[100];
    int edge_cost[100];
    int edge_size;
    int cost;
    int visited;
} Node;
void dijkstra_noheap(Node *node, const int n) {
    for(int i = 0; i < n; ++i) node[i].cost = -1, node[i].visited = 0;
    node[0].cost = 0;
    while(1) {
        Node *next = NULL;
        for(Node *it = node; it != node + n; ++it) {
            if(it->visited || it->cost < 0) continue;
            if(next == NULL || it->cost < next->cost) next = it;
        }
        if(next == NULL) break;
        next->visited = 1;
        Node u = *next;
        for(int i = 0; i < u.edge_size; ++i) {
            int to = u.edge_to[i];
            int cost = u.cost + u.edge_cost[i];
            if(node[to].cost < 0 || cost < node[to].cost) node[to].cost = cost;
        }
    }
}
